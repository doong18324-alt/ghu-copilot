# GHU 코파일럿

광주보건대학교 구성원(직원·교수·학생)을 위한 AI 업무·학습 플랫폼 시제품입니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `src/` | 화면(React). GitHub Pages에 올라가는 부분 |
| `server/` | AI 중계 서버(Node.js, 추가 패키지 없음). API 키를 보관하고 각 AI 회사에 요청을 전달 |
| `.github/workflows/deploy.yml` | main 브랜치에 올리면 GitHub Pages에 자동 배포 |
| `.env.example` | 설정값 견본. 복사해서 `.env`로 만들어 사용 |

## 두 가지 모드

- **시연 모드**: `VITE_API_BASE`가 비어 있으면 AI 응답은 예시 문구로 나옵니다. 서버 없이 화면만으로 작동합니다.
- **실연결 모드**: `VITE_API_BASE`에 중계 서버 주소를 넣으면 실제 AI가 답합니다.

규정 조항 검색, 공문 발송 전 점검(날짜·맞춤법·개인정보), 실습 일지 식별정보 가림, 회의록 할 일 추출, 업무 프로젝트·할 일·스터디룸 예약은 시연 모드에서도 실제로 작동합니다(저장은 브라우저에만 됨).

## 내 컴퓨터에서 실행

```
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다.

실제 AI까지 시험하려면 `.env.example`을 `.env`로 복사해 API 키와 모델 이름을 넣고, `VITE_API_BASE=http://localhost:8787`로 설정한 뒤 터미널을 하나 더 열어 실행합니다.

```
npm run server
```

## 실제 운영 전에 꼭 할 일

1. 학교 통합인증(SSO) 연결: `server/auth.js`의 `sso` 부분 구현
2. 중계 서버를 학교 서버나 클라우드에 설치 (GitHub Pages에는 서버를 올릴 수 없음)
3. 대화 기록·파일 저장소(데이터베이스) 연결: 지금은 브라우저 저장만 됨
4. 개인정보 처리방침과 교내 AI 이용 지침 확정

자세한 순서는 별도 「연결 안내서」를 따릅니다.
