# 문제를 푸는 것이 가장 좋은 복습입니다

## 다시 읽기와 꺼내 보기

시험 준비 시간의 대부분을 교재와 필기를 다시 읽는 데 쓰는 학생이 많습니다. 다시 읽으면 내용이 익숙해져 안심이 되지만, 익숙한 것과 기억에서 꺼낼 수 있는 것은 다릅니다. 시험은 꺼내는 능력을 봅니다.

학습과학에서는 기억에서 정보를 꺼내 보는 연습(인출 연습)이 다시 읽기보다 장기 기억에 더 도움이 된다는 결과가 여러 연구에서 반복되었습니다. 이를 시험 효과(testing effect)라고 부릅니다. 틀린 문제도 공부가 됩니다. 꺼내려고 애쓴 뒤 정답을 확인하면, 그냥 정답을 읽을 때보다 더 잘 남습니다.

## 시험 효과를 높이는 조건

| 조건 | 이유 |
|---|---|
| 정답을 보기 전에 먼저 답한다 | 꺼내려는 노력 자체가 기억을 강화 |
| 바로 피드백을 받는다 | 틀린 기억이 굳지 않게 |
| 간격을 두고 다시 푼다 | 분산 학습과 결합 |
| 유형을 섞어 푼다 | 비슷한 개념을 구분하는 능력 향상 |
| 쉬운 문제만 풀지 않는다 | 적당히 어려운 문제가 더 남음 |

# 3단계 난이도 문제

## 수준별로 나누어 만들기

| 단계 | 묻는 것 | 문제 예(심부전) |
|---|---|---|
| 1. 기억 | 정의, 분류, 기준 | 좌심부전의 대표 증상은? |
| 2. 이해·적용 | 기전, 원리, 비교, 계산 | 이뇨제를 쓰는 심부전 환자에게서 저칼륨혈증이 생길 수 있는 이유는? |
| 3. 판단 | 사례에서 우선순위, 다음 행동 | 기좌호흡과 수포음이 새로 나타난 환자에게 가장 먼저 할 간호중재는? |

국가시험은 2단계와 3단계 문제의 비중이 큽니다. 1단계 문제만 풀면 점수가 잘 오르지 않습니다.

## 문제 만들기 프롬프트

```prompt 3단계 셀프 테스트
아래는 [과목] [단원]의 제 필기와 강의 자료입니다.
[붙여 넣기 또는 첨부]

이 자료 안의 내용으로 5지선다 문제 9개를 만들어 주세요.
- 기억 3문제, 이해·적용 3문제, 사례 판단 3문제
- 오답 보기는 학생들이 흔히 헷갈리는 개념으로
- 문제만 먼저 보여 주고, 정답과 해설은 제가 "답 공개"라고 할 때까지 숨겨 주세요.
- 해설에는 자료 속 근거 위치를 적어 주세요.
- 자료에 없는 수치나 기준은 쓰지 마세요.
```

자료를 주고 만들게 해야 우리 수업 범위와 용어에 맞는 문제가 나옵니다. NotebookLM 같은 자료 기반 도구에서도 같은 방식으로 문제를 만들 수 있습니다.

# 한 문제씩 푸는 튜터 방식

## 힌트 단계

한 번에 모든 문제와 답을 받으면 정답을 먼저 보게 됩니다. 한 문제씩 풀고, 틀리면 바로 답을 보지 않고 힌트를 받아 다시 풀면 인출 연습 효과가 커집니다.

```prompt 한 문제씩 튜터
[단원] 범위에서 국가시험형 5지선다 문제를 한 번에 한 문제씩 내 주세요.
- 제가 답하면 맞았는지만 먼저 알려 주세요.
- 틀렸으면 정답을 바로 알려 주지 말고 힌트를 한 번 주세요. 두 번째도 틀리면 정답과 해설을 주세요.
- 해설에는 왜 정답인지와 제가 고른 보기가 왜 틀렸는지를 모두 써 주세요.
- 10문제가 끝나면 틀린 문제의 개념을 모아 다시 2문제를 내 주세요.
```

## 확신도 표시하기

답할 때 "확신 높음, 중간, 낮음"을 함께 적으면 내 메타인지를 점검할 수 있습니다. 확신이 높았는데 틀린 문제가 가장 위험한 오개념입니다. 이런 문제는 「AI 1:1 오답 피드백」으로 꼭 분석합니다.

| 결과 | 확신 | 의미 | 할 일 |
|---|---|---|---|
| 맞음 | 높음 | 안정된 지식 | 간격을 길게 두고 복습 |
| 맞음 | 낮음 | 운이 좋았을 수 있음 | 해설 확인 후 다시 풀기 |
| 틀림 | 낮음 | 아직 모르는 지식 | 개념 공부 후 재시험 |
| 틀림 | 높음 | 오개념 | 오답 피드백으로 원인 분석 |

# AI가 만든 문제의 품질 확인

## 흔한 문제점

AI가 만든 문제는 연습에는 충분히 쓸 만하지만 다음 문제가 생길 수 있습니다.

- 정답이 두 개이거나 없는 문제
- 해설과 정답이 서로 다른 문제
- 교재 기준과 다른 수치나 분류
- 개정 전 법령이나 지침을 기준으로 한 문제
- 오답 보기가 너무 엉뚱해 쉽게 맞히는 문제

## 품질 점검

!!! AI 문제를 풀기 전후로 확인합니다
- 정답이 하나뿐이고 해설과 일치한다
- 수치와 기준을 교재와 대조했다
- 법령, 지침 관련 문제는 최신 기준인지 확인했다
- 오답 보기가 그럴듯하다
- 의심스러운 문제는 교수님이나 교재로 확인했다

틀린 문제를 발견하는 것 자체도 좋은 공부입니다. "이 문제는 왜 정답이 둘인가"를 따지는 과정에서 개념이 더 정확해집니다.

## 실제 시험 자료와 함께

AI 문제만으로는 실제 시험의 형식과 난이도를 다 반영할 수 없습니다. 학과가 제공하는 모의고사, 국가시험 시행 기관이 공개하는 출제 기준과 공개 문항을 함께 봅니다. 공개 문항을 AI에 넣어 비슷한 문제를 만들 때는 개인 공부에만 쓰고, 원문을 옮겨 자료로 배포하지 않습니다.

# 결과로 약점 찾기

## 오답 원인 세 가지

| 원인 | 예 | 해결 |
|---|---|---|
| 지식 부족 | 개념을 처음 봄, 외우지 않음 | 개념 공부, 키워드 키트, 설명 카드 |
| 이해 부족 | 외웠지만 응용 못 함 | 질문 대화법, 설명 공부법 |
| 실수 | 문제를 잘못 읽음, 부정문 놓침 | 문제 읽기 습관, 표시하기 |

## 약점 분석과 재시험

```prompt 오답 패턴 분석
아래는 제가 푼 셀프 테스트 결과입니다.
[문제 번호, 주제, 내 답, 정답, 확신도, 맞음·틀림]

1. 주제별 정답률을 표로 정리해 주세요.
2. 틀린 문제를 지식 부족, 이해 부족, 실수로 나누어 주세요(판단이 어려우면 제게 질문해 주세요).
3. 가장 약한 주제 2개로 재시험 문제 6개를 만들어 주세요. 이번에는 사례 판단 문제를 절반 이상 넣어 주세요.
```

재시험은 바로 풀지 말고 하루 이틀 뒤에 풉니다. 간격을 두고 다시 꺼내 볼 때 효과가 큽니다.

# 계열별 3단계 문제 예

| 계열 | 기억 | 이해·적용 | 판단 |
|---|---|---|---|
| 물리치료 | 회전근개에 속하는 근육은? | 어깨 벌림에서 가시위근의 역할은? | 드롭 암 검사 양성 환자에게 먼저 할 평가는? |
| 임상병리 | 응고검사용 항응고제는? | 구연산나트륨 양이 많으면 결과는? | 용혈 검체의 칼륨 결과를 받았을 때 할 일은? |
| 방사선 | 흡수선량의 단위는? | 거리를 두 배로 하면 선량률은? | 임신 가능성 있는 환자의 복부 촬영 의뢰가 왔을 때? |
| 치위생 | DMFT의 F는? | 불소가 우식을 예방하는 기전은? | 교정 환자의 백반이 늘었을 때 교육 우선순위는? |
| 사회복지 | 사례관리의 단계는? | 강점 관점이 사정에 주는 영향은? | 클라이언트가 서비스를 거부할 때 첫 대응은? |

# 문제 만들기도 공부입니다

남이 만든 문제를 푸는 것보다 내가 문제를 만들어 보면 출제자의 관점이 생깁니다. 특히 그럴듯한 오답 보기를 만들려면 개념을 정확히 알아야 합니다.

```prompt 내가 만든 문제 평가
제가 만든 문제입니다.
[문제, 보기, 정답, 해설]
1. 정답이 하나뿐인지
2. 오답 보기가 그럴듯한지, 너무 쉽게 걸러지는 보기는 무엇인지
3. 문제의 수준(기억, 이해·적용, 판단)
4. 더 좋은 문제로 고친 방향
을 평가해 주세요.
```

# 자주 묻는 질문

**문제를 하루에 몇 개 풀어야 하나요?**
개수보다 꾸준함과 오답 분석이 중요합니다. 매일 짧게라도 풀고, 틀린 문제를 반드시 분석하는 것을 기본으로 합니다.

**시험 범위가 넓으면 문제를 어떻게 만들게 하나요?**
단원을 나누어 만들고, 마지막에 단원을 섞은 문제를 따로 만듭니다.

# 자가진단과 자주 하는 실수

## 셀프 테스트 자가진단

!!! 내 셀프 테스트를 점검합니다
- 다시 읽기보다 문제 풀기에 시간을 더 쓴다
- 기억, 이해·적용, 판단 문제를 모두 푼다
- 정답을 보기 전에 먼저 답한다
- 확신도를 함께 기록한다
- 틀린 문제를 원인별로 나눈다
- 재시험을 간격을 두고 푼다

## 자주 하는 실수

| 실수 | 고치는 방법 |
|---|---|
| 문제와 정답을 한 번에 받음 | 답 공개 전까지 숨기기, 한 문제씩 튜터 방식 |
| 맞힌 문제만 보고 안심 | 확신도 낮은 정답도 다시 확인 |
| 1단계 문제만 풂 | 사례 판단 문제 비중 늘리기 |
| AI 문제를 확인 없이 믿음 | 품질 점검표로 확인 |
| 틀린 문제를 해설만 읽고 넘김 | 원인 분석과 재시험 |
