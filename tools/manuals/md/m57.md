# 치기공과 AI

## 치과기공사의 일과 디지털 전환

치과기공사는 치과의사의 의뢰에 따라 보철물, 교정 장치, 의치 같은 치과 기공물을 만드는 전문 인력입니다. 최근 치과기공은 구강 스캐너로 얻은 디지털 인상, 컴퓨터 설계(CAD), 밀링과 3D 프린팅(CAM)으로 빠르게 바뀌고 있습니다. 설계 소프트웨어에는 자동 설계 기능이 들어가고 있어, 치과기공사는 자동 결과를 판단하고 다듬는 능력이 점점 중요해집니다.

생성형 AI는 기공물을 직접 만들지는 못하지만 학습과 작업 관리에서 도움을 줍니다.

| 영역 | AI가 돕는 부분 | 치과기공사가 판단할 부분 |
|---|---|---|
| 재료 학습 | 재료별 물성 비교, 취급 주의 정리 | 실제 재료의 제조사 지침 확인 |
| 제작 과정 학습 | 공정 단계 정리, 흔한 실패 원인 | 실제 작업의 품질 판단 |
| 디지털 작업 흐름 | 스캔부터 출력까지 단계 정리, 파일 관리 규칙 | 설계의 적합성 |
| 의뢰서 해석 | 용어 정리, 확인 질문 목록 | 실제 의뢰 내용 확인과 소통 |
| 품질 관리 | 점검표, 불량 원인 분석 틀 | 실제 측정과 판정 |

## 원칙

- **환자 정보와 구강 스캔 파일은 넣지 않습니다.** 의뢰서의 환자 이름과 구강 스캔 데이터는 개인정보이자 건강정보입니다.
- **재료 수치는 제조사 지침이 기준입니다.** 소성 온도, 경화 시간, 혼합 비율은 제품마다 다르므로 AI가 제시한 수치를 그대로 쓰지 않습니다.
- **업무 범위를 지킵니다.** 치과기공사는 치과의사의 의뢰에 따라 작업합니다. AI가 진단이나 치료 방침을 제시해도 따르지 않습니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 치과재료학 | 물성 암기 | AI로 재료 비교표를 만들고 교재·제조사 자료로 검증 | 재료 선택 근거 |
| 고정성 보철 기공학 | 실습 | 공정별 흔한 실패와 원인을 AI로 정리하고 실습 결과와 대조 | 문제 해결 |
| 디지털 치과기공 | 소프트웨어 실습 | 작업 흐름도와 파일 관리 규칙을 AI로 정리, 자동 설계 결과 비판 | 디지털 작업 관리 |
| 의치 기공학 | 실습 | 의뢰서 해석 연습, 확인 질문 목록 만들기 | 의사소통 |
| 치과기공 실무 | 현장 실습 | 품질 점검표 설계 | 품질 관리 |

# 교수자용 수업 활동

## 활동 1. 재료 비교표 검증

```prompt 프롬프트 1. 재료 비교표
치과 보철 재료 [예: 지르코니아, 리튬 디실리케이트, 금속 도재] 를 비교표로 정리해 주세요.
열: 재료, 주요 성분, 강도 특성, 심미성, 주요 적응증, 가공 방법, 취급 주의.
수치(강도, 온도)는 쓰지 말고 [교재·제조사 확인]으로 둡니다.
```

학생은 표의 각 칸을 교재와 제조사 기술 자료로 확인해 채우고, AI 설명과 다른 부분을 표시합니다.

## 활동 2. 실패 원인 분석

```prompt 프롬프트 2. 공정별 실패 원인
[공정, 예: 왁스 패턴부터 주조까지]의 단계별로 흔한 실패 유형과 원인, 예방 방법을 표로 정리해 주세요.
열: 단계, 실패 유형, 가능한 원인, 예방 방법, 확인 방법.
```

학생은 자신의 실습 결과물에서 실패가 있으면 이 표로 원인을 추정하고, 교수와 함께 실제 원인을 확인합니다. AI 표가 실제 원인을 놓친 경우 표를 보완합니다.

## 활동 3. 디지털 작업 흐름

```prompt 프롬프트 3. 디지털 작업 흐름도
구강 스캔 데이터 수신부터 밀링 또는 3D 프린팅, 후처리, 출고까지 디지털 치과기공 작업 흐름을 단계별로 정리해 주세요.
단계마다 확인할 품질 항목과 흔한 오류, 파일 이름 규칙 예시를 넣어 주세요. 특정 제품명은 쓰지 마세요.
```

| 공정 조건 | 소성 온도, 경화 시간, 혼합 비율 | 제조사 사용 설명서 |

!!! 치기공 AI 결과물을 쓰기 전에 확인합니다
- 환자 정보와 구강 스캔 파일을 AI에 넣지 않았다
- 재료 수치와 공정 조건을 교재와 제조사 자료로 확인했다
- 치아 번호 표기가 수업 기준과 같다
