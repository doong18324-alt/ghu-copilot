# 이 워크북 쓰는 법

## 지식을 환자 앞으로 가져가는 연습

교재로 배운 지식은 질환별로 정리되어 있지만, 실제 환자는 "저는 심근경색입니다"라고 말하며 오지 않습니다. 가슴이 답답하다, 숨이 차다, 갑자기 말이 어눌해졌다처럼 증상과 상황으로 옵니다. 임상추론은 흩어진 단서를 모아 문제를 찾고, 우선순위를 정하고, 다음 행동을 고르는 과정입니다. 이 워크북은 가상 사례로 이 과정을 반복 연습하게 합니다.

## 사례마다 같은 여섯 단계

| 단계 | 할 일 |
|---|---|
| 1. 가상 차트 읽기 | 주호소, 병력, 활력징후, 신체검진에서 이상 소견 표시 |
| 2. 용어와 검사 해독 | 모르는 용어와 검사 의미 정리 |
| 3. 병태생리 이해 | 증상이 왜 생기는지 기전으로 연결 |
| 4. AI 가상 환자 인터뷰 | 추가로 물어볼 것을 직접 묻기 |
| 5. 임상추론 디브리핑 | 내 판단을 쓰고 AI에게 빈틈 점검 받기 |
| 6. 워크시트와 해설 | 문제 목록, 우선순위, 내 직종의 역할 정리 |

## 꼭 지킬 것

- 모든 사례는 학습용으로 만든 가상 인물입니다. 실습에서 만난 실제 환자를 사례로 바꾸어 AI에 넣지 않습니다.
- 사례 속 수치는 학습을 위해 만든 값입니다. 검사의 정상 범위와 치료 기준은 교재와 기관 지침으로 확인합니다.
- 약물 이름과 용량, 처치 결정은 의사와 기관의 지침을 따릅니다. 학생의 역할과 권한 안에서 판단을 연습합니다.

## 모든 사례에 쓰는 두 가지 프롬프트

```prompt AI 가상 환자

- 제가 "인터뷰 끝"이라고 하면 제가 놓친 중요한 질문 3개를 알려 주세요.
```

# 사례 1. 가슴 통증과 식은땀을 호소하는 58세 남성

## 가상 차트

| 항목 | 내용 |
|---|---|
| 주호소 | 40분 전부터 가슴 한가운데를 누르는 듯한 통증, 왼팔로 뻗침 |
| 현병력 | 계단을 오르다 시작, 쉬어도 나아지지 않음. 식은땀, 메스꺼움 |
| 과거력 | 고혈압, 이상지질혈증, 흡연 30년 |
| 활력징후 | 혈압 150/92 mmHg, 맥박 104회/분, 호흡 22회/분, 체온 36.8°C, 산소포화도 94% |
| 신체검진 | 창백, 피부 축축함, 불안한 표정 |

## 용어와 검사

| 용어·검사 | 의미 |
|---|---|
| 급성 관상동맥증후군(ACS) | 관상동맥이 갑자기 좁아지거나 막혀 심근에 혈액이 부족해지는 상태의 총칭 |
| 12유도 심전도 | ST 분절 상승 등 심근 허혈과 손상 소견 확인 |
| 심장 트로포닌 | 심근 손상 시 혈중에 오르는 표지자, 심근에 특이도가 높음 |
| 방사통 | 원래 부위에서 다른 곳으로 뻗치는 통증 |

## 병태생리

동맥경화로 좁아진 관상동맥의 죽상판이 터지면 그 자리에 혈전이 생겨 혈류가 갑자기 줄거나 막힙니다. 혈액을 받지 못한 심근은 산소 부족으로 통증을 일으키고, 시간이 지나면 괴사합니다. 교감신경이 활성화되어 빈맥, 식은땀, 창백이 나타납니다. 심근이 손상되면 펌프 기능이 떨어지고 전기적으로 불안정해져 치명적 부정맥이 생길 수 있습니다. 그래서 시간이 가장 중요합니다.

## 생각해 볼 질문

1. 이 환자에게서 심장 원인을 의심하게 하는 단서는 무엇인가?
2. 가장 먼저 확인하거나 준비해야 할 검사는 무엇인가?
3. 내 직종이 즉시 할 수 있는 일과 보고할 대상은?
4. 가슴 통증을 일으키는 다른 원인 가운데 놓치면 위험한 것은?

## 해설 요점

- 단서: 쉬어도 낫지 않는 압박성 흉통, 왼팔 방사통, 식은땀, 위험 인자(고혈압, 이상지질혈증, 흡연).
- 우선: 심전도를 빨리 확인하고 활력징후와 산소포화도를 감시하며 의료진에게 즉시 보고합니다. 기관의 흉통 대응 절차를 따릅니다.
- 감별: 대동맥 박리, 폐색전, 긴장성 기흉처럼 생명을 위협하는 다른 원인도 함께 생각합니다.
- 오개념: "젊거나 통증이 심하지 않으면 심장 문제가 아니다." 여성, 노인, 당뇨 환자는 전형적이지 않은 증상(숨참, 피로, 소화불량 같은 느낌)으로 오기도 합니다.

# 사례 2. 숨이 차고 쌕쌕거리는 22세 여성

## 가상 차트

| 항목 | 내용 |
|---|---|
| 주호소 | 2시간 전부터 숨이 차고 가슴이 조임, 쌕쌕거리는 소리 |
| 현병력 | 감기 3일째, 오늘 대청소 중 먼지에 노출된 뒤 악화. 평소 흡입기를 가끔 사용 |
| 과거력 | 어릴 때부터 천식, 알레르기 비염 |
| 활력징후 | 혈압 124/78 mmHg, 맥박 112회/분, 호흡 28회/분, 체온 37.6°C, 산소포화도 91% |
| 신체검진 | 앉아서 앞으로 기댄 자세, 문장을 끊어서 말함, 호기 시 천명음, 보조호흡근 사용 |

## 용어와 검사

| 용어·검사 | 의미 |
|---|---|
| 천명음(wheezing) | 좁아진 기도로 공기가 지나며 나는 고음의 소리 |
| 보조호흡근 | 목빗근 등 평소 호흡에 쓰지 않는 근육. 사용하면 호흡 부담이 크다는 신호 |
| 최고호기유속(PEF) | 최대한 빠르게 내쉰 공기 속도, 기도 폐쇄 정도 평가 |
| 속효성 기관지확장제 | 좁아진 기도를 빠르게 넓히는 흡입약 |

## 병태생리

천식은 기도에 만성 염증이 있어 자극(감염, 먼지, 찬 공기, 운동)에 기도가 과민하게 반응하는 질환입니다. 발작 때는 기관지 평활근이 수축하고, 점막이 붓고, 끈끈한 분비물이 늘어 기도가 좁아집니다. 특히 숨을 내쉴 때 공기가 빠져나가기 어려워 천명음이 들리고, 폐에 공기가 갇혀 호흡 부담이 커집니다. 문장을 끊어 말하거나 천명음이 오히려 작아지면서 의식이 흐려지면 공기 흐름이 매우 줄어든 위험 신호일 수 있습니다.

## 생각해 볼 질문

1. 발작이 심하다고 판단할 수 있는 단서는?
2. 환자에게 편한 자세와 그 이유는?
3. 천명음이 갑자기 작아졌다면 좋아진 것인가?
4. 퇴원 교육에서 다룰 내용은?

## 해설 요점

- 단서: 문장을 끊어 말함, 보조호흡근 사용, 산소포화도 저하, 빈맥, 빈호흡.
- 자세: 앉아서 앞으로 기댄 자세가 가로막 움직임과 보조호흡근 사용에 유리합니다.
- 함정: 천명음이 작아지는 것은 공기 흐름 자체가 줄어든 위험 신호일 수 있으므로 즉시 보고합니다.
- 교육: 흡입기 사용법(스페이서 활용), 유발 요인 피하기, 악화 시 행동 계획, 정기 진료.

# 사례 3. 갑자기 한쪽 팔다리 힘이 빠지고 말이 어눌해진 67세 여성

## 가상 차트

| 항목 | 내용 |
|---|---|
| 주호소 | 1시간 전 아침 식사 중 오른손에 쥔 숟가락을 떨어뜨림, 말이 어눌해짐 |
| 현병력 | 가족이 발견, 마지막으로 정상이었던 시각은 오늘 오전 7시 30분 |
| 과거력 | 심방세동, 고혈압, 당뇨병 |
| 활력징후 | 혈압 172/96 mmHg, 맥박 불규칙 92회/분, 호흡 18회/분, 체온 36.6°C, 혈당 [측정값 확인] |
| 신경학적 검진 | 오른쪽 얼굴 처짐, 오른팔·다리 근력 저하, 말 이해는 비교적 되나 표현이 어려움 |

## 용어와 검사

| 용어·검사 | 의미 |
|---|---|
| 편마비(hemiplegia) | 몸 한쪽의 마비 |
| 구음장애(dysarthria) | 말소리를 만드는 근육 문제로 발음이 어눌함 |
| 실어증(aphasia) | 언어를 이해하거나 표현하는 능력의 장애 |
| 뇌 CT | 출혈성 뇌졸중과 허혈성 뇌졸중 구분에 가장 먼저 시행 |
| 마지막 정상 시각 | 치료 결정의 기준이 되는 증상 발생 시각 |

## 병태생리

심방세동이 있으면 심방에서 혈액이 고여 혈전이 생기기 쉽고, 이 혈전이 떨어져 뇌혈관을 막으면 허혈성 뇌졸중이 생깁니다. 왼쪽 대뇌반구의 운동 영역이 손상되면 반대쪽인 오른쪽 몸에 마비가 오고, 대부분 사람에게서 언어 중추가 있는 왼쪽 반구가 손상되면 실어증이 함께 나타날 수 있습니다. 막힌 혈관 주변에는 아직 살릴 수 있는 뇌 조직이 있어, 빨리 혈류를 회복할수록 결과가 좋아집니다.

## 생각해 볼 질문

1. 뇌졸중을 빠르게 선별하는 증상 세 가지는?
2. 마지막 정상 시각이 왜 중요한가?
3. 혈당을 꼭 확인하는 이유는?
4. 이 환자에게 입으로 물이나 약을 줄 때 주의할 점은?

## 해설 요점

- 선별: 얼굴 처짐, 팔 힘 빠짐, 말 이상. 하나라도 있으면 즉시 알리고 병원 내 뇌졸중 대응 절차를 따릅니다.
- 시각: 재관류 치료 여부를 정하는 기준이 되므로 정확히 기록합니다.
- 혈당: 저혈당도 뇌졸중과 비슷한 증상을 일으킬 수 있습니다.
- 삼킴: 삼킴 평가 전에는 입으로 아무것도 주지 않고 흡인을 예방합니다.

# 사례 4. 넘어진 뒤 엉덩이 통증으로 걷지 못하는 74세 여성

## 가상 차트

| 항목 | 내용 |
|---|---|
| 주호소 | 화장실에서 미끄러져 넘어진 뒤 오른쪽 엉덩이 통증, 일어서지 못함 |
| 현병력 | 밤에 혼자 화장실 가다 넘어짐. 최근 수면제 복용 시작 |
| 과거력 | 골다공증, 고혈압, 백내장 |
| 활력징후 | 혈압 138/84 mmHg, 맥박 96회/분, 호흡 20회/분, 체온 36.7°C, 통증 숫자척도 8점 |
| 신체검진 | 오른쪽 다리가 짧아 보이고 바깥으로 돌아감, 엉덩관절 움직일 때 심한 통증 |

## 용어와 검사

| 용어·검사 | 의미 |
|---|---|
| 넙다리뼈 목 골절 | 엉덩관절 아래 넙다리뼈의 좁은 부분 골절, 노인 낙상 후 흔함 |
| 단축과 외회전 | 엉덩이 골절에서 흔히 보이는 다리 모양 |
| 골다공증 | 뼈의 양과 질이 떨어져 작은 충격에도 골절되기 쉬운 상태 |
| 섬망 | 갑자기 생기는 주의력과 의식의 혼란, 노인 수술 전후 흔함 |

## 병태생리

골다공증으로 약해진 뼈는 서 있는 높이에서 넘어지는 정도의 충격에도 부러질 수 있습니다. 넙다리뼈 목이 부러지면 주변 근육이 당기면서 다리가 짧아지고 바깥으로 돌아갑니다. 노인은 오래 누워 있으면 근력 저하, 욕창, 폐렴, 혈전, 섬망 같은 합병증이 빠르게 생기므로 수술과 조기 재활이 중요합니다. 낙상의 원인(수면제, 시력, 야간 화장실 동선)을 찾아 다시 넘어지지 않게 하는 것도 치료의 일부입니다.

- 보충: 경구수액제를 조금씩 자주 먹이고, 모유 수유는 계속합니다. 당분이 많은 주스나 탄산음료는 피합니다.
- 응급 신호: 계속 토해서 마시지 못함, 소변이 거의 없음, 심하게 처지거나 깨우기 어려움, 혈변.
- 전파 예방: 기저귀 교체 후와 식사 준비 전 손 씻기, 장난감과 표면 소독, 증상이 있는 동안 어린이집 등원 여부는 기관 기준에 따름.

# 사례 분석 실력을 키우는 방법

## 같은 사례를 세 번 다르게

| 회차 | 방법 |
|---|---|
| 1회 | 혼자 차트를 읽고 문제 목록을 만든 뒤 해설과 비교 |
| 2회 | AI 가상 환자에게 문진해 차트에 없는 정보를 직접 찾기 |
| 3회 | 사례의 한 가지 조건을 바꿔(예: 나이, 동반 질환) 우선순위가 어떻게 달라지는지 따지기 |

```prompt 조건 바꾸기
[사례 번호]의 조건 하나를 바꾼 변형 사례 3개를 만들어 주세요.
예: 나이를 바꾸기, 동반 질환 추가, 활력징후 하나 악화
변형마다 원래 사례와 비교해 우선순위가 어떻게 달라지는지 제가 먼저 쓰겠습니다. 제가 쓴 뒤에 평가해 주세요.
```

## 흔한 추론 오류

| 오류 | 예 | 막는 방법 |
|---|---|---|
| 첫인상 고정 | 처음 떠올린 진단만 붙잡음 | "다른 가능성 두 가지는?"을 습관처럼 묻기 |
| 확인 편향 | 생각과 맞는 단서만 봄 | 맞지 않는 단서를 따로 적기 |
| 성급한 종결 | 그럴듯한 답이 나오면 멈춤 | 위험한 원인을 놓치지 않았는지 마지막 점검 |
| 최근 경험 편향 | 최근 본 질환을 먼저 떠올림 | 단서 목록에서 다시 출발 |

# 사례 워크시트

## 내 추론 정리표

| 항목 | 내용 |
|---|---|
| 핵심 단서(이상 소견) | |
| 문제 목록(우선순위 순) | |
| 우선순위 근거 | |
| 추가로 확인할 정보 | |
| 내 직종이 할 행동 | |
| 보고할 대상과 보고 내용(SBAR) | |
| 이 사례에서 배운 원칙 | |

## SBAR로 보고 연습

| 단계 | 내용 예(사례 1) |
|---|---|
| 상황(S) | 7병동 58세 남성 환자가 40분째 압박성 흉통과 식은땀을 호소합니다 |
| 배경(B) | 고혈압, 이상지질혈증, 흡연력이 있습니다 |
| 평가(A) | 맥박 104회, 산소포화도 94%, 심장 원인이 의심됩니다 |
| 요청(R) | 지금 바로 보시고 심전도 확인을 부탁드립니다 |

```prompt SBAR 점검
제가 [사례 번호] 환자에 대해 쓴 SBAR 보고입니다.
[붙여 넣기]
보고를 받는 의료진의 입장에서 빠진 정보, 불필요한 정보, 요청이 불분명한 부분을 알려 주세요.
```

## 사례 분석 평가 기준

교수자나 스터디 그룹이 사례 분석 보고서를 평가할 때 쓸 수 있는 기준입니다.

| 기준 | 우수 | 보통 | 보완 필요 |
|---|---|---|---|
| 단서 찾기 | 주요 이상 소견을 빠짐없이 찾음 | 대부분 찾음 | 중요한 단서를 놓침 |
| 병태생리 연결 | 증상을 기전으로 설명 | 일부 설명 | 증상 나열에 그침 |
| 우선순위 | 생명과 안전 기준으로 순서 정함 | 순서는 맞으나 근거 부족 | 순서가 바뀜 |
| 직종 역할 | 권한 안에서 구체적 행동 | 행동이 막연함 | 권한을 넘는 판단 |
| 보고 | SBAR로 정확히 | 일부 빠짐 | 무엇을 요청하는지 불분명 |
| 근거 | 교재와 지침으로 확인 | 일부 확인 | 확인 없이 AI 답 인용 |

## 나만의 사례 만들기

워크북의 사례를 마쳤다면 교재 단원마다 가상 사례를 직접 만들어 봅니다. AI에게 사례를 만들게 할 때는 학습 목표를 분명히 주고, 사례의 의학적 타당성을 교재로 확인합니다.

```prompt 가상 사례 만들기
[과목] [단원]의 학습 목표는 [목표]입니다.
이 목표를 연습할 가상 사례를 만들어 주세요.
- 주호소, 현병력, 과거력, 활력징후, 신체검진(표)
- 단서 가운데 하나는 놓치기 쉬운 것으로
- 사례 아래에 생각해 볼 질문 4개(답은 따로)
- 실제 인물이나 실제 사례를 쓰지 말고, 수치는 학습용 가상 값으로 표시해 주세요.
```

!!! 이 워크북을 마치며 확인합니다
- 차트에서 이상 소견을 찾아 문제 목록을 만들 수 있다
- 증상을 병태생리로 설명할 수 있다
- AI 가상 환자에게 직접 문진해 보았다
- 디브리핑으로 놓친 단서와 우선순위를 점검했다
- SBAR로 보고를 연습했다
- 내 직종의 역할과 권한 안에서 판단했다
- 실제 환자 정보를 쓰지 않았다

# 바이탈에서 이어서 하기

- **다학제 케이스 컨퍼런스:** 같은 사례를 여러 직종 입장에서 회의해 봅니다.
- **임상실습 성찰일지 코치:** 실습에서 겪은 상황을 개인정보를 가린 성찰로 정리합니다.
- **보건의료 국가고시 CBT 모의고사·오답노트:** 사례형 문제로 판단을 확인합니다.
- **개인정보 가명처리기:** 사례 과제 제출 전 식별 정보가 없는지 점검합니다.
