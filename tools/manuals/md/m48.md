# 물리치료와 AI

## 물리치료사의 일과 AI가 닿는 곳

물리치료사는 근골격계, 신경계, 심폐계 손상과 기능 저하가 있는 대상자의 움직임과 기능 회복을 돕습니다. 평가, 중재 계획, 운동치료와 도수치료, 물리적 인자 치료, 환자 교육이 주요 업무입니다. 손으로 하는 평가와 치료는 AI가 대신할 수 없지만, 그 앞뒤의 학습, 계획, 교육, 기록 연습에서는 AI가 도움을 줍니다. 최근에는 카메라와 센서로 자세와 보행을 분석하는 도구도 늘고 있어 그 원리와 한계를 아는 것도 중요해졌습니다.

| 영역 | AI가 돕는 부분 | 물리치료사가 판단할 부분 |
|---|---|---|
| 평가 학습 | 평가 도구 정리, 검사 절차 체크리스트 | 실제 시행과 결과 해석 |
| 중재 계획 | 가상 사례의 목표 설정, 운동 프로그램 초안 | 대상자 상태에 맞는 강도·금기 판단 |
| 환자 교육 | 가정 운동 안내문, 통증 교육 자료 | 내용의 정확성, 대상자 이해 확인 |
| 근거 탐색 | 문헌 요약, 근거 비교 | 원문 확인, 임상 적용 판단 |
| 동작 분석 도구 | 결과 보고서 문장 정리 | 측정의 타당성, 임상 판단 |

## 원칙

- **실습 대상자 정보는 넣지 않습니다.** 진단명, 수술 기록, 영상 소견, 평가 결과를 실제 대상자 것으로 넣지 않습니다.
- **운동 강도와 금기는 근거로 확인합니다.** 수술 후 시기별 허용 범위, 심혈관 위험 대상자의 운동 강도는 교재, 진료지침, 담당 의사 지시를 따릅니다.
- **AI의 진단을 받아들이지 않습니다.** AI가 특정 질환을 진단하거나 감별하는 문장을 쓰더라도 이는 학습용 참고일 뿐입니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 기능해부학·운동학 | 그림과 강의 | AI로 근육 기능 비교표를 만들고 교재로 검증, 동작 분석 앱으로 관절각 측정 체험 | 움직임 이해 |
| 근골격계 물리치료 | 사례 강의 | AI 가상 사례로 평가·목표·중재를 쓰고 동료 검토 | 임상 추론 |
| 신경계 물리치료 | 영상 관찰 | 보행 분석 도구 결과와 관찰 평가를 비교 토론 | 관찰 분석, 도구 비판 |
| 운동치료학 | 운동 처방 연습 | AI가 만든 운동 프로그램의 강도·금기 오류 찾기 | 안전한 처방 |
| 근거 기반 실무 | 논문 읽기 | AI로 논문 구조 요약 후 원문 대조, PICO 질문 만들기 | 근거 탐색 |

# 교수자용 수업 활동

## 활동 1. 가상 사례로 임상 추론하기

```prompt 프롬프트 1. 가상 사례 만들기
근골격계 물리치료 수업용 가상 사례를 만들어 주세요.
조건: [예: 우측 어깨 통증이 3개월 된 50대 사무직], 주호소, 병력, 일상생활 제한, 통증 양상, 간단한 관찰 소견을 A4 반 쪽으로. 실제 인물이나 기관을 떠올리게 하는 정보는 쓰지 마세요.
사례 뒤에 교수용으로 추가로 시행해야 할 평가 항목과, 의뢰가 필요한 위험 신호(red flag)가 있는지 판단할 근거 문장을 따로 적어 주세요.
```

학생은 사례를 읽고 평가 계획, 문제 목록, 목표, 중재 계획을 씁니다. 그 뒤 AI에게 같은 사례로 계획을 받아 비교하고, AI 계획에서 근거가 약하거나 위험한 부분을 찾아 발표합니다.

## 활동 2. 운동 프로그램 안전성 검증

```prompt 프롬프트 2. 검증용 운동 프로그램 받기
[대상, 예: 무릎 인공관절 전치환술 후 6주된 70대]를 위한 4주 가정 운동 프로그램을 써 주세요. 운동마다 자세, 횟수, 세트, 주의사항을 적어 주세요.
```

학생은 이 프로그램을 교재와 진료지침으로 대조해 다음을 확인합니다.

- 수술 후 시기에 비해 강도나 관절가동범위 요구가 과하지 않은가
- 금기 동작이 들어 있지 않은가
- 진행 기준(언제 강도를 올리는가)과 중단 기준(통증, 부종, 열감)이 있는가
- 대상자가 혼자 안전하게 할 수 있는 운동인가

## 활동 3. 카메라 기반 동작 분석 도구 이해

휴대폰 카메라로 관절 위치를 추정해 자세와 보행을 분석하는 도구는 사람의 몸에서 주요 관절 지점(랜드마크)을 찾아 각도와 거리를 계산합니다. 학생이 다음 한계를 직접 확인하게 합니다.

| 한계 | 확인 방법 |
|---|---|
| 2차원 투영 오차 | 같은 동작을 정면과 측면에서 찍어 각도 비교 |
| 옷과 조명 | 헐렁한 옷과 꼭 맞는 옷으로 비교 |
| 가려진 관절 | 한쪽 팔이 몸에 가려질 때 결과 변화 관찰 |
| 기준 장비와의 차이 | 고니오미터로 잰 값과 비교 |

이 활동은 도구를 믿지 말라는 것이 아니라, 어떤 조건에서 믿을 수 있는지 판단하는 능력을 기르는 것이 목적입니다.

# 학생용 실습 프롬프트

## 평가 도구 정리

```prompt 프롬프트 3. 평가 도구 비교
[영역, 예: 노인 균형 평가] 에 쓰는 평가 도구를 비교표로 정리해 주세요.
열: 도구명, 측정하는 것, 시행 방법 요약, 소요 시간, 필요한 장비, 해석 시 주의점.
절단점과 정상 기준 같은 수치는 쓰지 말고 [원문 확인]으로 둡니다. 제가 원 논문이나 교재에서 찾아 채우겠습니다.
```

## 환자 교육 자료

```prompt 프롬프트 4. 가정 운동 안내문
제가 정한 운동 3가지를 어르신이 집에서 따라 할 수 있는 안내문으로 써 주세요.
[운동명, 자세, 횟수, 주의사항을 제가 정해서 붙여 넣기]
조건: 큰 글씨용 짧은 문장, 운동마다 "이럴 때는 멈추세요" 항목, 제가 준 내용 외의 운동은 추가하지 않음.
```

## 논문 읽기

```prompt 프롬프트 5. 논문 구조 요약

연구 질문(PICO), 연구 설계, 대상자 수와 특성, 중재와 비교군, 주요 결과(수치는 원문 그대로, 위치 표시), 저자가 밝힌 한계, 임상 적용 시 고려할 점.
원문에 없는 해석은 [해석]으로 표시해 주세요.
```

# 전공 지식으로 검증하기

| 영역 | AI가 자주 틀리는 것 | 대조 자료 |
|---|---|---|
| 수술 후 재활 | 시기별 허용 범위, 체중 지지 단계 | 교재, 진료지침, 담당 의사 프로토콜 |
| 운동 강도 | 심혈관 위험 대상자의 강도 설정, 중단 기준 | ACSM 지침 등 교재와 지침 |
| 위험 신호 | 의뢰가 필요한 증상을 일반 통증으로 처리 | 교재의 위험 신호 목록 |
| 평가 도구 | 절단점, 신뢰도 수치 | 원 논문, 교재 |
| 물리적 인자 | 적용 조건, 금기 | 물리적 인자 치료 교재 |
| 근거 | 존재하지 않는 논문, 과장된 효과 | 학술 데이터베이스 원문 |

!!! 물리치료 AI 결과물을 쓰기 전에 확인합니다
- 실습 대상자 정보를 AI에 넣지 않았다
- 운동 강도, 시기, 금기를 교재와 지침으로 확인했다
- 위험 신호와 중단 기준이 들어갔다
- 평가 도구의 수치는 원 논문이나 교재로 확인했다
- 인용한 논문이 실제로 있고 내용이 맞다
- 동작 분석 도구 결과를 임상 판단 없이 그대로 쓰지 않았다
