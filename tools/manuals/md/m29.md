# 왜 다학제 협업을 배우나

## 환자는 한 직종만 만나지 않습니다

뇌졸중으로 입원한 환자 한 명을 생각해 봅시다. 의사가 진단과 치료 방향을 정하고, 간호사가 하루 종일 상태를 관찰하고, 물리치료사가 걷기를, 작업치료사가 손 기능과 일상 동작을, 언어재활사가 말과 삼킴을, 영양사가 식단을, 약사가 약물을, 사회복지사가 퇴원 후 돌봄과 비용을 맡습니다. 이들이 따로 움직이면 환자는 같은 질문을 여러 번 받고, 서로 다른 설명을 듣고, 퇴원 뒤 필요한 지원이 빠집니다.

다학제(전문직 간) 교육(Interprofessional Education, IPE)은 서로 다른 직종 학생이 함께 배우며 서로의 역할을 이해하고 협업하는 법을 익히는 교육입니다. 세계보건기구는 전문직 간 교육과 협력 실천이 보건의료 체계를 강화한다고 보고 이를 권고해 왔습니다.

## 협업에 필요한 역량

| 역량 | 뜻 | 행동 예 |
|---|---|---|
| 가치와 윤리 | 환자 중심, 서로의 전문성 존중 | 다른 직종의 의견을 끝까지 듣기 |
| 역할과 책임 | 내 직종과 다른 직종의 역할 이해 | 내 범위를 넘는 판단은 해당 직종에 묻기 |
| 의사소통 | 정확하고 존중하는 정보 공유 | 전문 용어를 풀어 쓰고 SBAR로 보고 |
| 팀워크 | 공동 목표를 향한 역할 분담과 갈등 해결 | 목표를 먼저 합의하고 역할 나누기 |

# 팀기반학습으로 연습하기

## 팀기반학습의 흐름

팀기반학습(Team-Based Learning, TBL)은 미리 공부한 내용을 개인 시험과 팀 시험으로 확인한 뒤, 팀이 실제와 비슷한 문제를 함께 해결하는 수업 방식입니다.

| 단계 | 할 일 |
|---|---|
| 1. 예습 | 사례와 관련된 각 직종의 역할과 핵심 지식 공부 |
| 2. 개인 확인 | 개인 퀴즈 |
| 3. 팀 확인 | 같은 퀴즈를 팀이 토론해 다시 풀기 |
| 4. 적용 과제 | 팀이 사례 문제를 해결하고 결과 발표 |
| 5. 동료 평가와 성찰 | 서로의 기여 평가, 개인 성찰 일지 |

## 팀을 만들 때

가능하면 서로 다른 직종 학생으로 팀을 만듭니다. 같은 학과만 있으면 다른 직종 역할을 한 명씩 맡고, 그 직종의 역할을 조사해 대변합니다. AI는 부족한 직종의 관점을 보충하는 데 쓰되, 그 직종 학생이나 교수의 확인을 받습니다.

```prompt 직종 역할 조사
[사례 요약]
이 환자의 돌봄에 참여할 수 있는 직종(의사, 간호사, 물리치료사, 작업치료사, 언어재활사, 영양사, 약사, 사회복지사, 방사선사, 임상병리사 등)별로 다음을 표로 정리해 주세요.
- 이 사례에서 맡을 수 있는 역할
- 다른 직종에 공유해야 할 정보
- 다른 직종에게서 받아야 할 정보
각 직종의 법적 업무 범위는 확인이 필요하다고 표시해 주세요.
```

# 사례 1. 다발성 중증 외상 환자의 응급 대응

## 사례

40대 남성이 오토바이 사고로 응급실에 도착했습니다. 의식이 흐리고, 왼쪽 가슴에 멍이 있고, 오른쪽 넙다리가 변형되어 있습니다. 혈압이 낮고 맥박이 빠릅니다(가상 사례).

## 팀 과제

1. 처음 몇 분 동안 각 직종이 할 일을 시간 순서로 정리합니다.
2. 1차 평가(기도, 호흡, 순환, 신경, 노출)의 순서에 맞춰 역할을 배치합니다.
3. 팀 리더, 기록 담당, 의사소통 방식(복명복창)을 정합니다.
4. 영상 검사와 검체 검사를 어떻게 연결할지 방사선사와 임상병리사 역할로 정리합니다.

## 핵심 포인트

- 응급 상황에서는 리더가 분명하고, 지시는 대상자 이름을 불러 구체적으로 하며, 받은 사람은 복명복창합니다.
- 각자 본 것을 즉시 공유합니다. "산소포화도 88%입니다"처럼 수치로 말합니다.
- 생명을 위협하는 문제부터 순서대로 다룹니다.

# 사례 2. 퇴원 후 지역사회 통합 돌봄

## 사례

78세 여성이 폐렴으로 2주간 입원한 뒤 퇴원을 앞두고 있습니다. 혼자 살고, 입원 중 근력이 많이 떨어졌으며, 약이 다섯 가지로 늘었습니다. 자녀는 다른 도시에 삽니다(가상 사례).

## 팀 과제

1. 퇴원 후 생길 수 있는 문제(낙상, 복약 실수, 영양 부족, 고립, 재입원)를 목록으로 만듭니다.
2. 문제마다 담당 직종과 지역사회 자원을 연결합니다.
3. 병원 팀과 지역사회 팀(보건소, 행정복지센터, 방문 서비스) 사이의 정보 전달 방법을 정합니다.
4. 환자가 원하는 생활(집에서 혼자 지내고 싶음)을 계획의 중심에 둡니다.

## 핵심 포인트

| 문제 | 관련 직종 | 연계 예 |
|---|---|---|
| 낙상 위험 | 물리치료, 작업치료 | 근력·균형 운동, 집 안 환경 점검 |
| 복약 | 약사, 간호사 | 복약 단순화 검토, 복약 달력 |
| 영양 | 영양사 | 단백질 섭취, 식사 지원 서비스 |
| 고립 | 사회복지사 | 지역 돌봄 서비스, 안부 확인 |

지역사회 통합 돌봄 제도와 서비스 이름, 신청 조건은 지자체와 공식 안내로 확인합니다.

# 사례 3. 급성 뇌졸중 환자의 재활

## 사례

65세 남성이 왼쪽 대뇌 경색으로 오른쪽 편마비와 실어증이 생겼습니다. 삼킴이 불완전하고, 우울해 보이며, 직장 복귀를 걱정합니다(가상 사례).

## 팀 과제

1. 입원 첫 주의 목표와 직종별 역할을 정합니다.
2. 삼킴 평가 결과에 따라 식사 형태를 정하는 과정을 언어재활사, 영양사, 간호사 역할로 정리합니다.
3. 우울 증상을 누가, 어떻게 확인하고 연결할지 정합니다.
4. 퇴원 시점의 기능 목표와 직장 복귀 상담 계획을 세웁니다.

## 핵심 포인트

- 목표는 환자와 가족이 원하는 것에서 출발합니다(예: 혼자 화장실 가기, 손주와 대화하기).
- 같은 목표를 여러 직종이 각자의 방법으로 돕습니다. 혼자 화장실 가기는 물리치료(이동), 작업치료(옷 내리고 올리기), 간호(배뇨 관리)가 함께합니다.
- 실어증 환자에게 설명할 때는 모든 직종이 같은 방식(짧은 문장, 그림)을 씁니다.

# 사례 4. 아동 천식 가정 관리

## 사례

9세 남아가 최근 한 달 동안 밤에 기침으로 자주 깨고, 체육 시간에 숨이 차서 쉬는 일이 늘었습니다. 흡입기 사용 방법을 정확히 모르고, 집에는 반려견과 카펫이 있으며, 보호자는 맞벌이로 아침 시간이 바쁩니다(가상 사례).

## 팀 과제

1. 학교, 가정, 의료기관 세 장소에서 아이의 천식 관리를 맡을 사람과 직종을 정리합니다.
2. 흡입기 교육을 누가 어떻게 하고, 아이가 제대로 하는지 어떻게 확인할지 정합니다.
3. 집 안 유발 요인을 점검하는 방법과 보호자가 현실적으로 바꿀 수 있는 것을 고릅니다.
4. 학교 보건교사와 담임에게 전달할 정보(악화 신호, 응급 시 행동)를 한 쪽으로 만듭니다.

## 핵심 포인트

| 장소 | 관련 직종 | 할 일 예 |
|---|---|---|
| 의료기관 | 의사, 간호사, 약사 | 진단과 처방, 흡입기 사용법 교육과 확인 |
| 가정 | 보호자, 방문 간호 | 유발 요인 줄이기, 증상 일지 |
| 학교 | 보건교사, 담임, 체육교사 | 악화 신호 알기, 운동 전 준비, 응급 연락 |
| 지역 | 보건소 | 아토피·천식 관리 프로그램 등 지역 자원 연계(지역별 확인) |

아동 사례에서는 아이 본인이 이해할 수 있는 말로 설명하고, 아이가 직접 해 보게 하는 것이 중요합니다. 같은 내용도 보호자용과 아이용 설명을 따로 준비합니다.

# 사례 5. 지역사회 정신건강 위기와 연계

## 사례

32세 여성이 최근 실직 후 두 달째 집 밖에 거의 나가지 않고, 이웃이 며칠째 불이 꺼져 있다며 행정복지센터에 연락했습니다. 방문한 사회복지사에게 "다 끝내고 싶다"는 말을 했습니다(가상 사례).

## 팀 과제

1. 첫 방문에서 사회복지사가 가장 먼저 확인할 것과 혼자 판단하면 안 되는 지점을 정리합니다.
2. 정신건강 전문기관, 보건소, 응급 체계로 연결하는 경로와 기준을 정합니다.
3. 위기가 지난 뒤 생활 안정을 위한 고용, 소득, 주거 지원을 담당 직종별로 나눕니다.
4. 여러 기관이 관여할 때 정보 공유의 범위와 동의 절차를 정합니다.

## 핵심 포인트

- 자살 위험이 의심되면 직접 묻고, 혼자 해결하지 않으며, 기관의 위기 대응 절차와 전문기관 연계를 따릅니다.
- 여러 기관이 함께할 때는 클라이언트의 동의를 받아 필요한 정보만 공유합니다.
- 위기 대응과 생활 지원이 끊기지 않도록 연계 담당자를 한 명 정합니다.
- 위기 상담 전화 등 연계처는 최신 공식 안내로 확인해 둡니다.

# 사례 6. 집에서 지내는 치매 노인과 가족

## 사례

84세 남성이 중등도 치매로 아내(80세)와 둘이 지냅니다. 최근 밤에 집을 나가려 하고, 약을 두 번 먹거나 빠뜨리는 일이 생겼습니다. 아내는 허리 통증이 있고 지쳐 보입니다(가상 사례).

## 팀 과제

1. 환자와 돌보는 가족을 모두 돌봄 대상으로 놓고 문제 목록을 만듭니다.
2. 배회, 복약, 낙상, 영양, 돌봄 부담 각각에 맞는 직종과 서비스를 연결합니다.
3. 아내의 휴식을 보장하는 방법을 계획에 넣습니다.
4. 상태가 나빠질 때 시설 입소나 다른 돌봄으로 바꾸는 시점과 의논 방법을 정합니다.

## 핵심 포인트

| 문제 | 관련 직종 | 계획 예 |
|---|---|---|
| 배회 | 간호, 사회복지 | 배회 위험 평가, 실종 예방 서비스 안내(지자체별 확인) |
| 복약 | 약사, 간호 | 복약 단순화 검토, 약 정리함과 확인 방법 |
| 낙상 | 물리치료, 작업치료 | 야간 조명, 동선 정리, 균형 운동 |
| 돌봄 부담 | 사회복지, 간호 | 주야간보호 등 휴식 지원, 가족 상담 |
| 영양 | 영양사 | 식사 준비 부담을 줄이는 방법, 체중 확인 |

# 팀 확인 퀴즈 예

팀기반학습의 개인·팀 확인 단계에 쓸 수 있는 문항 예입니다. 정답은 아래에 있습니다.

1. 다학제 회의에서 환자 목표를 정할 때 가장 먼저 반영할 것은?
   ① 가장 경력이 긴 직종의 의견 ② 환자와 가족이 원하는 삶 ③ 병원의 재원일수 목표 ④ 가장 빨리 할 수 있는 처치 ⑤ 보험 적용 여부
2. 응급 소생 팀에서 지시를 받은 사람이 지시 내용을 소리 내어 되말하는 것을 무엇이라 하나?
   ① 브리핑 ② 복명복창 ③ 디브리핑 ④ 인수인계 ⑤ 동료 평가
3. 여러 기관이 클라이언트 정보를 공유할 때 원칙으로 옳은 것은?
   ① 모든 기록을 공유한다 ② 동의를 받고 필요한 정보만 공유한다 ③ 구두로는 제한이 없다 ④ 공공기관끼리는 동의가 필요 없다 ⑤ 가족에게는 모두 알린다
4. 같은 환자 목표를 여러 직종이 각자의 방법으로 돕는 예로 알맞은 것은?
   ① 각 직종이 서로 다른 목표를 세운다 ② 혼자 화장실 가기를 물리치료, 작업치료, 간호가 함께 돕는다 ③ 한 직종이 모든 교육을 맡는다 ④ 목표 없이 처치만 한다 ⑤ 퇴원 후 계획은 세우지 않는다

**정답:** 1 ②, 2 ②, 3 ②, 4 ②. 정보 공유의 구체적 기준은 개인정보 관련 법령과 기관 규정으로 확인합니다.

```prompt 팀 확인 퀴즈 만들기
[사례 요약]을 다룰 팀기반학습 수업의 개인·팀 확인 퀴즈 8문항을 5지선다로 만들어 주세요.
- 직종별 역할, 의사소통, 환자 중심 목표, 정보 공유 원칙을 고르게
- 오답 보기는 학생들이 흔히 하는 착각으로
- 정답과 해설은 문항 뒤에 따로
- 법적 업무 범위를 묻는 문항은 확인이 필요하다고 표시
```

# 역할 카드

| 역할 | 회의에서 꼭 말할 것 | 다른 직종에 물을 것 |
|---|---|---|
| 간호사 | 24시간 관찰한 변화, 안전 위험 | 활동 제한과 허용 범위 |
| 물리치료사 | 이동 능력, 근력·균형 평가, 운동 목표 | 통증 조절 시점, 체중 부하 제한 |
| 작업치료사 | 일상생활 동작 수행, 보조도구 필요 | 인지 상태, 퇴원 환경 |
| 언어재활사 | 의사소통 방법, 삼킴 상태 | 식사 형태, 투약 방법 |
| 영양사 | 영양 상태, 식사 형태와 양 | 삼킴 결과, 혈당·전해질 |
| 약사 | 약물 상호작용, 복약 단순화 | 신기능, 삼킴 가능 여부 |
| 사회복지사 | 가족, 경제, 지역 자원 | 퇴원 시점, 필요한 돌봄 수준 |
| 방사선사·임상병리사 | 검사 일정과 준비, 결과 전달 | 검사 우선순위, 감염 여부 |

# AI를 회의 진행자로 쓰기

## 다학제 회의에서 생기는 갈등

| 갈등 | 예 |
|---|---|
| 목표 충돌 | 물리치료는 빨리 걷게 하고 싶고, 간호는 낙상이 걱정됨 |
| 정보 불일치 | 직종마다 환자의 기능 수준을 다르게 기록 |
| 역할 겹침 | 같은 교육을 두 직종이 따로 함 |
| 위계 | 일부 직종의 의견이 묻힘 |

## AI 진행자 프롬프트

AI를 중립적인 회의 진행자로 세우면 팀 연습에서 의견을 정리하고 빠진 관점을 짚는 데 도움이 됩니다.

```prompt 다학제 회의 진행자
당신은 다학제 회의의 중립적인 진행자입니다. 아래는 가상 사례와 각 직종 역할을 맡은 팀원의 의견입니다.
[사례와 의견 붙여 넣기]

1. 모두가 동의하는 환자 목표를 한 문장으로 제안해 주세요.
2. 의견이 충돌하는 지점을 표로 정리하고, 각 의견의 근거와 걱정을 공정하게 적어 주세요.
3. 충돌을 줄일 수 있는 절충안 2가지를 제안해 주세요.
4. 회의에서 아직 말하지 않은 직종의 관점이 있으면 질문으로 알려 주세요.
판단은 팀이 하도록 결론을 내리지 마세요.
```

AI의 정리는 회의를 돕는 자료입니다. 결정은 팀이 근거를 따져 내립니다.

# 교수자를 위한 팀기반학습 운영 안내

## 한 차시 운영 예(100분)

| 시간 | 활동 |
|---|---|
| 사전 | 사례와 직종 역할 자료 배포, 예습 |
| 0~15분 | 개인 확인 퀴즈 |
| 15~30분 | 팀 확인 퀴즈와 이의 제기 |
| 30~40분 | 핵심 개념 짧은 설명 |
| 40~80분 | 팀 적용 과제(사례 해결) |
| 80~95분 | 팀별 동시 발표와 토론 |
| 95~100분 | 성찰 질문 안내 |

## 적용 과제 설계 원칙

팀기반학습에서는 적용 과제를 설계할 때 네 가지 원칙(흔히 4S라고 부름)을 씁니다.

| 원칙 | 뜻 |
|---|---|
| 의미 있는 문제 | 실제 현장과 닮은 문제 |
| 같은 문제 | 모든 팀이 같은 문제를 다룸 |
| 구체적 선택 | 팀이 하나의 선택이나 결정을 내리게 함 |
| 동시 발표 | 모든 팀이 같은 순간에 답을 공개해 비교 |

## AI 활용 규칙 예

- 사례와 역할 조사에는 AI를 쓸 수 있으나, 직종 업무 범위와 제도는 공식 자료로 확인한다.
- 팀 결정의 근거는 팀원이 설명할 수 있어야 한다.
- 실제 환자 정보는 쓰지 않는다.

# 통합 퇴원계획서와 포트폴리오

## 통합 퇴원계획서 틀

| 항목 | 내용 |
|---|---|
| 환자 목표 | 환자와 가족의 말로 |
| 현재 상태 | 직종별 핵심 평가 결과 요약 |
| 문제 목록 | 우선순위 순 |
| 직종별 계획 | 담당, 내용, 기간 |
| 교육 | 누가, 무엇을, 어떻게 확인할지 |
| 지역사회 연계 | 기관, 연락 방법, 전달할 정보 |
| 추적 | 다음 확인 시점과 담당 |

```prompt 퇴원계획서 점검
아래는 우리 팀이 쓴 통합 퇴원계획서입니다.
[붙여 넣기]
1. 환자 목표와 직종별 계획이 연결되지 않는 곳
2. 담당이 정해지지 않은 할 일
3. 같은 일을 두 직종이 겹쳐 하는 곳
4. 환자와 가족이 이해하기 어려운 표현
을 표로 알려 주세요. 계획서를 대신 쓰지는 마세요.
```
