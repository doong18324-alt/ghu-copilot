# 이 시리즈로 무엇을 배우나

## AI를 배워야 하는 이유

보건의료와 복지 현장은 빠르게 디지털로 바뀌고 있습니다. 병원은 전자의무기록과 영상 분석 AI를 쓰고, 복지 현장은 사례관리 시스템을, 행정 부서는 문서 자동화 도구를 씁니다. 졸업 후 일하게 될 현장에서 AI는 특별한 기술이 아니라 매일 쓰는 도구가 됩니다.

그렇다고 모두가 AI 개발자가 될 필요는 없습니다. 보건계열 학생에게 필요한 것은 세 가지입니다.

- **잘 묻는 능력:** 원하는 결과를 얻도록 AI에게 상황과 조건을 분명히 알려 주는 능력
- **판단하는 능력:** AI 답이 맞는지 전공 지식으로 확인하는 능력
- **지키는 능력:** 환자 정보와 개인정보를 보호하고 정직하게 쓰는 능력

이 시리즈는 이 세 가지를 단계별로 익히도록 구성했습니다.

# 대표 AI 도구

## 도구별 특징

생성형 AI 도구는 여러 가지가 있고 기능이 자주 바뀝니다. 아래는 학생이 많이 쓰는 도구의 일반적인 특징이며, 요금제와 기능은 각 서비스의 최신 안내를 확인합니다.

| 도구 | 잘하는 것 | 학생 활용 예 |
|---|---|---|
| ChatGPT | 대화형 질의응답, 글쓰기, 이미지 생성, 파일 분석 | 개념 설명, 글 다듬기, 발표 준비 |
| Gemini | 구글 서비스와의 연결, 검색 기반 답변 | 자료 찾기, 구글 문서 작업 |
| Claude | 긴 문서 읽기, 정리된 글쓰기, 코드 | 긴 교재 요약, 보고서 구조 잡기 |
| NotebookLM | 올린 자료 안에서만 답하기, 출처 표시, 음성 요약 | 교재·강의 자료 기반 복습 |
| 클로바노트 | 음성을 글로 바꾸기 | 강의 녹음 정리(교수 허락 필요) |

## 어떤 도구를 쓸까

| 하고 싶은 일 | 알맞은 방식 |
|---|---|
| 교재 내용을 정확히 복습 | 교재 범위를 올리고 그 안에서만 답하게 하는 도구(NotebookLM 등) |
| 개념을 쉽게 이해 | 대화형 도구에 학년과 수준을 알려 주고 설명 요청 |
| 최신 정보 확인 | 검색 기능이 있는 도구로 찾고, 출처 원문을 직접 열어 확인 |
| 보고서 구조 잡기 | 대화형 도구로 목차와 논리 흐름 점검 |
| 발표 연습 | 대화형 도구에 심사위원 역할을 맡겨 질문 받기 |

어떤 도구를 쓰든 답이 맞는지는 스스로 확인해야 합니다.

# 첫날 해 볼 일

## 30분 시작하기

1. **계정 만들기:** 학교가 안내하는 도구가 있으면 그 도구를 먼저 씁니다. 개인 계정을 만들 때는 비밀번호를 다른 서비스와 다르게 하고 2단계 인증을 켭니다.
2. **설정 확인:** 대화 내용이 모델 개선에 쓰이는지 설정에서 확인합니다.
3. **첫 질문:** 아래 프롬프트를 그대로 입력해 봅니다.

```prompt 첫 질문 연습
저는 [학과] [학년] 학생입니다. 이번 학기에 [과목명]을 듣고 있습니다.
이 과목에서 가장 중요한 개념 5가지를 고르고, 각 개념을 고등학생도 이해할 수 있는 말로 두 문장씩 설명해 주세요.
마지막에 제가 이해했는지 확인할 질문 3개를 내 주세요. 답은 제가 먼저 말한 뒤 보여 주세요.
```

4. **확인:** AI가 설명한 개념 가운데 하나를 골라 교재에서 같은 내용을 찾아봅니다. 표현이 다르거나 틀린 곳이 있는지 봅니다.

# 학교에서 지킬 규칙

## 수업마다 규칙이 다릅니다

과목마다 AI 사용 허용 범위가 다릅니다. 강의계획서의 AI 활용 안내를 확인합니다.

| 유형 | 뜻 | 할 일 |
|---|---|---|
| 조건부 허용 | 아이디어, 요약, 문장 교정 등 일부만 허용 | 허용 범위 안에서 쓰고 사용 사실 표기 |
| 적극 활용 | 과제 전 과정에서 활용 가능 | 검증 기록과 출처 표기 제출 |
| 사용 금지 | 과제와 퀴즈에서 쓰면 안 됨 | 쓰지 않음 |

## 절대 넣으면 안 되는 정보

- 실습에서 만난 환자의 이름, 등록번호, 진단, 기록, 사진
- 다른 학생과 교직원의 이름, 학번, 연락처
- 본인의 주민등록번호, 계좌번호, 비밀번호
- 시험 문제(시험 중이거나 공개 전)

## 정직하게 쓰기

- AI가 쓴 글을 그대로 내 과제로 내지 않습니다.
- AI를 썼다면 어디에 어떻게 썼는지 밝힙니다.
- AI가 알려 준 출처는 실제로 있는지 확인합니다.

!!! 시작하기 전에 확인합니다
- 강의계획서에서 과목별 AI 사용 규칙을 확인했다
- 입력하면 안 되는 정보를 알고 있다
- 계정 보안 설정(비밀번호, 2단계 인증)을 마쳤다
- AI 답을 교재로 한 번 확인해 보았다
- 다음에 읽을 매뉴얼을 정했다
