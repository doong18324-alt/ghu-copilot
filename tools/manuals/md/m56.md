# 응급구조와 AI

## 응급구조사의 일과 AI가 닿는 곳

응급구조사는 병원 밖 현장과 이송 과정, 응급실에서 응급환자를 평가하고 처치하며 이송합니다. 짧은 시간에 정확하게 판단하고 정해진 절차를 몸에 익혀 수행하는 것이 핵심입니다. 생성형 AI는 현장 처치를 대신할 수 없지만, 다양한 상황을 만들어 판단을 반복 연습하게 하고, 보고와 인계를 연습시키고, 시민 교육 자료를 만드는 데 도움을 줍니다.

| 영역 | AI가 돕는 부분 | 응급구조사가 판단할 부분 |
|---|---|---|
| 시나리오 훈련 | 다양한 환자 상황, 상태 변화 단계 | 처치의 순서와 적절성 |
| 현장 판단 연습 | 가상 출동 상황의 정보 제시 | 현장 안전, 중증도 판단 |
| 보고·인계 | 무전 보고, 병원 인계 문장 연습 | 실제 정보의 정확성 |
| 시민 교육 | 심폐소생술·응급처치 교육 대본 | 최신 지침과의 일치 |
| 국가시험 | 개념 정리, 연습 문항 | 정답 근거 |

## 원칙

- **최신 지침이 기준입니다.** 심폐소생술과 응급처치 기준은 주기적으로 개정됩니다. AI는 개정 전 기준을 말할 수 있으므로 반드시 최신 한국 심폐소생술 지침과 교재로 확인합니다.
- **업무 범위를 확인합니다.** 1급과 2급 응급구조사의 업무 범위는 응급의료에 관한 법령에 정해져 있습니다. AI가 제시한 처치가 업무 범위 안인지 법령 원문으로 확인합니다.
- **실제 출동 기록은 넣지 않습니다.** 현장실습에서 본 환자 정보와 출동 기록은 AI에 넣지 않습니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 전문응급처치학 | 정해진 시나리오 반복 | AI로 조건이 다른 시나리오를 많이 만들어 판단 연습, 교수진 검토 | 상황 판단 |
| 응급환자 평가 | 체크리스트 암기 | AI 가상 환자와 문답으로 1차·2차 평가 연습 | 체계적 평가 |
| 재난관리 | 강의 | AI로 다수 사상자 상황을 만들어 중증도 분류 연습 | 중증도 분류 |
| 응급의료 통신 | 무전 연습 | AI로 보고문 평가와 개선 | 간결한 보고 |
| 응급처치 교육론 | 교안 작성 | 대상별 교육 대본을 AI로 만들고 지침으로 검증 | 교육 설계 |

# 교수자용 수업 활동

## 활동 1. 시나리오 생성과 검토

```prompt 프롬프트 1. 훈련 시나리오
응급구조학과 시뮬레이션 훈련용 시나리오를 써 주세요.
주제: [예: 고령 환자의 낙상 후 의식 변화]
구성: 출동 정보(신고 내용), 현장 도착 시 상황, 환자 초기 상태, 학생 행동에 따른 상태 변화 2갈래, 기대 행동 목록, 디브리핑 질문 5개.
지킬 것: 약물 용량과 처치 수치는 [지침 확인]으로 표시합니다. 응급구조사 업무 범위를 넘는 처치를 기대 행동에 넣지 마세요.
```

교수진은 시나리오의 의학적 타당성, 업무 범위, 안전을 검토한 뒤 훈련에 씁니다.

## 활동 2. 다수 사상자 중증도 분류

```prompt 프롬프트 2. 분류 연습 카드
다수 사상자 사고 중증도 분류 연습용 환자 카드 12장을 만들어 주세요.
카드마다 보행 가능 여부, 호흡, 맥박 또는 순환 상태, 의식 반응을 짧게 적습니다. 교수용으로 수업에서 쓰는 분류 체계에 따른 정답 분류를 따로 적되, 분류 체계 이름은 [수업 기준]으로 두세요.
```

수업에서 쓰는 분류 체계(교재와 공식 지침)를 기준으로 교수자가 정답을 확인한 뒤 씁니다.

# 학생용 실습 프롬프트

## 1차 평가 연습

```prompt 프롬프트 3. 가상 환자 평가 문답
당신은 응급 현장의 가상 환자 상황을 알려 주는 진행자입니다. 상황은 [예: 공사 현장 추락 환자]입니다.
제가 평가 순서대로 질문하면 그 항목의 소견만 알려 주세요. 제가 묻지 않은 정보는 먼저 알려 주지 마세요.
제가 "평가 끝"이라고 하면, 제 평가 순서에서 빠지거나 늦은 항목을 알려 주세요. 판단 기준은 교재의 평가 순서를 따른다고 밝혀 주세요.
```

## 무전 보고와 인계

```prompt 프롬프트 4. 인계 보고 평가
아래 가상 상황을 보고 제가 병원 인계 보고를 쓰겠습니다. 제 보고를 평가해 주세요.
[가상 상황]
[제 보고]
기준: 30초 안에 말할 수 있는가, 환자 나이·주호소·주요 소견·시행 처치·변화가 순서대로 있는가, 불필요한 말이 없는가.
고친 예시를 보여 주되 상황에 없는 정보는 추가하지 마세요.
```

## 시민 교육 대본

```prompt 프롬프트 5. 심폐소생술 교육 대본
[대상, 예: 초등학교 5학년]에게 20분 동안 할 가슴압박 소생술 교육 대본을 써 주세요.
포함: 왜 배우는지, 쓰러진 사람 발견 시 순서, 가슴압박 위치와 방법, 자동심장충격기 사용 안내, 실습 진행 방법.
압박 깊이, 속도 같은 수치는 [최신 지침 확인]으로 표시해 주세요.
```

# 지침과 법령으로 검증하기

| 영역 | 확인할 것 | 대조 자료 |
|---|---|---|
| 심폐소생술 | 순서, 압박 깊이·속도, 인공호흡 비율 | 최신 한국 심폐소생술 지침 |
| 업무 범위 | 1급·2급 응급구조사가 할 수 있는 처치 | 응급의료에 관한 법률 시행규칙 원문 |
| 외상 처치 | 지혈, 고정, 척추 보호 기준 | 교재, 최신 지침 |
| 중증도 분류 | 분류 기준 | 교재, 공식 지침 |
| 약물 | 사용 가능 약물과 투여 기준 | 법령, 교재, 의료지도 지침 |

!!! 응급구조 AI 결과물을 쓰기 전에 확인합니다
- 실제 출동·환자 정보를 AI에 넣지 않았다
- 처치 순서와 수치를 최신 지침으로 확인했다
- 응급구조사 업무 범위를 법령 원문으로 확인했다
- 시나리오는 교수진의 안전 검토를 거쳤다
- 시민 교육 자료가 최신 지침과 같다
