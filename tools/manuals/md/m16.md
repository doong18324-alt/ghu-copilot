# 질문의 수준이 이해의 깊이를 정합니다

## 같은 개념, 다른 질문

간경변 환자의 복수(배에 물이 차는 것)를 공부하는 두 학생이 있습니다.

| 학생 | 질문 | 얻은 것 |
|---|---|---|
| A | 간경변 복수 정리해 줘 | 원인, 증상, 치료가 나열된 요약 |
| B | 간이 굳으면 왜 배에 물이 차나요? 알부민이 낮아지는 것과 문맥압이 올라가는 것은 각각 어떤 역할을 하나요? 그러면 이뇨제를 쓸 때 무엇을 조심해야 하나요? | 기전에서 치료와 간호까지 이어지는 이해 |

A 학생의 요약은 시험 직전에 훑어보기는 좋지만, "이 환자에게 이뇨제를 쓸 때 관찰할 것은?" 같은 응용 문제를 만나면 막힙니다. B 학생은 질문을 이어 가며 개념 사이의 연결을 스스로 만들었습니다.

## 왜 질문하며 공부하면 오래 남나

"왜 그런가", "어떻게 그렇게 되나"를 묻고 답하는 과정에서 새 지식이 이미 아는 지식과 연결됩니다. 학습과학에서는 이를 정교화(elaborative interrogation)라고 부르며, 단순히 다시 읽는 것보다 이해와 기억에 도움이 된다는 연구가 많습니다. AI는 지치지 않는 질문 상대이므로 혼자서도 이 공부를 할 수 있게 해 줍니다.

# 5단계 꼬리 질문

## 질문 사다리

| 단계 | 묻는 것 | 질문 예(쇼크) |
|---|---|---|
| 1. 정의 | 무엇인가 | 쇼크란 무엇인가요? |
| 2. 기전 | 왜, 어떻게 생기나 | 혈압이 떨어지면 왜 장기가 손상되나요? |
| 3. 적용 | 실제 상황에서는 어떻게 보이나 | 쇼크 초기 환자에게서 무엇을 관찰할 수 있나요? |
| 4. 예외와 비교 | 언제 다르게 나타나나 | 패혈성 쇼크 초기에는 왜 피부가 따뜻할 수 있나요? |
| 5. 연결 | 다른 개념과 어떻게 이어지나 | 쇼크의 보상 반응은 자율신경계와 어떻게 연결되나요? |

1단계에서 멈추면 외운 지식, 3단계까지 가면 쓸 수 있는 지식, 5단계까지 가면 연결된 지식이 됩니다.

## 대화 진행 프롬프트

```prompt 5단계 꼬리 질문 진행
저는 [학과, 학년]이고 [개념]을 공부하고 있습니다.
당신은 소크라테스식 질문을 하는 튜터입니다. 다음 규칙으로 대화해 주세요.
- 정의, 기전, 적용, 예외와 비교, 연결의 순서로 한 번에 한 질문만 합니다.
- 제가 답하면 맞은 부분과 부족한 부분을 짧게 짚고, 부족하면 힌트를 준 뒤 다시 답할 기회를 줍니다.
- 정답을 먼저 알려 주지 않습니다.
- 5단계가 끝나면 제가 잘 이해한 것과 다시 볼 것을 정리해 줍니다.
첫 질문을 시작해 주세요.
```

이 방식에서는 AI가 질문하고 내가 답합니다. 반대로 내가 질문하고 AI가 답하는 방식도 있습니다. 처음 배우는 개념은 내가 질문하는 방식으로 이해를 넓히고, 복습할 때는 AI가 질문하는 방식으로 확인하면 좋습니다.

# "왜"를 거슬러 올라가기

## 역추적 질문

현상 하나에서 출발해 "왜"를 세 번 정도 거슬러 올라가면 근본 원리에 닿습니다.

> 현상: 이뇨제를 쓰는 심부전 환자의 칼륨을 확인한다.
> 왜 1: 일부 이뇨제는 소변으로 칼륨을 많이 내보내기 때문이다.
> 왜 2: 그 이뇨제가 작용하는 세뇨관 부위에서 나트륨 재흡수가 줄면 뒤쪽 부위에서 칼륨 분비가 늘어나기 때문이다.
> 왜 3: 칼륨이 낮아지면 심장의 전기적 안정성이 흔들려 부정맥 위험이 커지기 때문이다.

마지막 "왜"에서 신장 생리와 심장 전기생리가 만납니다. 이렇게 연결되면 "디곡신을 함께 쓰는 환자에서 저칼륨혈증을 특히 조심하는 이유" 같은 응용 문제도 풀 수 있습니다.

```prompt 왜 역추적
[현상이나 간호·치료 행위: 예, 이뇨제를 쓰는 환자의 칼륨을 확인한다]
이 현상에서 출발해 "왜"를 세 번 거슬러 올라가는 연습을 하려고 합니다.
제가 먼저 "왜 1"에 답하겠습니다. 제 답을 평가하고 다음 "왜"를 물어 주세요.
세 번이 끝나면 전체 사슬을 정리하고, 사슬에서 틀린 연결이 있었다면 짚어 주세요.
```

# 좋은 질문을 만드는 요령

## 질문 틀

| 틀 | 예 |
|---|---|
| A는 왜 B를 일으키나요? | 염증은 왜 열을 일으키나요? |
| A와 B는 무엇이 다른가요? | 좌심부전과 우심부전의 증상 차이는 어디서 오나요? |
| A가 없으면 어떻게 되나요? | 인슐린이 없으면 지방 대사는 어떻게 바뀌나요? |
| A가 예외인 경우는 언제인가요? | 혈압이 정상인데 쇼크일 수 있나요? |
| A를 환자에게 어떻게 설명하나요? | 와파린 복용 환자에게 녹색 채소 이야기를 어떻게 하나요? |
| A를 알면 B를 예측할 수 있나요? | 신장 기능이 떨어지면 어떤 약의 용량을 조정해야 할지 예측할 수 있나요? |

## 질문할 때 넣을 것

- 내가 지금 알고 있는 것: "교재에서 A라고 배웠는데"
- 내가 헷갈리는 지점: "B와 어떻게 다른지 모르겠습니다"
- 원하는 깊이: "국가시험 수준으로", "기전까지"

## AI 답을 확인하는 질문

AI가 그럴듯하게 설명해도 틀릴 수 있습니다. 다음 질문을 덧붙이면 확인할 거리가 생깁니다.

- "방금 설명 가운데 교재나 지침에서 확인해야 할 부분은 어디인가요?"
- "이 설명이 틀릴 수 있는 예외 상황이 있나요?"
- "같은 내용을 다르게 설명하는 관점이 있나요?"

# 대화 예: 간경변과 복수

## 진행 요약

| 단계 | AI 질문 | 학생 답의 핵심 | AI 피드백 |
|---|---|---|---|
| 정의 | 복수란 무엇인가요? | 복강에 액체가 고인 것 | 맞음 |
| 기전 | 간경변에서 복수가 생기는 이유는? | 알부민이 줄어서 | 일부 맞음. 문맥압 상승도 중요한 원인임을 힌트 |
| 기전(재답) | 문맥압이 오르면 어떻게 되나요? | 혈관 안 압력이 높아 액체가 밖으로 밀려남 | 맞음. 두 원인을 함께 정리 |
| 적용 | 복수 환자를 어떻게 관찰하나요? | 복부 둘레, 체중 | 맞음. 섭취·배설량과 호흡 상태 추가 |
| 예외·비교 | 이뇨제를 쓸 때 조심할 점은? | 탈수 | 일부 맞음. 전해질 이상과 신기능도 확인 |
| 연결 | 이 내용은 어느 단원과 이어지나요? | 신장, 체액 | 맞음. 간성뇌증과의 연결도 제시 |

표는 대화가 어떻게 흐르는지 보여 주는 예입니다. 실제 공부에서는 AI가 정리한 내용을 교재와 대조합니다.

# 대화 후 1분 정리

## 질문 기반 요약

긴 대화는 시간이 지나면 흐려집니다. 대화가 끝나면 1분 안에 다음 세 줄을 내 손으로 씁니다.

1. **오늘 답하지 못했던 질문:**
2. **지금은 답할 수 있는 내용(내 말로):**
3. **아직 남은 질문:**

남은 질문은 다음 공부 시간의 첫 질문이 됩니다.

```prompt 대화 정리 점검
오늘 [개념]에 대해 꼬리 질문 대화를 했습니다. 아래는 제가 쓴 1분 정리입니다.
[세 줄 붙여 넣기]
제 요약에서 틀린 부분이 있으면 짚어 주시고, 남은 질문에 답할 때 볼 교재 범위를 알려 주세요.
```

# 질문 수준을 스스로 점검하기

## 질문 기록 분석

한 주 동안 AI에게 한 질문을 모아 수준별로 나누어 봅니다. 정의 질문만 많다면 기전과 적용 질문을 의식적으로 늘립니다.

```prompt 내 질문 분석
아래는 이번 주 제가 AI에게 한 공부 질문 목록입니다.
[질문 목록]
질문을 정의, 기전, 적용, 예외·비교, 연결 다섯 수준으로 분류해 개수를 세고, 수준이 낮은 질문 3개를 더 깊은 질문으로 바꾼 예를 보여 주세요.
```

# 자주 묻는 질문

**AI가 질문만 하고 답을 안 주니 답답합니다.**
처음에는 답답할 수 있지만, 스스로 답을 꺼내는 과정이 기억을 강하게 합니다. 두 번 막히면 힌트를, 세 번 막히면 정답을 달라고 규칙을 정해 두면 덜 답답합니다.

**꼬리 질문을 하다 보면 범위를 벗어납니다.**
시험 범위를 처음에 알려 주고 "범위를 벗어나면 알려 달라"고 조건을 넣습니다.

# 자가진단과 자주 하는 실수

## 질문 대화 자가진단

!!! 내 질문 대화를 점검합니다
- 정의에서 멈추지 않고 기전과 적용까지 질문했다
- 내가 먼저 답하고 피드백을 받았다
- "왜"를 세 번 거슬러 올라가 보았다
- AI 설명에서 확인할 부분을 물었다
- 대화 후 1분 정리를 내 손으로 썼다

## 자주 하는 실수

| 실수 | 고치는 방법 |
|---|---|
| AI가 질문하자마자 정답을 물어봄 | 먼저 틀려도 답해 보기. 힌트 요청 |
| 한 대화에 여러 개념을 섞음 | 개념 하나에 대화 하나 |
| 대화를 길게 하고 정리 안 함 | 1분 정리로 마무리 |
| AI 설명을 확인 없이 외움 | 교재와 대조, 확인 질문 덧붙이기 |
| 쉬운 질문만 반복 | 질문 틀 표에서 다른 유형 골라 쓰기 |
