# 학과 행정 문서와 AI

## 교수자가 쓰는 행정 문서

교수자는 강의와 연구 외에도 학과 운영에 필요한 문서를 꾸준히 씁니다. 특강을 하나 열려면 계획서, 강사 섭외 공문, 안내문, 결과보고서가 필요하고, 산학협력위원회를 열면 회의록과 후속 조치 문서가 따라옵니다. 이런 문서는 형식이 정해져 있고 내용이 반복되기 때문에 생성형 AI가 가장 큰 도움을 주는 영역입니다.

| 문서 | 주로 쓰는 시점 | AI가 돕는 부분 |
|---|---|---|
| 특강·견학 계획서 | 행사 2~4주 전 | 추진 목적, 운영 개요 표, 기대 효과 문장 |
| 강사 섭외·협조 공문 | 행사 3주 전 | 격식 있는 서한 문안 |
| 학생 안내문 | 행사 1~2주 전 | 짧고 분명한 공지, 카드뉴스 문구 |
| 결과보고서 | 행사 직후 1주 이내 | 개조식 정리, 만족도 결과 요약, 환류 방안 |
| 위원회 회의록 | 회의 직후 | 녹취 정리, 결정 사항과 실행 과제 표 |
| 교육과정 개편 보고서 | 학기 말·연말 | 개편 근거 정리, 교과목 변경 대비표 |
| 업무협약 관련 서한 | 협약 추진 시 | 제안 서한, 초청장, 보도 문안 |

## 보안 기준

학과 행정 문서에는 개인정보와 내부 정보가 섞이기 쉽습니다. AI에 입력하기 전에 다음을 확인합니다.

| 입력하지 않는 정보 | 대신 넣는 방법 |
|---|---|
| 교직원·학생 주민등록번호, 계좌번호, 연락처 | 아예 빼고 최종 문서에서 직접 기입 |
| 미확정 인사 정보 | 다루지 않음 |
| 공개 전 예산 세부 단가, 입찰 정보 | 총액 수준만 쓰거나 [금액]으로 표시 |
| 학생 성적, 상담 내용 | 다루지 않음 |
| 외부 기관의 비공개 내부 자료 | 공개된 정보만 사용 |

행사 개요, 공개된 일정표, 회의 안건 요약, 안내문 초안은 안전하게 다룰 수 있습니다.

# 대학 행정 문체

## 개조식 문체의 원칙

대학 내부 결재 문서는 대부분 개조식으로 씁니다. 문장을 끝까지 서술하지 않고 핵심어로 끝맺어 읽는 사람이 빠르게 훑을 수 있게 합니다.

| 원칙 | 서술식 | 개조식 |
|---|---|---|
| 명사형 종결 | 특강을 진행하였습니다 | 특강 운영 |
| 핵심 먼저 | 학생들의 반응이 좋았으며 만족도가 높게 나왔습니다 | 만족도 4.6점(5점 척도), 참여 학생 62명 |
| 한 항목 한 내용 | 장소는 본관이고 시간은 2시이며 대상은 2학년입니다 | 일시: …, 장소: …, 대상: … |
| 수치는 단위와 함께 | 많은 학생이 참여 | 재학생 62명(재적 대비 78%) |

종결은 "~함", "~임", "~예정", "~추진"처럼 씁니다. 다만 대외 공문과 학생 안내문은 개조식이 아니라 정중한 서술식으로 씁니다.

## 숫자와 날짜 표기

- 날짜: 2026. 11. 20.(금) 14:00~16:00
- 금액: 1,500,000원 또는 150만 원(문서 안에서 하나로 통일)
- 비율: 소수점 한 자리까지, 분모를 함께 표시
- 기간: 2026. 11. 1.~11. 30.

학교마다 세부 표기 규정이 다를 수 있으므로, 교무처나 기획처의 최근 결재 문서를 하나 골라 형식 기준으로 삼습니다.

# 행사 계획서와 결과보고서

## 계획서

```prompt 프롬프트 1. 학과 행사 계획서
역할: 당신은 대학 학과 행정 문서 작성을 돕는 담당자입니다.

아래 메모로 학과 내부 결재용 [행사명] 계획서를 개조식으로 작성해 주세요.

메모:
- 주관: [학과명]
- 일시·장소: [ ]
- 대상·예상 인원: [ ]
- 강사·기관: [이름 대신 소속과 직위만, 예: 지역 종합병원 재활의학과 물리치료팀장]
- 목적과 배경: [한두 줄]
- 소요 예산: [총액과 항목, 단가는 제외 가능]
- 연계 교과목·사업: [ ]

구성:
1. 추진 목적(2~3개 항목)
2. 운영 개요(표: 일시, 장소, 대상, 내용, 주관)
3. 세부 운영 계획(시간표)
4. 소요 예산(표: 항목, 금액, 산출 근거)
5. 기대 효과(정량·정성 구분)
6. 행정 사항(홍보, 안전, 만족도 조사)

지킬 것: 제가 주지 않은 수치나 기관명은 만들지 말고 [ ]로 남겨 주세요.
```

## 결과보고서

결과보고서는 계획서와 짝을 이룹니다. 계획 대비 실적을 비교하는 표가 들어가면 보고서의 설득력이 커집니다.

```prompt 프롬프트 2. 결과보고서
아래 계획서와 실제 운영 메모로 결과보고서를 개조식으로 작성해 주세요.
[계획서 붙여 넣기]
[운영 메모: 실제 참여 인원, 진행 내용, 만족도 조사 결과, 참여자 의견 요약, 집행 예산]

구성:
1. 추진 개요
2. 계획 대비 실적(표: 항목, 계획, 실적, 달성률)
3. 주요 운영 내용과 성과(정량 성과, 정성 성과 구분)
4. 만족도 조사 결과(문항별 평균, 주요 의견 3가지)
5. 개선점과 환류 방안(교과·비교과 연계 방향 포함)
6. 예산 집행 내역

계산이 필요한 달성률과 평균은 계산 과정을 표 아래에 따로 적어 주세요. 제가 직접 검산하겠습니다.
```

> AI는 표 안의 계산을 자주 틀립니다. 달성률, 평균, 합계는 AI가 보여 준 계산 과정을 따라 계산기나 엑셀로 반드시 다시 계산합니다. 바이탈의 **보도자료·공지·회의록·결과보고서 작성 앱(결과보고서 모드)**는 계획 수치와 실적 수치를 넣으면 달성률을 직접 계산해 줍니다.

## 만족도 조사 결과 정리

주관식 응답이 수십 개 있으면 AI가 주제별로 묶는 데 도움이 됩니다.

```prompt 프롬프트 3. 주관식 응답 묶기
아래는 행사 만족도 조사의 주관식 응답입니다(개인정보 없음).
[응답 목록]

1. 응답을 4~6개 주제로 묶고, 주제마다 응답 개수와 대표 응답 2개(원문 그대로)를 적어 주세요.
2. 개선 요구가 담긴 응답만 따로 모아 주세요.
3. 개수는 응답을 실제로 세어서 적고, 하나의 응답이 두 주제에 걸치면 두 번 세었다고 표시해 주세요.
```

# 회의록

## 녹취에서 회의록까지

학과 회의나 산학협력위원회는 참석자 동의를 받고 녹음한 뒤 클로바노트 같은 음성 기록 도구로 글로 바꾸면 정리 시간이 크게 줄어듭니다. 녹취록을 AI에 넣기 전에 참석자 이름을 직위나 역할로 바꿉니다.

```prompt 프롬프트 4. 위원회 회의록
아래 회의 녹취록(참석자 이름은 역할로 바꿈)을 대학 위원회 회의록 양식으로 정리해 주세요.
[녹취록]

구성:
1. 회의 개요: 회의명, 일시, 장소, 참석(역할), 안건
2. 안건별 논의 요약: 핵심 의견만, 발언자 역할 표시
3. 의결 사항: 합의된 결론을 문장으로
4. 실행 과제: 표(과제, 담당, 기한)
5. 다음 회의 안건

지킬 것:
- 녹취록에 없는 결정을 만들지 않습니다.
- "검토하기로 함"처럼 결론이 아닌 것은 의결 사항이 아니라 실행 과제로 둡니다.
- 담당이나 기한이 녹취록에 없으면 [미정]으로 둡니다.
```

회의록 작성과 실행 과제 관리는 「위원회·부서 회의록 구조화 및 실행 과제 추출 가이드」에서 더 자세히 다룹니다.

# 교육과정 개편 보고서

## 개편 보고서의 구조

교육과정 개편 보고서는 "왜 바꾸는가"를 근거로 설명하는 문서입니다. 근거가 약하면 심의에서 수정 요구를 받습니다. 일반적인 구성은 다음과 같습니다.

1. 개편 배경: 산업 수요 변화, 직무 분석, 이전 교육과정 운영 결과
2. 수요 조사 결과: 재학생, 졸업생, 산업체 의견
3. 개편 방향: 학과 교육목표와 인재상, 핵심역량
4. 교과목 변경 내역: 신설, 폐지, 통합, 학점 변경 대비표
5. 역량-교과목 연계표
6. 기대 효과와 운영 계획

## AI 활용 지점

| 단계 | AI 활용 | 교수자가 할 일 |
|---|---|---|
| 수요 조사 분석 | 주관식 응답 주제 분류, 요약 | 원자료 확인, 수치 검산 |
| 직무 분석 정리 | 공개된 직무 자료를 표로 정리 | 직무 자료 출처 확인 |
| 교과목 대비표 | 신구 교과목 비교표 작성 | 학점·시수 정확성 확인 |
| 역량 연계표 | 교과목별 역량 연결 초안 | 학과 합의 내용으로 수정 |
| 문장 다듬기 | 개조식 정리, 중복 제거 | 학교 공식 용어 사용 확인 |

```prompt 프롬프트 5. 교과목 변경 대비표
아래 기존 교육과정과 개편안을 비교해 변경 대비표를 만들어 주세요.
[기존 교과목 목록: 학년, 학기, 교과목명, 이수구분, 학점]
[개편안 교과목 목록: 같은 형식]

표 열: 구분(신설·폐지·통합·변경·유지), 기존 교과목, 개편 교과목, 학점 변화, 비고.
표 아래에 학년별 총 학점 변화와 이수구분별 학점 합계를 기존·개편으로 비교해 주세요.
제가 주지 않은 변경 사유는 쓰지 말고 비고 칸을 비워 두세요.
```

# 대외 서한과 공문

## 실습기관·산업체 협조 요청

외부 기관에 보내는 문서는 정중함과 명확함이 함께 필요합니다. 상대가 무엇을, 언제까지, 어떻게 회신하면 되는지가 한눈에 보여야 합니다.

```prompt 프롬프트 6. 협조 요청 서한
[수신: 예) 지역 종합병원 재활의학과 실습 담당자]에게 보낼 [목적: 2027학년도 1학기 임상실습 사전 협의 간담회 초청] 서한을 작성해 주세요.

포함할 내용: 인사, 간담회 목적, 일시·장소, 주요 협의 안건 3가지, 회신 방법과 기한, 담당 교수 연락처 자리 [ ].
어조: 보건의료 현장 기관에 대한 존중이 드러나는 격식 있는 서한체. A4 한 쪽 이내.
```

## 업무협약 관련 문서

업무협약은 제안 서한, 협약서 초안, 협약식 안내, 보도자료로 이어집니다. 협약서 본문은 법적 효력이 있는 문서이므로 AI 초안을 그대로 쓰지 않고 학교의 표준 협약서 양식과 담당 부서 검토를 거칩니다. AI는 협약 목적과 협력 분야를 정리하는 문장, 협약식 안내문, 보도자료 초안에 주로 활용합니다. 보도자료 작성은 「입시·학사·장학 공지사항 및 카드뉴스·보도자료 작성 가이드」를 참고합니다.

!!! 결재 상신 전에 확인합니다
- AI 입력 자료에 개인정보와 비공개 예산 단가가 없었다
- 날짜, 요일, 시간, 장소를 학사력과 예약 내역으로 확인했다
- 인원, 금액, 달성률, 평균을 직접 다시 계산했다
- 기관명, 직위, 사업명을 공식 명칭으로 썼다
- 녹취록에 없는 결정이 회의록에 들어가지 않았다
- 학교 결재 문서 양식(번호 체계, 표기)에 맞췄다
- 외부 발송 문서는 학과장 또는 담당 부서의 검토를 거쳤다

# 바이탈에서 이어서 하기

- **보도자료·공지·회의록·결과보고서 작성 앱:** 보도자료, 회의록, 결과보고서 세 가지 모드가 있습니다. 회의록 모드는 메모에서 결정 사항과 할 일(담당, 기한)을 뽑아 표로 정리하고, 결과보고서 모드는 계획 대비 실적 달성률을 계산합니다.
- **프롬프트 라이브러리 3-1~3-3, 3-9:** 추진계획 기안, 결과보고서, 회의록, 예산 산출 근거 프롬프트를 입력칸 방식으로 씁니다.
- **입시 홍보 스튜디오:** 학과 홍보 영상과 게시글을 기획할 때 씁니다.
