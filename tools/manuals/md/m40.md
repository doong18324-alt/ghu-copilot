# 행정 데이터와 AI

## 무엇을 맡길 수 있는가

행정 직원은 학생 현황, 만족도 조사, 예산 집행, 프로그램 참여 실적처럼 숫자가 많은 자료를 자주 다룹니다. 생성형 AI는 이런 작업에서 세 가지를 잘합니다.

- **수식 만들기:** "A열 학과별로 C열 금액을 더하고 싶다"고 말하면 맞는 함수를 알려 줍니다.
- **글 응답 분류:** 수백 건의 주관식 응답을 주제별로 묶고 대표 응답을 뽑습니다.
- **해석 문장 초안:** 표를 주면 보고서에 넣을 요약 문장과 시사점 초안을 씁니다.

반면 AI가 대화창 안에서 직접 하는 계산은 믿기 어렵습니다. 행 수가 많은 표의 합계, 평균, 비율을 대화창에서 계산시키면 틀리는 경우가 흔합니다. 계산은 엑셀이 하고, AI는 엑셀에서 쓸 수식을 알려 주는 역할을 맡기는 것이 원칙입니다.

## 데이터 보안

| 자료 | AI 입력 |
|---|---|
| 집계된 통계표(학과별 인원, 평균 점수) | 가능 |
| 열 이름과 예시 몇 행(가짜 값으로 바꾼 것) | 가능 |
| 개인정보가 지워진 주관식 응답 | 가능 |
| 학생·교직원 개인별 원자료(이름, 학번, 성적, 연락처) | 불가 |
| 공개 전 예산 세부 내역 | 원칙적으로 불가 |

수식을 물을 때는 실제 데이터가 필요 없습니다. 열 구조만 알려 주면 됩니다.

# 엑셀 수식 묻는 법

## 잘 묻는 방법

AI에게 수식을 물을 때는 시트 구조를 정확히 알려 줘야 합니다.

```prompt 프롬프트 1. 수식 요청
엑셀 수식을 알려 주세요.

시트 구조:
- 시트 이름: 참여명단
- A열: 학번, B열: 학과, C열: 학년, D열: 프로그램명, E열: 참여 시간
- 데이터는 2행부터 500행까지

원하는 결과:
- 다른 시트 '집계'의 A2부터 학과 이름이 있고, B열에 학과별 총 참여 시간을 구하고 싶습니다.

조건: 엑셀 버전은 [Microsoft 365 / 2019 / 2016]입니다. 수식과 함께 각 부분이 무엇을 하는지 한 줄씩 설명해 주세요.
```

엑셀 버전을 알려 주는 이유는 XLOOKUP, FILTER, UNIQUE 같은 함수가 오래된 버전에서는 동작하지 않기 때문입니다.

## 자주 쓰는 함수

| 하고 싶은 일 | 함수 | 예시 |
|---|---|---|
| 조건에 맞는 합계 | SUMIFS | =SUMIFS(참여명단!E:E, 참여명단!B:B, A2) |
| 조건에 맞는 개수 | COUNTIFS | =COUNTIFS(참여명단!B:B, A2, 참여명단!C:C, 2) |
| 조건에 맞는 평균 | AVERAGEIFS | =AVERAGEIFS(만족도!F:F, 만족도!B:B, A2) |
| 다른 표에서 값 찾기 | XLOOKUP | =XLOOKUP(A2, 명부!A:A, 명부!C:C, "없음") |
| 오래된 버전에서 값 찾기 | INDEX와 MATCH | =INDEX(명부!C:C, MATCH(A2, 명부!A:A, 0)) |
| 중복 없이 목록 만들기 | UNIQUE | =UNIQUE(참여명단!B2:B500) |
| 조건에 맞는 행 뽑기 | FILTER | =FILTER(참여명단!A2:E500, 참여명단!C2:C500=1) |
| 오류 대신 빈칸 | IFERROR | =IFERROR(수식, "") |
| 비율 | 나눗셈과 표시 형식 | =B2/C2 후 표시 형식을 백분율로 |

> 위 예시의 시트 이름과 열은 앞의 프롬프트 1 구조를 가정한 것입니다. 실제 파일의 시트 이름과 열에 맞게 바꿉니다.

## 수식 오류 고치기

수식이 오류를 내면 오류 메시지와 수식을 그대로 붙여 넣어 묻습니다.

```prompt 프롬프트 2. 오류 고치기
아래 수식이 #N/A 오류를 냅니다. 원인 후보와 고치는 방법을 알려 주세요.
수식: [수식 붙여 넣기]
상황: [찾는 값과 찾을 범위의 예시 값 2~3개, 형식(숫자인지 글자인지)]
```

흔한 원인은 다음과 같습니다.

| 오류 | 흔한 원인 |
|---|---|
| #N/A | 찾는 값이 없음, 숫자와 글자 형식 불일치, 앞뒤 공백 |
| #VALUE! | 숫자가 들어갈 곳에 글자 |
| #REF! | 참조하던 행이나 열이 삭제됨 |
| #DIV/0! | 0으로 나눔 |
| #SPILL! | 결과가 펼쳐질 칸에 이미 값이 있음 |

학번처럼 숫자로 보이는 글자는 형식 불일치가 잦습니다. TRIM으로 공백을 지우거나, 한쪽 열의 형식을 통일합니다.

# 반복 작업 자동화

## 매크로와 스크립트

매달 같은 형식으로 집계표를 만드는 일은 매크로(VBA)나 Office 스크립트로 자동화할 수 있습니다. AI는 매크로 코드를 써 주지만, 실행 전에 몇 가지를 지킵니다.

- **원본 파일을 복사해 시험합니다.** 매크로는 실행 취소가 되지 않는 경우가 많습니다.
- **코드가 하는 일을 설명받습니다.** "이 코드가 한 줄씩 무엇을 하는지 설명해 주세요"라고 요청하고, 파일 삭제나 외부 전송 같은 동작이 없는지 확인합니다.
- **학교 보안 정책을 확인합니다.** 매크로 실행이 막혀 있는 PC가 있으므로 정보화 담당 부서에 문의합니다.

```prompt 프롬프트 3. 반복 집계 매크로
엑셀 VBA 매크로를 만들어 주세요.

상황: 매달 '원자료' 시트에 새 데이터를 붙여 넣고, 학과별 참여 인원과 총 참여 시간을 '월별집계' 시트에 새 열로 추가합니다.
원자료 구조: A 학번, B 학과, C 프로그램, D 참여일(날짜), E 참여 시간
원하는 동작:
1. 사용자가 입력한 연월(예: 2026-11)의 데이터만 집계
2. 월별집계 시트의 맨 오른쪽 다음 열에 결과 추가, 첫 행에 연월 표시
3. 학과 목록은 월별집계 시트 A열에 이미 있음

조건: 원자료는 수정하거나 지우지 않습니다. 코드 위에 실행 방법을, 코드 안에 짧은 설명을 넣어 주세요.
```

## 피벗 테이블

복잡한 수식보다 피벗 테이블이 나은 경우가 많습니다. 학과별, 학년별, 월별 집계처럼 여러 기준으로 나누어 보는 표는 피벗 테이블로 만들고, AI에게는 "이 목적의 피벗 테이블에서 행, 열, 값, 필터에 무엇을 넣어야 하나요?"라고 묻습니다.

# 주관식 응답 분석

## 분석 절차

만족도 조사나 의견 수렴의 주관식 응답은 읽기만 해도 시간이 오래 걸립니다. AI로 분류할 때는 다음 절차를 따릅니다.

1. **정리:** 응답을 한 줄에 하나씩, 번호를 붙여 정리합니다. 빈 응답과 "없음"은 뺍니다.
2. **개인정보 확인:** 응답 안에 이름이나 연락처가 있으면 지웁니다.
3. **분류 기준 만들기:** 처음 50건 정도로 AI가 주제를 제안하게 하고, 담당자가 기준을 확정합니다.
4. **전체 분류:** 확정한 기준으로 전체를 분류합니다. 많으면 100건씩 나눕니다.
5. **검증:** 무작위로 20건을 골라 담당자가 직접 분류한 결과와 비교합니다.
6. **집계:** 분류 결과를 엑셀로 옮겨 개수를 셉니다. 개수 세기는 AI가 아니라 엑셀이 합니다.

```prompt 프롬프트 4. 분류 기준 만들기
아래는 [조사명] 주관식 응답 가운데 일부입니다(개인정보 없음).
[응답 50건, 번호 포함]

1. 응답을 묶을 수 있는 주제 5~8개를 제안해 주세요.
2. 주제마다 정의 한 줄과 해당하는 응답 번호 예시를 적어 주세요.
3. 어느 주제에도 넣기 어려운 응답 번호를 따로 적어 주세요.
```

```prompt 프롬프트 5. 전체 분류
아래 분류 기준으로 응답을 분류해 주세요.
[확정한 분류 기준: 주제명과 정의]
[응답 100건, 번호 포함]

출력은 표로, 열은 [번호, 주제, 긍정/부정/제안, 핵심 내용 10자 이내]입니다.
한 응답이 두 주제에 해당하면 주된 주제 하나만 고르고, 비고에 다른 주제를 적어 주세요.
응답 원문은 다시 쓰지 마세요.
```

표를 엑셀에 붙여 넣은 뒤 COUNTIF나 피벗 테이블로 주제별 개수를 셉니다.

## 대표 응답 고르기

보고서에는 주제별 대표 응답을 원문 그대로 인용합니다. AI가 원문을 다듬어 인용하지 않게 "원문을 한 글자도 바꾸지 말고 인용해 주세요"라고 지시하고, 원본과 대조합니다.

# 보고서용 정리

## 표에서 시사점까지

```prompt 프롬프트 6. 통계 해석 문장
아래는 [조사명] 결과 집계표입니다. 계산은 이미 끝났습니다.
[집계표 붙여 넣기]

1. 표의 핵심 결과를 3문장으로 요약해 주세요. 표에 있는 숫자만 쓰고 새로 계산하지 마세요.
2. 전년 대비 또는 집단 간 차이가 큰 항목 3개를 골라 주세요.
3. 시사점 3가지와 개선 방안을 개조식으로 써 주세요. 표만으로 원인을 단정할 수 없는 경우 "추가 확인 필요"로 표시해 주세요.
```

## 해석할 때 조심할 점

| 주의 | 설명 |
|---|---|
| 응답자 수 | 응답자가 적은 집단의 평균은 크게 흔들립니다. 집단별 응답 수를 함께 표시합니다 |
| 응답률 | 응답률이 낮으면 만족한 사람이나 불만이 큰 사람만 응답했을 수 있습니다 |
| 원인 단정 | 두 수치가 함께 움직여도 한쪽이 원인이라고 단정할 수 없습니다 |
| 작은 차이 | 5점 척도의 0.1점 차이는 의미 있는 차이가 아닐 수 있습니다 |
| 척도 해석 | 평균만 보지 말고 "불만족" 응답 비율도 함께 봅니다 |

## 그래프

보고서용 그래프는 엑셀에서 직접 만듭니다. 비교는 막대그래프, 시간 흐름은 꺾은선그래프가 기본입니다. 원그래프는 항목이 3~4개일 때만 씁니다. 두 개의 세로축을 쓰는 그래프는 읽는 사람이 오해하기 쉬우므로 그래프를 두 개로 나눕니다.

!!! 보고서에 넣기 전에 확인합니다
- AI에 개인별 원자료를 넣지 않았다
- 합계, 평균, 비율은 엑셀로 계산했다
- AI가 알려 준 수식을 표본 몇 행에 직접 검산했다
- 매크로는 복사본 파일에서 먼저 시험했다
- 주관식 분류 결과를 무작위 20건으로 직접 검증했다
- 인용한 응답이 원문과 같다
- 집단별 응답 수와 응답률을 함께 표시했다
- 표만으로 단정할 수 없는 원인은 단정하지 않았다

- **미래전략 앱:** 학과별 지표 표를 붙여 넣으면 기준값과 비교해 진단 결과를 보여 줍니다.
- **프롬프트 라이브러리 3-4, 3-7:** 엑셀 수식, 설문 문항 설계와 결과 해석 프롬프트를 입력칸 방식으로 씁니다.
