# 근거 기반 강의안이 필요한 이유

## 일반 대화형 AI의 한계

생성형 AI에게 "슬관절 전방십자인대 재건술 후 재활 강의안을 만들어 주세요"라고만 요청하면 그럴듯한 강의안이 나옵니다. 문제는 그 내용이 어느 교재, 어느 지침에 근거하는지 알 수 없다는 점입니다. AI는 학습한 수많은 글의 평균적인 내용을 문장으로 만들어 내기 때문에, 오래된 기준과 최신 기준이 섞이거나 다른 나라의 제도가 우리 상황처럼 서술되기도 합니다. 논문 제목과 저자를 그럴듯하게 지어내는 일도 흔합니다.

보건의료 강의에서 이런 오류는 단순한 실수로 끝나지 않습니다. 학생은 강의 내용을 그대로 국가시험과 임상에 가져갑니다. 그래서 강의안 제작에서는 "AI가 아는 것"이 아니라 "내가 준 자료에 있는 것"으로 답하게 만드는 방식이 필요합니다.

## 자료 기반 도구의 원리

NotebookLM처럼 사용자가 올린 문서 안에서만 답을 찾는 도구, 또는 Claude·ChatGPT에 파일을 첨부하고 "첨부 자료에 있는 내용만 쓰라"고 지시하는 방식을 자료 기반(grounded) 작업이라고 합니다. 이 방식에는 세 가지 장점이 있습니다.

- **출처 추적:** 답변의 각 문장이 자료의 어느 부분에서 왔는지 표시되므로 교수자가 바로 원문을 확인할 수 있습니다.
- **범위 통제:** 강의에서 다룰 범위를 교수자가 고른 자료로 한정할 수 있습니다.
- **최신성 관리:** 개정된 지침을 올리면 그 기준으로 답합니다.

다만 자료 기반 도구도 자료를 잘못 요약하거나 두 문서의 내용을 섞을 수 있습니다. 출처 표시가 있다는 것은 확인하기 쉽다는 뜻이지 맞다는 뜻이 아닙니다.

# 자료 준비

## 어떤 자료를 올릴 것인가

| 자료 유형 | 쓰임 | 주의할 점 |
|---|---|---|
| 주교재 해당 장 | 강의 범위의 기준 | 저작권 범위 안에서 본인 수업 준비용으로만 사용 |
| 임상 진료지침 | 최신 권고와 근거 수준 | 발행 연도와 개정판 여부 확인 |
| 체계적 문헌고찰·메타분석 | 중재 효과의 근거 | 초록만이 아니라 본문 결과 표 포함 |
| 학과 실습 매뉴얼 | 실습 절차와 안전 기준 | 학과 공식 최신본 사용 |
| 국가시험 출제 범위 | 강조할 내용 선정 | 국가시험원 공개 원문 사용 |
| 본인의 기존 강의 슬라이드 | 강의 흐름과 용어 통일 | 오래된 수치가 남아 있는지 확인 |

## 자료를 올리기 전에 할 일

- **범위를 좁힙니다.** 교재 전체 600쪽보다 이번 주 강의에 해당하는 40쪽을 올리는 편이 정확도가 높습니다.
- **파일 이름을 바꿉니다.** "지침_대한OO학회_2024.pdf"처럼 출처와 연도가 보이게 하면 출처 표시를 읽기 쉽습니다.
- **스캔본은 글자 인식을 확인합니다.** 이미지로만 된 PDF는 내용을 읽지 못하거나 일부만 읽습니다. PDF에서 글자를 드래그해 선택되는지 먼저 확인합니다.
- **개인정보가 든 자료는 올리지 않습니다.** 실제 환자 사례 기록, 학생 과제 원본은 제외합니다.

> 교재와 논문은 저작권이 있는 자료입니다. 교수자 본인의 수업 준비를 위해 도구에 올려 요약을 받는 것과, 그 내용을 길게 옮겨 학생에게 배포하는 것은 다릅니다. 슬라이드에는 원문을 길게 인용하지 않고 출처를 밝혀 요약합니다.

# 강의안 만들기

## 1단계. 자료 구조 파악

자료를 올린 직후 바로 강의안을 요청하지 않습니다. 먼저 자료 전체의 구조를 받아 보고, 강의에 쓸 부분을 교수자가 고릅니다.

```prompt 프롬프트 1. 자료 구조 파악
올린 자료들의 구조를 정리해 주세요.

1. 자료별로 제목, 발행 연도, 다루는 범위를 한 줄씩 적습니다.
2. 자료 전체에서 반복해서 나오는 핵심 개념 10개를 고르고, 각 개념이 어느 자료 몇 쪽(또는 어느 절)에 있는지 표시합니다.
3. 자료끼리 내용이 서로 다른 부분(수치, 권고 등급, 절차 순서)이 있으면 따로 표로 정리합니다.

자료에 없는 내용은 추가하지 마세요.
```

3번 결과가 특히 중요합니다. 교재와 최신 지침의 권고가 다르면 강의에서 어떤 기준을 가르칠지 교수자가 먼저 정해야 합니다.

## 2단계. 50분 강의안

```prompt 프롬프트 2. 50분 강의안
역할: 당신은 보건계열 전공 수업의 강의안 작성을 돕는 조교입니다.

상황: [학과, 학년] 학생을 대상으로 [주제] 50분 강의를 준비합니다. 이 강의의 학습목표는 다음과 같습니다.
[학습목표 2~3개]

작업 순서:
1. 도입(5분), 전개(35분), 정리(10분)로 나눕니다.
2. 전개는 3개 소주제로 나누고, 소주제마다 핵심 설명, 예시 1개, 학생에게 던질 질문 1개를 넣습니다.
3. 각 설명 문장 끝에 근거가 된 자료 이름과 위치를 괄호로 표시합니다.
4. 정리에는 학습목표별 확인 질문 1개씩과 다음 시간 예고를 넣습니다.

지킬 것:
- 올린 자료에 근거가 없는 내용은 쓰지 말고, 꼭 필요하다고 판단되면 [자료 밖 내용: 교수자 확인 필요]로 표시합니다.
- 수치(정상 범위, 용량, 각도, 횟수)는 자료의 표기 그대로 옮깁니다.
- 자료끼리 다른 기준이 있으면 둘 다 적고 어느 쪽인지 표시합니다.
```

## 3단계. 학생 수준에 맞추기

같은 내용도 1학년과 3학년에게는 다르게 설명해야 합니다. 강의안을 받은 뒤 다음처럼 조정합니다.

- "1학년 학생이 처음 듣는다고 가정하고, 전문 용어가 처음 나올 때 쉬운 말로 풀어 주세요."
- "3학년 학생이 임상실습을 앞두고 있다고 가정하고, 각 소주제에 실습 현장에서 자주 마주치는 상황 예시를 하나씩 추가해 주세요."
- "국가시험에서 자주 묻는 구분(예: 유형별 차이, 금기증)을 표로 정리해 정리 단계에 넣어 주세요."

# 슬라이드와 시각자료

## 슬라이드 구성안

AI에게 바로 PPT 파일을 만들게 하는 것보다, 먼저 슬라이드별 구성안을 받아 검토한 뒤 직접 만들거나 슬라이드 도구로 옮기는 편이 결과가 좋습니다.

```prompt 프롬프트 3. 슬라이드 구성안
위 강의안을 슬라이드 18장 이내로 나누어 주세요.

슬라이드마다 다음을 적습니다.
- 제목(15자 이내)
- 화면에 넣을 핵심 문장 3개 이내(문장당 20자 이내)
- 넣을 그림·도표 설명(무엇을 보여 줄지)
- 발표자 노트(말로 설명할 내용 3~4문장)
- 근거 자료 위치

원칙: 한 장에 한 가지 메시지만 담습니다. 긴 설명은 화면이 아니라 발표자 노트에 둡니다.
```

## 좋은 슬라이드의 기준

| 기준 | 피할 것 | 대신 할 것 |
|---|---|---|
| 한 장에 한 메시지 | 교재 문단을 그대로 옮긴 글 상자 | 핵심 문장 한 줄과 도표 하나 |
| 글자 크기 | 강의실 뒤에서 안 보이는 작은 글씨 | 본문 24pt 이상을 기본으로 |
| 도표 | 의미 없는 장식 그림 | 비교표, 흐름도, 해부 그림처럼 이해를 돕는 그림 |
| 출처 | 출처 없는 그림과 수치 | 슬라이드 아래에 짧은 출처 표기 |
| 색 | 색으로만 구분하는 그래프 | 색과 함께 글자 표시나 무늬를 같이 사용 |

## 그림과 도표 만들기

해부 구조나 임상 사진은 저작권과 정확성 문제가 있어 AI 이미지 생성 도구로 만들지 않는 것이 원칙입니다. 대신 다음을 활용합니다.

- **흐름도와 비교표:** AI에게 "이 절차를 흐름도로 표현할 단계와 화살표 관계를 정리해 주세요"라고 요청한 뒤 슬라이드 도구의 도형으로 직접 그립니다.
- **개념 비유 그림:** 정확성이 덜 중요한 도입부 그림은 이미지 생성 도구를 쓸 수 있지만, 해부학적으로 틀린 부분이 없는지 확인합니다.
- **공개 자료:** 교재 출판사가 교수자용으로 제공하는 그림, 저작권이 열린 의학 일러스트 자료를 우선 사용합니다.

## 비유와 연상 자료

어려운 기전을 일상의 비유로 설명하면 학생의 이해가 빨라집니다. 다만 비유는 언제나 일부만 맞습니다. 비유를 쓸 때는 어디까지 맞고 어디서부터 틀리는지도 함께 알려 주어야 오개념이 생기지 않습니다.

```prompt 프롬프트 5. 비유와 그 한계
[개념, 예: 근방추와 골지건기관의 역할 차이]를 대학 1학년이 이해할 수 있는 일상 비유로 설명해 주세요.

비유 2가지를 제시하고, 각 비유마다 다음을 적어 주세요.
1. 비유가 잘 들어맞는 부분
2. 비유가 실제와 다른 부분(학생이 오해할 수 있는 점)
3. 비유 뒤에 이어서 할 정확한 설명 2문장
```

## 음성 요약 활용

NotebookLM의 음성 요약(오디오 개요) 기능은 올린 자료를 두 사람이 대화하는 형식의 음성으로 바꿔 줍니다. 통학 시간에 들을 수 있는 복습 자료로 유용하지만, 대화 형식이라 내용을 단순화하거나 과장하는 경우가 있습니다. 학생에게 배포하기 전에 교수자가 끝까지 들어 보고 틀린 설명이 없는지 확인합니다.

# 검증

## 강의안 검증 절차

1. **출처 표시가 없는 문장을 찾습니다.** 출처 괄호가 빠진 문장은 AI가 자료 밖에서 가져왔을 가능성이 높습니다.
2. **수치를 원문과 대조합니다.** 정상 범위, 약물 용량, 운동 강도, 각도, 반복 횟수는 하나씩 원문 쪽수를 열어 확인합니다.
3. **용어를 통일합니다.** 교재와 지침이 서로 다른 번역어를 쓰면 강의 전체에서 하나로 맞추고 처음 나올 때 다른 표현을 함께 적습니다.
4. **최신성을 확인합니다.** 지침의 발행 연도와 개정 여부를 학회 홈페이지에서 확인합니다.
5. **안전 관련 내용을 다시 봅니다.** 금기증, 주의사항, 중단 기준이 빠지지 않았는지 확인합니다.

## 자주 생기는 오류

| 오류 | 예 | 대처 |
|---|---|---|
| 자료끼리 섞기 | 두 지침의 권고 등급을 한 문장에 섞음 | 자료별로 따로 정리하게 다시 요청 |
| 과도한 일반화 | 특정 대상 연구 결과를 모든 환자에게 적용 | 연구 대상과 조건을 함께 적게 요청 |
| 단위 오류 | mg과 μg, kg과 lb 혼동 | 원문 대조 |
| 지어낸 참고문헌 | 존재하지 않는 논문 제목 | 학술 검색에서 제목으로 직접 검색 |
| 오래된 기준 | 개정 전 기준 서술 | 최신판 자료만 올리고 다시 생성 |

!!! 강의에 쓰기 전에 확인합니다
- 모든 핵심 문장에 출처가 표시되어 있다
- 수치는 원문 쪽수를 열어 직접 대조했다
- 자료끼리 다른 기준은 어느 기준을 가르칠지 정했다
- 금기증, 주의사항, 중단 기준이 빠지지 않았다
- 슬라이드에 원문을 길게 옮긴 부분이 없다
- 그림과 수치에 출처를 적었다
- 학생 배포용 음성·요약 자료를 교수자가 끝까지 검토했다

## 자주 묻는 질문

**NotebookLM에 교재 전체를 올려도 되나요?**
도구의 파일 크기 제한 안이라면 올릴 수는 있지만, 범위가 넓을수록 답이 일반적이 되고 엉뚱한 장을 인용할 가능성이 커집니다. 강의 범위에 해당하는 장만 올리는 편이 정확합니다.

**영어 논문을 올리고 한국어 강의안을 받아도 되나요?**
가능합니다. 다만 전문 용어 번역이 교재와 다를 수 있으므로, "전문 용어는 한국어 뒤에 영어 원어를 괄호로 함께 적어 주세요"라고 지시하면 확인이 쉽습니다.

**학생에게 NotebookLM 노트북을 공유해도 되나요?**
교재 원문이 들어 있는 노트북을 공유하면 사실상 교재를 배포하는 것이 됩니다. 공유할 때는 교수자가 만든 요약 자료나 공개 지침만 담은 노트북을 따로 만듭니다.
