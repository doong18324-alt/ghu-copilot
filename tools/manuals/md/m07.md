# 이 가이드북으로 무엇을 하나

## AI를 검색창처럼 쓰는 단계에서 벗어나기

많은 학생이 AI를 검색창처럼 씁니다. 짧은 질문을 넣고, 나온 답을 읽고, 마음에 들지 않으면 질문을 조금 바꿔 다시 넣습니다. 이 방식으로도 간단한 궁금증은 풀리지만, 과제나 실습 준비처럼 결과물이 필요한 일에서는 시간이 오래 걸리고 결과도 들쭉날쭉합니다.

이 가이드북은 4주 동안 AI에게 일을 정확하게 맡기는 방법을 단계별로 익히도록 구성했습니다. 마지막 주에는 그동안 만든 프롬프트를 모아 나만의 전공 학습 도우미를 만듭니다.

## 이 과정이 지키는 세 가지 원칙

1. **내 생각이 먼저입니다.** AI는 내 초안을 다듬고 빠진 점을 찾는 데 씁니다. 과제를 통째로 맡기지 않습니다.
2. **사실은 직접 확인합니다.** 수치, 기준, 논문, 제도는 교재와 공식 자료로 확인합니다.
3. **정보는 지킵니다.** 환자, 실습 기관, 다른 사람의 정보는 넣지 않습니다.

# 4주 구성

## 주차별 목표와 결과물

| 주차 | 주제 | 익힐 기법 | 주차 결과물 |
|---|---|---|---|
| 1주 | 프롬프트 기본기 | 역할, 과제, 맥락, 출력 형식(RTCO), 되묻기, 고쳐 나가기 | 내 전공 개념 학습 프롬프트 3개 |
| 2주 | 전공 자료 요약과 비교 | 구조화 요약, 자료 기반 질문, 비교표 | 전공 자료 1편 구조화 요약표와 비교표 |
| 3주 | 실무 문서와 발표 | 결론 먼저 쓰기(피라미드 구조), 보고서 개요, 발표 대본 | 1쪽 보고서와 5분 발표 개요 |
| 4주 | 예시 제시와 단계적 사고, 면접 | 예시 몇 개 보여 주기(Few-Shot), 단계별로 따지게 하기, 모의면접관 | 모의면접 기록과 나만의 학습 도우미 지시문 |

## 주차별 권장 학습 시간

| 활동 | 시간 |
|---|---|
| 매뉴얼 읽기 | 30분 |
| 예시 프롬프트 따라 하기 | 30분 |
| 내 전공으로 바꿔 실습하기 | 40분 |
| 결과 기록과 성찰 | 20분 |

하루에 몰아서 하기보다 일주일 동안 두세 번 나누어 하면 기법이 손에 익습니다.

# 계열별 활용 예

## 같은 기법, 다른 전공

기법은 같아도 전공마다 쓰는 장면이 다릅니다. 매뉴얼의 예시를 내 전공 상황으로 바꿔 실습합니다.

| 계열 | 1주 예 | 2주 예 | 3주 예 | 4주 예 |
|---|---|---|---|---|
| 보건계열(간호, 물리치료, 임상병리, 방사선, 치위생 등) | 질환의 병태생리 설명 | 진료지침 두 개 비교 | 환자 교육 자료 기획 | 병원 면접 상황 질문 |
| 사회복지계열 | 사회복지 이론 정리 | 정책 보고서 요약 | 프로그램 기획서 개요 | 기관 면접과 사례 질문 |
| 사회실무계열(경영, 행정, 서비스 등) | 실무 용어 정리 | 업계 동향 자료 비교 | 업무 보고서 작성 | 직무 면접 질문 |

## 내 전공 예시 찾기

```prompt 전공 맞춤 실습 주제 찾기
저는 [학과, 학년]입니다. 이번 학기에 [과목 2~3개]를 듣고 있습니다.
4주 프롬프트 실습(1주 개념 학습, 2주 자료 요약과 비교, 3주 보고서와 발표, 4주 면접)에 쓸 실습 주제를 주차별로 2개씩 제안해 주세요.
수업 진도와 맞도록 너무 어려운 주제는 빼 주세요.
```

# 학습 방법

## 실습 기록 남기기

매주 실습한 프롬프트와 결과를 기록합니다. 4주가 지나면 이 기록이 그대로 나만의 프롬프트 모음과 학습 포트폴리오가 됩니다.

| 날짜 | 목적 | 쓴 프롬프트 | 결과에서 좋았던 점 | 고친 점 | 확인한 자료 |
|---|---|---|---|---|---|
| | | | | | |

## 결과를 평가하는 기준

AI 결과물이 좋은지 판단하는 기준을 미리 정해 두면 고칠 방향이 분명해집니다.

!!! AI 결과물 평가 기준
- 내가 요청한 과제에 답했는가
- 요청한 형식과 분량을 지켰는가
- 사실과 수치가 교재나 공식 자료와 맞는가
- 내 수준과 목적에 맞는가
- 내가 이해하고 설명할 수 있는가

## 함께 공부하기

같은 과 친구 두세 명과 같은 과제에 각자 프롬프트를 써 보고 결과를 비교하면 서로의 요령을 빨리 배울 수 있습니다. 결과가 다른 이유를 찾아보는 것 자체가 좋은 공부입니다.

# 지켜야 할 규칙

## 과제와 시험

과목마다 AI 활용 규칙이 다릅니다. 강의계획서와 교수님 안내를 가장 먼저 확인합니다. 허용된 범위 안에서 썼더라도 과제에는 AI 사용 사실을 밝힙니다. 시험 중 AI 사용은 별도 허용이 없는 한 부정행위입니다.

## 입력하지 않는 정보

| 정보 | 이유 |
|---|---|
| 실습 기관 환자 정보, 기록 | 개인정보와 비밀 보호 의무 |
| 다른 학생의 과제, 성적, 연락처 | 타인의 정보와 저작물 |
| 미공개 시험 문제, 내부 자료 | 학업 정직성, 기관 보안 |
| 교재 전체 스캔본 | 저작권 |

# 시작하기

## 첫날 할 일

1. 내 학과와 이번 학기 과목을 적습니다.
2. "전공 맞춤 실습 주제 찾기" 프롬프트로 4주 실습 주제를 정합니다.
3. 실습 기록 표를 만듭니다(문서나 스프레드시트).
4. 1주차 매뉴얼을 읽습니다.

## 4주 뒤의 모습

- 어떤 과제든 역할, 과제, 맥락, 출력 형식을 넣어 프롬프트를 쓸 수 있습니다.
- 긴 자료를 목적에 맞게 구조화하고 비교할 수 있습니다.
- 결론부터 쓰는 보고서와 5분 발표 개요를 만들 수 있습니다.
- 예시를 보여 주거나 단계적으로 따지게 해 더 정확한 답을 얻을 수 있습니다.
- 나만의 전공 학습 도우미 지시문을 갖게 됩니다.

!!! 시작하기 전에 확인합니다

- 4주 실습 주제를 정했다
