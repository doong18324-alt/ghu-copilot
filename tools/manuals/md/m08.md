# 1주차에 익힐 것

## 이번 주 목표

- 프롬프트의 네 요소를 넣어 질문을 쓸 수 있다.
- 첫 답을 보고 무엇을 더할지 판단해 고쳐 나갈 수 있다.
- 내 전공 개념을 공부하는 프롬프트 세 개를 완성한다.

## 왜 기본기부터인가

생성형 AI는 질문에 적힌 정보만으로 일을 합니다. 내가 몇 학년인지, 이 답을 어디에 쓸지, 어느 정도 길이를 원하는지 적지 않으면 AI는 "가장 일반적인 사람"을 위한 답을 만듭니다. 그 결과가 백과사전처럼 넓고 얕은 답입니다. 네 요소는 AI가 나를 위한 답을 만들도록 필요한 정보를 빠짐없이 주는 체크리스트입니다.

# RTCO 네 요소

## R: 역할(Role)

AI가 어떤 관점과 수준으로 답할지 정합니다. 역할은 "전문가"처럼 막연하게 쓰기보다 누구를 상대하는 어떤 사람인지까지 씁니다.

| 약한 역할 | 강한 역할 |
|---|---|
| 의사처럼 답해 줘 | 간호학과 2학년에게 성인간호학을 가르치는 조교 |
| 전문가로서 | 노인복지관에서 10년 일한 사회복지사로, 신입 직원 교육을 맡은 사람 |

역할을 준다고 AI가 실제 전문가가 되는 것은 아닙니다. 설명의 수준과 말투, 강조점이 바뀔 뿐입니다. 사실 확인은 여전히 필요합니다.

## T: 과제(Task)

해야 할 일을 동사로 분명히 씁니다. "알려 줘"보다 "비교해", "단계별로 나눠", "표로 정리해", "예를 3개 들어"가 정확합니다. 한 번에 여러 일을 시킬 때는 번호를 붙입니다.

## C: 맥락과 조건(Context)

왜 필요한지, 지금 어디까지 알고 있는지, 지켜야 할 조건이 무엇인지 씁니다.

- **목적:** 중간고사 대비, 실습 전 예습, 조별 발표
- **현재 수준:** "교재 4장까지 배움", "약리학은 아직 배우지 않음"
- **조건:** "교재 용어를 쓸 것", "수치는 넣지 말 것", "한국 제도 기준"

맥락은 결과를 가장 크게 바꾸는 요소입니다. 같은 "심부전 설명"도 "시험 대비"와 "환자 교육 자료"에서는 전혀 다른 답이 나와야 합니다.

## O: 출력 형식(Output)

결과를 받을 모양을 정합니다. 표, 번호 목록, 문단 수, 글자 수, 말투, 포함할 항목을 적습니다. 원하는 형식이 분명하면 예시 한 줄을 보여 줍니다.

```prompt RTCO 기본형
[R] 당신은 [누구를 상대하는 어떤 역할]입니다.
[T] [동사로 쓴 과제, 번호를 붙여 여러 개도 가능]
[C] 목적: [어디에 쓸지] / 현재 수준: [어디까지 배웠는지] / 조건: [지킬 것, 하지 말 것]
[O] 형식: [표, 목록, 분량, 말투, 포함할 항목]
```

# 고쳐 나가는 대화

## 첫 답은 초안입니다

AI의 첫 답이 완벽한 경우는 드뭅니다. 첫 답을 보고 다음 중 무엇이 문제인지 판단해 한 가지씩 고칩니다.

| 첫 답의 문제 | 더할 요청 |
|---|---|
| 너무 일반적이다 | 맥락 추가: "제 과목은 [과목]이고 시험 범위는 [범위]입니다" |
| 너무 길다 | 형식 제한: "표 하나로, 항목당 한 줄" |
| 너무 어렵다 | 수준 조정: "고등학교 생물 수준으로 다시" |
| 틀린 내용이 있다 | 지적과 근거 요청: "교재에는 [내용]이라고 되어 있습니다. 어느 쪽이 맞는지 근거를 들어 주세요" |
| 내가 원하는 게 아니다 | 목적 재설명: "제가 원하는 것은 [결과물]입니다" |

## 되묻게 하기

내가 무엇을 빠뜨렸는지 모를 때는 AI에게 먼저 묻게 합니다.

```prompt 되묻기
[하려는 일]을 하려고 합니다. 바로 답하지 말고, 좋은 결과를 위해 필요한 정보를 5개 이내로 먼저 질문해 주세요.
```

## 대화가 길어지면 새로 시작하기

한 대화창에서 주제를 여러 번 바꾸면 AI가 앞의 내용을 섞어 답하는 일이 생깁니다. 주제가 바뀌면 새 대화를 열고, 지금까지 정리된 조건을 요약해 붙여 넣고 시작합니다.

# 계열별로 보는 잘못된 예와 고친 예

## 보건계열

| 구분 | 프롬프트 |
|---|---|
| 잘못된 예 | 고혈압 약 알려 줘 |
| 문제 | 목적과 수준이 없어 약 목록만 길게 나옴. 용량 같은 수치가 확인 없이 섞일 수 있음 |
| 고친 예 | 당신은 간호학과 3학년에게 약리학을 가르치는 조교입니다. 고혈압 치료제 계열(이뇨제, ACE 억제제, 안지오텐신 수용체 차단제, 칼슘통로 차단제, 베타 차단제)을 작용 기전, 대표 부작용, 간호 시 관찰할 점으로 비교표를 만들어 주세요. 국가시험 대비용이며, 용량은 넣지 말아 주세요. |

```prompt 보건계열 개념 학습
당신은 [학과] [학년]에게 [과목]을 가르치는 조교입니다.
[개념]을 다음 순서로 설명해 주세요.
1. 한 문장 정의
2. 왜 중요한지(임상 장면 하나)
3. 기전 또는 원리를 3단계로
4. 헷갈리기 쉬운 비슷한 개념과의 차이
5. 국가시험형 확인 문제 1개(답은 맨 아래에)
교재 용어를 쓰고, 수치나 용량은 넣지 말아 주세요.
```

## 사회복지계열

| 구분 | 프롬프트 |
|---|---|
| 잘못된 예 | 사례관리 설명해 줘 |
| 문제 | 정의만 나오고 실천 과정이 빠짐 |
| 고친 예 | 당신은 사회복지실천론을 가르치는 교수입니다. 사례관리의 과정(접수, 사정, 계획, 개입, 점검, 종결)을 단계별로 실천 행동, 쓰는 도구, 주의할 윤리 쟁점으로 표를 만들어 주세요. 독거노인 가상 사례를 하나 들어 각 단계에 적용해 주세요. |

## 사회실무계열

| 구분 | 프롬프트 |
|---|---|
| 잘못된 예 | 마케팅 전략 짜 줘 |
| 문제 | 대상, 예산, 기간이 없어 일반론만 나옴 |
| 고친 예 | 당신은 소규모 건강 관련 업체의 마케팅 담당자입니다. 대학 근처 소규모 필라테스 스튜디오가 20대 학생 신규 회원을 늘리는 3개월 계획을 세우려 합니다. 예산은 월 [금액]입니다. 온라인과 오프라인 방법을 각각 3개씩, 예상 비용과 성과를 확인할 지표와 함께 표로 제안해 주세요. |

# 프롬프트를 더 좋게 만드는 요소

네 요소에 익숙해지면 다음 요소를 더해 봅니다.

| 요소 | 쓰는 법 | 예 |
|---|---|---|
| 예시 | 원하는 형식의 예를 한 줄 | "형식 예: 개념 / 정의 / 시험 포인트" |
| 금지 | 하지 말 것 | "추측으로 수치를 쓰지 마세요" |
| 확인 | 답 끝에 점검 요청 | "확인이 필요한 부분을 표시해 주세요" |
| 단계 | 한 번에 끝내지 않기 | "먼저 개요만, 제가 확인하면 본문" |
| 독자 | 결과를 읽을 사람 | "보호자가 읽을 안내문" |

# 1주차 자주 묻는 질문

**역할을 꼭 넣어야 하나요?**
간단한 질문에는 없어도 됩니다. 설명의 수준과 관점이 중요할 때 넣으면 효과가 큽니다.

**AI가 제 수준보다 너무 어렵게 설명합니다.**
현재 수준을 구체적으로 씁니다. "1학년, 생리학은 배웠지만 약리학은 아직"처럼 배운 것과 안 배운 것을 함께 알려 줍니다.

**결과를 고쳐 달라고 하면 처음부터 다시 씁니다.**
"2번 항목만 고쳐 주세요, 나머지는 그대로 두세요"처럼 고칠 범위를 정확히 말합니다.
