# 머리말: 생성형 AI 시대, 대학생에게 '프롬프트'란 무엇인가?

생성형 AI(ChatGPT, Claude, Gemini 등)를 사용할 때 많은 대학생들이 겪는 대표적인 실패 패턴은 검색창에 키워드를 넣듯 단편적인 한 줄 질문을 던지는 것입니다. "심실세동 알려줘", "복지관 사례관리 어떻게 해?", "과제 주제 추천해줘"와 같은 질문은 인터넷 검색 결과의 평균적인 요약본만을 반환합니다.

AI는 본질적으로 '확률적 언어 모델'입니다. 즉, 사용자가 제공하는 입력값(Prompt, 프롬프트)의 맥락과 조건이 구체적이고 정교할수록, AI는 수많은 가능성 중에서 사용자가 원하는 정확한 도메인 지식의 궤도로 진입합니다. 질문이 흐리멍덩하면 AI도 인터넷 백과사전의 뻔한 소리를 하거나 모르는 것도 아는 척 그럴듯하게 거짓말이나 엉뚱한 답변을 지어내는 '환각 현상(거짓말하기)'을 일으킵니다.

따라서 프롬프트 엔지니어링은 복잡하고 어려운 컴퓨터 코딩 기술이 아닙니다. AI에게 나의 학업 수준과 목적에 맞춘 '24시간 개인 튜터(과외 선생님)이자 연구 조교' 역할을 부여하는 친절하고 구체적인 '역할 설계 기술이자 말동무 쪽지'입니다. 이 1주차 핸드북을 통해 기본 뼈대를 마스터하면, 이후 단계에서 다룰 '나만의 AI 비서(Custom GPT/Agent)' 제작의 핵심 시스템 지침(System Instructions)을 충분히 작성할 수 있게 됩니다.

# 완성도를 높이는 만능 프롬프트 프레임워크: RTCO (역·일·상·모)

프롬프트 작성의 황금률은 **RTCO(Role, Task, Context, Output)** 4요소 모델입니다. 전문대 학생들의 눈높이에 맞춰 쉽게 풀어내면 **'역·일·상·모'** 공식이 됩니다. 이 4가지 요소를 체계적으로 갖추면 엉뚱한 답변을 대폭 줄이고 즉시 과제와 학습에 쓸 수 있는 고품질의 답변을 얻을 수 있습니다.

## 1. R - Role (역할 부여 / 역)

-   **왜 중요한가?**: AI에게 구체적인 직책과 역할을 지정하지 않으면 '초등학생부터 전문가까지 두루 이해할 수 있는 평이한 백과사전식 말투'로 답합니다. 반면 구체적인 직책과 경력을 부여하면 전문 어휘, 실무적 관점, 문제 해결 방식이 즉각 적용됩니다.

-   **좋은 예시**: "당신은 대학병원에서 10년 이상 신규 간호사를 교육해 온 수간호사이자 임상 튜터입니다." / "당신은 종합사회복지관 15년 차 통합사례관리 슈퍼바이저입니다."

-   **핵심 팁**: 직책뿐 아니라 '경력 연수'나 '상대방(학습자 수준)'을 함께 지정하면 톤앤매너가 완벽해집니다.

## 2. T - Task (수행할 핵심 작업 / 일)

-   **왜 중요한가?**: AI가 최종적으로 달성해야 할 행동 목표를 단일하고 명확하게 정의해야 합니다. 여러 작업을 두서없이 섞으면 AI가 일부를 누락합니다.

-   **좋은 예시**: "활동전위 발생 기전을 설명해 주세요." / "초기 사정(Intake) 계획서를 작성해 주세요." / "학부모 컴플레인 대응 스크립트를 작성해 주세요."

## 3. C - Context & Constraint (맥락, 배경정보 및 제약 조건 / 상)

-   **왜 중요한가?**: 답변의 질을 결정짓는 가장 핵심적인 단계입니다. 어떤 배경에서 이 작업이 필요한지, 포함해야 할 핵심 요소와 절대 하지 말아야 할 제약 사항을 명시합니다.

-   **포함 요소**: 학습자의 현재 수준, 타깃 대상, 사용할 이론이나 프로토콜, 제외할 내용(예: "전문 의학용어는 괄호 안에 영문 병기할 것", "추측성 내용은 배제하고 검증된 가이드라인에 기반할 것", "어려운 한자어는 쉬운 일상어로 풀어서 쓸 것").

## 4. O - Output (출력 형식 및 규격 / 모)

-   **왜 중요한가?**: AI가 줄글로만 길게 늘어놓으면 가독성이 떨어져 과제에 바로 인용하기 어렵습니다. 원하는 구조와 서식을 미리 지정합니다.

-   **지정 방법**: 표(Table), 3단계 불릿 포인트, 글자 수 제한, 마크다운 헤더, 서술형 보고서 톤 등.

# 전공 불문 만능 개념 학습 템플릿

학기 중 어려운 전공서적을 읽거나 시험공부를 할 때, 교수님이나 선배에게 물어보듯 1:1 과외를 받을 수 있는 표준 프롬프트입니다.

## 복사해서 쓰는 프롬프트

```prompt 복사해서 쓰는 프롬프트
[Role/역할] 당신은 전문대 학부생을 1:1로 지도하는 친절하고 깊이 있는 전공 과외 선생님입니다.

[Task/할 일] 제가 제시하는 전공 개념을 초심자가 직관적으로 이해할 수 있도록 3단계로 구조화해 설명해 주세요.
[Context/상황 및 조건]
- 학습할 개념: [여기에 공부할 개념 입력, 예: 항상성 유지 기전 / 사회복지 잔여주의와 제도주의 / 감가상각 누계액]
- 어려운 학술 용어만 나열하지 말고, 일상생활 속 구체적인 비유(일상 사물이나 상황)를 1가지 들어 주세요.
- 시험이나 과제에서 학생들이 가장 흔하게 오해하거나 헷갈리는 오개념(Misconception) 1가지와 감별 기준을 포함해 주세요.
[Output/모양새]

다음의 3단계 형식으로 작성해 주세요:
1. 30초 핵심 요약 (2줄 이내)
2. 일상 속 비유를 통한 쉬운 설명 (예시 포함)
3. 시험 대비 체크포인트: 흔한 오개념 vs 실제 정답 비교
```

## 에이전트 확장 브릿지: "이 프롬프트가 나만의 AI 비서가 됩니다"

여러분이 작성한 이 RTCO 프롬프트는 단순한 1회성 질문에 그치지 않습니다.

이 텍스트를 그대로 복사하여 생성형 AI의 **'사용자 정의 지침(Custom Instructions)'** 또는 **'GPTs(Agent Builder)의 시스템 프롬프트'**란에 붙여넣으면, 접속할 때마다 매번 역할을 길게 설명할 필요 없이 **"나만을 위해 24시간 대기하는 전공 맞춤형 AI 비서"**로 영구 작동하게 됩니다.

*(상세한 AI 에이전트 구축 실습은 4주차 및 후속 심화 가이드북에서 본격적으로 다룹니다.)*

!!! 이번 주 과제를 마치기 전에 확인합니다
- 역할, 작업, 맥락, 형식을 갖춘 프롬프트를 썼다
- 첫 답을 다시 묻기로 한 번 이상 고쳤다
- 결과의 사실과 수치를 교재와 공식 자료로 확인했다
- 개인정보와 실습 대상자 정보를 넣지 않았다
- 잘 된 프롬프트를 나만의 모음에 기록했다
