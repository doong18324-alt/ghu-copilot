# 평가 문서의 특징

## 왜 평가 문서는 다르게 써야 하는가

대학은 기관 평가인증, 재정지원사업 연차 평가, 정보공시처럼 외부 기준에 따라 실적을 보고하는 일이 많습니다. 이런 문서는 일반 보고서와 세 가지가 다릅니다.

- **기준이 정해져 있습니다.** 평가 지표의 정의, 산출식, 기준 시점이 평가 편람에 정해져 있습니다.
- **근거가 필요합니다.** 서술 하나하나에 근거 자료(결재 문서, 결과보고서, 통계)가 따라야 합니다.
- **수치가 다른 자료와 맞아야 합니다.** 같은 수치가 공시 자료, 사업 보고서, 평가 보고서에 서로 다르게 나오면 신뢰를 잃습니다.

생성형 AI는 흩어진 실적을 평가 항목에 맞춰 정리하고 서술문을 다듬는 데 큰 도움을 줍니다. 그러나 지표 산출과 수치 확인은 AI에 맡기지 않습니다.

# 지표 정의부터 확인

## 지표 정의서

평가 문서 작성은 지표 정의를 확인하는 일에서 시작합니다. 편람의 정의를 표로 옮겨 두면 담당자가 바뀌어도 같은 기준으로 작성할 수 있습니다.

| 항목 | 내용 |
|---|---|
| 지표명 | 편람의 공식 명칭 |
| 정의 | 무엇을 재는가 |
| 산출식 | 분자와 분모의 정확한 정의 |
| 기준 시점 | 언제 기준의 자료인가 |
| 포함·제외 기준 | 누구를, 무엇을 넣고 빼는가 |
| 자료 출처 | 어느 시스템, 어느 부서 자료인가 |
| 담당 부서 | 자료를 책임지는 부서 |

```prompt 프롬프트 1. 지표 정의서 정리
아래는 평가 편람의 지표 설명입니다.
[편람 원문 붙여 넣기]
지표마다 위 표 형식(지표명, 정의, 산출식, 기준 시점, 포함·제외 기준, 자료 출처)으로 정리해 주세요.
편람에 없는 항목은 "편람에 없음"으로 적고 추측하지 마세요. 산출식은 편람 표현을 그대로 옮겨 주세요.
```

# 근거 자료 관리

## 근거 목록

평가 보고서의 서술마다 근거 자료 번호를 붙이고, 근거 자료 목록을 따로 관리합니다.

| 근거 번호 | 자료명 | 생산 부서 | 생산일 | 관련 항목 | 보관 위치 |
|---|---|---|---|---|---|
| 근거 2-1-1 | | | | | |

## 실적 정리

부서마다 보낸 실적 자료는 형식이 제각각입니다. AI로 평가 항목에 맞춰 묶으면 정리 시간이 줄어듭니다.

```prompt 프롬프트 2. 실적을 평가 항목에 맞추기
아래는 여러 부서에서 받은 [연도] 실적 메모입니다(개인정보 없음).
[실적 메모]
평가 항목 목록: [항목 번호와 이름]
실적마다 해당하는 평가 항목을 연결하고, 표(항목, 실적 요약, 수치, 근거 자료명, 제출 부서)로 정리해 주세요.
어느 항목에도 맞지 않는 실적과, 근거 자료명이 없는 실적은 따로 표시해 주세요. 수치는 메모에 있는 그대로만 옮깁니다.
```

# 서술문 작성

## 좋은 평가 서술문의 구조

평가 위원은 많은 보고서를 읽습니다. 서술문은 다음 순서로 쓰면 읽기 쉽습니다.

1. **기준과 체계:** 이 항목을 위해 어떤 규정, 계획, 조직을 갖추었는가
2. **운영 실적:** 실제로 무엇을 했는가(수치와 근거)
3. **성과와 환류:** 결과는 어떠했고, 평가 결과를 어떻게 다음 계획에 반영했는가

| 약한 서술 | 강한 서술 |
|---|---|
| 학생 만족도 제고를 위해 다양한 노력을 기울임 | 학생 상담 운영 규정(근거 3-2-1)에 따라 상담을 운영하였고, 상담 만족도 조사 결과(근거 3-2-4)를 바탕으로 다음 학년도에 야간 상담 시간을 신설함(근거 3-2-5) |
| 우수한 성과를 거둠 | 목표 대비 실적과 그 근거를 수치로 제시 |

```prompt 프롬프트 3. 평가 서술문
아래 자료로 평가 항목 [항목 번호와 이름]의 서술문을 써 주세요.
[해당 항목의 실적 표와 근거 목록]
구성: 기준과 체계, 운영 실적, 성과와 환류. 문장마다 근거 번호를 괄호로 붙입니다.
조건: 실적 표에 없는 사실과 수치를 쓰지 않습니다. "획기적", "탁월한" 같은 평가 표현 대신 사실을 씁니다. 분량은 [ ]자 이내.
```

# 수치 검증

## 같은 수치가 여러 곳에 나올 때

평가 문서의 신뢰를 가장 크게 떨어뜨리는 것은 수치 불일치입니다. 다음 절차로 확인합니다.

1. **원천 자료 하나로 정합니다.** 같은 지표는 하나의 시스템, 하나의 기준 시점 자료만 씁니다.
2. **계산은 엑셀로 합니다.** AI가 문장 안에서 계산한 비율이나 합계는 쓰지 않습니다.
3. **교차 대조합니다.** 공시 자료, 사업 보고서, 평가 보고서의 같은 지표를 한 표에 모아 비교합니다.

```prompt 프롬프트 4. 문서 간 수치 대조
아래 두 문서에서 같은 지표로 보이는 수치를 찾아 표로 대조해 주세요.
[문서 A의 해당 부분]
[문서 B의 해당 부분]
표 열: 지표, 문서 A 값과 위치, 문서 B 값과 위치, 일치 여부, 기준 시점 차이 가능성.
값을 새로 계산하지 말고 문서에 적힌 그대로 옮겨 주세요.
```

## 공개 자료와의 일관성

대학의 공시 자료는 누구나 볼 수 있습니다. 평가 보고서의 수치가 공시 자료와 다르면 그 이유(기준 시점, 산출 범위)를 설명할 수 있어야 합니다.

!!! 평가 문서를 제출하기 전에 확인합니다
- 지표 정의와 산출식을 편람 원문으로 확인했다
- 서술문의 문장마다 근거 번호가 있다
- 근거 자료가 실제로 있고 목록과 맞다
- 모든 수치를 원천 자료와 엑셀 계산으로 확인했다
- 같은 지표의 수치가 다른 문서와 맞거나 차이를 설명할 수 있다
- 평가 표현 대신 사실과 수치로 썼다
- AI에 개인정보와 공개 전 내부 자료를 넣지 않았다
