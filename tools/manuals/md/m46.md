# 간호와 AI

## 간호사의 일과 AI가 닿는 곳

간호는 사정, 진단, 계획, 수행, 평가로 이어지는 간호과정을 바탕으로 대상자를 돌보는 일입니다. 생성형 AI는 이 과정에서 생각을 정리하고 문서를 쓰고 교육 자료를 만드는 데 도움을 줄 수 있지만, 대상자를 직접 관찰하고 판단하는 일은 대신하지 못합니다.

| 영역 | AI가 돕는 부분 | 간호사가 판단할 부분 |
|---|---|---|
| 간호과정 학습 | 가상 사례의 자료 분류, 간호진단 후보, 계획 초안 | 실제 대상자 사정과 우선순위 결정 |
| 환자 교육 | 퇴원 교육, 자가관리 안내문을 쉬운 말로 | 교육 내용의 정확성, 대상자 이해 확인 |
| 의사소통 | 치료적 의사소통 연습, SBAR 보고 연습 | 실제 상황의 판단과 공감 |
| 시뮬레이션 | 시나리오 초안, 디브리핑 질문 | 시나리오의 임상적 타당성, 안전 |
| 국가시험 | 개념 정리, 연습 문항 | 정답 근거 확인 |

## 원칙

- **실습에서 만난 대상자 정보는 넣지 않습니다.** 이름, 병실, 진단명과 나이의 조합, 검사 결과, 투약 기록은 가명으로 바꿔도 일반 AI 서비스에 넣지 않는 것이 원칙입니다. 사례 학습은 가상 사례로 합니다.
- **투약은 AI 답변으로 판단하지 않습니다.** 용량, 경로, 상호작용은 약전, 의약품 정보, 기관 지침으로 확인합니다.
- **간호기록은 직접 씁니다.** 실제 간호기록은 의료법상 기록이며 사실 그대로 직접 작성해야 합니다. AI는 가상 사례로 기록 형식을 연습하는 데만 씁니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 기본간호학·실습 | 교재 절차 암기 | AI로 절차 체크리스트를 만들고 교재·지침과 대조해 오류 수정 | 절차 정확성, 근거 확인 |
| 성인간호학 | 지면 사례 간호과정 | AI 가상 사례로 간호과정을 쓰고, AI가 제시한 간호진단을 비판 | 임상 추론 |
| 아동·모성간호학 | 교육 자료 제작 | 대상자 수준별 교육 자료를 AI로 만들고 검증 | 대상자 맞춤 교육 |
| 정신간호학 | 역할극 | AI 가상 대상자와 치료적 의사소통 연습 | 치료적 의사소통 |
| 간호관리학 | 사례 토론 | AI로 SBAR 보고와 인계 연습 | 보고·인계 |
| 시뮬레이션 실습 | 기존 시나리오 | AI로 시나리오 초안을 만들고 교수진이 검토 | 시나리오 설계 |

# 교수자용 수업 활동

## 활동 1. 간호진단 비판하기

```prompt 프롬프트 1. 가상 사례 만들기
성인간호학 수업용 가상 사례를 만들어 주세요.
조건: [예: 수술 후 2일째 70대 환자], 활력징후, 통증 정도, 검사 결과 일부, 환자와 보호자의 말, 간호사가 관찰한 내용을 포함한 A4 반 쪽 분량. 실제 인물이나 기관을 떠올리게 하는 정보는 쓰지 마세요.
사례 뒤에 교수용으로 핵심 간호 문제 3가지와 그 근거 자료(사례 속 문장)를 따로 적어 주세요.
```

수업에서는 학생이 사례로 간호과정을 쓴 뒤, AI에게도 같은 사례로 간호진단을 받아 비교합니다. AI가 제시한 진단의 근거가 사례에 실제로 있는지, 우선순위가 맞는지를 토론합니다. AI의 간호진단 표현이 수업에서 쓰는 간호진단 분류 체계의 용어와 다를 수 있으므로 공식 용어로 고치는 것도 활동에 포함합니다.

## 활동 2. 시뮬레이션 시나리오 초안

```prompt 프롬프트 2. 시뮬레이션 시나리오
간호 시뮬레이션 실습용 시나리오 초안을 써 주세요.
주제: [예: 수혈 중 이상반응 초기 대응]
대상 학생: 3학년, 4인 1조, 20분 진행
구성: 학습목표 3개, 사전 정보(학생에게 줄 것), 환자 상태 변화 단계(시간별 활력징후와 증상), 학생에게 기대하는 행동, 촉진자 개입 기준, 디브리핑 질문 5개.
지킬 것: 약물 용량, 수혈 속도 같은 수치는 [교재·기관 지침 확인]으로 표시합니다.
```

시나리오는 반드시 교수진이 임상적 타당성과 안전을 검토한 뒤 씁니다.

## 활동 3. 환자 교육 자료 검증

학생이 AI로 [예: 심부전 환자의 퇴원 교육] 자료를 만들고, 교재와 공신력 있는 환자 교육 자료로 검증해 고칩니다. 검증표에는 AI가 쓴 내용, 근거 자료, 판정, 수정 내용을 적습니다.

# 학생용 실습 프롬프트

## 치료적 의사소통 연습

```prompt 프롬프트 3. 치료적 의사소통 역할극
당신은 입원 3일째 수술을 앞두고 불안해하는 가상의 50대 환자입니다. 저는 간호학과 학생입니다.
실제 환자처럼 짧게 대답하고, 제가 공감하지 못하거나 말을 끊으면 더 말하지 않는 반응을 보여 주세요.
제가 "연습 끝"이라고 하면 역할을 멈추고, 제 말 가운데 치료적 의사소통 기법(경청, 반영, 명료화 등)이 쓰인 문장과 비치료적 반응(성급한 안심, 충고 등)이 쓰인 문장을 골라 알려 주세요.
```

## SBAR 보고 연습

SBAR는 상황(Situation), 배경(Background), 사정(Assessment), 권고(Recommendation) 순서로 보고하는 방식입니다.

```prompt 프롬프트 4. SBAR 보고 평가
아래 가상 사례를 보고 제가 SBAR로 보고문을 쓰겠습니다. 제 보고문을 평가해 주세요.
[가상 사례]
[제 보고문]

평가 기준: 네 요소가 모두 있는가, 핵심 수치가 들어갔는가, 권고가 구체적인가, 30초 안에 말할 수 있는 길이인가.
고친 예시를 하나 보여 주되, 사례에 없는 정보는 추가하지 마세요.
```

## 국가시험 개념 정리

```prompt 프롬프트 5. 우선순위 판단 연습
간호사 국가시험의 우선순위 문제를 연습하고 싶습니다. [주제, 예: 호흡기계 환자 간호]에서 우선순위 판단 원칙을 정리하고, 원칙을 적용하는 가상 사례 3개를 만들어 주세요.
사례마다 제가 먼저 답하면 그다음 해설을 보여 주세요. 국가시험 기출문항을 옮기지 마세요.
```

# 전공 지식으로 검증하기

| 영역 | AI가 자주 틀리는 것 | 대조 자료 |
|---|---|---|
| 투약 | 용량, 투여 경로, 희석, 속도, 상호작용 | 의약품 정보, 기관 지침, 약리학 교재 |
| 활력징후 기준 | 연령별 정상 범위 | 기본간호학 교재 |
| 감염 관리 | 격리 유형별 보호구, 손 위생 시점 | 감염관리 지침, 교재 |
| 간호진단 | 분류 체계와 다른 용어, 근거 없는 진단 | 수업에서 쓰는 간호진단 분류 체계 |
| 환자 교육 | 오래된 권고, 대상자 상황과 맞지 않는 일반론 | 교재, 공신력 있는 환자 교육 자료 |
| 법과 윤리 | 간호사 업무 범위, 기록 의무 | 의료법, 간호 윤리 강령 |

!!! 간호 AI 결과물을 쓰기 전에 확인합니다
- 실습 대상자 정보를 AI에 넣지 않았다
- 투약 관련 수치를 AI 답변으로 판단하지 않았다
- 간호진단을 공식 분류 체계 용어로 고쳤다
- 교육 자료의 내용을 교재와 공신력 있는 자료로 확인했다
- 시뮬레이션 시나리오는 교수진 검토를 거쳤다
- 실제 간호기록은 AI로 쓰지 않았다
