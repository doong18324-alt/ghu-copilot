# 설명해 보면 아는 것과 모르는 것이 갈립니다

## 읽을 때는 다 아는 것 같습니다

교재를 읽을 때는 문장이 다 이해되는 것 같습니다. 그런데 친구가 "활동전위가 뭐야?"라고 물었을 때 막상 설명하려 하면 말이 꼬이고, 중간 단계를 건너뛰고, 교재 문장을 그대로 외워 말하게 됩니다. 이 순간이 바로 내가 모르는 부분이 드러나는 순간입니다.

읽기만 할 때는 익숙함을 이해로 착각하기 쉽습니다. 이것을 유창성 착각이라고 합니다. 설명해 보는 공부는 이 착각을 깨뜨립니다. 학습과학에서는 스스로 설명하는 활동(자기 설명)이 이해와 응용 능력을 높인다는 연구가 많이 보고되었습니다.

## 파인만 공부법

물리학자 리처드 파인만의 이름을 딴 이 방법은 네 단계로 이루어집니다.

| 단계 | 할 일 |
|---|---|
| 1. 고르기 | 공부할 개념 하나를 고릅니다 |
| 2. 설명하기 | 그 분야를 모르는 사람에게 쉬운 말로 설명합니다 |
| 3. 빈틈 찾기 | 막히거나 어려운 용어로 얼버무린 부분을 찾아 교재로 돌아갑니다 |
| 4. 다시 쓰기 | 더 짧고 쉽게, 비유를 넣어 다시 설명합니다 |

혼자 하면 2단계에서 누구에게 설명할지가 문제입니다. AI를 설명 상대로 세우면 언제든 이 공부를 할 수 있습니다.

# AI와 함께하는 네 단계

## 1단계: 개념 고르기

한 번에 하나의 개념만 고릅니다. "심장"처럼 넓은 주제보다 "심장의 전도 체계", "프랭크-스탈링 법칙"처럼 5분 안에 설명할 수 있는 크기가 좋습니다.

## 2단계: 초보 학생에게 설명하기

```prompt 호기심 많은 초보 학생
당신은 보건계열 1학년이 되기 직전인 고등학생입니다. 생물은 조금 알지만 [과목]은 전혀 모릅니다.
제가 [개념]을 설명하겠습니다. 다음 규칙으로 반응해 주세요.
- 제 설명에서 이해가 안 되는 단어가 나오면 "그게 뭐예요?"라고 물어 주세요.
- 단계가 건너뛰어진 것 같으면 "그럼 그 사이에는 무슨 일이 생겨요?"라고 물어 주세요.
- 이해가 되면 제 설명을 당신의 말로 한 문장 요약해 주세요.
- 제 설명이 틀렸다고 생각되면 학생답게 "책에서 다르게 본 것 같은데요"라고 말해 주세요.
제가 설명을 시작하겠습니다.
```

음성 대화 기능을 쓰면 실제로 말로 설명하는 연습이 되어 더 효과적입니다. 실습 현장에서 환자와 보호자에게 설명하는 상황과도 닮았습니다.

## 3단계: 설명 평가받기

설명이 끝나면 역할을 바꿔 AI에게 평가를 맡깁니다.

```prompt 설명 평가
지금부터는 [과목]을 가르치는 교수의 입장에서 제 설명을 평가해 주세요.
[설명 전문 붙여 넣기 또는 위 대화 이어서]

평가 기준
1. 정확성: 틀린 내용
2. 완결성: 빠진 핵심 단계
3. 쉬움: 풀어 쓰지 않은 전문 용어
4. 연결: 원인과 결과가 이어지는가
기준마다 점수(1~5)와 근거, 고칠 점을 표로 주세요. 정답 설명문은 쓰지 말고, 제가 교재에서 확인할 부분을 알려 주세요.
```

정답 설명문을 바로 받지 않는 것이 중요합니다. AI 설명을 받으면 다시 읽기 공부로 돌아가 버립니다. 빈틈을 알았으면 교재로 돌아가 내가 채웁니다.

## 4단계: 다시 쓰기

교재로 빈틈을 채운 뒤 설명을 다시 씁니다. 이번에는 더 짧게, 비유 하나를 넣고, 전문 용어는 처음 나올 때 풀어 씁니다. 다시 쓴 설명으로 2단계를 한 번 더 하면 처음보다 질문이 줄어든 것을 확인할 수 있습니다.

# 설명 예: 활동전위

## 첫 번째 설명과 받은 질문

> 학생의 첫 설명: 활동전위는 신경세포가 탈분극되었다가 재분극되는 것입니다. 나트륨 채널이 열리고 칼륨 채널이 열려서 생깁니다.
> 초보 학생 AI: 탈분극이 뭐예요? 채널이 열리면 왜 전기가 생겨요? 나트륨이랑 칼륨은 동시에 열려요?

질문 세 개가 곧 빈틈입니다. 학생은 용어를 외웠지만 "세포 안팎의 전하 차이"와 "이온이 이동하는 방향과 순서"를 설명하지 못했습니다.

## 다시 쓴 설명

> 신경세포 안쪽은 평소 바깥보다 전기적으로 음(-)의 상태입니다. 자극이 충분히 크면 세포막의 나트륨 통로가 먼저 열리고, 바깥에 많던 나트륨 이온이 안으로 몰려 들어와 안쪽이 순간 양(+)으로 바뀝니다(탈분극). 곧 나트륨 통로가 닫히고 칼륨 통로가 열려 칼륨 이온이 밖으로 나가면서 안쪽이 다시 음으로 돌아갑니다(재분극). 도미노가 하나씩 넘어가듯 이 변화가 옆 부위로 차례로 이어지는 것이 신경 신호의 전달입니다.

교재와 대조하면 막전위 수치, 문턱값, 불응기 같은 세부 내용을 더 채울 수 있습니다. 이 예시는 설명 방식을 보여 주기 위한 것이며, 시험 공부는 교재로 확인합니다.

# 설명 카드 만들기

## 10분 설명 카드

설명이 끝나면 카드 한 장으로 남깁니다. 이 카드가 시험 직전 복습 자료가 됩니다.

| 칸 | 내용 |
|---|---|
| 개념 | |
| 한 문장 설명 | 비전공자도 이해할 문장 |
| 핵심 단계 | 3~5단계 |
| 비유 | 일상의 무엇과 닮았나 |
| 처음에 막혔던 곳 | 2단계에서 받은 질문 |
| 교재에서 확인한 것 | 쪽수와 함께 |
| 연결 개념 | 이 개념을 알아야 이해되는 다음 개념 |

## 카드로 복습하기

카드의 "한 문장 설명"과 "핵심 단계"를 가리고, 개념 이름만 보고 다시 설명해 봅니다. 말로 할 수 있으면 통과, 막히면 그 칸을 다시 봅니다.

# 함께 하면 더 좋습니다

## 짝 설명

친구와 짝을 지어 한 사람은 설명하고 한 사람은 초보 학생 역할을 합니다. 설명이 끝나면 역할을 바꿉니다. AI는 짝 설명 뒤 두 사람의 설명을 비교해 서로 빠진 점을 찾는 데 씁니다.

## 스터디 그룹에서

그룹원이 각자 개념 하나씩 맡아 5분 설명을 준비해 옵니다. 다른 그룹원은 설명 평가 기준표로 점수를 매기고 질문을 합니다.

# 환자 설명으로 넓히기

## 같은 개념, 다른 청중

같은 개념을 교수님께, 동기에게, 환자에게 설명하면 내용과 말투가 모두 달라집니다. 세 가지로 설명해 보면 이해가 훨씬 단단해지고, 실습에서 환자 교육을 할 때도 도움이 됩니다.

| 청중 | 초점 | 피할 것 |
|---|---|---|
| 교수님 | 정확한 용어와 기전 | 지나친 단순화 |
| 동기 | 헷갈리는 점과 외우는 요령 | 설명 없이 용어만 나열 |
| 환자 | 왜 중요한지, 무엇을 해야 하는지 | 전문 용어, 불필요한 기전 |

```prompt 청중별 설명 평가
[개념]을 세 청중에게 설명한 제 글입니다.
교수님용: [ ]
동기용: [ ]
환자용: [ ]
청중별로 수준이 맞는지, 환자용에 전문 용어가 남아 있는지, 셋 사이에 사실이 어긋난 곳이 있는지 평가해 주세요.
```

# 자주 묻는 질문

**말로 설명하는 게 너무 어색합니다.**
처음에는 글로 써서 읽어도 됩니다. 두 번째부터는 글을 보지 않고 핵심 단계만 보고 말해 봅니다.

**설명할 개념을 고르기 어렵습니다.**
지난 시험에서 틀린 개념, 셀프 테스트에서 확신이 낮았던 개념부터 고릅니다.

# 자가진단과 자주 하는 실수

## 설명 공부 자가진단

!!! 내 설명 공부를 점검합니다
- 개념을 5분 안에 설명할 크기로 골랐다
- 전문 용어를 처음 나올 때 풀어 썼다
- 받은 질문을 빈틈으로 기록했다
- 정답 설명을 받지 않고 교재로 빈틈을 채웠다
- 다시 쓴 설명으로 한 번 더 설명했다
- 설명 카드를 만들었다

## 자주 하는 실수

| 실수 | 고치는 방법 |
|---|---|
| 교재 문장을 외워 말함 | 교재를 덮고 내 말로. 비유를 하나 넣기 |
| 너무 큰 주제를 고름 | 5분 크기로 쪼개기 |
| 평가 후 AI 정답을 받아 읽음 | 확인할 부분만 받고 교재로 채우기 |
| 한 번 설명하고 끝냄 | 다시 쓰고 다시 설명하기 |
| 글로만 설명 | 음성으로도 해 보기 |

# 바이탈에서 이어서 하기

- **어려운 개념 쉽게 풀기·미니 퀴즈:** 설명한 개념을 퀴즈로 확인합니다.
- **프롬프트 라이브러리 1-1:** 설명 전에 개념을 쉬운 말로 풀어 보는 데 씁니다.
- **다학제 케이스 컨퍼런스:** 내 직종 입장에서 다른 직종에게 설명하는 연습을 합니다.
