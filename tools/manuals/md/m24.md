# 왜 NotebookLM인가

## 일반 대화형 AI와 무엇이 다른가

ChatGPT나 Claude 같은 대화형 AI에게 전공 질문을 하면, AI는 학습한 일반 지식으로 답합니다. 설명은 매끄럽지만 우리 수업 교재와 용어가 다르거나, 출처를 알 수 없거나, 그럴듯하게 틀린 내용이 섞일 수 있습니다.

NotebookLM은 구글의 자료 기반 AI 도구입니다. 내가 올린 자료(소스)를 바탕으로 답하고, 답의 문장마다 어느 자료의 어느 부분에서 왔는지 인용 번호로 보여 줍니다. 인용 번호를 누르면 원문 위치로 바로 이동할 수 있어 확인이 쉽습니다.

| 구분 | 일반 대화형 AI | NotebookLM |
|---|---|---|
| 답의 근거 | 학습한 일반 지식 | 내가 올린 자료 |
| 출처 확인 | 직접 찾아야 함 | 인용 번호로 원문 위치 표시 |
| 우리 수업 용어 | 다를 수 있음 | 올린 자료의 용어를 따름 |
| 강점 | 넓은 설명, 글쓰기, 아이디어 | 자료 정리, 비교, 시험 대비, 근거 확인 |
| 약점 | 환각 위험 | 올린 자료가 틀리거나 부족하면 답도 부족 |

NotebookLM도 자료를 잘못 요약하거나 여러 자료를 섞어 답하는 경우가 있습니다. 인용 번호를 눌러 원문을 확인하는 습관은 여전히 필요합니다. 기능 이름, 올릴 수 있는 자료 수와 종류, 언어 지원은 계속 바뀌므로 화면의 최신 안내를 확인합니다.

## 학습과학으로 보면

| 원리 | NotebookLM에서 |
|---|---|
| 자료 기반 학습 | 우리 수업 자료 안에서 공부해 시험 범위와 용어가 맞음 |
| 인출 연습 | 퀴즈와 플래시카드로 꺼내 보기 |
| 정교화 | 자료끼리 비교하고 연결하는 질문 |
| 이중 부호화 | 마인드맵, 오디오 오버뷰로 다른 감각 활용 |

# 자료 준비와 노트북 설계

## 올릴 수 있는 자료와 올리면 안 되는 자료

| 구분 | 예 | 판단 |
|---|---|---|
| 내가 만든 자료 | 강의 필기, 요약 노트, 오답 노트 | 올려도 됨 |
| 수업에서 받은 자료 | 강의 슬라이드, 수업 자료 | 개인 공부용으로 올림, 공유하지 않음 |
| 공개 자료 | 공개된 진료지침, 정부 보고서, 공개 논문 | 올려도 됨 |
| 교재 전체 스캔본 | 출판된 교재를 통째로 스캔 | 저작권 문제, 올리지 않음 |
| 실습 기관 자료 | 환자 기록, 기관 내부 매뉴얼 | 올리지 않음 |
| 다른 사람의 과제 | 친구 리포트 | 올리지 않음 |

## 노트북은 목적별로 나눕니다

한 노트북에 모든 자료를 넣으면 답이 흐려지고 다른 과목 내용이 섞입니다. 노트북은 목적 하나에 하나씩 만듭니다.

| 노트북 종류 | 넣을 자료 | 예 |
|---|---|---|
| 과목 노트북 | 한 과목의 강의 자료와 필기 | 성인간호학 1 |
| 단원 노트북 | 어려운 단원의 자료와 관련 지침 | 심부전 단원 |
| 국가시험 노트북 | 과목별 요약 노트, 오답 노트, 출제 기준 | 국가시험 단권화 |
| 연구 노트북 | 졸업 연구 주제의 논문들 | 노인 낙상 예방 운동 |

## 자료를 잘 올리는 요령

- **파일 이름을 분명하게** 합니다. 예: "성인간호_03주_심부전_강의자료", "성인간호_03주_내필기"
- **스캔 PDF는 글자가 인식되는지** 확인합니다. 글자를 선택할 수 없는 이미지 PDF는 내용을 제대로 읽지 못할 수 있습니다.
- **내 필기를 함께 올립니다.** 강의 자료만 있으면 교수님이 강조한 부분이 빠집니다.
- **진료지침은 발행 기관과 연도**를 파일 이름에 넣습니다. 개정 전 자료가 섞이지 않게 합니다.

```prompt 노트북 첫 점검
이 노트북에 올린 자료 목록을 보고 다음을 정리해 주세요.
1. 자료별 핵심 주제 한 줄과 다루는 범위
2. 자료끼리 겹치는 주제
3. 자료끼리 설명이 서로 다른 부분
4. 이 노트북의 목적([목적])을 이루기에 빠진 주제
답에는 자료 인용을 붙여 주세요.
```

# 출처를 확인하며 질문하기

## 질문 네 가지 틀

| 틀 | 묻는 것 | 예 |
|---|---|---|
| 정의와 기준 | 무엇인가, 기준은 무엇인가 | 자료에서 심부전을 어떻게 분류하나요? |
| 기전과 이유 | 왜, 어떻게 | 이뇨제를 쓸 때 칼륨을 확인하는 이유를 자료 근거로 설명해 주세요 |
| 비교 | 무엇이 다른가 | 강의 자료와 진료지침의 권고가 다른 곳이 있나요? |
| 적용 | 상황에서 어떻게 | 자료 내용으로 볼 때 기좌호흡이 새로 생긴 환자에게 먼저 확인할 것은? |

## 꼬리 질문으로 깊게

첫 답의 인용을 확인한 뒤, 답 안의 핵심어를 다시 묻는 방식으로 파고듭니다.

```prompt 자료 기반 꼬리 질문
[개념]에 대해 자료 안에서만 답해 주세요.
1. 정의와 분류(인용 포함)
2. 기전을 단계별로(인용 포함)
3. 자료에서 이 개념과 함께 나오는 다른 개념과의 관계
4. 자료만으로는 답할 수 없는 부분
제가 각 답을 확인한 뒤 다음 질문을 하겠습니다.
```

## 자료에 없는 것을 물었을 때

NotebookLM은 자료에 없는 내용을 물으면 "자료에 없다"고 답하는 경우가 많습니다. 이것은 장점입니다. 자료에 없는 내용은 교재나 다른 공식 자료를 찾아 노트북에 더하거나, 일반 대화형 AI로 개념을 물은 뒤 교재로 확인합니다.

# 자동으로 만드는 학습 자료

## 스튜디오 기능

NotebookLM의 스튜디오(Studio) 영역에서는 올린 자료를 바탕으로 여러 형태의 학습 자료를 만들 수 있습니다. 메뉴 이름과 종류는 업데이트에 따라 달라질 수 있습니다.

| 자료 | 쓰는 곳 | 활용 요령 |
|---|---|---|
| 학습 가이드 | 단원 정리, 시험 대비 | 핵심 개념과 예상 질문을 내 필기와 비교 |
| 브리핑 문서 | 여러 자료의 요점 한눈에 | 조별 과제 시작 때 팀원과 공유 |
| 자주 묻는 질문(FAQ) | 헷갈리는 점 정리 | 답을 가리고 내가 먼저 답해 보기 |
| 타임라인 | 역사, 정책 변천, 질환 경과 | 연도와 사건을 교재와 대조 |
| 마인드맵 | 단원 구조 보기 | 백지 복습 후 비교용 |
| 퀴즈, 플래시카드 | 인출 연습 | 틀린 문제는 인용을 따라 원문 다시 보기 |
| 오디오 오버뷰 | 이동 중 복습 | 아래 별도 설명 |

## 생성 결과를 내 노트로

자동 생성 자료는 그대로 저장만 하면 다시 읽기 공부가 됩니다. 다음 순서로 내 노트로 바꿉니다.

1. 생성된 학습 가이드의 질문에 내가 먼저 답합니다.
2. 인용을 따라가 답을 확인합니다.
3. 틀리거나 몰랐던 부분만 노트에 추가합니다.
4. 정리한 노트를 다시 소스로 올려 다음 복습에 씁니다.

```prompt 맞춤 학습 가이드
[과목] [단원] 학습 가이드를 만들어 주세요.
- 대상: [학과] [학년], 목적: [중간고사, 국가시험 등]
- 구성: 핵심 개념 10개(정의와 인용), 헷갈리는 개념 쌍 3개와 구분 기준, 사례형 질문 5개(답은 따로)
- 강의 자료와 제 필기가 다르게 설명한 부분이 있으면 따로 표시해 주세요.
```

# 오디오 오버뷰로 듣는 복습

## 무엇인가

오디오 오버뷰는 올린 자료를 두 진행자가 대화하듯 설명하는 음성으로 만들어 주는 기능입니다. 통학, 실습지 이동, 운동 시간에 들으며 복습할 수 있습니다. 진행 방식, 길이, 언어, 초점을 지정하는 설정은 화면의 안내를 따릅니다.

## 듣기만 하면 부족합니다

듣는 공부는 편하지만 수동적이 되기 쉽습니다. 다음 방법으로 능동적으로 듣습니다.

- **듣기 전:** 이번 단원에서 답을 찾을 질문 세 개를 적습니다.
- **듣는 중:** 질문의 답이 나오면 짧게 메모합니다.
- **들은 뒤:** 책을 덮고 들은 내용을 1분 동안 소리 내어 요약합니다. 막힌 곳은 노트북에서 인용을 찾아 확인합니다.

## 초점을 지정하는 요청 예

```prompt 오디오 오버뷰 초점 지정
이 노트북의 자료로 오디오 오버뷰를 만들 때 다음에 초점을 맞춰 주세요.
- 대상: [학과] [학년], 다음 주 실습 전 복습
- 꼭 다룰 내용: [예, 심부전 환자 관찰 항목, 이뇨제 투여 시 확인할 것, 위험 신호]
- 진행 방식: 한 사람이 질문하고 다른 사람이 설명, 마지막에 핵심 3가지 반복
```

오디오 내용도 자료를 바탕으로 만들어지지만 틀리거나 과장된 표현이 섞일 수 있습니다. 시험과 실습에 쓸 내용은 노트북의 인용으로 확인합니다.

# 졸업 연구와 국가시험 단권화

## 선행연구 정리 매트릭스

졸업 연구나 캡스톤 과제를 준비할 때는 논문 여러 편을 같은 기준으로 비교하는 표(연구 매트릭스)가 필요합니다. NotebookLM에 공개 논문을 올리고 기준별로 정리하게 할 수 있습니다.

```prompt 연구 매트릭스
이 노트북의 논문들을 다음 열로 표를 만들어 주세요.
저자·연도, 연구 설계, 대상과 수, 중재 또는 노출, 비교군, 측정 도구, 주요 결과(원문 수치), 저자가 밝힌 한계
- 각 칸에 인용을 붙여 주세요.
- 논문에 없는 칸은 "보고 없음"으로 적어 주세요.
- 표 아래에 논문들 사이의 공통 결과와 서로 다른 결과를 각각 3줄로 정리해 주세요.
```

매트릭스의 수치는 반드시 원문 표와 하나씩 대조합니다. 연구 질문과 결론은 내가 씁니다. AI가 정리한 표를 그대로 과제나 논문에 옮기지 않습니다.

## 국가시험 단권화

국가시험 준비 막바지에는 여러 과목 자료를 한 권으로 모은 단권화 노트가 필요합니다. 국가시험 노트북에 다음을 넣습니다.

- 과목별 요약 노트(내가 정리한 것)
- 오답 노트와 오개념 카드
- 국가시험 시행 기관이 공개한 출제 기준
- 최신 법령 요약(보건의약 관계 법규 과목)

```prompt 오답 역추적 단권화
이 노트북의 오답 노트를 바탕으로 다음을 해 주세요.
1. 틀린 문제를 출제 기준의 과목과 영역별로 분류
2. 같은 개념을 반복해서 틀린 경우를 묶어 원인 정리
3. 영역별로 제가 다시 볼 요약 노트의 위치를 인용으로 연결
4. 가장 약한 영역 3개로 사례형 확인 문제 6개(답은 따로)
```

# 전공별 노트북 설계 예

## 계열별 활용

| 학과 | 노트북 예 | 넣을 자료 | 자주 쓸 질문 |
|---|---|---|---|
| 간호 | 성인간호 심혈관 | 강의 자료, 내 필기, 공개 진료지침 요약 | 질환별 사정, 중재, 교육 비교 |
| 물리치료 | 근골격 평가 | 강의 자료, 검사 방법 정리 노트 | 검사별 목적, 양성 소견, 감별 |
| 임상병리 | 혈액학 | 강의 자료, 검사 원리 필기 | 검사 지표 변화와 질환 연결 |
| 방사선 | 촬영 기법 | 강의 자료, 자세 정리 노트 | 부위별 자세, 중심선, 평가 기준 |
| 치위생 | 예방치학 | 강의 자료, 지수 측정 방법 필기 | 지수 계산과 해석 |
| 응급구조 | 전문소생술 | 강의 자료, 공개 지침 요약 | 리듬별 처치 순서 |
| 사회복지 | 사회복지정책 | 강의 자료, 공개 정책 보고서 | 정책 비교, 전달 체계 |
| 보건의료정보 | 질병분류 | 강의 자료, 분류 지침 정리 | 코딩 원칙과 예외 |
| 영양 | 임상영양 | 강의 자료, 식사요법 정리 | 질환별 식사요법 비교 |

## 학년별 노트북 구성

| 학년 | 노트북 구성 |
|---|---|
| 1학년 | 기초 과목(해부생리, 의학용어)별 노트북 |
| 2학년 | 전공 과목별 노트북, 어려운 단원은 단원 노트북 |
| 3학년 | 실습 대비 노트북(술기와 관련 이론), 과목별 노트북 유지 |
| 4학년 | 국가시험 노트북(과목별 요약 노트와 오답 노트 통합), 졸업 연구 노트북 |

# 노트를 쌓아 가는 방법

## 대화를 자산으로

좋은 답을 얻었을 때 대화창에만 두면 다음에 찾기 어렵습니다. 노트로 저장하고 제목을 붙입니다.

| 노트 제목 규칙 | 예 |
|---|---|
| [과목]_[주제]_[형식] | 성인간호_심부전_비교표 |
| [과목]_[주차]_[질문] | 혈액학_05주_빈혈감별질문 |

저장한 노트가 쌓이면 노트 자체를 다시 소스로 올려 "내 노트를 바탕으로" 질문할 수 있습니다. 시험 직전에는 교재보다 내 노트 노트북이 더 빠르게 핵심을 짚어 줍니다.

## 주간 루틴 예

| 요일 | 할 일 |
|---|---|
| 수업 당일 | 강의 자료와 필기를 과목 노트북에 올리기 |
| 다음 날 | 학습 가이드의 질문에 먼저 답하고 인용으로 확인 |
| 주중 | 헷갈린 개념을 꼬리 질문으로 파고들어 노트 저장 |
| 주말 | 퀴즈 기능으로 한 주 내용 인출 연습, 틀린 개념 노트에 추가 |

# 함께 쓰는 노트북

## 스터디 그룹에서

같은 과목을 듣는 친구들과 노트북을 공유하면 각자 정리한 필기를 합쳐 더 풍부한 자료를 만들 수 있습니다. 공유 전에 다음을 확인합니다.

- 수업 자료를 공유해도 되는지 담당 교수의 방침
- 각자 올린 필기의 출처(누가 정리했는지 파일 이름에 표시)
- 개인정보나 실습 기관 자료가 섞이지 않았는지

## 역할 나누기

| 역할 | 하는 일 |
|---|---|
| 자료 담당 | 강의 자료와 공개 자료를 정리해 올림 |
| 질문 담당 | 이번 주 핵심 질문 10개를 만들고 답을 노트로 저장 |
| 검증 담당 | 노트의 인용을 따라가 원문과 맞는지 확인 |
| 퀴즈 담당 | 퀴즈를 만들어 모임에서 함께 풂 |

역할은 주마다 돌아가며 맡아 모두가 질문하고 검증하는 경험을 하도록 합니다.

# 다른 AI 도구와 함께 쓰기

## 역할 분담

| 도구 | 잘하는 일 | 함께 쓰는 예 |
|---|---|---|
| NotebookLM | 내 자료 안에서 답하고 출처 표시 | 자료 기반 요약, 근거 확인 |
| 대화형 AI(ChatGPT, Claude, Gemini) | 넓은 설명, 비유, 역할극, 글 다듬기 | 개념을 쉽게 이해한 뒤 NotebookLM으로 교재 근거 확인 |
| 검색 기반 AI | 최신 웹 자료 찾기 | 최신 지침이나 공개 자료를 찾아 NotebookLM에 소스로 추가 |

어떤 도구를 쓰든 최종 확인은 교재와 공식 자료입니다. 도구마다 답이 다르면 그 차이가 공부할 거리입니다.

# 실전 예: 성인간호 심부전 단원 노트북

## 1단계: 자료 올리기

| 파일 이름 | 내용 |
|---|---|
| 성인간호_05주_심부전_강의자료 | 수업 슬라이드 |
| 성인간호_05주_심부전_내필기 | 수업 중 필기와 교수님 강조점 |
| 심부전_공개지침요약_[기관]_[연도] | 공개된 진료지침의 요약본 |
| 성인간호_05주_오답 | 단원 퀴즈에서 틀린 문제와 이유 |

## 2단계: 첫 점검

"노트북 첫 점검" 프롬프트로 자료끼리 다르게 설명한 부분을 찾습니다. 예를 들어 강의 자료와 지침 요약의 분류 방식이 다르면, 수업 기준이 무엇인지 표시하고 지침의 발행 연도를 확인합니다.

## 3단계: 질문 순서

| 순서 | 질문 |
|---|---|
| 1 | 좌심부전과 우심부전의 증상 차이를 기전과 함께, 인용 포함 |
| 2 | 심부전 환자에게 매일 체중을 재는 이유 |
| 3 | 이뇨제를 쓰는 환자의 관찰 항목과 근거 |
| 4 | 강의 자료와 지침에서 생활 교육 내용이 다른 부분 |
| 5 | 내 오답 노트의 문제를 자료로 다시 설명 |

## 4단계: 결과물

- 좌우 심부전 비교표(인용 포함)를 노트로 저장
- 학습 가이드 질문 10개에 먼저 답하고 확인
- 퀴즈 기능으로 10문제 풀고 틀린 개념을 오답 노트에 추가
- 오디오 오버뷰를 실습 전날 이동 중에 듣고 1분 요약

이 과정을 마친 단원 노트북은 3학년 실습과 4학년 국가시험 준비 때 그대로 다시 씁니다.

# 확인 습관 점검표

!!! NotebookLM 답을 쓰기 전에 확인합니다
- 답의 인용 번호를 눌러 원문을 읽었다
- 인용한 자료가 최신 판인지 확인했다
- 자료끼리 다를 때 수업 기준과 공식 기준을 확인했다
- 자료에 없다고 한 내용을 다른 공식 자료로 찾았다
- 내 노트에는 내 말로 다시 썼다

# 오류 탈출 요령

## 자주 생기는 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 답이 엉뚱하거나 흐림 | 노트북에 목적이 다른 자료가 섞임 | 목적별로 노트북 나누기 |
| 자료를 읽지 못함 | 글자가 인식되지 않는 스캔 PDF | 글자 인식이 되는 파일로 다시 올리기 |
| 자료끼리 설명이 다름 | 발행 연도나 대상이 다른 자료 | 최신 공식 자료 우선, 차이를 노트에 기록 |
| 인용 위치와 답이 안 맞음 | 요약 과정의 오류 | 인용 원문을 읽고 내가 고쳐 쓰기 |
| 생성 자료만 쌓임 | 읽기만 함 | 질문에 먼저 답하고 확인하는 순서 지키기 |

## 짧은 요령

- 질문 끝에 "인용을 붙여 주세요"를 넣으면 확인이 쉬워집니다.
- 좋은 답은 노트로 저장하고, 저장한 노트를 다시 소스로 올리면 다음 질문이 더 정확해집니다.
- 공유 기능으로 스터디 그룹과 노트북을 함께 쓸 때는 수업 자료의 공유 범위와 저작권을 먼저 확인합니다.

!!! 이 매뉴얼을 읽은 뒤 확인합니다
- NotebookLM과 일반 대화형 AI의 차이를 설명할 수 있다
- 올려도 되는 자료와 안 되는 자료를 구분할 수 있다
- 목적별로 노트북을 설계했다
- 인용을 확인하며 꼬리 질문을 했다
- 자동 생성 자료를 내 노트로 바꾸었다
- 오디오 오버뷰를 능동적으로 들었다
- 연구 매트릭스나 국가시험 단권화를 시작했다
