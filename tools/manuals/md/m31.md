# 왜 데이터 리터러시인가

## 숫자를 읽고 묻는 능력

병동의 낙상 건수 그래프, 외래 대기 시간 보고서, 새로 도입한 AI 영상 판독 도구의 성능 자료, 보건소의 지역 건강 통계는 모두 데이터로 말합니다. 데이터 리터러시는 이런 자료를 읽고, 의문을 품고, 정리하고, 의사결정에 쓰는 능력입니다. 데이터 분석가가 되지 않더라도 보건의료인은 다음 질문을 할 수 있어야 합니다.

- 이 숫자의 분모는 무엇인가?
- 이 자료는 누구를, 언제, 어떻게 측정했나?
- 빠진 값이나 이상한 값은 어떻게 처리했나?
- 이 그래프가 과장하는 것은 없나?
- 이 AI 도구의 성능은 어떤 환자에게서 확인되었나?

## 이 입문서의 순서

| 장 | 익힐 것 | 결과물 |
|---|---|---|
| 데이터 표준과 공공데이터 | 데이터가 어디서 어떤 형식으로 오는지 | 공공데이터 목록 |
| 데이터 정제 | 빠진 값, 이상값, 형식 문제 처리 | 정제 기록표 |
| 시각화 | 목적에 맞는 그래프 | 그래프 1장과 해석 |
| AI 도구 평가 | 진단 보조 AI의 성능과 한계 | 도구 평가표 |
| 질 향상 보고서 | 데이터로 문제를 찾고 개선 | 1쪽 QI 보고서 |

# 보건의료 데이터의 표준과 공공데이터

## 표준이 필요한 이유

같은 검사를 병원마다 다른 이름으로 부르면 자료를 모아 비교할 수 없습니다. 표준은 데이터를 서로 이해할 수 있게 하는 공통어입니다.

| 표준 | 대상 |
|---|---|
| 한국표준질병·사인분류(KCD) | 진단명과 사망 원인 |
| 건강보험 행위·약제 코드 | 진료 행위, 약제, 치료재료 |
| LOINC | 검사 항목 |
| SNOMED CT | 임상 용어 |
| HL7 FHIR | 시스템 간 진료 정보 교환 형식 |
| DICOM | 의료영상 |

## 연습에 쓸 수 있는 공개 자료

| 자료 | 어디서 | 쓰는 예 |
|---|---|---|
| 국가 통계 | 국가통계포털(KOSIS) | 연령별 만성질환 유병률 추이 |
| 국민건강영양조사 결과 | 질병관리청 | 비만, 고혈압 유병률 |
| 지역사회건강조사 결과 | 질병관리청 | 지역별 건강 행태 비교 |
| 공공데이터 | 공공데이터포털 | 의료기관 현황, 응급실 정보 |
| 보건의료 빅데이터 | 건강보험심사평가원·국민건강보험공단 공개 통계 | 질병별 진료 인원 |

원시자료(개인 단위 자료)는 대부분 이용 신청과 승인 절차가 필요합니다. 학생 실습에는 공개된 요약 통계를 쓰고, 연구용 원시자료는 지도교수와 함께 정해진 절차로 신청합니다. 자료를 쓸 때는 출처, 기준 연도, 정의를 함께 기록합니다.

```prompt 공공데이터 찾기 계획
저는 [학과] [학년]이고 [주제: 예, 지역 노인의 낙상과 신체활동]에 대한 데이터 과제를 합니다.
1. 이 주제에 쓸 수 있는 국내 공개 통계의 종류와 제공 기관
2. 각 자료에서 확인할 지표 이름과 정의
3. 자료끼리 비교할 때 주의할 점(조사 방법, 연도, 대상 차이)
을 표로 정리해 주세요. 자료 이름과 제공 기관은 제가 직접 확인하겠습니다. 확실하지 않으면 확인 필요로 표시해 주세요.
```

# 데이터 정제

## 정제가 분석의 대부분입니다

실제 데이터에는 빠진 값, 잘못 입력된 값, 형식이 섞인 값이 많습니다. 정제 없이 계산하면 평균 하나도 틀립니다.

| 문제 | 예 | 처리 방향 |
|---|---|---|
| 빠진 값 | 체중이 비어 있음 | 빠진 이유 확인, 분석에서 제외하거나 정해진 방법으로 처리하고 기록 |
| 범위 밖 값 | 체온 365°C | 입력 오류 확인, 원자료 대조 후 수정 또는 제외 |
| 극단값 | 재원일수 120일 | 오류가 아니면 유지, 중앙값 함께 보고 |
| 단위 섞임 | kg과 lb | 한 단위로 변환 |
| 표기 섞임 | "남", "M", "남성" | 하나의 코드로 통일 |
| 중복 | 같은 사람이 두 번 | 고유 번호로 확인 후 제거 |

## 정제 원칙

1. 원자료는 그대로 보관하고 복사본에서 작업합니다.
2. 모든 수정을 기록합니다. 무엇을, 왜, 어떻게 바꿨는지 적습니다.
3. 이상값을 지우기 전에 오류인지 실제 값인지 확인합니다.
4. 처리 방법을 보고서에 밝힙니다.

## AI로 정제 계획 세우기

실제 환자 자료는 AI에 넣지 않습니다. 가상 자료나 공개 자료, 또는 변수 구조만 설명해 정제 방법을 묻습니다.

```prompt 정제 계획
아래는 제 데이터의 변수 구조와 요약입니다. 실제 값은 넣지 않았습니다.
[변수명, 형식, 범위, 빠진 값 개수, 고유값 예]
1. 변수별로 확인할 문제(범위, 형식, 표기)
2. 엑셀이나 구글 시트에서 문제를 찾는 방법(필터, 조건부 서식, 함수)
3. 문제별 처리 선택지와 각각의 장단점
4. 정제 기록표 양식
을 알려 주세요.
```

# 시각화

## 목적이 그래프를 고릅니다

| 목적 | 그래프 | 주의 |
|---|---|---|
| 시간에 따른 변화 | 선 그래프 | 시간 간격을 일정하게 |
| 집단 비교 | 막대 그래프 | 축은 0에서 시작 |
| 분포 | 히스토그램, 상자그림 | 평균만 보여 주지 않기 |

| 질 관리 | 관리도, 런차트 | 기준선과 관리 한계 표시 |

## 과장하는 그래프 알아보기

- 막대 그래프의 세로축을 중간에서 잘라 작은 차이를 크게 보이게 함

- 분모가 다른 건수를 그대로 비교함
- 3차원 효과로 크기를 왜곡함
- 상관관계 그래프에 인과관계 제목을 붙임

# 진단 보조·영상 분석 AI 평가하기

## 성능 지표 읽기

진단 보조 AI의 성능은 여러 지표로 보고됩니다.

| 지표 | 뜻 | 질문 |
|---|---|---|
| 민감도 | 실제 환자 가운데 양성으로 찾아낸 비율 | 놓치는 환자는 얼마나 되나? |
| 특이도 | 실제 비환자 가운데 음성으로 판정한 비율 | 불필요한 경보는 얼마나 되나? |
| 양성예측도 | 양성 판정 가운데 실제 환자 비율 | 경보가 울렸을 때 믿을 만한가? |
| AUC | 여러 기준점에서의 전반적 판별 능력 | 하나의 숫자로 요약된 성능 |

양성예측도는 질환이 얼마나 흔한지(유병률)에 따라 크게 달라집니다. 같은 민감도와 특이도라도 질환이 드문 집단에서 쓰면 양성 판정의 상당수가 거짓 양성일 수 있습니다.

## 도구를 쓰기 전에 물을 것

| 질문 | 이유 |
|---|---|
| 어떤 환자 자료로 개발하고 검증했나? | 개발 자료와 우리 환자가 다르면 성능이 떨어질 수 있음 |
| 다른 기관 자료로 외부 검증했나? | 한 기관 자료에서만 좋은 성능은 일반화되기 어려움 |
| 의료기기 허가나 인증을 받았나? | 국내에서는 식품의약품안전처의 의료기기 규제 대상일 수 있음 |
| 어떤 상황에서 틀리기 쉬운가? | 영상 품질, 드문 질환, 특정 인구 집단 |
| 최종 판단은 누가 하나? | AI는 보조, 판단과 책임은 사람 |
| 결과를 어떻게 기록하고 감시하나? | 성능 저하와 오류를 계속 확인 |

```prompt AI 도구 평가표
아래는 [진단 보조 AI 도구]에 대해 공개된 설명과 논문 초록입니다.
[붙여 넣기]
위 여섯 가지 질문에 대해 자료에서 답할 수 있는 것과 없는 것을 표로 정리해 주세요.
수치는 자료에 있는 것만 쓰고, 자료에 없는 것은 "확인 필요"로 적어 주세요.

```

## 생성형 AI의 진료 활용

생성형 AI는 기록 요약, 환자 교육 자료 초안, 문헌 정리에 쓰이기 시작했습니다. 그러나 사실과 다른 내용을 만들 수 있고, 환자 정보 보호 문제가 있습니다. 기관이 승인한 도구와 절차 안에서만 쓰고, 결과는 반드시 사람이 확인합니다. 자세한 원칙은 「보건의료인을 위한 생성형 AI 활용 윤리 및 데이터 보호 지침서」를 봅니다.

# 질 향상 보고서와 데이터 기반 의사결정

## 질 향상의 순환

질 향상(Quality Improvement, QI) 활동은 문제를 데이터로 확인하고, 작은 변화를 시험하고, 결과를 다시 측정하는 순환입니다. 계획(Plan), 실행(Do), 연구(Study), 개선(Act)의 앞 글자를 딴 PDSA 순환이 널리 쓰입니다.

| 단계 | 할 일 | 예(병동 낙상) |
|---|---|---|
| 계획 | 문제 정의, 목표, 측정 지표, 시험할 변화 | 야간 낙상이 많음, 재원 1,000일당 낙상 건수 감소 목표, 야간 배뇨 도움 순회 시험 |
| 실행 | 작은 규모로 시험 | 한 병동에서 4주 |
| 연구 | 데이터로 결과 확인 | 런차트로 전후 비교 |
| 개선 | 확대, 수정, 중단 결정 | 효과가 있으면 다른 병동으로 확대 |

## 지표 고르기

| 지표 종류 | 뜻 | 예 |
|---|---|---|
| 구조 | 인력, 시설, 장비 | 야간 간호 인력 수 |
| 과정 | 실제로 한 일 | 낙상 위험 평가 수행률 |
| 결과 | 환자에게 나타난 변화 | 낙상률, 낙상으로 인한 손상 |
| 균형 | 변화의 부작용 | 야간 순회로 인한 수면 방해 호소 |

## 1쪽 QI 보고서

| 칸 | 내용 |
|---|---|
| 제목 | 핵심 메시지 한 문장 |
| 문제 | 현황 데이터와 분모 |
| 목표 | 구체적이고 측정 가능하게 |
| 변화 | 시험한 개선 활동 |
| 결과 | 그래프 1개와 수치 |
| 해석과 한계 | 데이터로 말할 수 있는 것과 없는 것 |
| 다음 단계 | 확대, 수정, 중단 |

```prompt QI 보고서 점검
아래는 제가 공개 자료나 가상 자료로 작성한 1쪽 QI 보고서입니다.
[붙여 넣기]
1. 목표가 측정 가능한가
2. 지표의 분모와 정의가 분명한가
3. 결과 해석이 자료를 넘어서지 않는가(대조군 없는 전후 비교의 한계 등)
4. 균형 지표가 빠지지 않았는가
를 점검해 주세요. 수치를 새로 만들지 마세요.
```

# 기초 통계로 해석하기

## 기술통계와 추론통계

| 구분 | 하는 일 | 예 |
|---|---|---|
| 기술통계 | 자료를 요약 | 평균, 중앙값, 표준편차, 비율 |
| 추론통계 | 표본으로 모집단을 추론 | 두 집단 비교, 관계 검정, 신뢰구간 |

## 결과표를 읽는 법

| 표현 | 뜻 | 주의 |
|---|---|---|
| p 값 | 차이가 없다고 가정했을 때 이만큼의 차이가 우연히 나올 확률 | p가 작다고 차이가 크거나 중요한 것은 아님 |
| 신뢰구간 | 참값이 있을 것으로 추정되는 범위 | 범위가 넓으면 추정이 불확실 |
| 효과크기 | 차이나 관계의 크기 | 임상적으로 의미 있는 크기인지 함께 판단 |
| 상대위험도, 교차비 | 노출군과 비노출군의 위험 비교 | 1이면 차이 없음, 기준 집단 확인 |

## 상관과 인과

두 변수가 함께 움직인다고 하나가 다른 하나의 원인은 아닙니다. 커피를 많이 마시는 사람에게 어떤 질환이 많다는 관찰 결과는, 커피 때문일 수도 있지만 흡연 같은 다른 요인(교란 변수)이 둘 다에 영향을 주었을 수도 있습니다. 인과를 말하려면 무작위 배정 연구나 교란을 충분히 통제한 연구 설계가 필요합니다.

```prompt 결과 해석 점검
아래는 [연구 또는 보고서]의 결과 문장과 표입니다.
[붙여 넣기]
1. 이 결과로 말할 수 있는 것과 말할 수 없는 것
2. 가능한 교란 변수
3. 통계적 유의성과 임상적 의미를 구분한 해석
을 정리해 주세요. 수치는 원문에 있는 것만 써 주세요.
```

## 실습: 가상 낙상 자료로 런차트 만들기

1. AI에게 가상 자료를 만들게 합니다(월, 재원일수, 낙상 건수 24개월).
2. 월별 낙상률(재원 1,000일당 건수)을 계산합니다.
3. 선 그래프에 중앙값 선을 추가해 런차트를 만듭니다.
4. 개선 활동을 시작한 달에 표시하고 전후 변화를 설명합니다.

```prompt 가상 QI 자료 만들기

- 24개월, 열: 월, 재원일수, 낙상 건수
- 13개월째에 개선 활동을 시작했다고 가정하고, 이후 약간 줄어드는 경향
- 무작위 변동을 넣어 매달 값이 고르지 않게
표 아래에 런차트를 만드는 순서를 단계별로 알려 주세요.
```

# 디지털 헬스케어 도구 평가

## 앱, 웨어러블, 원격 모니터링

건강 앱과 웨어러블 기기, 원격 모니터링이 늘면서 환자가 직접 측정한 자료를 가져오는 일이 많아졌습니다. 이런 자료를 볼 때도 같은 질문을 합니다.

| 질문 | 확인할 것 |
|---|---|
| 측정이 정확한가 | 기기의 검증 자료, 의료기기 여부 |
| 측정 조건이 일정한가 | 착용 위치, 시간, 활동 상태 |
| 누구에게 맞는가 | 고령자, 피부색, 질환에 따른 정확도 차이 |
| 정보가 안전한가 | 개인정보 처리방침, 데이터 저장 위치 |
| 행동 변화로 이어지는가 | 사용 지속률, 효과 근거 |

## 디지털 치료기기와 소프트웨어 의료기기

질병의 예방, 관리, 치료를 목적으로 하는 소프트웨어 가운데 일부는 의료기기로 분류되어 허가나 인증을 받아야 합니다. 일반 건강관리 앱과 의료기기 소프트웨어는 목적과 규제가 다르므로, 환자에게 권하기 전에 어느 쪽인지, 근거가 무엇인지 확인합니다. 분류 기준과 허가 현황은 식품의약품안전처 자료로 확인합니다.

# 실습 과제

## 과제: 공개 데이터로 1쪽 보고서 만들기

1. 관심 주제를 정하고 공개 통계 하나를 고릅니다.
2. 자료의 출처, 기준 연도, 지표 정의를 기록합니다.
3. 필요한 부분을 표로 옮기고 정제 기록을 남깁니다.
4. 목적에 맞는 그래프 한 장을 만듭니다.
5. 해석 세 문장과 한계 두 문장을 씁니다.
6. AI로 보고서를 점검받고, 수치는 원자료와 다시 대조합니다.

!!! 이 입문서를 마치며 확인합니다
- 보건의료 데이터 표준의 종류와 역할을 안다
- 공개 데이터를 찾고 출처와 정의를 기록했다
- 정제 원칙을 지키고 정제 기록표를 썼다
- 과장된 그래프를 알아보고 고칠 수 있다
- 민감도, 특이도, 양성예측도를 해석할 수 있다
- 진단 보조 AI를 쓰기 전에 물을 질문을 안다
- PDSA 순환으로 1쪽 QI 보고서를 썼다
