# 점수보다 과정을 보는 이유

## 같은 점수, 다른 이유

중간고사에서 70점을 받은 두 학생이 있습니다. 한 학생은 시험 전날 처음 공부를 시작했고, 다른 학생은 3주 동안 꾸준히 했지만 읽기만 반복했습니다. 점수는 같지만 다음 시험을 위해 고칠 점은 전혀 다릅니다. 첫 학생은 계획이, 두 번째 학생은 공부 방법이 문제입니다.

점수는 결과일 뿐 원인을 알려 주지 않습니다. 시험이 끝난 뒤 "다음엔 더 열심히 해야지"로 끝내면 같은 실수를 반복합니다. 학습 프로세스 리뷰는 공부를 어떻게 했는지 돌아보고, 무엇을 유지하고 무엇을 바꿀지 구체적으로 정하는 활동입니다. 내가 어떻게 배우는지 알고 조절하는 능력을 메타인지라고 하며, 자기주도학습의 중심이 됩니다.

# 사후 검토의 네 가지 질문

## 질문 틀

사후 검토(After Action Review, AAR)는 군대와 병원, 기업에서 활동이 끝난 뒤 쓰는 돌아보기 방법입니다. 누구 잘못인지 따지지 않고 배울 점을 찾는 것이 원칙입니다.

| 질문 | 학습 리뷰에서 |
|---|---|
| 1. 무엇을 하려고 했나 | 계획한 공부 시간, 범위, 방법, 목표 점수 |
| 2. 실제로 무슨 일이 있었나 | 실제 공부 시간, 한 범위, 쓴 방법, 결과 |
| 3. 왜 차이가 생겼나 | 시간 배치, 방법, 컨디션, 외부 일정 |
| 4. 다음에 무엇을 할까 | 유지할 것, 바꿀 것, 새로 해 볼 것 |

3번 질문이 가장 중요합니다. "의지가 약해서"는 원인이 아닙니다. 실습 다음 날 계획을 너무 많이 잡았는지, 읽기만 하고 문제를 풀지 않았는지처럼 바꿀 수 있는 원인을 찾습니다.

# 시험 직후 리뷰

## 기억이 생생할 때 합니다

시험이 끝나고 결과가 나오기 전, 또는 결과가 나온 직후에 리뷰를 합니다. 시간이 지나면 공부 과정이 흐려집니다.

## 리뷰 전에 모을 자료

- 시험 전 세운 학습 계획
- 실제 공부 기록(플래너, 캘린더)
- 셀프 테스트와 오답 기록
- 시험 문항별로 기억나는 어려움(어떤 유형이 어려웠는지)
- 점수(나온 경우)

## 리뷰 프롬프트

```prompt 시험 직후 학습 리뷰
[과목] [시험 종류]를 마쳤습니다. 사후 검토 네 가지 질문으로 함께 돌아봐 주세요.
1. 계획: [계획 붙여 넣기]
2. 실제: [실제 공부 기록, 쓴 방법, 시험에서 어려웠던 유형, 점수]

다음 순서로 진행해 주세요.
- 계획과 실제의 차이를 표로 정리
- 차이의 원인을 시간 배치, 공부 방법, 컨디션, 외부 요인으로 나누어 분석(의지 탓은 원인에서 제외)
- 다음 시험을 위해 유지할 것 2개, 바꿀 것 2개, 새로 해 볼 것 1개
- 각 항목에 이 시리즈의 어떤 방법(플래너, 구조화, 키워드 키트, 질문 대화, 설명, 비유, 셀프 테스트, 오답 피드백)을 쓸지
원인이 분명하지 않으면 제게 질문해 주세요.
```

## 리뷰 결과 예

간호학과 2학년 학생의 중간고사 리뷰를 정리하면 다음과 같은 모습이 됩니다.

| 항목 | 내용 |
|---|---|
| 계획 | 3주 동안 하루 2시간, 교재 3회독, 목표 85점 |
| 실제 | 앞 2주는 하루 1시간 미만, 마지막 주 몰아서 읽기 2회, 문제 풀이 없음, 72점 |
| 어려웠던 유형 | 사례 판단 문제, 약물 비교 |
| 원인 | 실습 주간에 계획이 과다. 읽기만 하고 인출 연습 없음. 약물을 따로 외워 비교하지 못함 |
| 유지 | 강의 당일 필기 정리 |
| 바꿀 것 | 실습 주간은 하루 30분 퀴즈로 축소. 읽기 대신 셀프 테스트 |
| 새로 해 볼 것 | 약물 비교표와 3분 백지 복습 |

# 공부 피로와 번아웃 점검

## 방법보다 상태가 문제일 때

리뷰를 하다 보면 방법이 아니라 지친 상태가 원인인 경우가 있습니다. 실습, 아르바이트, 과제가 겹치는 학기에는 특히 그렇습니다. 공부 효율이 떨어졌다고 공부 시간을 더 늘리면 상황이 나빠질 수 있습니다.

| 신호 | 예 |
|---|---|
| 집중 저하 | 같은 문단을 여러 번 읽어도 들어오지 않음 |
| 수면 변화 | 잠들기 어렵거나 자도 피곤함 |
| 흥미 상실 | 좋아하던 과목도 하기 싫음 |
| 몸의 신호 | 두통, 소화 불편이 자주 생김 |
| 회피 | 공부를 시작하기 전부터 미루고 휴대폰을 오래 봄 |

```prompt 공부 피로 점검
최근 [기간] 동안 제 일정과 상태를 정리해 보려고 합니다.
일정: [실습, 수업, 아르바이트, 과제]
상태: [수면, 집중, 기분, 몸의 신호를 제 말로]

1. 일정에서 부담이 몰린 시기와 이유를 정리해 주세요.
2. 다음 2주 동안 공부량을 어떻게 조정하면 좋을지, 꼭 지킬 휴식 시간과 함께 제안해 주세요.
3. 제가 혼자 해결하기보다 도움을 받아야 할 신호가 있다면 알려 주세요.
의학적 진단은 하지 말아 주세요.
```

AI는 일정을 정리하고 조정하는 데 도움을 줄 수 있지만 상담이나 진료를 대신하지 않습니다. 지친 상태가 2주 이상 이어지거나, 일상생활이 어렵거나, 마음이 크게 힘들면 학교의 학생상담 부서나 전문가의 도움을 받습니다. 도움을 청하는 것은 보건의료인이 갖춰야 할 자기 관리 능력입니다.

# 나에게 맞는 공부 방식 정리

## 학기마다 업데이트하는 공부 설명서

리뷰가 쌓이면 나에게 맞는 공부 방식이 보입니다. 이를 한 쪽짜리 "나의 공부 설명서"로 정리해 두고 학기마다 고칩니다.

| 항목 | 내 경우 |
|---|---|
| 집중이 잘 되는 시간 | |
| 잘 맞는 장소 | |
| 효과가 컸던 방법 | |
| 효과가 적었던 방법 | |
| 자주 빠지는 함정 | |
| 계획이 무너지는 상황과 대처 | |
| 지쳤을 때 신호와 쉬는 방법 | |

```prompt 나의 공부 설명서
아래는 지난 [학기 또는 기간] 동안의 학습 리뷰 기록입니다.
[리뷰 기록 붙여 넣기]
기록에서 반복되는 패턴을 찾아 "나의 공부 설명서"를 위 표 형식으로 정리해 주세요.
기록에 근거가 없는 항목은 비워 두고, 다음 학기에 확인해 볼 점으로 적어 주세요.
```

## 아홉 권을 하나로 잇기

| 리뷰에서 나온 원인 | 쓸 방법 |
|---|---|
| 계획이 과다하거나 몰아서 함 | 학습 플래너 |
| 큰 그림이 없음 | 마인드맵과 구조화 |
| 낯선 용어에 막힘 | 키워드 탐색 키트 |
| 외웠지만 응용 못 함 | 질문 대화법, 설명 공부법 |
| 비슷한 개념이 헷갈림 | 비유·시나리오 연상법, 비교표 |
| 읽기만 함 | 셀프 테스트 |
| 같은 문제를 또 틀림 | 오답 피드백 |

# 학기 단위 리뷰

## 학기 말 돌아보기

시험별 리뷰를 모아 학기 말에 한 번 더 돌아봅니다.

| 질문 | 기록 |
|---|---|
| 이번 학기 가장 효과가 컸던 공부 방법은? | |
| 시간을 가장 많이 썼지만 효과가 적었던 것은? | |
| 과목별로 다음 학기에 이어질 약점은? | |
| 실습, 아르바이트, 건강 가운데 공부에 영향을 준 것은? | |
| 다음 학기에 새로 해 볼 방법 하나는? | |

```prompt 학기 말 리뷰
이번 학기 제 시험별 리뷰 기록과 학기 성적 요약입니다.
[붙여 넣기]
1. 학기 전체에서 반복된 패턴
2. 다음 학기 과목 구성([다음 학기 과목])을 고려한 공부 방법 제안
3. 다음 학기 첫 주에 할 일 세 가지
를 정리해 주세요.
```

# 지도교수 상담에 활용하기

학습 리뷰와 공부 설명서를 지도교수 상담에 가져가면 대화가 구체적이 됩니다. "공부가 잘 안 돼요" 대신 "실습 주간에 계획이 무너지고, 읽기만 하는 습관이 있어 셀프 테스트로 바꿔 보려 합니다"처럼 말할 수 있습니다. 교수는 과목 특성에 맞는 조언과 학교의 학습 지원 프로그램을 연결해 줄 수 있습니다.
