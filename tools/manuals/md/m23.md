## 해부생리학은 지도입니다

해부생리학은 보건계열 모든 전공의 출발점입니다. 간호학의 질환 간호, 물리치료의 운동치료, 임상병리의 검사 해석, 방사선의 영상 판독, 치위생의 구강 구조 이해가 모두 이 지도 위에서 이루어집니다. 그런데 1학년 때는 용어가 너무 많고, 구조와 기능이 따로 노는 것처럼 느껴져 외우기 바쁩니다.

이 워크북은 계통마다 같은 다섯 단계를 반복합니다.

비유는 이해를 돕는 다리일 뿐입니다. 비유를 이해한 뒤에는 반드시 교재 용어로 다시 말해 보고, 시험 답안에는 교재 용어를 씁니다. 이 워크북의 설명은 핵심 개념만 간추린 것이므로 세부 내용과 수치는 수업 교재로 확인합니다.

# 골격계통: 몸을 받치는 살아 있는 구조물

## 용어 쪼개기

| 용어 | 쪼개기 | 뜻 |
|---|---|---|
| osteoblast | oste(뼈) + blast(만드는 세포) | 뼈모세포(조골세포), 새 뼈를 만듦 |
| osteoclast | oste(뼈) + clast(부수는 것) | 뼈파괴세포(파골세포), 뼈를 흡수 |
| osteoporosis | oste(뼈) + por(구멍) + osis(상태) | 골다공증 |
| arthritis | arthr(관절) + itis(염증) | 관절염 |
| chondrocyte | chondr(연골) + cyte(세포) | 연골세포 |

## 핵심 기전 1. 뼈는 계속 다시 지어집니다

뼈는 한 번 만들어지면 그대로 있는 돌 같은 조직이 아닙니다. 오래된 건물을 부분적으로 허물고 새로 짓는 리모델링 공사처럼, 파골세포가 낡은 뼈를 흡수하고 조골세포가 그 자리에 새 뼈를 채웁니다. 이 과정을 뼈 재형성(bone remodeling)이라고 합니다.

- 운동처럼 뼈에 힘이 실리면 새로 짓는 쪽이 활발해져 뼈가 튼튼해집니다.
- 오래 누워 있거나 우주 비행처럼 하중이 없으면 허무는 쪽이 앞서 뼈가 약해집니다.
- 폐경 후에는 에스트로겐이 줄어 허무는 쪽이 앞서기 쉬워 골다공증 위험이 커집니다.

비유의 한계: 건물 공사는 끝이 있지만 뼈 재형성은 평생 계속되며, 혈중 칼슘 조절과도 연결되어 있습니다.

## 핵심 기전 2. 뼈는 칼슘 은행입니다

혈액 속 칼슘은 근육 수축, 신경 전달, 혈액 응고에 꼭 필요해서 좁은 범위로 유지됩니다. 뼈는 칼슘을 저축해 둔 은행 역할을 합니다.

| 호르몬 | 분비 장소 | 혈중 칼슘에 미치는 영향 | 주요 작용 |
|---|---|---|---|
| 부갑상샘호르몬(PTH) | 부갑상샘 | 올림 | 뼈에서 칼슘을 꺼내고, 콩팥 재흡수를 늘리고, 활성 비타민 D 생성을 늘림 |
| 칼시토닌 | 갑상샘 | 낮춤 | 파골세포 활동 억제 |
| 활성 비타민 D | 간과 콩팥을 거쳐 활성화 | 올림 | 장에서 칼슘 흡수 증가 |

임상 연결: 갑상샘 수술 뒤 부갑상샘이 손상되면 혈중 칼슘이 떨어져 입 주위 저림이나 근육 경련이 생길 수 있습니다.

## AI 튜터 프롬프트

```prompt 골격계 튜터
뼈 재형성을 건물 리모델링에 비유해 설명하고, 부갑상샘호르몬과 칼시토닌이 혈중 칼슘이 낮을 때와 높을 때 각각 어떻게 반응하는지 표로 정리해 주세요. 끝에 제가 답할 확인 질문을 하나 해 주세요.
```

## 확인 퀴즈

1. 새 뼈를 만드는 세포의 이름은?
2. 혈중 칼슘이 낮을 때 분비가 늘어나는 호르몬은?
3. 오래 누워 있는 환자의 뼈가 약해지는 이유를 한 문장으로 쓰세요.
4. 활성 비타민 D가 칼슘 흡수를 늘리는 장소는?

## 해설과 오개념

1. 조골세포(osteoblast). blast는 "만드는", clast는 "부수는"으로 기억합니다.
2. 부갑상샘호르몬. 칼시토닌은 칼슘을 낮추는 쪽입니다.
3. 뼈에 실리는 하중이 줄어 뼈 흡수가 형성보다 앞서기 때문입니다.
4. 소장(작은창자)입니다.

**흔한 오개념:** "뼈는 성장이 끝나면 변하지 않는다." 성인의 뼈도 평생 재형성됩니다. 그래서 운동과 영양이 노년기 뼈 건강에도 중요합니다.

# 근육계통: 몸을 움직이는 모터

## 용어 쪼개기

| 용어 | 쪼개기 | 뜻 |
|---|---|---|
| myocardium | my(근육) + cardi(심장) + um | 심장근육 |
| myalgia | my(근육) + algia(통증) | 근육통 |
| sarcomere | sarco(살) + mere(부분) | 근육원섬유마디, 수축의 기본 단위 |
| atrophy | a(없음) + trophy(영양, 성장) | 위축 |
| hypertrophy | hyper(과다) + trophy | 비대 |

## 핵심 기전 1. 근육은 섬유가 미끄러지며 짧아집니다

근육 세포 안에는 가는 필라멘트(액틴)와 굵은 필라멘트(마이오신)가 번갈아 놓여 있습니다. 수축할 때 필라멘트 자체가 짧아지는 것이 아니라, 마이오신 머리가 액틴을 붙잡고 당기기를 반복하면서 두 필라멘트가 서로 겹쳐 미끄러져 들어갑니다. 줄다리기 선수들이 밧줄을 손으로 번갈아 당겨 끌어오는 모습과 비슷합니다. 이것을 활주설(sliding filament theory)이라고 합니다. 마이오신 머리가 당기고 떨어지는 데에는 ATP가 필요합니다.

비유의 한계: 줄다리기는 밧줄 한쪽만 끌려오지만, 근육원섬유마디에서는 양쪽 액틴이 가운데로 함께 끌려옵니다.

## 핵심 기전 2. 칼슘이 자물쇠를 엽니다

쉬고 있을 때 액틴의 결합 자리는 트로포마이오신이라는 단백질이 덮고 있어 마이오신이 붙을 수 없습니다. 신경 신호가 오면 근육 세포 안 저장소(근형질세망)에서 칼슘이 나오고, 칼슘이 트로포닌에 붙으면 트로포마이오신이 비켜나 결합 자리가 열립니다. 신호가 끝나 칼슘이 다시 저장소로 들어가면 자리가 닫히고 근육이 이완됩니다.

| 순서 | 일어나는 일 |
|---|---|
| 1 | 운동신경 신호가 근육에 도착 |
| 2 | 근형질세망에서 칼슘 방출 |
| 3 | 칼슘이 트로포닌에 결합, 결합 자리 노출 |
| 4 | 마이오신이 액틴을 당김(ATP 사용) |
| 5 | 칼슘 회수, 이완 |


1. 근수축의 기본 단위는?
2. 수축할 때 필라멘트 자체의 길이는 짧아지는가?
3. 액틴의 결합 자리를 여는 데 직접 관여하는 이온은?
4. 오래 쓰지 않은 근육이 가늘어지는 현상을 뜻하는 용어는?

## 해설과 오개념

1. 근육원섬유마디(sarcomere).
2. 아닙니다. 필라멘트끼리 겹치는 정도가 커질 뿐입니다.
3. 칼슘 이온.
4. 위축(atrophy).

**흔한 오개념:** "근육은 늘어나는 힘도 스스로 낸다." 근육은 당기는 힘만 냅니다. 관절을 반대로 움직이는 것은 반대쪽 근육(길항근)이나 중력입니다.

# 순환계통: 멈추지 않는 펌프와 배관

## 용어 쪼개기

| 용어 | 쪼개기 | 뜻 |
|---|---|---|
| tachycardia | tachy(빠른) + cardi(심장) + ia | 빈맥 |
| bradycardia | brady(느린) + cardi + ia | 서맥 |
| arteriosclerosis | arterio(동맥) + scler(굳음) + osis | 동맥경화증 |
| thrombus | thromb(덩어리) | 혈전 |
| ischemia | isch(막다) + emia(혈액) | 허혈 |

## 핵심 기전 1. 판막은 일방통행 문입니다

심장은 네 개의 방(좌우 심방과 심실)으로 이루어진 펌프입니다. 방과 방 사이, 방과 혈관 사이에 있는 판막은 한쪽으로만 열리는 문처럼 혈액이 거꾸로 흐르지 않게 합니다.

| 혈액 흐름 | 지나는 판막 |
|---|---|
| 우심방 → 우심실 | 삼첨판 |
| 우심실 → 폐동맥 | 폐동맥판 |
| 좌심방 → 좌심실 | 승모판(이첨판) |
| 좌심실 → 대동맥 | 대동맥판 |

심장 소리는 판막이 닫힐 때 납니다. 첫째 소리는 심실 수축이 시작되며 방실판(삼첨판, 승모판)이 닫히는 소리, 둘째 소리는 수축이 끝나며 반달판(폐동맥판, 대동맥판)이 닫히는 소리입니다.

## 핵심 기전 2. 심장은 스스로 박자를 만듭니다

심장 근육은 뇌의 명령 없이도 스스로 전기 신호를 만들어 뜁니다. 박자를 정하는 곳은 우심방의 동방결절입니다. 신호는 심방을 거쳐 방실결절에서 잠시 늦춰진 뒤(심방이 혈액을 다 보낼 시간을 줌), 히스다발과 좌우 다발갈래, 푸르키네섬유를 따라 심실 전체로 퍼집니다. 자율신경은 이 박자를 빠르게 하거나 느리게 조절할 뿐입니다.

| 심전도 파형 | 뜻 |
|---|---|
| P파 | 심방 탈분극 |
| QRS군 | 심실 탈분극 |
| T파 | 심실 재분극 |

비유의 한계: 메트로놈처럼 일정한 박자를 만든다고 생각하기 쉽지만, 실제 박동 수는 운동, 체온, 감정, 호르몬에 따라 계속 바뀝니다.

# 신경계통: 빠른 전기 통신망

## 용어 쪼개기

| 용어 | 쪼개기 | 뜻 |
|---|---|---|
| neuron | neur(신경) + on | 신경세포 |
| neuralgia | neur + algia | 신경통 |
| hemiplegia | hemi(절반) + plegia(마비) | 반신마비 |

## 핵심 기전 1. 활동전위

임상 연결: 다발성경화증처럼 말이집이 손상되는 질환에서는 신호 전달이 느려지거나 끊겨 다양한 신경 증상이 나타납니다.

# 비뇨계통: 피를 거르는 정수 시설

## 용어 쪼개기

| 용어 | 쪼개기 | 뜻 |
|---|---|---|

## 핵심 기전 1. 여과, 재흡수, 분비

콩팥의 기본 단위인 네프론은 세 단계로 소변을 만듭니다.

| 단계 | 장소 | 일어나는 일 | 비유 |
|---|---|---|---|
| 여과 | 사구체 | 혈압으로 혈액의 물과 작은 물질을 걸러 냄. 혈구와 큰 단백질은 걸러지지 않음 | 체로 거르기 |

| 분비 | 세뇨관 | 혈액에 남은 노폐물, 일부 약물, 수소 이온 등을 추가로 내보냄 | 놓친 쓰레기 직접 버리기 |

걸러진 액체의 대부분은 다시 흡수되고 일부만 소변으로 나옵니다. 정상에서는 포도당이 거의 모두 재흡수되므로, 소변에서 포도당이 나오면 혈당이 재흡수 한계를 넘었는지 의심합니다.

## 핵심 기전 2. 항이뇨호르몬과 수분 조절

# 내분비계통: 느리지만 넓게 전하는 우편

## 용어 쪼개기

| 용어 | 쪼개기 | 뜻 |
|---|---|---|
| endocrine | endo(안) + crine(분비) | 내분비, 혈액으로 분비 |
| hyperthyroidism | hyper + thyroid(갑상샘) + ism(상태) | 갑상샘기능항진증 |
| hypoglycemia | hypo + glyc(당) + emia | 저혈당 |
| adrenal | ad(곁) + renal(콩팥) | 부신 |
| polydipsia | poly(많은) + dipsia(갈증) | 다갈증 |

## 핵심 기전 1. 신경은 전화, 호르몬은 우편

신경계는 특정 대상에게 빠르게 신호를 보내는 전화와 같고, 내분비계는 혈액이라는 우편망에 호르몬을 실어 수용체를 가진 모든 세포에 천천히, 넓게, 오래 영향을 주는 우편과 같습니다. 호르몬은 혈액을 타고 온몸을 돌지만, 그 호르몬의 수용체를 가진 세포(표적세포)만 반응합니다.

비유의 한계: 우편은 주소가 정해져 있지만 호르몬은 모든 곳에 뿌려지고, 받는 쪽의 수용체가 반응 여부를 정합니다.

## 핵심 기전 2. 음성되먹임

대부분의 호르몬은 실내 온도 조절기처럼 작동합니다. 시상하부가 신호를 보내 뇌하수체가 자극 호르몬을 내고, 그 자극을 받은 샘(갑상샘, 부신겉질 등)이 호르몬을 냅니다. 호르몬이 충분해지면 그 호르몬이 다시 시상하부와 뇌하수체를 억제해 분비를 줄입니다. 이것을 음성되먹임이라고 합니다.

| 상황 | 갑상샘호르몬 | 뇌하수체의 갑상샘자극호르몬(TSH) |
|---|---|---|
| 갑상샘 자체가 호르몬을 과다 분비 | 높음 | 낮아짐(억제됨) |
| 갑상샘 자체가 호르몬을 못 만듦 | 낮음 | 높아짐(억제가 풀림) |

## 핵심 기전 3. 혈당은 두 호르몬이 시소처럼 맞춥니다

| 호르몬 | 분비 세포 | 작용 | 결과 |
|---|---|---|---|
| 인슐린 | 이자 베타세포 | 근육·지방세포의 포도당 흡수, 간의 글리코겐 합성 촉진 | 혈당 낮춤 |
| 글루카곤 | 이자 알파세포 | 간의 글리코겐 분해와 포도당 신생 촉진 | 혈당 올림 |

# 면역계통: 몸을 지키는 경비 조직

## 용어 쪼개기

| 용어 | 쪼개기 | 뜻 |
|---|---|---|
| leukocyte | leuk(흰) + cyte(세포) | 백혈구 |
| phagocytosis | phago(먹다) + cyt + osis | 식세포작용 |
| lymphadenopathy | lymph(림프) + aden(샘) + pathy(병) | 림프절병증 |
| anaphylaxis | ana(거꾸로) + phylaxis(보호) | 아나필락시스 |
| immunodeficiency | immuno(면역) + deficiency(결핍) | 면역결핍 |

## 핵심 기전 1. 선천면역과 후천면역

| 구분 | 선천면역 | 후천(적응)면역 |
|---|---|---|
| 비유 | 건물 입구 경비원 | 수배 전단을 가진 특수 수사팀 |
| 반응 속도 | 빠름(즉시~수 시간) | 처음엔 느림(며칠), 두 번째부터 빠름 |
| 특이성 | 넓게 일반적으로 반응 | 특정 항원에만 반응 |
| 기억 | 없음 | 있음 |
| 주요 요소 | 피부·점막, 호중구, 대식세포, 염증 반응 | T세포, B세포, 항체 |

예방접종은 후천면역의 기억을 이용합니다. 병원체의 일부나 약하게 만든 형태로 수사팀에게 미리 수배 전단을 돌려, 실제 병원체가 들어왔을 때 빠르게 대응하게 합니다.

## 핵심 기전 2. 염증의 다섯 징후

다친 부위가 붉어지고, 붓고, 열이 나고, 아프고, 기능이 떨어지는 것은 면역세포가 손상 부위로 모이도록 혈관이 넓어지고 투과성이 커지기 때문입니다. 염증은 해로운 반응이 아니라 치유의 시작이지만, 지나치거나 오래가면 조직을 손상시킵니다.

## 핵심 기전 3. 과민반응

면역계가 해롭지 않은 물질에 지나치게 반응하는 것이 알레르기입니다. 꽃가루나 음식 성분에 대해 만들어진 IgE 항체가 비만세포에 붙어 있다가 다시 노출되면 히스타민 등이 한꺼번에 나와, 심하면 혈관 확장과 기도 수축이 온몸에 일어나는 아나필락시스가 생깁니다.

## AI 튜터 프롬프트

```prompt 면역계 튜터
선천면역과 후천면역을 경비원과 수사팀에 비유해 설명하고, 예방접종이 후천면역의 어떤 성질을 이용하는지 두 문장으로 정리해 주세요. 비유의 한계를 한 줄로 알려 주고, 제가 백혈구 종류와 역할을 짝짓는 퀴즈를 내 주세요.
```

## 확인 퀴즈

1. 처음 감염 때는 느리지만 두 번째부터 빠르게 반응하는 면역은?
2. 염증의 다섯 징후는?
3. 알레르기 반응에서 비만세포에 붙어 있는 항체는?
4. 예방접종이 이용하는 면역의 성질은?

## 해설과 오개념

1. 후천(적응)면역.
2. 발적, 부종, 열감, 통증, 기능 장애.
3. IgE.
4. 면역 기억.

**흔한 오개념:** "열은 무조건 빨리 내려야 하는 나쁜 반응이다." 열은 면역 반응의 일부이기도 합니다. 해열 여부는 환자 상태와 지침에 따라 판단하며, 교재와 담당자의 지시를 따릅니다.

# 계통을 잇는 복습

## 계통 연결 질문

해부생리학의 계통은 따로 움직이지 않습니다. 계통을 마친 뒤 다음 연결 질문에 답해 봅니다.

| 질문 | 연결되는 계통 |
|---|---|
| 운동할 때 심박수와 호흡수가 함께 늘어나는 이유는? | 근육, 순환, 호흡, 신경 |
| 혈압이 떨어지면 콩팥은 어떻게 반응하나? | 순환, 비뇨, 내분비 |
| 당뇨병 환자의 상처가 잘 낫지 않는 이유는? | 내분비, 순환, 면역 |
| 혈중 칼슘이 낮으면 근육과 신경에 어떤 일이 생기나? | 골격, 근육, 신경 |
| 간이 손상되면 약물 효과는 어떻게 달라질 수 있나? | 소화, 순환 |

