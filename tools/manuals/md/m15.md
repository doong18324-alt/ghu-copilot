# 낯선 과목 앞에서 막히는 이유

## 첫 수업이 어려운 진짜 이유

약리학 첫 시간에 "콜린성", "아드레날린성", "길항제", "작용제", "반감기"가 한꺼번에 쏟아지면 많은 학생이 수업 내용을 따라가지 못합니다. 머리가 나빠서가 아닙니다. 새로운 용어를 처리하느라 작업 기억이 꽉 차서, 용어 사이의 관계와 설명을 담을 여유가 없기 때문입니다. 이것을 인지 부하라고 합니다.

수업 전에 핵심 용어를 미리 한 번 보고 들어가면 상황이 달라집니다. 용어가 익숙하면 수업 시간에 그 용어를 해석하는 데 쓰던 힘을 설명을 이해하는 데 쓸 수 있습니다. 미리 본 내용이 새 정보를 걸어 둘 고리 역할을 하는 셈입니다.

## 맨땅에 정독하기와 키워드 먼저 보기

| 구분 | 교재 정독부터 | 키워드 키트로 예습 |
|---|---|---|
| 시간 | 단원 하나에 한두 시간 | 10분 |
| 수업 중 | 모르는 용어에 막혀 흐름을 놓침 | 아는 용어를 붙잡고 설명에 집중 |
| 남는 것 | 앞부분만 자세히, 뒷부분은 흐릿 | 단원 전체 윤곽과 핵심 용어 |
| 이어지는 공부 | 다시 처음부터 | 키트의 질문을 수업에서 확인 |

# 키워드 탐색 키트의 구성

## 세 부분

| 부분 | 내용 | 목적 |
|---|---|---|
| 핵심 키워드 10개 | 단원을 이해하는 데 꼭 필요한 용어와 한 줄 정의 | 수업의 기본 어휘 확보 |
| 쉬운 큰 그림 | 단원 전체를 비전공자도 이해할 말로 설명한 한 문단 | 세부 내용을 걸어 둘 뼈대 |
| 연결 질문 3개 | 수업에서 답을 찾아야 할 질문 | 수업을 능동적으로 듣게 함 |

여기에 의학용어가 많은 과목은 "용어 쪼개기"를 더합니다.

## 키워드는 10개면 충분합니다

단원의 모든 용어를 미리 외우려 하면 예습이 부담이 되어 오래가지 못합니다. 그 단원에서 가장 자주 나오고, 다른 개념의 기초가 되는 10개만 고릅니다. 나머지는 수업과 복습에서 채웁니다.

# 키트 만들기

## 기본 프롬프트

```prompt 키워드 탐색 키트
저는 [학과, 학년]이고 다음 수업에서 [과목]의 [단원]을 배웁니다. 아직 이 단원은 처음입니다.
[가능하면 강의계획서의 주차 설명이나 강의 자료 목차를 붙여 넣기]

수업 전 10분 예습용 키워드 탐색 키트를 만들어 주세요.
1. 쉬운 큰 그림: 이 단원이 무엇을 다루는지 중학생도 이해할 말로 5문장 이내
2. 핵심 키워드 10개: 표(용어, 영어, 한 줄 정의, 다른 키워드와의 관계)
3. 연결 질문 3개: 수업을 들으며 답을 찾을 질문
4. 이 단원과 이어지는 이전 과목 개념 2개
교재 용어를 쓰고, 정의는 짧게 해 주세요. 확실하지 않은 정의는 [교재 확인]으로 표시해 주세요.
```

## 용어 쪼개기를 더할 때

```prompt 의학용어 해독
[단원]의 핵심 의학용어 10개를 접두사, 어근, 접미사로 쪼개 표로 정리해 주세요.
열: 용어, 쪼갠 부분, 부분별 뜻, 전체 뜻, 같은 부분을 쓰는 다른 용어 1개
용어: [키트의 키워드 또는 강의 자료에서 뽑은 용어]
```

용어를 쪼개 보면 처음 보는 단어도 뜻을 추측할 수 있게 됩니다. 예를 들어 "-itis(염증)", "-ectomy(절제)", "-algia(통증)", "brady-(느린)", "tachy-(빠른)"를 알면 수많은 용어가 한꺼번에 풀립니다.

## 내가 가진 자료로 만들기

강의계획서나 강의 자료가 있으면 붙여 넣거나 NotebookLM 같은 자료 기반 도구에 올려 키트를 만듭니다. AI가 일반 지식으로 만든 키트보다 우리 수업의 범위와 용어에 맞는 키트가 나옵니다.

# 키트 예: 자율신경계 작용 약물

## 쉬운 큰 그림

몸에는 의식하지 않아도 저절로 움직이는 기능을 조절하는 신경이 있습니다. 위기 상황에서 심장을 빨리 뛰게 하는 교감신경과, 쉬는 동안 소화와 회복을 돕는 부교감신경입니다. 약은 이 신경이 내보내는 신호를 흉내 내거나(작용제) 막아서(차단제, 길항제) 몸의 반응을 바꿉니다. 그래서 같은 계열의 약이라도 어느 신경을 흉내 내는지, 막는지에 따라 효과와 부작용이 정반대로 나타납니다.

## 핵심 키워드 예

| 용어 | 영어 | 한 줄 정의 |
|---|---|---|
| 교감신경 | sympathetic nerve | 투쟁-도피 반응을 일으키는 자율신경 |
| 부교감신경 | parasympathetic nerve | 휴식-소화 반응을 일으키는 자율신경 |
| 아세틸콜린 | acetylcholine | 부교감신경 등에서 신호를 전달하는 물질 |
| 노르에피네프린 | norepinephrine | 교감신경 말단에서 신호를 전달하는 물질 |
| 수용체 | receptor | 신호 물질이 붙어 반응을 일으키는 자리 |
| 작용제 | agonist | 수용체에 붙어 신호를 흉내 내는 약 |
| 길항제 | antagonist | 수용체에 붙어 신호를 막는 약 |
| 알파·베타 수용체 | alpha, beta receptor | 교감신경 신호를 받는 수용체의 종류 |
| 무스카린 수용체 | muscarinic receptor | 부교감신경 신호를 받는 수용체의 한 종류 |
| 부작용 | adverse effect | 원하지 않는 작용. 같은 수용체가 다른 장기에도 있어서 생김 |

## 연결 질문 예

1. 베타 차단제를 먹는 사람의 심박수는 왜 느려질까?
2. 천식 환자에게 비선택적 베타 차단제를 조심하는 이유는 무엇일까?
3. 부교감 차단제를 먹으면 입이 마르는 이유는 무엇일까?

예시 키트의 정의는 이해를 돕기 위한 간단한 설명입니다. 시험 공부는 교재의 정의로 합니다.

# 수업 전 10분 예습

## 세 단계

| 시간 | 할 일 |
|---|---|
| 3분 | 쉬운 큰 그림을 읽고, 단원이 무엇을 다루는지 한 문장으로 말해 보기 |
| 5분 | 키워드 10개를 소리 내어 읽고, 가린 채로 뜻을 떠올려 보기 |
| 2분 | 연결 질문 3개를 노트 맨 위에 적기 |

## 수업 중과 수업 후

- 수업 중에는 연결 질문의 답이 나오는 부분에 표시합니다.
- 수업이 끝나면 연결 질문에 내 말로 답을 씁니다. 답하지 못한 질문은 「AI 질문 대화법」으로 파고듭니다.
- 키워드 표에 수업에서 들은 설명을 덧붙여 내 용어집으로 만듭니다.

```prompt 수업 후 확인
수업 전에 만든 키워드 키트와 수업 후 제가 쓴 연결 질문의 답입니다.
[키트와 내 답 붙여 넣기]
1. 제 답에서 틀리거나 부족한 부분을 짚어 주세요(정답을 바로 주지 말고 힌트부터).
2. 키워드 10개 가운데 제 답에 쓰이지 않은 것을 알려 주세요.
3. 다음 복습 때 풀 확인 문제 3개를 만들어 주세요.
```

# 계열별 키트 예

| 계열 | 단원 예 | 핵심 키워드 예 | 연결 질문 예 |
|---|---|---|---|
| 간호 | 수액과 전해질 | 등장액, 저장액, 고장액, 삼투압, 부종 | 왜 저장액은 세포를 붓게 하나? |
| 물리치료 | 보행 분석 | 입각기, 유각기, 보폭, 활보장, 분속수 | 편마비 보행은 어느 시기가 달라지나? |
| 임상병리 | 응고 검사 | PT, aPTT, 내인 경로, 외인 경로, INR | 와파린과 헤파린은 왜 다른 검사로 보나? |
| 방사선 | X선 발생 | 관전압, 관전류, 제동복사, 특성 X선, 여과 | 관전압을 높이면 영상 대조도는 어떻게 되나? |
| 치위생 | 치아 형태 | 교두, 와, 융선, 근관, 법랑질 | 하악 제1대구치는 왜 먼저 관리해야 하나? |
| 사회복지 | 사회복지정책 | 보편주의, 선별주의, 현금급여, 현물급여, 전달 체계 | 같은 문제에 두 방식은 어떻게 다르게 접근하나? |
| 보건의료정보 | 질병분류 | 주진단, 부진단, 병인, 증상 발현 부위, 외인 | 왜 증상만으로 주진단을 정하지 않나? |

# 용어집 키우기

## 학기 용어집

단원마다 만든 키워드 표를 하나의 용어집 파일로 모읍니다. 열은 용어, 영어, 한 줄 정의, 처음 나온 단원, 헷갈리는 용어, 내 메모로 둡니다. 학기 말에는 용어집 자체가 훌륭한 복습 자료가 됩니다.

```prompt 용어집 점검
아래는 제 학기 용어집입니다.
[붙여 넣기]
1. 정의가 서로 겹치거나 모순되는 용어 쌍
2. 정의가 너무 길어 한 줄로 줄일 수 있는 것
3. 함께 묶어 외우면 좋은 용어 그룹
을 알려 주세요. 정의를 바꿀 때는 교재 확인이 필요하다고 표시해 주세요.
```

# 자주 묻는 질문

**강의계획서가 없으면 어떻게 하나요?**
교재의 해당 장 목차와 소제목을 붙여 넣어도 충분합니다.

**예습을 했는데도 수업이 어려워요.**
키워드 수를 줄이고 큰 그림을 더 쉽게 다시 만들어 보세요. 수업 후 연결 질문에 답하지 못한 부분은 질문 대화법으로 이어갑니다.

# 자가진단과 자주 하는 실수

## 키트 자가진단

!!! 내 키트를 점검합니다
- 키워드가 10개 이내이고 단원의 기초 개념이다
- 정의가 한 줄로 짧고 교재 용어와 맞다
- 큰 그림을 내 말로 한 문장으로 말할 수 있다
- 연결 질문을 수업 노트에 적었다
- 수업 후 연결 질문에 답을 썼다

## 자주 하는 실수

| 실수 | 고치는 방법 |
|---|---|
| 키워드를 30개 넘게 뽑음 | 10개로 줄이고 나머지는 수업에서 |
| 정의를 외우는 데 30분 | 예습은 10분. 친숙해지는 것이 목적 |
| AI 정의를 확인 없이 외움 | 수업과 교재로 정의를 고쳐 씀 |
| 예습만 하고 수업 후 정리 안 함 | 연결 질문 답 쓰기로 마무리 |
| 강의 자료 없이 만들어 범위가 어긋남 | 강의계획서나 자료를 함께 넣기 |
