# 왜 구조로 정리해야 하나

## 읽었는데 남는 게 없는 이유

교재를 처음부터 끝까지 줄을 그으며 읽고 나면 공부를 많이 한 것 같습니다. 그런데 책을 덮고 "이 단원에서 가장 중요한 개념 세 가지와 그 관계"를 말해 보라고 하면 막히는 경우가 많습니다. 글은 한 줄로 이어지지만 지식은 위아래와 옆으로 연결된 구조이기 때문입니다.

예를 들어 신장 단원에서 "사구체 여과", "세뇨관 재흡수", "레닌-안지오텐신-알도스테론계", "이뇨제"는 교재의 서로 다른 쪽에 나옵니다. 이 개념들이 "소변이 만들어지는 과정"과 "그 과정을 조절하고 바꾸는 방법"이라는 큰 틀 안에서 이어진다는 것을 보지 못하면, 각각을 따로 외우게 되고 응용 문제에서 연결하지 못합니다.

## 구조화가 기억을 돕는 이유

| 원리 | 설명 |
|---|---|
| 조직화 | 정보를 범주와 계층으로 묶으면 한 번에 다룰 수 있는 양이 늘어남 |
| 이중 부호화 | 글과 시각적 구조를 함께 쓰면 기억의 단서가 두 갈래로 생김 |
| 정교화 | 개념 사이의 관계를 따지는 과정에서 이해가 깊어짐 |
| 인출 연습 | 구조를 보지 않고 다시 그려 보면 기억을 꺼내는 연습이 됨 |

# 단원을 계층 구조로 바꾸기

## 세 단계 계층

| 단계 | 뜻 | 예(신장 단원) |
|---|---|---|
| 1단계: 중심 주제 | 단원이 답하려는 큰 질문 | 신장은 어떻게 체액과 노폐물을 조절하는가 |
| 2단계: 큰 가지 | 중심 주제를 나누는 4~6개 범주 | 구조, 소변 생성, 조절 호르몬, 검사, 대표 질환, 약물 |
| 3단계: 세부 가지 | 각 범주의 핵심 개념과 기준 | 소변 생성 아래: 여과, 재흡수, 분비 |

큰 가지는 서로 겹치지 않고, 합치면 단원 전체를 덮도록 나눕니다. 큰 가지가 여덟 개를 넘으면 너무 잘게 나눈 것이니 다시 묶습니다.

## AI로 계층 구조 만들기

```prompt 단원 계층 구조
아래는 [과목] [단원] 강의 자료와 제 필기입니다.
[붙여 넣기 또는 파일 첨부]

1. 이 단원의 중심 질문을 한 문장으로 써 주세요.
2. 큰 가지 4~6개로 나누고, 각 가지 아래 세부 개념을 3~5개씩 마크다운 목록(들여쓰기)으로 정리해 주세요.
3. 서로 다른 가지에 있지만 관련 있는 개념 쌍을 3개 찾아 관계를 한 줄로 설명해 주세요.
4. 자료에 없는 내용은 추가하지 말고, 필기에서 빠진 것 같은 부분은 마지막에 질문으로 적어 주세요.
```

## 마인드맵 도구로 옮기기

AI가 들여쓰기 목록(마크다운) 형태로 준 구조는 마인드맵 도구에 붙여 넣으면 바로 그림으로 바뀝니다. Markmap 같은 도구는 마크다운 목록을 마인드맵으로 보여 주고, XMind 같은 도구는 목록을 붙여 넣어 가지를 만들 수 있습니다. 도구별 지원 방식은 확인하고 씁니다.

손으로 직접 그리는 것도 좋은 방법입니다. AI가 만든 구조를 보면서 종이에 옮겨 그리는 과정 자체가 복습이 됩니다.

# 헷갈리는 개념을 한 장으로

## 비교표의 힘

보건계열 시험은 비슷한 개념을 구분하는 문제를 자주 냅니다. 좌심부전과 우심부전, 철결핍빈혈과 거대적혈모구빈혈, 상부운동신경원과 하부운동신경원 손상, 사례관리와 집단사회사업처럼 짝을 이룬 개념은 한 장의 비교표로 정리하면 차이가 선명해집니다.

```prompt 헷갈리는 개념 비교표
[개념 A]와 [개념 B](필요하면 C까지)를 한 장 비교표로 정리해 주세요.
비교 기준: [예, 정의, 원인, 기전, 주요 증상·소견, 검사, 치료·중재, 간호·관찰 포인트]
- 마지막 행에 "시험에서 구분하는 결정적 단서"를 넣어 주세요.
- 교재 용어를 쓰고, 확실하지 않은 칸은 [교재 확인]으로 비워 두세요.
- 표 아래에 두 개념을 섞어 묻는 확인 문제 2개를 내 주세요(답은 맨 아래).
```

## 표를 받은 뒤 할 일

1. [교재 확인] 칸을 교재로 채웁니다.
2. 다른 칸도 교재와 대조해 틀린 곳을 고칩니다.
3. "결정적 단서" 행을 내 말로 다시 씁니다.

# 계열별 구조 예

## 보건계열

| 과목 | 중심 질문 | 큰 가지 예 |
|---|---|---|
| 해부학(상지) | 팔은 어떤 구조로 움직이는가 | 뼈, 관절, 근육(구획별), 신경, 혈관 |
| 약리학(자율신경계) | 자율신경계에 작용하는 약은 어떻게 나뉘는가 | 교감 작용제, 교감 차단제, 부교감 작용제, 부교감 차단제, 대표 부작용 |
| 임상병리(혈액학) | 빈혈은 어떻게 분류하고 감별하는가 | 형태 분류, 원인 분류, 검사 지표, 대표 질환 |

| 사회복지실천 | 실천은 어떤 과정으로 진행되는가 | 관계 형성, 사정, 계획, 개입, 종결과 평가 |

| 서비스 실무 | 좋은 서비스는 어떻게 설계하는가 | 고객 이해, 서비스 과정, 품질, 불만 처리 |

# 3분 백지 복습

## 보는 공부에서 꺼내는 공부로

마인드맵을 예쁘게 만들고 다시 보기만 하면 효과가 줄어듭니다. 구조를 보지 않고 다시 그려 보는 것이 진짜 복습입니다.

## 3분 백지 복습 순서

1. **1분:** 빈 종이 가운데 중심 질문을 쓰고 큰 가지를 기억나는 대로 그립니다.
2. **2분:** 각 가지 아래 세부 개념을 채웁니다. 기억나지 않으면 빈칸으로 둡니다.
3. **확인:** 원래 구조와 비교해 빠진 것을 다른 색으로 채웁니다.
4. **기록:** 빠진 개념을 따로 적어 다음 복습 때 먼저 봅니다.

## AI로 빈칸 찾고 퀴즈 받기

```prompt 백지 복습 점검
아래는 원래 마인드맵 구조와 제가 백지에 다시 그린 구조입니다.
원래: [붙여 넣기]
백지: [붙여 넣기]

1. 제가 빠뜨린 개념과 잘못 연결한 부분을 표로 정리해 주세요.
2. 빠뜨린 개념만으로 확인 문제 5개를 한 번에 하나씩 내 주세요.
3. 다 풀면 다음 복습 때 먼저 볼 개념 3개를 알려 주세요.
```

# 구조화를 시험 준비로 잇기

## 구조도에서 문제로

구조도의 가지와 관계는 그대로 시험 문제가 됩니다.

| 구조도 요소 | 만들 수 있는 문제 |
|---|---|
| 큰 가지의 분류 | "다음 중 [분류]에 속하지 않는 것은?" |
| 세부 개념의 정의 | "[정의]에 해당하는 것은?" |
| 가지 사이의 관계 | "[A]가 [B]를 일으키는 기전은?" |
| 비교표의 결정적 단서 | 사례에서 두 개념을 구분하는 문제 |

```prompt 구조도로 문제 만들기
아래는 제가 만든 [단원] 구조도입니다.
[구조도 붙여 넣기]
구조도의 분류, 정의, 관계, 비교에서 각각 2문제씩 5지선다 8문제를 만들어 주세요.
문제만 먼저 보여 주고 정답은 제가 "답 공개"라고 하면 알려 주세요.
```

## 단원끼리 잇는 큰 구조도

학기 말에는 단원별 구조도를 모아 과목 전체 구조도를 만듭니다. 단원 사이에 이어지는 개념(예: 순환계의 혈압 조절과 비뇨계의 레닌-안지오텐신계)을 선으로 잇다 보면, 따로 외웠던 내용이 하나의 체계로 보이기 시작합니다.

```prompt 단원 연결 지도
아래는 [과목]의 단원별 구조도 요약입니다.
[단원별 중심 질문과 큰 가지]
1. 단원 사이에 이어지는 개념 쌍 8개와 관계
2. 과목 전체를 한 문장으로 요약하는 중심 질문
3. 연결이 약해 다시 공부할 곳
을 정리해 주세요.
```

# 자주 묻는 질문

**손으로 그리는 것과 도구로 만드는 것 중 무엇이 좋은가요?**
처음 공부할 때는 손으로 그리면서 생각하는 과정이 도움이 되고, 수정과 공유가 많을 때는 도구가 편합니다. 어느 쪽이든 백지 복습을 꼭 함께 합니다.

**구조도가 너무 커져서 한눈에 안 보입니다.**
단원 구조도와 과목 구조도를 나누고, 과목 구조도에는 큰 가지와 연결만 남깁니다.

**AI가 만든 구조가 교재 목차와 다릅니다.**
목차는 설명 순서이고 구조도는 개념 관계입니다. 다를 수 있습니다. 다만 개념 자체가 교재와 다르면 교재를 따릅니다.

# 자가진단과 자주 하는 실수

## 구조화 자가진단

!!! 내 구조도를 점검합니다
- 중심 질문이 한 문장으로 분명하다
- 큰 가지가 4~6개이고 서로 겹치지 않는다
- 세부 개념이 교재 용어로 쓰여 있다
- 가지 사이의 관계를 설명할 수 있다
- AI가 만든 내용을 교재와 대조했다
- 백지 복습을 한 번 이상 했다

## 자주 하는 실수

| 실수 | 고치는 방법 |
|---|---|
| 교재 목차를 그대로 옮김 | 목차는 순서일 뿐, 중심 질문에 맞게 다시 묶기 |
| 가지가 너무 많음 | 비슷한 것끼리 묶어 4~6개로 |
| 구조도를 보기만 함 | 3분 백지 복습으로 꺼내 보기 |
| AI 구조를 확인 없이 씀 | 교재와 대조하고 내 필기와 비교 |
| 예쁘게 꾸미는 데 시간을 씀 | 손그림도 충분. 내용과 관계에 집중 |
