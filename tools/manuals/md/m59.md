# 식품영양과 AI

## 영양사의 일과 AI가 닿는 곳

영양사는 단체급식 관리, 식단 작성, 영양 상담과 교육, 식품 위생 관리를 맡습니다. 숫자(영양소 함량, 섭취기준, 원가)와 기준(위생 법령)을 정확히 다루는 일이 많습니다. 생성형 AI는 식단 아이디어, 상담 연습, 교육 자료 작성에 도움을 주지만 영양 성분 계산은 자주 틀리므로 공식 자료와 계산 도구로 확인해야 합니다.

| 영역 | AI가 돕는 부분 | 영양사가 판단할 부분 |
|---|---|---|
| 식단 작성 | 메뉴 아이디어, 조리법 다양화 | 영양 기준 충족, 원가, 조리 여건 |
| 영양 상담 | 상담 연습, 교육 자료 | 대상자 평가와 상담 판단 |
| 단체급식 | 작업 일정표, 위생 점검표 초안 | 실제 운영과 법령 준수 |
| 식품 안전 | 교육 자료, 사고 사례 정리 | 기준 수치, 대응 절차 확인 |
| 국가시험 | 개념 정리, 연습 문항 | 정답 근거 |

## 원칙

- **영양 수치는 공식 자료로 계산합니다.** 식품 영양 성분은 국가 식품 영양 성분 자료로, 섭취기준은 한국인 영양소 섭취기준 최신판으로 확인합니다. AI가 말한 칼로리와 영양소 함량을 그대로 쓰지 않습니다.
- **질환별 식사요법은 지침으로 확인합니다.** 당뇨병, 신장질환, 고혈압 식사요법은 학회 지침과 임상영양학 교재가 기준입니다.
- **상담 대상자 정보는 넣지 않습니다.** 실습 대상자의 건강 정보와 식사 기록은 AI에 넣지 않습니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 식단관리 | 손으로 식단 작성 | AI로 메뉴 후보를 받고 영양 계산 도구로 검증·수정 | 기준 충족 식단 |
| 임상영양학 | 사례 강의 | 가상 사례 식사요법 계획과 AI 계획 비교, 지침으로 검증 | 임상 판단 |
| 영양교육 | 교안 작성 | 대상별 교육 자료 제작과 검증 | 교육 설계 |
| 급식관리 | 강의 | 위생 점검표, 작업 일정표 초안을 법령·지침으로 검토 | 운영 관리 |
| 식품위생학 | 법규 암기 | 사고 사례로 원인과 예방 정리, 법령 원문 확인 | 위생 판단 |

# 교수자용 수업 활동

## 활동 1. 식단 검증 과제

```prompt 프롬프트 1. 식단 초안 받기
[대상, 예: 고등학교 급식, 1끼] 5일 식단 초안을 만들어 주세요. 끼니마다 밥, 국, 주찬, 부찬 2가지, 후식 구성으로 합니다. 메뉴와 주재료만 적고 영양소 수치는 쓰지 마세요.
```

학생은 이 식단을 영양 계산 도구와 국가 식품 영양 성분 자료로 계산해 해당 대상의 급식 영양 기준을 충족하는지 확인하고, 부족하거나 넘치는 영양소를 고려해 식단을 고칩니다. AI에게 수치를 쓰지 말라고 한 이유를 학생에게 설명하면, 영양 수치는 원자료로 계산해야 한다는 원칙을 자연스럽게 익힙니다.

## 활동 2. 질환별 식사요법 비교

```prompt 프롬프트 2. 가상 사례
임상영양학 수업용 가상 사례를 만들어 주세요. [예: 제2형 당뇨병이 있는 60대 남성, 혼자 살며 외식이 잦음] 신체 계측, 식습관, 생활 패턴을 포함한 A4 반 쪽. 실제 인물을 떠올리게 하는 정보는 쓰지 마세요.
```

학생은 사례로 영양 판정과 식사 계획을 세우고, AI가 만든 계획과 비교해 학회 지침과 다른 부분을 찾습니다.

# 학생용 실습 프롬프트

## 영양 상담 연습

```prompt 프롬프트 3. 상담 역할극
당신은 체중 관리 상담을 받으러 온 가상의 30대 직장인입니다. 야근이 잦고 아침을 거르며 밤에 배달 음식을 먹습니다. 저는 식품영양학과 학생입니다.
실제처럼 바꾸기 어려운 이유를 말해 주세요. "상담 끝"이라고 하면 역할을 멈추고, 제가 일방적으로 지시한 부분과 대상자의 상황을 반영한 부분을 구분해 알려 주세요.
```

## 영양 교육 자료

```prompt 프롬프트 4. 교육 자료
[대상, 예: 초등학교 3학년]에게 [주제, 예: 당류 줄이기]를 가르치는 15분 교육 자료를 만들어 주세요.
포함: 흥미를 끄는 질문, 핵심 메시지 3개, 활동 1개, 확인 퀴즈 3개.
권장량 같은 수치는 [섭취기준 확인]으로 표시해 주세요.
```

## 위생 점검표

```prompt 프롬프트 5. 위생 점검표 초안
단체급식소의 하루 위생 점검표 초안을 만들어 주세요. 입고 검수, 보관, 전처리, 조리, 배식, 세척·소독, 개인 위생으로 나누고, 항목마다 확인 방법을 적어 주세요.
온도와 시간 기준은 [법령·지침 확인]으로 표시해 주세요.
```

# 기준 자료로 검증하기

| 영역 | AI가 자주 틀리는 것 | 대조 자료 |
|---|---|---|
| 영양 성분 | 식품별 열량, 영양소 함량 | 국가 식품 영양 성분 자료 |
| 섭취기준 | 연령·성별 기준값, 개정 내용 | 한국인 영양소 섭취기준 최신판 |
| 식사요법 | 질환별 권고 | 학회 진료지침, 임상영양학 교재 |
| 위생 기준 | 보관 온도, 가열 조건, 보존식 | 식품위생 관련 법령, 식약처 자료 |
| 알레르기 | 표시 대상 식품 | 식품 표시 관련 법령 |

!!! 식품영양 AI 결과물을 쓰기 전에 확인합니다
- 영양 수치를 공식 자료로 계산했다
- 섭취기준을 최신판으로 확인했다
- 질환별 식사요법을 지침과 교재로 확인했다
- 위생 기준 수치를 법령과 지침으로 확인했다
- 대상자 건강 정보를 AI에 넣지 않았다
