# 규정 기반 응대가 어려운 이유

## 규정 문의의 특징

학생과 학부모의 문의 가운데 상당수는 규정에 답이 있습니다. 휴학은 몇 학기까지 가능한지, 성적 장학금 기준이 무엇인지, 수강 신청 정정은 언제까지인지 같은 질문입니다. 그런데 규정은 여러 문서에 흩어져 있고, 개정이 잦으며, 조항끼리 서로 참조합니다. 담당자가 바뀌면 같은 질문에 다른 답이 나가기도 합니다.

생성형 AI를 규정 자료와 함께 쓰면 조항을 빠르게 찾고 학생이 이해하기 쉬운 말로 답변 초안을 만들 수 있습니다. 그러나 규정 답변은 학생의 학적, 장학금, 졸업에 직접 영향을 줍니다. AI가 조항을 잘못 읽거나 개정 전 조항을 인용하면 학생에게 실제 손해가 생깁니다. 그래서 이 작업은 반드시 "근거 조항을 담당자가 직접 확인한다"는 원칙 위에서 합니다.

## 일반 대화형 AI를 쓰면 안 되는 이유

자료를 주지 않고 "휴학은 몇 학기까지 가능한가요?"라고 물으면 AI는 다른 대학의 일반적인 규정이나 지어낸 조항으로 답합니다. 우리 학교 규정을 근거로 답하게 하려면 규정 원문을 직접 주고, 그 안에서만 답하도록 지시해야 합니다.

# 규정 자료 준비

## 올릴 자료

| 자료 | 확인할 것 |
|---|---|
| 학칙 | 최신 개정일 |
| 학사 운영 규정, 시행세칙 | 학칙과 함께 봐야 하는 세부 기준 |
| 장학금 지급 규정과 학기별 공고 | 규정과 이번 학기 공고가 다를 수 있음 |
| 국고사업 집행 지침 | 사업별, 연도별 지침 |
| 부서 업무 매뉴얼 | 규정에 없는 실무 절차 |
| 기존 FAQ | 오래된 답변이 있는지 확인 |

## 자료 정리 규칙

- **파일 이름에 개정일을 넣습니다.** 예: 학칙_2026-03-01개정.pdf
- **개정 전 자료는 빼고 최신본만 올립니다.** 옛 규정이 함께 있으면 AI가 섞어서 답합니다.
- **규정과 공고를 구분합니다.** 학기별 공고(신청 기간, 금액)는 규정과 별도 파일로 올리고 학기를 파일 이름에 넣습니다.
- **공개 규정만 올립니다.** 내부 심의 자료, 개인 사례는 올리지 않습니다.

> NotebookLM처럼 올린 자료 안에서만 답을 찾는 도구를 쓰면 답변마다 근거 위치가 표시되어 확인이 쉽습니다. 학교가 공식 도입한 AI 서비스가 있다면 그 서비스를 우선 씁니다.

# 조항 찾기

## 근거 조항 검색

```prompt 프롬프트 1. 근거 조항 찾기
올린 규정 자료에서 다음 질문의 근거 조항을 찾아 주세요.
질문: [예: 군 휴학 중 복학 신청은 언제 해야 하나요?]

1. 관련 조항을 모두 찾아 [규정명, 조, 항, 호]와 원문을 그대로 옮겨 주세요.
2. 조항끼리 서로 참조하거나 예외 규정이 있으면 함께 적어 주세요.
3. 이 조항들만으로 답이 정해지는지, 담당 부서 판단이 필요한 부분이 있는지 구분해 주세요.

올린 자료에 근거가 없으면 "자료에 근거 없음"이라고만 답하고 추측하지 마세요.
```

## 조항을 읽을 때 주의할 점

| 주의 | 예 |
|---|---|
| 원칙과 예외 | "휴학은 통산 O학기를 넘을 수 없다. 다만 군 휴학은 산입하지 않는다" |
| 위임 규정 | "세부 사항은 총장이 따로 정한다"면 시행세칙이나 공고를 함께 봐야 함 |
| 개정 부칙 | 개정 전 입학생에게는 옛 규정을 적용하는 경과 규정 |
| 용어 정의 | "학기", "재학생"의 정의가 규정마다 다를 수 있음 |
| 기한 계산 | "~일 이내", "~일 전까지"의 시작일과 포함 여부 |

부칙의 경과 규정은 특히 놓치기 쉽습니다. 학번에 따라 적용 기준이 다른 경우 답변에 반드시 반영합니다.

# 민원 답변 초안

## 답변의 구조

좋은 민원 답변은 다음 순서를 따릅니다.

1. **공감과 확인:** 문의 내용을 한 문장으로 다시 확인합니다.
2. **결론:** 묻는 것에 대한 답을 먼저 말합니다.
3. **근거:** 어느 규정의 어느 조항인지 밝힙니다.
4. **해야 할 일:** 학생이 다음에 할 행동과 기한, 방법을 적습니다.
5. **추가 안내:** 예외 상황이나 상담 창구를 안내합니다.

```prompt 프롬프트 2. 민원 답변 초안
아래 문의에 답변 초안을 써 주세요.
문의: [개인정보를 지운 문의 내용]
근거 조항: [프롬프트 1에서 담당자가 확인한 조항 원문]

조건:
- 위 구조(확인, 결론, 근거, 해야 할 일, 추가 안내)를 따릅니다.
- 근거 조항에 없는 내용은 답하지 않고 "담당 부서에서 개별 확인이 필요합니다"로 안내합니다.
- 존댓말, 행정 용어는 쉬운 말로 바꾸되 규정명과 조항 번호는 정확히 씁니다.
- 학생에게 불리한 결론이라도 돌려 말하지 않고, 가능한 대안이 규정에 있으면 함께 안내합니다.
- 300자 안팎.
```

## 학부모 문의

학부모 문의는 학생 본인의 정보와 관련된 경우가 많습니다. 성적, 출결, 학적 같은 학생 개인정보는 학생 본인의 동의 없이 학부모에게 알려 줄 수 없는 경우가 있으므로, 학교의 개인정보 처리 기준을 먼저 확인합니다. AI 답변 초안에는 일반적인 규정 안내만 넣고, 학생 개인의 상황은 담당자가 확인 절차를 거쳐 따로 안내합니다.

## 감정이 격한 민원

화가 난 상태의 민원에는 규정 설명보다 상황 인정이 먼저입니다. 다만 규정에 없는 약속은 하지 않습니다.

| 피할 표현 | 바꾼 표현 |
|---|---|
| 규정상 불가능합니다 | 말씀하신 상황이 얼마나 답답하실지 이해합니다. 현재 규정(OO 제O조)에서는 이 경우 OO가 어렵습니다. 대신 OO 방법이 있어 안내드립니다 |
| 저희 소관이 아닙니다 | 이 부분은 OO팀에서 담당하고 있습니다. 연락처는 OO이며, 제가 문의 내용을 미리 전달해 두겠습니다 |
| 이미 공지했습니다 | 공지가 충분히 전달되지 못한 점 아쉽게 생각합니다. 다시 정리해 안내드리면 |

# FAQ 만들기

## 반복 문의 모으기

FAQ는 실제 문의에서 시작해야 쓸모가 있습니다. 지난 한 학기 동안 받은 문의를(개인정보 삭제) 모아 AI로 묶습니다.

```prompt 프롬프트 3. 반복 문의 묶기
아래는 지난 학기 [부서]에 들어온 문의 목록입니다(개인정보 삭제).
[문의 목록, 번호 포함]

1. 같은 내용을 묻는 문의끼리 묶고, 묶음마다 대표 질문 한 문장과 문의 개수를 적어 주세요.
2. 개수가 많은 순서로 정렬해 주세요.
3. 개수는 실제로 세어 적고, 애매한 문의는 따로 표시해 주세요.
```

## FAQ 답변 작성

```prompt 프롬프트 4. FAQ 작성
위 대표 질문 상위 [15]개에 대해 FAQ 답변을 써 주세요. 근거는 올린 규정 자료에서만 찾습니다.

질문마다 [질문, 답변 2~4문장, 근거 조항, 관련 신청 시기]를 적어 주세요.
근거가 없는 질문은 답변 대신 "담당 부서 확인 필요"로 표시합니다.
분류(학적, 수업, 성적, 장학, 졸업)별로 묶어 주세요.
```

## FAQ 운영

- FAQ 맨 위에 마지막 수정일과 근거 규정의 개정일을 표시합니다.
- 규정이 개정되면 관련 FAQ를 함께 고칩니다. 규정 개정 공지와 FAQ 수정을 하나의 절차로 묶어 두면 빠뜨리지 않습니다.
- 학기마다 바뀌는 날짜와 금액은 FAQ 본문에 넣지 않고 해당 학기 공지로 연결합니다.

# 검증과 책임

## AI 답변을 그대로 보내지 않는 이유

| 위험 | 예 |
|---|---|
| 조항 오독 | "할 수 있다"와 "하여야 한다"를 바꿔 읽음 |
| 예외 누락 | 원칙만 답하고 예외 조항을 빠뜨림 |
| 개정 전 조항 | 옛 규정 파일이 섞여 있으면 그 내용으로 답함 |
| 경과 규정 누락 | 학번별 적용 기준을 무시 |
| 단정 | 담당 부서 판단이 필요한 사항을 확정된 것처럼 답함 |

!!! 답변을 보내기 전에 확인합니다
- AI에 학생 이름, 학번, 연락처를 입력하지 않았다
- 근거 조항을 규정집 원문에서 직접 확인했다
- 최신 개정본 기준이며 경과 규정을 확인했다
- 예외 조항과 위임 규정을 함께 확인했다
- 담당 부서 판단이 필요한 부분을 확정적으로 답하지 않았다
- 학생 개인정보를 학부모에게 알리는 내용이 없다
- 답변의 날짜와 기한이 이번 학기 공고와 같다

# 바이탈에서 이어서 하기

- **학칙·대학 규정 Q&A 챗봇:** 규정 PDF를 올리면 질문에 맞는 조항을 찾아 보여 줍니다. 답변과 함께 근거 조항 원문이 표시되므로 담당자가 바로 확인할 수 있습니다.
- **학내 민원·학부모 문의 응대 스크립트:** 문의 유형과 상황을 고르면 공감, 결론, 근거, 안내 순서의 응대 문안을 만듭니다.
- **개인정보 가명처리기:** 문의 원문의 이름과 연락처를 가린 뒤 AI에 넣습니다.
- **프롬프트 라이브러리 3-6, 3-8:** 규정 근거 민원 답변과 정중한 회신 메일 프롬프트를 입력칸 방식으로 씁니다.
