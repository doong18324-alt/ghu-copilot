# 프롬프트가 결과를 바꾸는 이유

## 같은 AI, 다른 답

두 학생이 같은 AI에게 질문했습니다.

| 학생 | 질문 | 받은 답 |
|---|---|---|
| A | 당뇨병 알려 줘 | 백과사전처럼 일반적인 설명 열 줄 |
| B | 간호학과 2학년이 성인간호학 중간고사를 준비합니다. 제2형 당뇨병의 병태생리를 인슐린 저항성과 베타세포 기능 저하 두 가지로 나눠, 각각 시험에 나올 만한 핵심 개념 3개씩 표로 정리해 주세요. | 시험 공부에 바로 쓸 수 있는 표 |

AI의 실력이 달라진 것이 아닙니다. B 학생은 자신이 누구인지, 무엇을 하려는지, 어떤 형식이 필요한지를 알려 주었습니다. 프롬프트(prompt)는 AI에게 주는 작업 지시서입니다. 지시서가 구체적일수록 결과도 구체적입니다.

## AI는 내 상황을 모릅니다

사람에게 부탁할 때는 상대가 내 학과와 학년, 지금 하는 과제를 대략 알고 있습니다. AI는 대화창에 적힌 내용 말고는 아무것도 모릅니다. 처음 만난 유능한 조교에게 일을 맡긴다고 생각하고, 조교가 되물을 만한 내용을 미리 적어 주면 됩니다.

# 프롬프트의 네 가지 요소

## 역할, 과제, 맥락, 출력 형식

| 요소 | 질문 | 예 |
|---|---|---|
| 역할(Role) | AI가 어떤 관점으로 답할까 | 물리치료학과 1학년을 가르치는 해부학 조교 |
| 과제(Task) | 무엇을 해야 하나 | 어깨관절 돌림근띠 네 근육을 비교 |
| 맥락(Context) | 왜, 누구를 위해, 어떤 조건에서 | 실기 시험 전날, 촉진 위치를 외워야 함 |
| 출력(Output) | 어떤 모양으로 받을까 | 근육별 이음·닿음·작용을 표로, 외우는 요령 한 줄 |

이 네 요소의 앞 글자를 따서 RTCO라고 부르기도 합니다. 모든 질문에 네 요소를 다 넣을 필요는 없습니다. 간단한 질문은 과제만으로 충분하고, 결과가 마음에 들지 않을 때 빠진 요소를 하나씩 더하면 됩니다.

```prompt 네 요소를 갖춘 기본형
당신은 [역할: 예, 임상병리학과 2학년을 가르치는 혈액학 조교]입니다.
[과제: 예, 철결핍빈혈과 거대적혈모구빈혈의 검사 소견을 비교]해 주세요.
상황: [맥락: 예, 다음 주 퀴즈를 준비 중이고, 교재 5장까지 배웠습니다. 아직 골수검사는 배우지 않았습니다.]
형식: [출력: 예, 항목별 비교표(MCV, 적혈구 모양, 원인, 대표 검사), 표 아래에 헷갈리기 쉬운 점 2가지]
```

## 결과를 좋게 만드는 다섯 가지 습관

1. **분량을 정합니다.** "짧게"보다 "5줄 이내", "표 1개"가 정확합니다.
2. **수준을 정합니다.** "고등학생이 이해할 수준", "국가시험 수준"처럼 독자를 밝힙니다.
3. **하지 말 것을 적습니다.** "추측으로 수치를 쓰지 마세요", "영어 약어는 풀어 써 주세요"
4. **예시를 보여 줍니다.** 원하는 형식의 예를 한 줄 넣으면 AI가 그 모양을 따라 합니다.
5. **한 번에 끝내지 않습니다.** 첫 답을 보고 "2번 항목을 더 자세히", "표에 기전 열을 추가"처럼 고쳐 나갑니다.

## 되묻게 하기

내가 무엇을 빠뜨렸는지 모를 때는 AI에게 먼저 질문하라고 시킵니다.

```prompt 되묻기 요청
[하려는 일: 예, 노인 낙상 예방 교육 자료를 만들려고 합니다.]
바로 답하지 말고, 좋은 결과를 만들기 위해 당신이 알아야 할 정보를 5개 이내로 먼저 질문해 주세요. 제가 답하면 그때 작성해 주세요.
```

# 전공 교재와 논문 요약하기

## 요약은 목적에 따라 다릅니다

| 목적 | 요청 방법 |
|---|---|
| 시험 대비 | 핵심 개념, 정의, 비교, 숫자 기준을 뽑아 달라고 함 |
| 과제 자료 조사 | 주장, 근거, 한계를 나눠 달라고 함 |
| 발표 준비 | 청중이 기억할 메시지 3개와 근거로 정리 |
| 실습 준비 | 절차, 주의사항, 확인할 관찰 항목 순서로 정리 |

## 자료를 직접 주고 요약시키기

AI가 기억에만 의존해 요약하면 교재 내용과 다를 수 있습니다. 내가 가진 강의 자료나 교재의 해당 부분을 주고 그 안에서만 답하라고 하면 정확도가 올라갑니다. NotebookLM처럼 올린 자료 안에서만 답하는 도구는 출처 위치까지 표시해 주므로 확인이 쉽습니다. 교재 전체를 스캔해 올리는 것은 저작권 문제가 될 수 있으니, 수업에서 받은 자료와 내가 쓴 필기를 중심으로 씁니다.

```prompt 자료 기반 요약
아래는 [과목] [주차] 강의 자료에서 제가 옮겨 적은 내용입니다.
[자료 붙여 넣기]

이 자료 안의 내용만 사용해 다음을 만들어 주세요.
1. 핵심 개념 5개와 한 줄 정의
2. 서로 헷갈리기 쉬운 개념 쌍과 구분 기준
3. 자료에 없어서 교재로 확인해야 할 부분
자료에 없는 내용은 추가하지 마세요.
```

## 영어 논문 읽기

논문은 처음부터 끝까지 번역하기보다 구조를 따라 읽는 것이 빠릅니다. 초록(Abstract)에서 연구 질문과 결론을 먼저 잡고, 방법(Methods)에서 대상과 측정 도구를, 결과(Results)에서 핵심 수치를 확인합니다.

```prompt 논문 구조 읽기
아래는 제가 읽고 있는 논문의 초록입니다.
[초록 붙여 넣기]

1. 연구 질문을 한 문장으로
2. 연구 설계(예: 무작위대조시험, 단면조사)와 대상자
3. 주요 결과(수치는 초록에 있는 것만)
4. 저자의 결론
5. 이 결론을 그대로 받아들이기 전에 본문에서 확인할 점
을 한국어로 정리해 주세요. 전문 용어는 한국어(영어) 형태로 써 주세요.
```

AI가 정리한 수치는 반드시 원문 표와 대조합니다. 초록에 없는 수치를 AI가 덧붙였다면 지어낸 것일 수 있습니다.

## 두 자료 비교하기

교재 두 권이나 지침 두 개의 설명이 다를 때 AI에게 비교표를 만들게 하면 차이가 잘 보입니다. 이때 "어느 쪽이 맞는지"는 AI에게 판단을 맡기지 말고, 발행 연도와 기관을 확인해 최신 공식 자료를 우선합니다.

# 의학용어와 외국어 학습

## 의학용어는 쪼개서 외웁니다

의학용어 대부분은 접두사, 어근, 접미사로 나뉩니다. 예를 들어 gastroenteritis는 gastro(위) + enter(장) + itis(염증)입니다. AI에게 용어를 쪼개 설명하게 하면 처음 보는 단어도 뜻을 추측할 수 있게 됩니다.

```prompt 의학용어 쪼개기
다음 의학용어를 접두사, 어근, 접미사로 나누고 각 부분의 뜻과 전체 뜻을 표로 정리해 주세요.
같은 어근이나 접미사를 쓰는 다른 용어도 2개씩 예로 들어 주세요.
용어: [예, cholecystectomy, nephrolithiasis, bradycardia, hemiplegia]
```

## 반복 퀴즈로 굳히기

외운 것은 꺼내 보는 연습(인출 연습)을 할 때 오래 남습니다. AI에게 퀴즈를 내 달라고 하고, 답을 맞히면 다음 문제로, 틀리면 설명을 듣는 방식으로 진행합니다.

```prompt 의학용어 퀴즈
[범위: 예, 심혈관계 의학용어 30개] 범위에서 한 번에 한 문제씩 퀴즈를 내 주세요.
- 한국어 뜻을 보여 주면 제가 영어 용어를 씁니다.
- 제가 답하면 맞았는지 알려 주고, 틀렸으면 용어를 쪼개 설명해 주세요.
- 10문제가 끝나면 틀린 용어만 모아 다시 내 주세요.
```

## 외국어 회화 연습

해외 실습, 외국인 환자 응대, 영어 면접을 준비할 때 AI와 역할극을 할 수 있습니다. 음성 대화 기능을 쓰면 말하기 연습도 됩니다.

```prompt 영어 환자 응대 연습
당신은 영어를 쓰는 외래 환자입니다. 저는 [직종: 예, 방사선사]로 [상황: 예, 흉부 X선 촬영 전 금속 제거와 자세 안내]를 합니다.
- 실제 환자처럼 짧게 대답하고, 가끔 이해하지 못한 척 되물어 주세요.
- 대화가 10번 오가면 멈추고, 제 문장 가운데 어색한 표현 3개를 더 자연스러운 표현으로 고쳐 주세요.
```

# 발표 자료와 대본

## 발표는 메시지부터

발표 자료를 만들 때 가장 흔한 실수는 슬라이드부터 만드는 것입니다. 청중이 발표가 끝난 뒤 기억해야 할 메시지를 먼저 정하고, 그 메시지를 뒷받침하는 근거를 슬라이드로 나눕니다.

```prompt 발표 뼈대 설계
주제: [예, 지역사회 노인의 근감소증과 운동]
청중: [예, 같은 과 동기와 담당 교수님]
시간: [예, 7분]

1. 청중이 기억할 핵심 메시지 3개
2. 메시지별 근거와 넣을 그림·표의 종류
3. 슬라이드 순서(제목만, 8장 이내)
를 제안해 주세요. 수치나 연구 결과는 넣지 말고, 제가 찾아야 할 자료가 무엇인지만 적어 주세요.
```

마지막 조건이 중요합니다. 수치는 내가 직접 찾은 출처에서 가져와야 발표에서 질문을 받았을 때 답할 수 있습니다.

## 슬라이드 한 장의 원칙

- 한 장에 메시지 하나
- 제목은 주제어가 아니라 문장으로. 예: "근감소증" 대신 "근력 운동은 근감소증 노인의 보행 속도를 높인다"
- 글은 청중이 읽는 데 10초 이내
- 그림과 표에는 출처

## 대본과 예상 질문

발표 대본을 AI와 함께 다듬을 때는 내가 먼저 초안을 쓰고 "말로 할 때 자연스럽게, 시간은 1분 30초 분량으로"처럼 고쳐 달라고 합니다. 대본을 통째로 AI에게 쓰게 하면 내 말투가 아니어서 발표가 어색해집니다.

```prompt 예상 질문 받기
아래는 제 발표 대본입니다.
[대본 붙여 넣기]

당신은 이 분야를 잘 아는 교수입니다. 발표가 끝난 뒤 받을 만한 날카로운 질문 5개를 만들어 주세요.
질문마다 제 대본의 어느 부분이 약해서 나온 질문인지 표시해 주세요. 답은 제가 먼저 써 보겠습니다.
```

# 계열별 프롬프트 예

| 계열 | 상황 | 프롬프트 핵심 |
|---|---|---|
| 간호 | 실습 전 질환 예습 | 역할: 성인간호 조교 / 과제: 질환의 사정 포인트와 간호 진단 예 / 맥락: 내일 실습, 교재 [장]까지 학습 / 형식: 표 |
| 물리치료 | 평가 방법 정리 | 역할: 근골격 평가 조교 / 과제: 어깨 특수검사 비교 / 맥락: 실기 시험 / 형식: 검사명, 방법, 양성 소견, 의미 |
| 임상병리 | 검사 원리 이해 | 역할: 임상화학 조교 / 과제: 효소 검사 원리 설명 / 맥락: 처음 배움 / 형식: 3단계 그림 설명 |
| 방사선 | 촬영 자세 정리 | 역할: 방사선 촬영 실습 조교 / 과제: 부위별 자세와 중심선 / 맥락: 실습 전 / 형식: 표 |
| 사회복지 | 이론 비교 | 역할: 사회복지실천 교수 / 과제: 두 관점 비교 / 맥락: 중간고사 / 형식: 비교표와 사례 적용 |
| 경영·행정 | 보고서 개요 | 역할: 실무 담당자 / 과제: 1쪽 보고서 개요 / 맥락: 팀장 보고 / 형식: 결론 먼저 |

# 자주 묻는 질문

**프롬프트가 너무 길어지면 오히려 결과가 나빠지지 않나요?**
필요한 정보가 많을수록 결과가 좋아지는 경우가 많습니다. 다만 서로 모순되는 조건이 섞이면 결과가 흐려지므로, 조건을 번호로 정리해 줍니다.

**같은 프롬프트인데 매번 답이 다릅니다.**
생성형 AI는 같은 질문에도 조금씩 다른 답을 냅니다. 형식이 중요하면 예시를 보여 주고, 사실은 항상 확인합니다.

**영어로 물으면 더 정확한가요?**
주제와 도구에 따라 다릅니다. 영어 자료가 많은 분야는 영어로 묻고 한국어로 정리해 달라고 할 수 있지만, 국내 제도와 교재 용어는 한국어로 묻는 것이 맞습니다.

# 프롬프트를 쓸 때 지킬 것

## 넣지 않을 정보

실습 기관의 환자 정보, 동료나 교수의 개인정보, 아직 공개되지 않은 시험 문제는 AI에 넣지 않습니다. 사례 과제는 처음부터 가상 사례로 만듭니다.

## 결과를 확인하는 습관

!!! AI 답을 쓰기 전에 확인합니다
- 수치, 용량, 기준은 교재나 공식 지침과 대조했다
- 논문 제목과 저자는 RISS, KCI, PubMed에서 직접 찾았다
- 과목의 AI 활용 규칙을 확인했다
- 내 말로 다시 쓸 수 있을 만큼 이해했다
- 과제에 AI 사용 사실을 밝혔다

# 맺음말과 실습

## 실습 1. 같은 질문, 다른 프롬프트

다음 두 질문을 같은 AI에 넣고 결과를 비교합니다.

1. "[내 전공 개념] 설명해 줘"
2. 네 요소를 모두 넣은 프롬프트

어떤 요소를 넣었을 때 결과가 가장 많이 달라졌는지 한 문장으로 씁니다.

## 실습 2. 되묻기 경험

"되묻기 요청" 프롬프트로 과제 하나를 시작해 봅니다. AI가 한 질문 가운데 내가 생각하지 못했던 것을 적어 둡니다.
