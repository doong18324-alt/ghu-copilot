# 치위생과 AI

## 치과위생사의 일과 AI가 닿는 곳

치과위생사는 구강질환 예방과 구강건강 증진을 맡는 전문 인력입니다. 치석 제거와 불소 도포 같은 예방 처치, 구강보건교육, 진료 보조, 지역사회 구강보건 사업이 주요 업무입니다. 이 가운데 생성형 AI가 직접 도움을 줄 수 있는 곳은 손으로 하는 처치가 아니라 말과 글로 하는 일입니다.

| 업무 | AI가 돕는 부분 | 치과위생사가 판단할 부분 |
|---|---|---|
| 구강보건교육 | 대상자 연령·상황에 맞춘 교육 대본, 리플릿 문안, 퀴즈 | 칫솔질법과 위생용품 선택의 임상적 타당성 |
| 환자 상담 | 상담 시나리오 연습, 동기면담 문장 | 환자의 실제 구강 상태 평가 |
| 진료 기록 | 기록 문장 정리 연습(가상 사례) | 실제 기록의 정확성, 의료법상 기록 의무 |
| 지역사회 사업 | 사업 계획서 초안, 설문 문항, 결과 요약 | 대상 집단 특성, 사업 효과 판단 |
| 국가시험 대비 | 개념 정리, 연습 문항 | 정답 근거의 정확성 |

## 이 학과에서 AI를 쓸 때의 원칙

- **환자 정보는 넣지 않습니다.** 실습기관에서 만난 환자의 이름, 나이, 치식, 병력, 구강 사진은 AI에 입력하지 않습니다. 연습은 가상 사례로 합니다.
- **AI의 임상 권고는 교재로 확인합니다.** 불소 농도, 도포 주기, 전신질환자 처치 주의사항은 교재와 지침으로 대조합니다.
- **업무 범위를 지킵니다.** AI가 진단이나 치료 계획을 제시해도 치과위생사의 업무 범위와 치과의사의 지도 원칙에 맞는지 판단합니다.

# 수업 설계: 기존 방식과 AI 융합 방식

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 구강보건교육학 및 실습 | 표준 교안으로 매체 제작 | 대상자 조건(연령, 전신질환, 장애)별 교육 시나리오를 AI로 만들고 교재로 검증해 수정 | 대상자 맞춤 교육 설계, 근거 검증 |
| 임상치위생학 | 지면 사례 분석 | AI 가상 환자와 문진 연습, 치주 관리 계획 초안 비판 | 문진 의사소통, 임상 추론 |
| 지역사회구강보건 | 일반 대상 캠페인 기획 | 기관 특성별 프로그램 기획, 설문 설계와 결과 해석 | 사업 기획, 자료 해석 |
| 예방치학 | 이론 강의 중심 | AI가 만든 예방 지침의 오류 찾기 활동 | 비판적 사고, 근거 기반 판단 |

# 교수자용 수업 활동

## 활동 1. 전신질환자 맞춤 구강보건교육 매체 만들기

학생이 AI로 교육 매체 초안을 만들고, 교재 기준으로 오류를 찾아 고친 뒤 최종 매체를 제출하는 PBL 과제입니다.

```prompt 프롬프트 1. PBL 과제 지시문 만들기
역할: 당신은 치위생학과 구강보건교육학 교수의 수업 설계를 돕는 조교입니다.

2학년 학생이 생성형 AI를 활용해 '전신질환자 맞춤 구강보건교육 매체'를 만드는 PBL 과제 지시문을 써 주세요.

대상 조건 예: [제2형 당뇨병이 있는 60대 치주질환자 / 항응고제를 복용하는 70대 / 임신 2기 임산부] 가운데 조별로 하나 배정
학생 수행 단계:
1. AI에게 대상자 맞춤 구강관리 안내문 초안 요청(사용한 프롬프트 제출)
2. 예방치학·임상치위생학 교재로 AI 초안의 오류를 찾아 검증표 작성
3. 오류를 고쳐 리플릿 또는 카드뉴스 완성
4. 3분 발표

함께 만들 것: 과제 일정(2주), 제출물 목록, 20점 만점 루브릭(검증의 정확성 8점, 대상자 눈높이 전달 6점, 구강보건교육학적 타당성 6점).
```

## 활동 2. AI 예방 지침 오류 찾기

일부러 오류가 섞일 수 있는 AI 답변을 학생에게 주고, 교재와 대조해 틀린 곳을 찾게 하는 활동입니다. 교수자가 미리 AI 답변을 받아 오류를 확인해 둡니다.

```prompt 프롬프트 2. 오류 찾기 활동 자료
[주제, 예: 연령별 불소 이용 방법]에 대해 일반인용 안내문을 써 주세요. 분량은 A4 반 쪽입니다.
```

교수자는 이 결과를 교재와 대조해 오류와 모호한 부분을 미리 표시해 둡니다. 수업에서는 학생에게 결과만 주고 15분 동안 오류를 찾게 한 뒤, 찾은 오류와 근거를 발표하게 합니다. AI가 오류 없이 답했다면 "이 안내문을 3세 아동 보호자에게 줄 때 더해야 할 주의사항"처럼 질문을 바꿔 다시 받습니다.

## 활동 3. 지역사회 구강보건 프로그램 기획

```prompt 프롬프트 3. 기관 맞춤 프로그램 기획
[기관 유형: 노인요양시설 / 지역아동센터 / 장애인복지관]에서 4주 동안 운영할 구강건강 증진 프로그램 기획안을 써 주세요.

포함: 대상 특성 분석, 주차별 활동, 필요한 물품, 사전·사후 평가 방법(설문 5문항과 관찰 항목), 안전 주의사항.
조건: 근거가 필요한 수치(유병률 등)는 쓰지 말고 [통계 확인 필요]로 남깁니다. 학생이 국가 통계로 직접 채우게 하겠습니다.
```

# 학생용 실습 프롬프트

## 대상자별 교육 대본

```prompt 프롬프트 4. 15분 구강보건교육 대본
당신은 임상 경력이 많은 치과위생사입니다.
[교육 대상, 예: 요양병원 어르신과 요양보호사]에게 15분 동안 할 구강보건교육 지도안과 말하기 대본을 써 주세요.

내용: [예: 의치 세척과 보관, 구강건조 완화를 위한 구강 체조, 치간칫솔 사용법]
조건:
- 도입에 흥미를 끄는 질문 2개, 마지막에 이해 확인 질문 2개를 넣습니다.
- 어르신이 이해하기 쉬운 비유를 쓰되, 의학적으로 틀린 비유는 쓰지 않습니다.
- 시연이 필요한 부분은 [시연]으로 표시합니다.
```

## 가상 환자 문진 연습

```prompt 프롬프트 5. 가상 환자 역할극
지금부터 당신은 치과에 처음 온 가상 환자입니다. 저는 치위생학과 학생이고 문진을 연습합니다.

환자 설정(저에게 미리 알려 주지 마세요): 50대, 최근 잇몸에서 피가 나고 입 냄새가 신경 쓰임, 고혈압약 복용 중, 하루 칫솔질 1회, 흡연.
규칙:
- 제가 묻는 것에만 대답하고, 묻지 않은 정보는 먼저 말하지 않습니다.
- 실제 환자처럼 조금 긴장하고 짧게 대답합니다.
- 제가 "문진 끝"이라고 하면 역할을 멈추고, 제가 놓친 중요한 질문과 잘한 점을 3개씩 알려 주세요.
```

이 연습은 의사소통 연습용입니다. AI가 알려 주는 "놓친 질문"은 교재의 문진 항목과 대조해 확인합니다.

## 국가시험 개념 정리

```prompt 프롬프트 6. 헷갈리는 개념 비교표
치과위생사 국가시험을 준비하고 있습니다. [예: 바스법, 스틸만법, 차터스법, 회전법] 칫솔질법을 비교표로 정리해 주세요.
열: 방법, 칫솔 위치와 각도, 동작, 알맞은 대상, 주의점.
마지막에 각 방법을 구분하는 핵심 단서를 한 줄씩 적어 주세요.
```

AI가 만든 비교표는 교재와 반드시 대조합니다. 칫솔질법의 각도와 대상은 교재마다 표현이 조금 다를 수 있으므로, 수업에서 쓰는 주교재 기준으로 정리합니다.

# 전공 지식으로 검증하기

## 치위생 분야에서 AI가 자주 틀리는 부분

| 영역 | 확인할 것 | 대조 자료 |
|---|---|---|
| 칫솔질법과 위생용품 | 치주질환자, 교정 환자, 보철물 장착자에게 맞지 않는 방법(예: 치경부 마모 위험이 큰 횡마법)을 권하지 않았는가 | 예방치학, 임상치위생학 교재 |
| 불소 이용 | 연령별 불소 농도, 도포 주기, 삼킴 위험에 대한 주의가 최신 기준과 같은가 | 교재, 관련 학회·보건 당국 지침 |
| 전신질환 연계 | 당뇨, 심혈관질환, 항응고제·항혈소판제 복용자의 처치 주의사항이 정확한가 | 임상치위생학 교재 |
| 임산부·영유아 | 시기별 치과 처치 가능 여부, 영유아 구강관리 시작 시기 | 교재, 보건 당국 자료 |
| 수치와 통계 | 유병률, 권장량 같은 수치에 출처가 있는가 | 국가 통계, 원문 자료 |
| 업무 범위 | 진단이나 처방처럼 치과위생사 단독 업무가 아닌 내용을 권하지 않았는가 | 의료기사 등에 관한 법령과 교재 |

## 검증표 양식

학생 과제에서 쓰는 검증표는 다음 형식을 권합니다.

| 번호 | AI가 쓴 내용 | 근거 자료(교재명, 쪽) | 판정(맞음·틀림·불충분) | 수정 내용 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |

판정은 근거 자료를 직접 확인한 뒤에만 적습니다. 근거를 찾지 못하면 "불충분"으로 적고 수정 내용에 "삭제" 또는 "교수 확인 필요"를 씁니다.

!!! 치위생 AI 결과물을 쓰기 전에 확인합니다
- 환자 이름, 치식, 병력, 구강 사진을 AI에 넣지 않았다
- 칫솔질법과 위생용품 권고가 대상자에게 맞는지 교재로 확인했다
- 불소와 처치 관련 수치를 최신 교재·지침과 대조했다
- 전신질환자 주의사항을 확인했다
- 치과위생사 업무 범위를 넘는 권고가 없다
- 교육 대상자가 이해할 수 있는 말로 썼다
