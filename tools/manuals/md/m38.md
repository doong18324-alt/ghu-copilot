# 행정 문서 작성과 AI

## 직원 업무에서 문서가 차지하는 비중

대학 행정 업무의 많은 시간은 문서 작성에 쓰입니다. 사업 하나를 진행하려면 계획 기안, 예산 집행 품의, 협조 공문, 결과보고서가 차례로 필요하고, 같은 내용을 형식만 바꾸어 여러 번 쓰는 일이 잦습니다. 생성형 AI는 이 반복을 크게 줄여 줍니다. 핵심 사실만 메모로 정리하면 정해진 형식의 문서 초안을 몇 분 안에 받을 수 있습니다.

다만 행정 문서는 학교의 공식 의사결정 기록입니다. 금액, 날짜, 규정 조항이 하나라도 틀리면 결재가 반려되거나 감사에서 지적을 받습니다. AI가 쓴 초안은 반드시 원자료와 대조해야 합니다.

## 이 매뉴얼에서 다루는 문서

| 문서 | 목적 | 핵심 요소 |
|---|---|---|
| 기안문 | 업무 추진의 승인 요청 | 관련 근거, 추진 목적, 주요 내용, 붙임 |
| 사업 계획서 | 사업의 목표와 실행 방법 승인 | 추진 배경, 목표, 세부 내용, 일정, 예산, 기대 효과 |
| 결과보고서 | 추진 결과 보고와 환류 | 계획 대비 실적, 성과, 문제점, 개선 방안 |
| 예산 집행 사유서 | 지출의 필요성과 타당성 설명 | 집행 목적, 산출 근거, 관련 규정 |
| 내부 보고 메모 | 상급자에게 현황 보고 | 한 쪽 요약, 결정이 필요한 사항 |

# 보안 기준

## 입력 정보 등급

AI 도구는 입력한 내용을 서비스 개선에 쓰거나 외부 서버에 저장할 수 있습니다. 학교가 계약한 기업용 서비스가 아니라면 다음 기준을 지킵니다.

| 등급 | 예 | AI 입력 |
|---|---|---|
| 공개 | 홈페이지 공지, 공개 규정, 보도자료 | 가능 |
| 일반 업무 | 행사 개요, 일정, 안건 요약, 문서 양식 | 가능(개인 식별 정보 제외) |
| 내부 | 공개 전 예산 세부 내역, 내부 평가 결과, 미확정 계획 | 원칙적으로 불가, 필요하면 수치와 기관명을 [ ]로 바꿔 구조만 다룸 |
| 민감 | 주민등록번호, 계좌번호, 건강 정보, 성적, 징계, 인사 정보 | 불가 |

> 대학에서 공식 도입한 AI 서비스가 있다면 그 서비스의 보안 기준을 따릅니다. 개인 계정의 무료 서비스에는 내부 문서를 올리지 않습니다.

## 민감 정보 지우는 습관

메모를 AI에 붙여 넣기 전 10초만 훑어봅니다. 이름, 연락처, 계좌, 주민등록번호, 학번이 보이면 지웁니다. 바이탈의 **개인정보 가명처리기**에 먼저 넣으면 이름, 전화번호, 주민등록번호, 이메일, 주소 같은 정보를 찾아 기호로 바꿔 주고, AI 결과를 받은 뒤 원래 값으로 되돌릴 수 있습니다.

# 대학 공문서 문체

## 개조식 작성 규칙

| 규칙 | 설명 | 예 |
|---|---|---|
| 명사형 종결 | 문장을 "~함, ~임, ~예정"으로 끝냄 | 2026학년도 신입생 대상 운영 예정 |
| 두괄식 | 결론과 요청을 먼저 | 붙임과 같이 OO 계획을 보고드리니 승인하여 주시기 바랍니다 |
| 항목 번호 체계 | 1. → 가. → 1) → 가) 순서 | 학교 규정의 항목 기호 체계를 따름 |
| 한 항목 한 내용 | 여러 사실을 한 줄에 몰지 않음 | 일시와 장소를 별도 항목으로 |
| 수치는 단위·기준과 함께 | 비율은 분모를 밝힘 | 참여율 78%(62명/80명) |
| 쉬운 말 | 불필요한 한자어, 외래어 줄이기 | "제고" 대신 "높임"도 가능(기관 관행 확인) |

## 기안문의 기본 구조

1. **관련:** 근거 문서나 규정(예: 관련 규정 조항, 상급 기관 공문 번호)
2. **본문 첫 문장:** 무엇을 왜 하는지 한 문장
3. **세부 내용:** 가, 나, 다로 나누어 일시, 대상, 내용, 예산
4. **붙임:** 첨부 문서 목록과 부수
5. **끝 표시:** 학교 문서 규정에 따른 "끝." 표기

관련 근거의 규정 조항과 공문 번호는 AI가 알 수 없습니다. 이 부분은 반드시 직접 채웁니다.

# 문서 유형별 프롬프트

## 기안문

```prompt 프롬프트 1. 기안문 초안
역할: 당신은 대학 행정 문서 작성 규칙을 잘 아는 행정 담당자입니다.

아래 메모로 전자결재 기안문 본문 초안을 작성해 주세요.

메모:
- 업무: [예: 2026학년도 2학기 재학생 AI 활용 역량 특강 운영]
- 관련 근거: [규정명과 조항, 관련 공문 번호. 모르면 비워 둠]
- 일시·장소·대상: [ ]
- 주요 내용: [ ]
- 예산: [총액과 예산 과목]
- 붙임: [첨부할 문서 목록]

작성 규칙:
- 개조식, 명사형 종결
- 항목 기호는 1. 가. 1) 가) 순서
- 관련 근거와 예산 과목을 제가 주지 않았다면 [확인 필요]로 둡니다
- 첫 문장은 "~을 다음과 같이 시행하고자 합니다" 형식
- 마지막은 붙임 목록과 "끝."
```

## 사업 계획서

```prompt 프롬프트 2. 사업 계획서
아래 자료로 [사업명] 계획서를 작성해 주세요.
[메모: 배경, 목표, 대상, 주요 활동, 일정, 예산 총액과 항목, 성과지표]

구성:
1. 추진 배경과 필요성(근거 자료가 있으면 출처 표시)
2. 추진 목표(정량 목표는 지표, 목표값, 측정 방법을 표로)
3. 세부 추진 내용(활동별 내용, 대상, 시기)
4. 추진 일정(월별 표)
5. 소요 예산(표: 항목, 산출 근거, 금액)
6. 기대 효과
7. 성과 관리와 환류 계획

제가 주지 않은 수치, 기관명, 통계는 쓰지 말고 [ ]로 남겨 주세요. 예산 합계는 계산 과정을 표 아래에 보여 주세요.
```

## 결과보고서

```prompt 프롬프트 3. 결과보고서
아래 계획서와 실적 메모로 결과보고서를 개조식으로 작성해 주세요.
[계획서]
[실적 메모: 실제 운영 내용, 참여 인원, 성과지표 실적, 만족도, 집행액, 발생한 문제]

구성:
1. 추진 개요
2. 성과지표 달성 현황(표: 지표, 목표, 실적, 달성률, 비고)
3. 주요 추진 내용
4. 예산 집행 현황(표: 항목, 예산, 집행액, 집행률)
5. 성과와 한계
6. 개선 방안과 차기 반영 계획

계산 규칙: 달성률 = 실적 ÷ 목표 × 100, 소수점 첫째 자리까지. 모든 계산 과정을 표 아래에 적어 주세요.
실적 메모에 없는 성과를 추가하지 마세요.
```

## 예산 집행 사유서

```prompt 프롬프트 4. 집행 사유서

- 사업과의 관련성: [ ]

반 쪽 분량의 개조식으로, 감사 담당자가 읽고 필요성과 타당성을 바로 이해할 수 있게 써 주세요. 규정 조항을 지어내지 마세요.
```

행정 문서의 표는 정보가 많아 읽기 어렵기 쉽습니다. 열은 5개 안팎으로 줄이고, 합계 행을 맨 아래에 둡니다. AI에게 "표를 A4 세로 한 쪽 폭에 맞게 열을 줄이고, 긴 설명은 표 아래 주석으로 빼 주세요"라고 요청합니다.

# 검증

## AI가 자주 틀리는 부분

| 부분 | 흔한 오류 | 확인 방법 |
|---|---|---|
| 합계와 비율 | 표 합계, 달성률, 집행률 계산 오류 | 엑셀로 다시 계산 |
| 날짜와 요일 | 요일이 틀리거나 공휴일을 모름 | 달력과 학사력 대조 |
| 규정 조항 | 조항 번호를 지어냄 | 학교 규정집 원문 확인 |
| 기관·사업 명칭 | 비슷한 이름으로 바꿔 씀 | 공식 명칭 대조 |
| 예산 과목 | 학교 예산 체계와 다른 과목명 | 예산 담당 부서 체계 확인 |
| 과장된 성과 표현 | "획기적", "크게 기여" | 실적 수치로 바꿈 |

## 바이탈의 검증 도구

산학협력단 지출결의서처럼 여러 문서의 금액과 날짜가 서로 맞아야 하는 경우 바이탈의 **산학협력단 결의서 스마트 검증기**를 씁니다. 견적서, 거래명세서, 결의서의 공급가액, 부가세, 합계와 날짜를 서로 대조하고, 주말 집행이나 지침 조항과 어긋나는 부분을 표시해 줍니다.

!!! 결재 상신 전에 확인합니다
- 개인정보와 민감 정보가 AI 입력에 들어가지 않았다
- 관련 근거의 규정 조항과 공문 번호를 원문으로 확인했다
- 모든 합계, 비율, 달성률을 직접 다시 계산했다
- 날짜와 요일이 맞고 공휴일과 겹치지 않는다
- 기관명, 사업명, 예산 과목이 공식 명칭과 같다
- 근거 없는 수치나 과장된 표현이 없다
- 학교 문서 양식(항목 기호, 끝 표시, 붙임)에 맞다

# 바이탈에서 이어서 하기

- **보도자료·공지·회의록·결과보고서 작성 앱:** 결과보고서 모드에서 계획과 실적 수치를 넣으면 달성률을 계산하고 개조식 초안을 만듭니다.
- **산학협력단 결의서 스마트 검증기:** 지출 증빙 문서 사이의 금액, 날짜, 부가세 불일치를 찾습니다.
- **개인정보 가명처리기:** AI 입력 전 개인정보를 가리고 결과를 받은 뒤 되돌립니다.
- **프롬프트 라이브러리 3-1, 3-2, 3-9:** 추진계획 기안, 결과보고서, 예산 산출 근거 프롬프트를 입력칸 방식으로 씁니다.

## 자주 묻는 질문

**학교 문서 양식 파일을 AI에 올려도 되나요?**
빈 양식은 공개 수준이므로 올려도 됩니다. 양식을 올리고 "이 양식의 항목 순서와 표기 규칙에 맞춰 작성해 주세요"라고 하면 형식 맞추는 시간이 줄어듭니다. 다른 사람이 작성한 결재 문서를 예시로 올릴 때는 이름과 금액을 지운 뒤 올립니다.

**AI가 쓴 문서라고 밝혀야 하나요?**
내부 행정 문서에 AI 사용 여부를 표시하는 별도 규정이 없다면 표시하지 않아도 됩니다. 다만 학교에 AI 활용 지침이 있으면 그에 따릅니다. 어느 경우든 문서의 책임은 기안자에게 있습니다.
