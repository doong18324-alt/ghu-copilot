# 좋은 문항이란 무엇인가

## 문항이 하는 일

시험 문항은 학생이 학습목표에 도달했는지 보여 주는 측정 도구입니다. 좋은 문항은 공부한 학생은 맞히고 공부하지 않은 학생은 틀리게 만듭니다. 반대로 나쁜 문항은 문장을 꼼꼼히 읽는 요령이나 보기의 길이 같은 단서로 맞힐 수 있게 하거나, 잘 아는 학생도 문장의 모호함 때문에 틀리게 만듭니다.

생성형 AI는 문항 초안을 매우 빠르게 만듭니다. 그러나 AI가 만든 문항은 정답이 둘이거나, 오답이 너무 뻔하거나, 교재와 다른 기준으로 정답을 정하는 경우가 자주 있습니다. 이 매뉴얼은 AI 초안을 받아 좋은 문항으로 다듬는 기준과 절차에 초점을 둡니다.

## 5지선다형 문항의 구조

| 구성 요소 | 설명 | 작성 원칙 |
|---|---|---|
| 문두 | 묻는 내용 | 문두만 읽고도 무엇을 묻는지 알 수 있게 씁니다 |
| 정답 | 하나의 옳은 답지 | 전문가 누구라도 동의하는 단 하나의 답이어야 합니다 |
| 오답지 | 그럴듯하지만 틀린 답지 4개 | 학생이 실제로 하는 오개념을 반영합니다 |
| 해설 | 정답 근거와 오답 이유 | 교재·지침의 위치를 함께 적습니다 |

## 문항 작성 원칙 열 가지

1. **한 문항은 한 가지만 묻습니다.** 두 개념을 동시에 묻으면 어느 쪽을 몰라서 틀렸는지 알 수 없습니다.
2. **문두는 완결된 질문으로 씁니다.** "다음 중 옳은 것은?"보다 "OO 환자에게 가장 먼저 시행해야 할 중재는?"이 좋습니다.
3. **부정형 문두는 피합니다.** 꼭 써야 하면 "아닌", "옳지 않은" 부분을 굵게 표시합니다.
4. **답지는 길이와 형식을 비슷하게 맞춥니다.** 정답만 길고 자세하면 그 자체가 단서가 됩니다.
5. **"모두 옳다", "모두 틀리다"는 쓰지 않습니다.** 부분 지식으로 맞히는 단서가 됩니다.
6. **오답지는 실제 오개념에서 가져옵니다.** 학생들이 자주 틀리는 답이 좋은 오답지입니다.
7. **답지는 일정한 순서로 배열합니다.** 숫자는 크기 순, 단어는 가나다 순으로 놓으면 위치 단서가 줄어듭니다.
8. **정답 위치를 고르게 나눕니다.** 시험지 전체에서 1~5번 정답이 비슷한 수가 되게 합니다.
9. **"항상", "절대" 같은 단정 표현을 조심합니다.** 학생은 이런 표현이 든 답지를 오답으로 짐작합니다.
10. **문두에 정답의 단서를 남기지 않습니다.** 문두와 정답에 같은 단어가 반복되지 않게 합니다.

# 문항 유형

## 지식 확인형

정의, 분류, 정상 범위처럼 기억과 이해 수준을 확인합니다. 출제가 쉽지만 이 유형만으로 시험을 구성하면 학생은 암기 위주로 공부합니다.

## 적용형

절차나 원리를 상황에 써 보게 합니다. "체중 60 kg인 대상자에게 OO 기준으로 계산하면"처럼 계산이나 판단 과정을 거쳐야 답이 나옵니다.

## 임상 사례형

짧은 사례(대상자 특성, 증상, 검사 결과)를 주고 우선순위, 해석, 다음 행동을 묻습니다. 국가시험의 비중이 커지는 유형이며 현장 판단력을 가장 잘 확인합니다. 좋은 사례형 문항의 사례에는 다음이 들어갑니다.

- 나이, 성별, 주요 상황 같은 대상자 정보
- 판단에 필요한 정보와 판단을 흐리는 정보가 적절히 섞인 소견
- 하나의 명확한 질문

## 문항 예시

아래는 이 매뉴얼을 위해 새로 만든 예시 문항입니다.

> 72세 여성이 최근 6개월 동안 두 번 넘어졌다고 한다. 의자에서 손을 짚지 않고 일어나기 어렵고, 보행 중 자주 멈춘다. 이 대상자의 낙상 위험을 선별하기 위해 가장 먼저 시행하기에 알맞은 검사는?
>
> ① 최대산소섭취량 검사　② 일어나 걸어가기 검사(TUG)　③ 1회 최대 반복 근력 검사　④ 등척성 악력 검사　⑤ 유연성 앉아 윗몸 앞으로 굽히기

정답은 ②입니다. 오답지는 모두 실제 체력 평가에 쓰이는 검사이지만, 낙상 위험 선별이라는 목적과 고령자 안전을 함께 고려하면 ②가 가장 알맞습니다. ①과 ③은 고위험 대상자에게 선별 단계에서 시행하기에 부담이 큰 검사라는 점이 학생의 판단 근거가 됩니다.

# AI로 초안 만들기

## 출제 범위 자료 준비

문항 품질은 AI에게 준 자료의 품질을 넘지 못합니다. 다음 자료를 함께 줍니다.

- 해당 주차의 강의안 또는 교재 범위(가능하면 파일로)
- 학습목표
- 출제할 문항 수와 유형 비율
- 학생 수준(학년, 이전 시험 평균 등 개인정보가 아닌 정보)

> 국가시험의 과거 문항을 그대로 입력해 변형하게 하는 방식은 쓰지 않습니다. 국가시험 문항은 저작권이 있는 자료이며, 변형 문항도 원문과 지나치게 비슷하면 문제가 됩니다. 국가시험 대비 문항은 국가시험원이 공개한 출제 범위와 교재를 근거로 새로 만듭니다.

## 기본 출제 프롬프트

```prompt 프롬프트 1. 5지선다형 문항 출제
역할: 당신은 보건계열 국가시험 문항 작성 원칙을 잘 아는 출제 보조자입니다.

자료: [강의안 또는 교재 범위를 첨부하거나 붙여 넣기]
학습목표: [학습목표 목록]

작업:
1. 위 자료만 근거로 5지선다형 문항 [10]개를 만듭니다. 지식 확인형 3개, 적용형 4개, 임상 사례형 3개로 나눕니다.
2. 문항마다 연결된 학습목표 번호, 예상 난이도(상·중·하), 정답, 해설을 적습니다.
3. 해설에는 정답 근거가 자료의 어디에 있는지, 그리고 각 오답지가 왜 틀렸는지 한 줄씩 적습니다.

지킬 것:
- 정답은 반드시 하나만 되게 합니다. 자료만으로 정답을 확정할 수 없는 문항은 만들지 않습니다.
- 답지 길이를 비슷하게 맞추고, 숫자 답지는 크기 순으로 배열합니다.
- 부정형 문두는 쓰지 않습니다.
- "모두 옳다", "모두 틀리다" 답지는 쓰지 않습니다.
- 정답 번호가 1~5번에 고르게 나뉘게 합니다.
```

## 임상 사례형 집중 출제

```prompt 프롬프트 2. 임상 사례형 문항
[주제]에 대해 임상 사례형 5지선다 문항 [5]개를 만들어 주세요.

사례 조건:
- 대상자 정보(나이, 성별, 상황)와 판단에 필요한 소견 3~4개를 3~5문장으로 씁니다.
- 판단을 흐리는 소견을 하나 넣되, 정답 판단을 바꾸지는 않게 합니다.
- 질문은 "가장 먼저", "가장 알맞은"처럼 우선순위나 판단을 묻습니다.

각 문항 뒤에 이 문항이 확인하는 판단 능력이 무엇인지 한 줄로 적어 주세요.
첨부 자료에 근거가 없는 소견이나 수치는 쓰지 마세요.
```

## 오답지 개선

AI가 만든 문항의 가장 흔한 약점은 오답지가 너무 뻔하다는 것입니다.

```prompt 프롬프트 3. 오답지 다듬기
아래 문항의 오답지를 더 그럴듯하게 고쳐 주세요.
[문항 붙여 넣기]

기준: 이 주제를 공부한 학생이 실제로 헷갈리는 개념에서 오답지를 가져옵니다. 오답지마다 어떤 오개념을 가진 학생이 고를지 한 줄로 적어 주세요. 정답은 바꾸지 마세요.
```

## 형성평가 퀴즈

수업 중 5분 퀴즈는 성적보다 이해 확인이 목적입니다. 학생 응답 도구나 학습관리시스템 퀴즈 기능에 바로 넣을 수 있게 형식을 맞춰 달라고 요청합니다.

```prompt 프롬프트 4. 수업 중 확인 퀴즈
오늘 수업 범위로 확인 퀴즈 5문항을 만들어 주세요. OX 2문항, 4지선다 3문항입니다.
각 문항 아래에 학생이 틀렸을 때 보여 줄 짧은 피드백(2문장)을 적어 주세요.
결과는 표로, 열은 [번호, 유형, 문항, 보기, 정답, 피드백]으로 합니다.
```

# 문항 검토

## 검토 기준표

AI가 만든 문항은 아래 기준으로 하나씩 검토합니다. 한 항목이라도 걸리면 고치거나 버립니다.

| 검토 항목 | 확인 질문 |
|---|---|
| 정답의 유일성 | 다른 답지도 정답으로 볼 여지가 없는가 |
| 근거 | 정답 근거가 교재나 지침에 있는가 |
| 학습목표 연결 | 이 문항이 어느 학습목표를 확인하는가 |
| 문두 명확성 | 문두만 읽고 무엇을 묻는지 아는가 |
| 단서 | 답지 길이, 반복 단어, 단정 표현이 단서가 되지 않는가 |
| 오답지 매력 | 각 오답지를 고를 학생이 실제로 있을까 |
| 난이도 | 학년 수준에 맞는가 |
| 표현 | 맞춤법, 용어 통일, 단위 표기가 맞는가 |

## AI에게 스스로 검토시키기

AI에게 다른 역할을 주고 검토시키면 놓친 문제를 찾는 데 도움이 됩니다. 다만 AI 검토 결과도 최종 판단은 교수자가 합니다.

```prompt 프롬프트 5. 검토자 역할
이번에는 당신이 문항 검토위원입니다. 아래 문항들을 검토해 주세요.
[문항 목록]

문항마다 다음을 확인하고 문제가 있으면 적어 주세요.
1. 정답이 둘 이상일 수 있는가
2. 문두나 답지에 정답의 단서가 있는가
3. 근거 자료와 다른 내용이 있는가
4. 수정안

문제가 없으면 "문제 없음"이라고만 적습니다.
```

# 시험 후 문항분석

## 왜 분석하는가

시험이 끝난 뒤 문항별 정답률과 변별도를 보면 어떤 문항이 제 역할을 했는지 알 수 있습니다. 이 결과는 다음 학기 문항 수정과 수업 개선의 가장 확실한 근거가 됩니다.

## 주요 지표

| 지표 | 의미 | 해석 기준(일반적 참고값) |
|---|---|---|
| 난이도(정답률, p) | 정답을 맞힌 학생 비율 | 0.3 미만 어려움, 0.3~0.8 적정, 0.8 초과 쉬움 |
| 변별도(D) | 상위 집단과 하위 집단의 정답률 차이 | 0.4 이상 우수, 0.3~0.39 양호, 0.2~0.29 보통, 0.2 미만 수정 필요 |
| 문항-총점 상관 | 이 문항과 나머지 점수의 상관 | 음수면 문항 오류를 의심 |
| 오답지 선택률 | 각 오답지를 고른 비율 | 아무도 고르지 않은 오답지는 기능하지 않음 |
| 신뢰도(KR-20) | 시험 전체의 내적 일관성 | 수업 내 시험에서는 0.7 이상을 대체로 바람직하게 봄 |

위 해석 기준은 교육평가 분야에서 흔히 쓰이는 참고값입니다. 문항의 목적(필수 지식 확인 문항은 정답률이 높아도 됨)에 따라 판단을 달리합니다.

## 분석 결과로 할 일

- **변별도가 음수인 문항:** 정답이 잘못 지정되었거나 문항에 오류가 있을 가능성이 높습니다. 채점 전에 확인했다면 학과 규정에 따라 처리합니다.
- **정답률이 매우 낮고 변별도도 낮은 문항:** 수업에서 다루지 않았거나 문항이 모호합니다.
- **아무도 고르지 않은 오답지:** 다음 학기에 더 그럴듯한 오답지로 바꿉니다.
- **특정 오답지에 상위 집단이 몰린 문항:** 그 오답지도 정답으로 볼 여지가 있는지 다시 검토합니다.

# 바이탈에서 이어서 하기

- **문항 분석기:** 학생별 응답을 CSV로 붙여 넣으면 문항별 정답률, 변별도, 문항-나머지 상관, 오답지 선택률, KR-20을 계산하고 개선이 필요한 문항을 표시합니다. 학생 이름 대신 번호만 넣어도 분석됩니다.
- **국가고시 CBT 모의고사·오답노트:** 학생이 직종별 연습 문항을 풀고 오답노트를 쓰는 앱입니다. 수업에서 만든 문항과 함께 자율 학습용으로 안내할 수 있습니다.
- **프롬프트 라이브러리 2-3, 2-4:** 국가시험형 객관식 출제와 오답 설계, 환자 사례형·서술형 문항 프롬프트를 입력칸 방식으로 씁니다.

!!! 시험지로 확정하기 전에 확인합니다
- 모든 문항의 정답을 교재나 지침에서 직접 확인했다
- 정답이 둘 이상일 수 있는 문항이 없다
- 문항마다 연결된 학습목표가 있다
- 정답 번호가 고르게 나뉘었다
- 부정형 문두는 굵게 표시했다
- 국가시험 문항을 옮기거나 거의 그대로 바꾼 문항이 없다
- 시험 후 문항분석 일정을 잡아 두었다
