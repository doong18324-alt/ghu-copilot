# 연구와 AI

## 연구 과정에서 AI가 닿는 곳

| 단계 | AI가 돕는 부분 | 연구자가 판단할 부분 |
|---|---|---|
| 주제 탐색 | 연구 질문 다듬기, PICO 구성 | 연구의 가치와 실행 가능성 |
| 문헌 탐색 | 검색어 후보, 검색식 초안, 읽은 논문 요약 | 실제 검색과 선별, 원문 확인 |
| 연구계획 | 계획서 구조, 빠진 항목 점검 | 설계, 표본, 윤리 판단 |
| 심의 서류 | 동의서를 쉬운 말로, 서류 간 일치 점검 | 위험과 이익 판단 |
| 자료 분석 | 분석 코드 초안, 오류 해결 | 분석 방법 선택, 결과 검증 |
| 원고 작성 | 문장 다듬기, 영문 교정, 구조 점검 | 내용과 해석, 저자 책임 |
| 심사 대응 | 의견 정리, 답변서 구조 | 수용 여부 판단, 근거 |

## 학술지와 연구윤리의 기준

국제 학술지와 출판윤리 단체들은 대체로 다음 원칙을 공유합니다. 다만 세부 기준은 학술지마다 다르므로 투고 전에 해당 학술지의 저자 안내를 반드시 확인합니다.

- **AI는 저자가 될 수 없습니다.** 저자는 연구에 책임을 지는 사람이어야 하기 때문입니다.
- **사용 사실을 밝힙니다.** 원고 작성이나 분석에 생성형 AI를 쓴 경우 방법이나 감사의 글 등 학술지가 정한 위치에 밝힙니다. 맞춤법 교정 수준의 사용은 밝히지 않아도 되는 학술지도 있습니다.
- **책임은 저자에게 있습니다.** AI가 만든 문장, 인용, 수치의 정확성은 저자가 책임집니다.
- **AI 생성 이미지는 제한됩니다.** 연구 결과를 보여 주는 그림을 AI로 생성하거나 바꾸는 것을 금지하는 학술지가 많습니다.
- **심사 원고는 AI에 넣지 않습니다.** 심사위원으로서 받은 미출판 원고는 기밀이므로 생성형 AI에 올리지 않습니다.

# 문헌 탐색

## AI 검색의 한계

생성형 AI에게 "이 주제의 논문 10편을 알려 달라"고 하면 존재하지 않는 논문이 섞여 나오는 경우가 많습니다. 체계적 문헌고찰처럼 재현 가능한 검색이 필요한 연구에서는 학술 데이터베이스에서 검색식으로 직접 검색해야 합니다. AI는 검색어와 검색식을 만드는 데 씁니다.

```prompt 프롬프트 1. 검색식 초안
연구 질문: [예: 지역사회 노인에서 복합 운동이 낙상 발생을 줄이는가]
이 질문을 PICO로 나누고, 요소마다 검색어 후보(통제어와 자유어)를 적어 주세요.
그다음 [PubMed] 검색식 초안을 만들어 주세요. 통제어는 실제 존재하는 용어만 쓰고, 확실하지 않은 용어는 [용어 확인]으로 표시해 주세요.
```

검색식은 데이터베이스에서 실제로 돌려 보고, 핵심 논문이 검색되는지 확인하며 고칩니다. 통제어(MeSH 등)는 데이터베이스의 용어 사전에서 직접 확인합니다.

## 논문 요약과 자료 추출

```prompt 프롬프트 2. 논문 구조 요약
첨부한 논문에서 다음을 추출해 표로 정리해 주세요.
연구 설계, 국가, 대상자 수와 특성, 중재와 비교, 결과 변수와 측정 도구, 주요 결과(수치는 원문 그대로와 위치), 저자가 밝힌 한계.
원문에 없는 항목은 "보고 안 됨"으로 적고 추측하지 마세요.
```

체계적 문헌고찰의 자료 추출에서는 AI 추출 결과를 연구자가 원문과 대조하는 이중 확인 절차를 거칩니다.

# 연구계획서와 심의 서류

## 빠진 항목 점검

연구 유형마다 보고 지침이 있습니다(무작위 대조시험의 CONSORT, 관찰연구의 STROBE, 체계적 문헌고찰의 PRISMA 등). 계획 단계부터 해당 지침의 항목을 반영하면 나중에 원고 작성이 쉬워집니다.

```prompt 프롬프트 3. 보고 지침 대조
아래 연구계획서를 [보고 지침 이름]의 항목과 대조해 주세요.
[계획서]
표 열: 지침 항목, 계획서 반영 여부(반영·일부·누락), 계획서 위치, 보완 제안.
지침 항목 이름은 공식 지침의 표현을 쓰고, 확실하지 않으면 [지침 원문 확인]으로 표시해 주세요.
```

## 연구 대상자 동의서

동의서는 연구 대상자가 이해할 수 있는 말로 써야 합니다. AI는 전문 용어를 쉬운 말로 바꾸는 데 유용합니다.

```prompt 프롬프트 4. 동의서 쉬운 말로
아래 연구 설명문을 중학생도 이해할 수 있는 말로 고쳐 주세요.
[설명문]
조건: 연구 목적, 참여 내용, 예상 위험과 불편, 이익, 자발적 참여와 철회 권리, 개인정보 보호, 문의처가 모두 남아 있어야 합니다. 내용을 빼거나 위험을 줄여 표현하지 마세요.
```

연구계획서, 동의서, 설문지 사이에 대상자 수, 방문 횟수, 수집 항목이 서로 맞는지도 AI로 대조할 수 있습니다. 최종 판단은 기관생명윤리위원회의 기준을 따릅니다.

# 자료 분석

## 분석 코드 작성

AI는 R, Python, SPSS 문법 같은 분석 코드를 잘 씁니다. 다만 다음을 지킵니다.

- **원자료를 올리지 않습니다.** 연구 대상자 자료는 심의 승인 범위를 넘어 외부 서비스에 올리지 않습니다. 변수 이름과 자료 구조, 가짜 예시 몇 행만 줍니다.
- **분석 방법은 연구자가 정합니다.** "어떤 분석을 해야 하나요?"에 대한 AI 답은 참고만 하고, 설계와 자료 특성에 맞는 방법은 연구자가 통계 교재와 방법론 문헌으로 결정합니다.
- **결과를 검증합니다.** 코드를 돌린 결과의 표본 수, 평균, 자유도가 자료와 맞는지 확인합니다.

```prompt 프롬프트 5. 분석 코드
R 코드를 써 주세요.
자료 구조: 파일 data.csv, 변수 id, group(중재·대조), time(사전·사후), score(연속형), age, sex
분석: 집단과 시점의 상호작용을 보는 반복측정 분석, 나이와 성별 보정
조건: 패키지 설치 명령 포함, 결과 표를 CSV로 저장, 각 단계에 짧은 설명. 자료의 가정 확인(정규성 등) 코드도 넣어 주세요.
```

# 원고와 심사 대응

## 원고 다듬기

- **문장 교정과 영문 교정:** AI는 문법과 표현을 다듬는 데 강합니다. 다만 전문 용어를 바꾸거나 주장의 강도를 바꾸지 않았는지 확인합니다.
- **인용 확인:** AI가 원고에 넣은 인용은 모두 원문에서 확인합니다. 인용한 문장의 주장과 수치가 해당 문헌에 실제로 있는지 문장 단위로 대조합니다.
- **표절 점검:** AI가 다른 논문의 문장을 거의 그대로 만들어 낼 수 있으므로 투고 전 유사도 검사를 합니다.

## 심사의견 답변

```prompt 프롬프트 6. 심사의견 정리
아래 심사의견을 항목별로 나누고, 각 의견이 요구하는 것(추가 분석, 설명 보완, 문장 수정, 범위 밖 요구)을 분류해 주세요.
[심사의견]
그다음 답변서 틀(의견 번호, 의견 요약, 답변, 원고 수정 위치)을 만들어 주세요. 답변 내용은 제가 쓰겠습니다.
```

심사의견을 모두 받아들일 필요는 없습니다. 근거가 약한 요구에는 방법론 문헌과 같은 설계의 선행 연구를 근거로 정중하게 반론합니다. 그 판단은 연구자가 합니다.

!!! 연구에 AI를 쓴 뒤 확인합니다
- 연구 대상자 원자료와 심사 중인 원고를 AI에 올리지 않았다
- AI가 제시한 문헌이 실제로 있고 인용 내용이 맞다
- 검색식은 데이터베이스에서 직접 실행해 확인했다
- 분석 방법은 연구자가 결정했고 결과를 검증했다
- 동의서의 필수 항목이 빠지지 않았다
- 투고 학술지의 AI 사용 정책을 확인하고 사용 사실을 밝혔다
- AI로 결과 그림을 만들거나 바꾸지 않았다
