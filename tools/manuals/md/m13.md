# 왜 계획이 무너지나

## 흔한 장면

간호학과 3학년 학생의 한 주를 생각해 봅시다. 월요일부터 수요일까지 병원 실습, 목요일과 금요일에 수업, 주말에 아르바이트가 있습니다. 다음 주에 성인간호학 중간고사가 있지만 실습 일지와 사례 보고서 마감도 겹쳤습니다. 결국 시험 전날 밤에 교재를 처음부터 읽기 시작합니다.

이 학생의 문제는 의지가 아니라 계획 방식입니다. 할 일 목록만 있고 실제로 쓸 수 있는 시간이 계산되지 않았고, 복습 시점이 정해지지 않았고, 계획이 틀어졌을 때 고칠 방법이 없었습니다.

## 몰아서 하기와 나누어 하기

| 구분 | 몰아서 하기 | 나누어 반복하기 |
|---|---|---|
| 방식 | 시험 직전 긴 시간 집중 | 짧은 학습을 간격을 두고 여러 번 |
| 시험 직후 | 비슷하게 기억할 수 있음 | 비슷하거나 조금 더 기억 |
| 몇 주 뒤 | 빠르게 잊음 | 더 오래 남음 |
| 다음 과목 연결 | 기초가 남지 않아 다시 공부 | 쌓인 지식 위에 새 지식 연결 |

학습과학 연구는 같은 시간을 써도 간격을 두고 나누어 공부할 때 더 오래 기억한다는 결과를 반복해서 보여 주었습니다. 이를 분산 학습 또는 간격 효과라고 합니다. 보건계열 지식은 학년이 올라가며 계속 쌓이고 국가시험에서 다시 쓰이므로, 오래 남는 공부가 특히 중요합니다.

# 계획에 필요한 세 가지 정보

## 1. 실제로 쓸 수 있는 시간

계획을 세우기 전에 일주일 동안 고정된 일정을 모두 적고 남는 시간을 셉니다. 이 작업을 시간 점검이라고 합니다.

| 요일 | 고정 일정 | 이동·식사·휴식 | 공부 가능 시간 | 집중도(상, 중, 하) |
|---|---|---|---|---|
| 월 | 실습 8~17시 | 2시간 | 21~22시 30분 | 하 |
| 화 | | | | |
| 수 | | | | |
| 목 | | | | |
| 금 | | | | |
| 토 | | | | |
| 일 | | | | |

집중도를 적는 이유가 있습니다. 실습 후 밤 시간에는 새 단원 공부보다 가벼운 복습이나 퀴즈가 맞고, 주말 오전처럼 집중이 잘 되는 시간에는 어려운 단원을 배치합니다.

## 2. 해야 할 일과 마감

과목별 시험 날짜, 과제 마감, 실습 일지 제출일을 모두 적습니다. 과목마다 범위와 분량(교재 쪽수, 강의 자료 수)도 적습니다.

## 3. 내 상태

과목별로 지금 얼마나 알고 있는지 솔직하게 표시합니다.

| 과목 | 범위 | 지금 이해도(1~5) | 시험일 | 필요한 반복 횟수 |
|---|---|---|---|---|
| | | | | |

이해도가 낮은 과목은 첫 학습에 시간을 더 쓰고, 높은 과목은 복습과 문제 풀이 위주로 배치합니다.

# AI로 계획 세우기

## 주간 계획 만들기

```prompt 분산 학습 주간 계획
저는 [학과, 학년]입니다. 다음 정보를 바탕으로 [기간: 예, 앞으로 3주] 학습 계획을 세워 주세요.

1. 요일별 공부 가능 시간과 집중도:
[시간 점검 표 붙여 넣기]

2. 해야 할 일과 마감:
[과목별 시험일, 범위, 과제 마감]

3. 과목별 현재 이해도:
[이해도 표 붙여 넣기]

계획 원칙
- 한 단원은 처음 공부한 뒤 1일, 3일, 7일 무렵에 짧게 다시 보도록 배치
- 집중도가 높은 시간에는 새 단원, 낮은 시간에는 복습과 퀴즈
- 한 번에 50분 공부 후 10분 휴식 기준
- 하루 공부 가능 시간을 넘기지 말 것
- 일주일에 반나절은 빈 시간으로 남겨 밀린 일을 처리

결과는 날짜별 표(날짜, 시간대, 과목, 할 일, 학습 방식)로 주세요.
```

복습 간격(1일, 3일, 7일)은 하나의 예시입니다. 정답이 정해진 간격은 없으므로 시험일과 내 일정에 맞게 조정합니다. 중요한 것은 한 번 공부한 내용을 간격을 두고 다시 꺼내 보는 것입니다.

## 할 일을 작게 쪼개기

"성인간호학 공부"처럼 큰 할 일은 시작하기 어렵습니다. 50분 안에 끝낼 수 있는 크기로 쪼갭니다.

| 큰 할 일 | 쪼갠 할 일 |
|---|---|
| 성인간호학 심혈관 단원 공부 | 심부전 병태생리 필기 정리 / 심부전 약물 비교표 / 심부전 사례 문제 10개 |
| 사례 보고서 | 사례 선정과 개요 / 문헌 3편 찾기 / 초안 / 수정 |

```prompt 할 일 쪼개기
다음 할 일을 50분 안에 끝낼 수 있는 단위로 쪼개 주세요. 각 단위에 끝났는지 확인할 수 있는 결과물을 적어 주세요.
할 일: [예, 해부학 상지 근육 단원 시험 준비]
범위: [교재 쪽수, 강의 자료]
```

## 캘린더로 옮기기

AI가 만든 표는 구글 캘린더나 휴대폰 캘린더에 옮겨야 실제로 지켜집니다. 공부 시간도 약속처럼 캘린더에 넣고 알림을 설정합니다.

# 계획이 틀어졌을 때

## 계획은 고치라고 있는 것입니다

실습이 늦게 끝나거나, 몸이 아프거나, 과제가 갑자기 생기면 계획은 틀어집니다. 이때 계획 전체를 포기하면 다시 벼락치기로 돌아갑니다. 밀린 부분만 다시 배치하면 됩니다.

```prompt 일정 조정
제 학습 계획표입니다.
[계획표 붙여 넣기]

변경 사항: [예, 수요일 실습이 21시에 끝나 수·목 공부를 못 했습니다. 금요일에 조별 과제 회의가 추가되었습니다.]

1. 밀린 할 일 가운데 시험에 더 중요한 것부터 다시 배치해 주세요.
2. 남은 시간으로 다 할 수 없다면 줄이거나 뺄 것을 제안해 주세요.
3. 복습 간격은 최대한 유지해 주세요.
바뀐 부분만 표시해 주세요.
```

## 줄일 때의 기준

시간이 모자라면 모든 것을 조금씩 하기보다 우선순위를 정합니다.

1. 시험 배점이 크고 아직 이해도가 낮은 단원
2. 이후 단원의 기초가 되는 개념
3. 이미 아는 내용의 반복 읽기는 퀴즈로 대체

# 주간 회고

## 왜 회고가 필요한가

계획을 세우는 것보다 계획을 고쳐 나가는 것이 더 중요합니다. 일주일에 한 번, 15분 정도 지난 주를 돌아보면 나에게 맞는 공부 시간과 방법이 점점 분명해집니다.

## 회고의 세 가지 질문

| 질문 | 예 |
|---|---|
| 유지할 것 | 아침 수업 전 30분 퀴즈는 잘 지켰고 효과가 있었다 |
| 문제였던 것 | 실습 후 밤 계획은 대부분 못 지켰다 |
| 다음 주에 해 볼 것 | 실습 날 밤에는 10분 퀴즈만, 대신 주말 오전 시간을 늘린다 |

이 방식을 유지(Keep), 문제(Problem), 시도(Try)의 앞 글자를 따서 KPT 회고라고도 합니다.

```prompt 주간 회고 도우미
이번 주 학습 계획과 실제로 한 것을 비교해 회고하려고 합니다.
계획: [붙여 넣기]
실제: [실제로 한 것과 못 한 것]
이번 주 퀴즈·시험 결과: [있으면]

유지할 것, 문제였던 것, 다음 주에 해 볼 것으로 나누어 정리해 주세요.
문제의 원인을 의지 탓으로 돌리지 말고 시간 배치, 할 일 크기, 학습 방식에서 찾아 주세요.
다음 주 계획에 반영할 구체적 수정 3가지를 제안해 주세요.
```

# 상황별 계획 예

## 실습 주간

실습이 있는 주는 공부 시간이 크게 줄어듭니다. 이때는 새 단원 진도보다 유지와 연결을 목표로 합니다.

| 시간 | 할 일 |
|---|---|
| 실습 출근 전 15분 | 전날 실습에서 본 질환·술기 키워드 3개 복습 |
| 실습 후 30분 | 실습에서 궁금했던 점을 교재로 확인하고 한 줄 메모 |
| 주말 | 실습 관련 단원을 셀프 테스트로 정리, 다음 주 계획 조정 |

## 시험 2주 전

| 기간 | 할 일 |
|---|---|
| 14~8일 전 | 과목별 전체 범위 한 번 훑기, 약한 단원 표시 |
| 7~3일 전 | 약한 단원 집중, 매일 문제 풀이와 오답 분석 |
| 2~1일 전 | 오답 카드와 요약 노트만, 충분한 수면 |

## 국가시험 6개월 계획의 뼈대

| 시기 | 목표 |
|---|---|
| 6~4개월 전 | 과목별 핵심 개념 정리, 단원별 문제 풀이 |
| 4~2개월 전 | 과목을 섞은 문제 풀이, 오답 원인 분석, 약한 과목 보강 |
| 2~1개월 전 | 실전 시간에 맞춘 모의고사, 오답 노트 반복 |
| 마지막 2주 | 오답 카드와 단권화 노트, 생활 리듬을 시험 시간에 맞추기 |

```prompt 국가시험 장기 계획
저는 [직종] 국가시험을 [시험 시기]에 봅니다. 지금은 [현재 시기]이고 과목별 자신감은 다음과 같습니다.
[과목별 이해도 1~5, 주당 공부 가능 시간]
1. 시기별 목표와 과목별 시간 배분(약한 과목 비중을 높게)
2. 월별 점검 지표(모의고사 점수, 오답 수 등)
3. 실습이나 취업 준비와 겹치는 시기의 조정 방안
을 표로 제안해 주세요. 시험 일정과 과목 구성은 제가 시행 기관 공고로 확인하겠습니다.
```

# 자주 묻는 질문

**계획을 세우는 데만 시간이 너무 걸립니다.**
처음 한 번은 30분 정도 걸리지만, 다음 주부터는 지난 계획을 고치는 데 10분이면 충분합니다. 완벽한 계획보다 고칠 수 있는 계획이 낫습니다.

**AI가 짠 계획이 너무 빡빡합니다.**
시간 점검 표의 공부 가능 시간을 줄여서 다시 넣고, "하루 공부 시간의 80%만 쓰고 나머지는 비워 두세요"라고 조건을 더합니다.

**과목이 많아 하루에 몇 과목을 해야 할지 모르겠습니다.**
하루에 두세 과목을 섞는 것이 한 과목만 오래 하는 것보다 집중과 기억에 유리한 경우가 많습니다. 다만 새 단원을 처음 공부할 때는 한 과목에 충분한 시간을 줍니다.
