# 스포츠의학과 AI

## 스포츠 현장의 데이터와 AI

스포츠 현장에서는 웨어러블 기기, GPS, 심박계, 영상 분석으로 훈련 부하와 움직임을 측정하는 일이 흔해졌습니다. 이런 자료를 해석하고 선수에게 설명하는 능력, 그리고 자동 분석 결과를 비판적으로 보는 능력이 스포츠의학 전문 인력에게 점점 중요해집니다. 생성형 AI는 프로그램 아이디어와 교육 자료, 자료 해석 문장을 만드는 데 도움을 주지만 부상 판단과 복귀 결정은 의료진과 전문가가 해야 합니다.

| 영역 | AI가 돕는 부분 | 전문가가 판단할 부분 |
|---|---|---|
| 컨디셔닝 | 주기화 프로그램 초안, 운동 다양화 | 선수 상태와 일정에 맞는 부하 |
| 부상 예방 | 예방 운동 정리, 교육 자료 | 개인별 위험 요인 평가 |
| 복귀 과정 | 단계별 기준 정리 학습 | 실제 복귀 결정(의료진과 협의) |
| 자료 해석 | 웨어러블 지표 설명, 보고 문장 | 측정 신뢰도, 해석의 타당성 |
| 선수 교육 | 영양, 수면, 회복 교육 자료 | 내용의 정확성 |

## 원칙

- **선수 건강 정보는 넣지 않습니다.** 부상 기록, 의료 정보, 측정 자료는 선수 이름과 함께 AI에 넣지 않습니다.
- **부상 진단과 복귀 결정을 AI에 맡기지 않습니다.**
- **도핑 관련 정보는 공식 자료로 확인합니다.** 금지 약물과 보충제 정보는 세계도핑방지기구와 한국도핑방지위원회의 최신 목록으로 확인합니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 트레이닝 방법론 | 프로그램 작성 | AI 주기화 프로그램의 부하 설정을 원리로 검증 | 프로그램 설계 |
| 스포츠 손상 | 손상 기전 강의 | 종목별 예방 운동 자료 제작과 검증 | 예방 교육 |
| 운동 재활 | 단계 학습 | 복귀 단계 기준을 AI로 정리하고 교재·문헌으로 확인 | 단계적 판단 |
| 스포츠 데이터 분석 | 이론 | 가상 웨어러블 자료 해석, 지표의 한계 토론 | 자료 해석 |
| 동작 분석 | 영상 관찰 | 카메라 기반 분석 도구 결과와 관찰 비교 | 도구 비판 |

# 교수자용 수업 활동

## 활동 1. 주기화 프로그램 검증

```prompt 프롬프트 1. 프로그램 초안
[종목, 수준, 시기, 예: 대학 축구 선수, 시즌 전 8주]를 위한 주기화 컨디셔닝 프로그램 초안을 주차별로 만들어 주세요. 근력, 파워, 스피드, 지구력, 회복을 포함하고 주차별 부하 변화를 설명해 주세요.
```

학생은 트레이닝 원리(점진적 과부하, 특이성, 회복)로 초안을 검토하고, 부하가 갑자기 늘어나는 구간이나 회복이 부족한 구간을 찾아 고칩니다.

## 활동 2. 웨어러블 자료 해석

```prompt 프롬프트 2. 가상 자료 만들기
수업용 가상 팀 자료를 만들어 주세요. 선수 10명(번호로만 표시)의 4주간 주간 훈련 부하, 아침 안정 시 심박, 수면 시간, 주관적 피로도를 표로 만들고, 이 가운데 2명은 부하 급증과 회복 지표 악화가 함께 나타나게 해 주세요. 교수용으로 그 2명을 따로 적어 주세요.
```

학생은 자료를 그래프로 그려 주의가 필요한 선수를 찾고, 지표 하나만으로 판단하면 안 되는 이유와 측정 오차를 함께 토론합니다.

# 학생용 실습 프롬프트

## 선수 교육 자료

```prompt 프롬프트 3. 회복 교육 자료
고등학생 선수를 위한 회복 관리 교육 자료를 A4 한 쪽으로 써 주세요. 수면, 수분, 영양, 훈련 후 정리 운동을 다룹니다.
보충제는 "복용 전 팀 의료진과 도핑 금지 목록 확인"으로만 안내하고 특정 제품을 권하지 마세요.
```

## 부상 예방 운동

```prompt 프롬프트 4. 예방 운동 정리
[부상, 예: 비접촉성 전방십자인대 손상] 예방을 위한 준비운동 프로그램의 구성 요소를 정리해 주세요.
근거가 된 연구나 프로그램 이름을 적되, 제가 원문을 확인할 수 있게 출처를 구체적으로 적고, 확실하지 않으면 [출처 확인 필요]로 표시해 주세요.
```

AI가 적은 연구와 프로그램 이름은 학술 데이터베이스에서 실제로 있는지, 내용이 맞는지 반드시 확인합니다.

# 근거로 검증하기

| 영역 | AI가 자주 틀리는 것 | 대조 자료 |
|---|---|---|
| 부하 설정 | 급격한 부하 증가, 회복 부족 | 트레이닝 방법론 교재 |
| 복귀 기준 | 단계와 기준의 단순화 | 교재, 최신 합의문 |
| 예방 프로그램 | 없는 연구 인용 | 학술 데이터베이스 원문 |
| 도핑 | 금지 약물 목록 | 세계도핑방지기구·한국도핑방지위원회 최신 목록 |
| 지표 해석 | 지표 하나로 단정 | 측정 도구 자료, 교재 |

!!! 스포츠의학 AI 결과물을 쓰기 전에 확인합니다
- 선수 건강 정보를 AI에 넣지 않았다
- 부하와 회복 설정을 트레이닝 원리로 확인했다
- 인용한 연구가 실제로 있고 내용이 맞다
- 도핑 관련 정보를 공식 목록으로 확인했다
- 부상 판단과 복귀 결정을 AI에 맡기지 않았다
