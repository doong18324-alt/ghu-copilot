# 방사선학과 AI

## 의료영상 분야의 두 가지 AI

방사선학 분야에는 성격이 다른 두 종류의 AI가 있습니다.

| 구분 | 영상 분석 AI | 생성형 언어 AI |
|---|---|---|
| 예 | 흉부 X선 이상 소견 검출, CT 영상 분할, 영상 잡음 감소 | ChatGPT, Gemini, Claude |
| 입력 | 영상 자체 | 글, 문서 |
| 규제 | 의료기기로 허가받아 임상에서 쓰는 제품이 있음 | 의료기기가 아님, 진단에 쓰면 안 됨 |
| 학생이 배울 것 | 원리, 성능 지표, 한계, 방사선사의 역할 변화 | 안내문, 학습 자료, 문서 작성 활용과 검증 |

이 매뉴얼은 주로 생성형 언어 AI를 수업과 실습에 쓰는 방법을 다루고, 영상 분석 AI는 학생이 알아야 할 개념 수준에서 정리합니다.

## 방사선사의 일과 AI가 닿는 곳

| 업무 | AI가 돕는 부분 | 방사선사가 판단할 부분 |
|---|---|---|
| 검사 전 환자 안내 | 금식, 조영제, 금속 제거 안내문의 쉬운 표현 | 검사별 실제 준비 사항, 금기 확인 |
| 촬영 술기 학습 | 자세, 중심선, 촬영 조건 정리표 | 실제 환자 상태에 따른 조정 |
| 방사선 안전 관리 | 교육 자료, 점검표 초안 | 법령 기준 수치, 실제 측정 |
| 품질 관리 | 점검 기록 양식, 결과 요약 | 장비 측정과 판정 |
| 영상 분석 AI 운용 | 결과 보고서 문장 정리 | AI 결과의 품질 확인, 판독은 의사 |

## 원칙

- **환자 영상과 개인정보는 넣지 않습니다.** 실습 영상이라도 환자 정보가 담긴 DICOM 파일이나 화면 캡처를 일반 AI 서비스에 올리지 않습니다.
- **생성형 AI로 영상을 판독하지 않습니다.** 영상 판독은 의사의 업무이며, 일반 생성형 AI는 영상 진단용으로 허가받지 않았습니다.
- **방사선 안전 수치는 법령과 교재로 확인합니다.** 선량 한도, 차폐 기준은 AI 답변이 아니라 원자력안전법령과 의료법령, 교재로 확인합니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 방사선영상기술학·실습 | 교재 그림으로 자세 학습 | AI로 부위별 촬영 체크리스트를 만들고 교재와 대조해 수정, 실습에서 사용 | 술기 절차 정리, 검증 |
| 방사선관리학 | 법령 조항 암기 | AI가 만든 안전 교육 자료의 수치 오류를 법령 원문으로 검증 | 법령 근거 확인 |
| 의료영상정보학 | 이론 강의 | 영상 분석 AI의 성능 지표 해석, 사례 토론 | AI 이해, 비판적 평가 |
| 환자 관리와 의사소통 | 역할극 | AI 가상 환자와 검사 전 설명 연습 | 환자 소통 |

# 교수자용 수업 활동

## 활동 1. 검사 전 환자 안내문 만들고 검증하기

```prompt 프롬프트 1. 과제 지시문
역할: 당신은 방사선학과 교수의 수업 설계를 돕는 조교입니다.

학생이 생성형 AI로 [검사, 예: 복부 조영 CT / 유방촬영 / MRI] 검사 전 환자 안내문을 만들고, 교재와 병원 지침 예시로 검증해 고치는 과제 지시문을 써 주세요.

수행 단계: AI 초안 받기 → 금식, 조영제 과민반응 확인, 신기능, 금속·이식 기기, 임신 가능성 항목을 교재로 검증 → 70대 어르신이 읽을 수 있게 고치기 → 동료 평가.
함께 만들 것: 검증표 양식, 20점 루브릭(정확성 10점, 이해 용이성 6점, 안전 항목 누락 없음 4점).
```

## 활동 2. 영상 분석 AI 성능 지표 읽기

영상 분석 AI를 소개하는 자료에는 민감도, 특이도, AUC 같은 지표가 나옵니다. 학생이 이 지표의 뜻과 한계를 알아야 현장에서 AI 결과를 올바르게 다룰 수 있습니다.

| 지표 | 뜻 | 학생이 기억할 점 |
|---|---|---|
| 민감도 | 실제 이상이 있는 영상 가운데 AI가 이상이라고 한 비율 | 높을수록 놓치는 경우가 적음 |
| 특이도 | 실제 정상인 영상 가운데 AI가 정상이라고 한 비율 | 높을수록 거짓 경보가 적음 |
| 양성 예측도 | AI가 이상이라고 한 것 가운데 실제 이상인 비율 | 유병률이 낮은 집단에서는 낮아짐 |
| AUC | 판별 기준을 바꿔 가며 본 전체 판별 능력 | 실제 사용 기준점에서의 성능은 따로 봐야 함 |

```prompt 프롬프트 2. 토론 질문 만들기
흉부 X선 이상 소견 검출 AI가 연구에서 민감도와 특이도가 모두 높게 보고되었다고 가정합니다.
방사선학과 3학년 수업 토론용 질문 5개를 만들어 주세요.
주제: 연구 환경과 실제 병원의 차이, 유병률과 양성 예측도, 영상 품질이 AI 성능에 미치는 영향, 방사선사의 역할, 책임 소재.
질문마다 학생이 생각해 볼 실마리를 한 줄씩 붙여 주세요. 특정 제품명은 쓰지 마세요.
```

## 활동 3. 방사선 안전 교육 자료 검증

```prompt 프롬프트 3. 안전 교육 초안
방사선 관계 종사자 신규 교육용으로 방사선 방어의 3원칙(시간, 거리, 차폐)과 개인 선량계 착용 방법을 설명하는 A4 한 쪽 자료를 써 주세요.
선량 한도 같은 법정 수치는 쓰지 말고 [법령 확인]으로 표시해 주세요.
```

학생은 [법령 확인] 자리를 원자력안전법령과 진단용 방사선 발생장치 관련 규칙의 원문에서 찾아 채우고, 출처 조항을 적습니다. AI가 수치를 쓰게 두지 않는 이유는, 선량 한도와 같은 수치는 개정과 적용 대상(종사자, 수시 출입자, 일반인)에 따라 달라 AI가 틀리기 쉽기 때문입니다.

# 전공 지식으로 검증하기

| 영역 | 확인할 것 | 대조 자료 |
|---|---|---|
| 검사 준비 | 금식 시간, 조영제 관련 확인 항목, 금속·이식 기기 금기 | 교재, 실습 병원 지침 |
| 촬영 술기 | 자세, 중심선, 입사각, 영상 평가 기준 | 방사선영상기술학 교재 |
| 방사선 물리 | 상호작용, 감쇠, 단위 | 방사선물리학 교재 |
| 안전 관리 | 선량 한도, 차폐, 선량계, 표지 | 원자력안전법령, 진단용 방사선 관련 규칙 원문 |
| MRI 안전 | 강자성체, 이식 기기의 조건부 허용 여부 | 교재, 기기별 제조사 안전 정보 |
| 영상 AI | 성능 지표 해석, 허가 여부 | 원 논문, 식품의약품안전처 허가 정보 |

!!! 방사선학 AI 결과물을 쓰기 전에 확인합니다
- 환자 영상, DICOM 파일, 개인정보를 AI에 올리지 않았다
- 생성형 AI로 영상을 판독하거나 진단하지 않았다
- 촬영 조건과 안전 수치를 교재와 법령 원문으로 확인했다
- 검사 준비 안내의 금기와 확인 항목이 빠지지 않았다
- 영상 AI 관련 수치는 원 논문이나 허가 자료에서 확인했다
- 환자가 이해할 수 있는 말로 썼다
