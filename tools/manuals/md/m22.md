# 마스터 코스는 무엇이 다른가

## 공부 방법에서 전공 실력으로

「AI 자기주도학습」 아홉 권이 계획, 질문, 설명, 셀프 테스트처럼 어느 과목에나 쓰는 공부 방법을 다뤘다면, 마스터 코스는 보건계열 전공의 구체적인 과제를 다룹니다. 의학용어와 해부생리학 암기, 교과서 정리, 환자 사례 분석, 실습 술기, 국가시험 오답 관리, 환자와의 대화, 다른 직종과의 협업, 의료 AI 윤리, 보건의료 데이터 분석까지 졸업 전에 갖춰야 할 역량을 순서대로 묶었습니다.

각 권은 설명만 읽고 끝나는 책이 아니라 워크북입니다. 권마다 직접 만들어 남기는 결과물이 있고, 이 결과물을 모으면 학습 포트폴리오가 됩니다. 포트폴리오는 국가시험 직전 복습 자료가 되고, 취업 면접에서 내가 어떻게 공부하고 성장했는지 보여 주는 근거가 됩니다.

## 이 코스가 지키는 원칙

1. **내가 먼저 하고 AI가 점검합니다.** 사례 분석, 체크리스트, 오답 원인은 내가 먼저 쓰고 AI에게 빈틈을 찾게 합니다.
2. **실제 환자 정보는 쓰지 않습니다.** 모든 사례는 가상 사례로 만듭니다.
3. **임상 기준은 교재와 기관 지침이 우선입니다.** AI가 제시한 절차나 수치는 반드시 확인합니다.
4. **결과물을 남깁니다.** 권마다 정해진 결과물을 포트폴리오에 모읍니다.

# 4단계 구성

## 한눈에 보기

| 단계 | 권 | 해결하는 문제 | 남기는 결과물 |
|---|---|---|---|
| 1단계: 기초 다지기 | 보건의학용어·해부생리학 암기 워크북 | 낯선 용어와 계통별 구조가 머리에 남지 않음 | 계통별 용어 카드, 비유 노트 |
| | NotebookLM 교과서 마스터 | 두꺼운 교과서에서 길을 잃음 | 단원별 자료 기반 노트, 출처 표시 요약 |
| 2단계: 임상·국시 실전 | 가상 사례분석 | 지식을 환자 상황에 적용하지 못함 | 사례분석 보고서 |
| | 실습 술기 체크리스트 툴킷 | 실습에서 순서와 근거를 놓침 | 술기별 체크리스트와 근거 메모 |
| | 국가시험 오답노트와 유사 문항 | 같은 유형을 반복해서 틀림 | 오답 원인 분석표, 유사 문항 묶음 |
| 3단계: 소통·협업 | 의사소통·공감 대화 시뮬레이터 | 환자와 보호자 앞에서 말문이 막힘 | 상황별 대화 연습 기록 |
| | 다학제 팀기반학습 포트폴리오 | 다른 직종의 역할과 협업 방법을 모름 | 팀 사례 회의 기록과 성찰문 |
| 4단계: 윤리·미래 | 생성형 AI 윤리와 데이터 보호 지침 | AI를 쓰다 개인정보와 윤리 문제를 일으킬 위험 | 상황별 판단 연습지, 개인 서약 |
| | 디지털 헬스케어 리터러시 | 데이터와 AI 도구를 업무에 쓰는 기초가 부족함 | 공개 데이터 분석 보고서 |

## 단계 사이의 연결

1단계에서 정리한 용어 카드와 교과서 노트는 2단계 사례분석과 오답 분석의 기초 자료가 됩니다. 2단계에서 만든 사례는 3단계 대화 연습과 팀 회의의 소재로 다시 씁니다. 4단계의 윤리와 데이터 역량은 앞 단계 전체에서 지켜야 할 기준을 정리하고, 졸업 후 실무로 이어 줍니다.

# 단계별 안내

## 1단계: 기초 다지기

보건계열 공부의 첫 장벽은 낯선 용어와 두꺼운 교과서입니다. 1단계는 이 장벽을 낮춥니다.

- **용어·해부생리학 워크북:** 계통별로 구조와 기능을 일상 비유로 이해하고, 용어를 쪼개 외우고, AI 퀴즈로 확인합니다.
- **NotebookLM 교과서 마스터:** 내가 가진 강의 자료와 필기를 올려 자료 안에서만 답하는 학습 도우미를 만들고, 출처 위치를 확인하며 공부합니다.

1단계를 마치면 계통별 핵심 용어 카드와 과목별 자료 기반 노트가 생깁니다.

## 2단계: 임상·국시 실전

지식을 머리에 담는 것과 환자 앞에서 판단하고 시험에서 정답을 고르는 것은 다른 능력입니다. 2단계는 이 둘을 잇습니다.

- **가상 사례분석:** 가상 환자의 자료에서 문제를 찾고, 우선순위를 정하고, 근거를 붙이는 연습을 합니다.
- **실습 술기 체크리스트:** 실습 기관과 교재의 절차를 바탕으로 단계별 체크리스트를 만들고, 단계마다 왜 그렇게 하는지 근거를 붙입니다.
- **국가시험 오답노트:** 틀린 문제의 원인을 분석하고, 같은 개념을 다른 상황에서 묻는 유사 문항으로 확인합니다.

## 3단계: 소통·협업

환자 안전과 치료 결과는 의사소통과 팀워크에 크게 좌우됩니다. 3단계는 이 역량을 연습합니다.

- **의사소통 시뮬레이터:** AI를 가상 환자나 보호자로 세워 정보 제공, 불안한 환자 응대, 어려운 소식 전하기 같은 상황을 연습합니다.
- **다학제 팀기반학습:** 여러 직종이 함께하는 가상 사례 회의를 통해 각 직종의 역할과 협업 방법을 배우고 기록합니다.

## 4단계: 윤리와 미래 확장

AI를 능숙하게 쓰는 보건의료인일수록 윤리와 개인정보 보호 기준이 분명해야 합니다.

- **AI 윤리와 데이터 보호:** 정보의 등급, 입력하면 안 되는 정보, 사고가 났을 때의 대응을 상황별로 연습합니다.
- **디지털 헬스케어 리터러시:** 공개 보건 데이터로 기초 분석을 하고, 디지털 헬스케어 도구의 근거와 한계를 평가합니다.

# 지도교수와 함께 쓰기

## 상담에 활용하기

학생은 학기 초 상담 때 이번 학기에 할 권과 결과물을 정하고, 학기 말 상담 때 포트폴리오를 보여 주며 돌아봅니다. 지도교수는 결과물보다 과정을 봅니다. 학생이 어떤 질문을 했고, 무엇을 틀렸고, 어떻게 고쳤는지를 함께 확인하면 다음 학기 지도 방향이 분명해집니다.

## 수업에 활용하기

전공 수업에서 특정 권의 활동을 과제로 쓸 수 있습니다. 예를 들어 성인간호학 수업에서 가상 사례분석을, 물리치료 실습 과목에서 술기 체크리스트를 과제로 낼 수 있습니다. 이때 AI 사용 범위와 사실 확인 방법을 과제 안내에 분명히 적습니다.

!!! 로드맵을 읽은 뒤 확인합니다

- 실제 환자 정보를 쓰지 않는 원칙을 안다
