# 2주차에 익힐 것

## 이번 주 목표

- 목적에 맞는 구조로 긴 자료를 요약할 수 있다.
- 자료를 직접 주고 그 안에서만 답하게 할 수 있다.
- 두 자료의 같은 점과 다른 점을 표로 비교할 수 있다.
- 요약 결과가 원문과 맞는지 확인할 수 있다.

## 세 줄 요약이 위험한 이유

"세 줄로 요약해 줘"는 편리하지만 전공 공부에는 맞지 않을 때가 많습니다. 세 줄 안에 들어가지 못한 조건, 예외, 한계가 빠지기 때문입니다. 예를 들어 어떤 운동이 노인의 보행 속도를 높였다는 연구를 세 줄로 줄이면 "대상자가 지역사회에 사는 건강한 노인이었다", "12주 동안만 관찰했다" 같은 조건이 사라집니다. 이 조건이 빠진 요약을 근거로 "모든 노인에게 효과가 있다"고 쓰면 틀린 과제가 됩니다.

구조화 요약은 정해진 틀에 맞춰 내용을 나누어 담는 요약입니다. 틀이 있으면 빠진 항목이 바로 보입니다.

# 구조화 요약의 네 가지 원칙

## 원칙 1. 목적을 먼저 정합니다

| 목적 | 뽑을 내용 |
|---|---|
| 시험 대비 | 정의, 분류, 기준, 비교, 순서 |
| 과제 근거 찾기 | 주장, 근거, 근거의 수준, 한계 |
| 실습 준비 | 절차, 주의사항, 관찰 항목, 위험 신호 |
| 발표 | 청중이 기억할 메시지와 뒷받침 자료 |

## 원칙 2. 자료를 주고 그 안에서만 답하게 합니다

AI가 기억으로 요약하면 실제 자료와 다른 내용이 섞입니다. 요약할 자료를 직접 붙여 넣거나 파일로 올리고, "자료에 없는 내용은 추가하지 말라"고 씁니다. NotebookLM처럼 올린 자료 안에서만 답하고 출처 위치를 표시하는 도구를 쓰면 확인이 쉽습니다.

## 원칙 3. 숫자와 조건은 따로 뽑습니다

수치, 기간, 대상, 단위는 요약 과정에서 가장 잘 틀리거나 빠집니다. 요약과 별도로 "자료에 나온 수치와 조건만 표로 뽑아 달라"고 요청하고 원문과 하나씩 대조합니다.

## 원칙 4. 모르는 것과 확인할 것을 표시하게 합니다

요약 끝에 "자료만으로는 알 수 없어 확인이 필요한 점"을 적게 하면, AI가 빈칸을 추측으로 채우는 것을 줄일 수 있고 내가 더 찾아볼 거리도 생깁니다.

```prompt 구조화 요약
아래는 [자료 종류: 예, 강의 자료, 논문, 진료지침 요약]입니다. 목적은 [목적]입니다.
[자료 붙여 넣기 또는 파일 첨부]

다음 틀로 정리해 주세요. 자료에 없는 내용은 추가하지 마세요.
1. 핵심 주장 또는 주제(한 문장)
2. 주요 내용(소제목별 2~3줄)
3. 수치와 조건(표: 항목, 값, 단위, 자료 속 위치)
4. 한계나 예외
5. 자료만으로 알 수 없어 확인이 필요한 점
```

# 자료 종류별 정리 틀

## 논문

| 항목 | 정리할 내용 |
|---|---|
| 연구 질문 | 무엇을 알고 싶었나 |
| 설계 | 무작위대조시험, 코호트, 단면조사, 질적연구, 체계적 문헌고찰 등 |
| 대상과 장소 | 누구를, 어디서, 몇 명 |
| 중재·노출과 비교 | 무엇을 했고 무엇과 비교했나 |
| 측정 | 무엇을 어떤 도구로 쟀나 |
| 주요 결과 | 핵심 수치(원문 그대로) |
| 결론과 한계 | 저자의 결론, 저자가 밝힌 한계 |
| 내 평가 | 내 과제에 쓸 수 있는 부분과 조심할 부분 |

설계는 근거의 강도를 판단하는 데 중요합니다. 같은 주제라도 여러 무작위대조시험을 모은 체계적 문헌고찰과 한 병원의 사례 보고는 무게가 다릅니다. 과제에 근거를 쓸 때는 어떤 설계의 연구인지 함께 밝힙니다.

## 진료지침과 실무 지침

| 항목 | 정리할 내용 |
|---|---|
| 발행 기관과 연도 | 누가, 언제 |
| 대상 | 어떤 환자, 어떤 상황 |
| 권고 | 권고 문장과 권고 등급 |
| 근거 수준 | 지침이 밝힌 근거 수준 |
| 바뀐 점 | 이전 판과 달라진 부분 |

지침은 개정되므로 발행 연도를 꼭 확인합니다. AI는 개정 전 내용을 말할 수 있습니다.

## 교재 장(章)

교재 한 장은 개념 지도 형태로 정리하면 전체 구조가 보입니다. 큰 개념 아래 하위 개념을 두고, 개념 사이의 관계(원인, 결과, 포함, 대비)를 화살표 설명으로 적습니다.

```prompt 교재 장 개념 지도
아래는 [과목] 교재 [장] 내용을 제가 정리한 필기입니다.
[필기 붙여 넣기]

1. 가장 큰 개념 1개와 하위 개념 4~6개를 계층 목록으로 만들어 주세요.
2. 하위 개념 사이의 관계를 "A는 B의 원인", "A와 B는 대비" 형식으로 5개 적어 주세요.
3. 필기에서 빠진 것 같은 연결 고리가 있으면 질문으로 알려 주세요.
```

# 두 자료 비교하기

## 비교표 만들기

두 교재, 두 지침, 두 이론을 비교할 때는 비교 기준을 먼저 정하고 표를 만듭니다. 기준이 없으면 AI가 임의로 항목을 골라 중요한 차이가 빠질 수 있습니다.

```prompt 두 자료 비교
아래 두 자료를 비교해 주세요.
자료 A: [붙여 넣기 또는 첨부]
자료 B: [붙여 넣기 또는 첨부]

비교 기준: [예, 대상, 정의, 진단 또는 판정 기준, 권고 내용, 근거 수준, 발행 연도]
1. 기준별 비교표(각 칸에 자료 속 근거 문장 위치 표시)
2. 두 자료가 같은 점 3개
3. 다른 점과 그 이유로 짐작되는 것(발행 시기, 대상 차이 등)
판단이 어려우면 "자료만으로는 판단 불가"라고 적어 주세요.
```

## 어느 쪽이 맞는지는 내가 판단합니다

두 자료가 다를 때 AI에게 "어느 쪽이 맞냐"고 묻는 것만으로는 부족합니다. 다음 순서로 판단합니다.

1. 발행 기관과 연도가 더 공식적이고 최신인 쪽을 확인합니다.
2. 대상과 상황이 서로 다른지 봅니다(성인과 소아, 입원과 지역사회).
3. 수업 교재와 담당 교수의 기준을 확인합니다.
4. 그래도 다르면 과제에 두 관점을 함께 쓰고 차이의 이유를 밝힙니다.

# 계열별 잘못된 예와 고친 예

## 보건계열

| 구분 | 프롬프트 |
|---|---|
| 잘못된 예 | 이 논문 요약해 줘 |
| 문제 | 대상과 조건이 빠지고, 수치가 바뀌어 나올 수 있음 |
| 고친 예 | 첨부한 논문을 "논문 정리 틀" 8개 항목으로 정리해 주세요. 수치는 원문 표현 그대로, 원문 위치(쪽, 표 번호)와 함께 적어 주세요. 제 과제 주제는 [주제]이고, 이 논문을 근거로 쓸 때 조심할 점을 마지막에 적어 주세요. |

## 사회복지계열

| 구분 | 프롬프트 |
|---|---|
| 잘못된 예 | 이 정책 보고서 핵심만 |
| 문제 | 정책 대상, 예산, 전달 체계 같은 중요한 항목이 빠짐 |
| 고친 예 | 첨부한 정책 보고서를 정책 목표, 대상, 서비스 내용, 전달 체계, 재원, 성과 지표, 한계로 나누어 표로 정리해 주세요. 보고서에 없는 항목은 "없음"으로 적어 주세요. |

## 사회실무계열

| 구분 | 프롬프트 |
|---|---|
| 잘못된 예 | 이 기사 두 개 비교해 줘 |
| 문제 | 비교 기준이 없어 인상 비교에 그침 |
| 고친 예 | 첨부한 두 기사를 주장, 근거 자료, 인용한 출처, 빠진 관점 기준으로 비교표를 만들어 주세요. 사실과 의견을 구분해 표시해 주세요. |

# 2주차 자주 묻는 질문

**파일 업로드가 안 되는 무료 버전에서는 어떻게 하나요?**
필요한 부분을 나누어 붙여 넣습니다. 긴 자료는 장별로 나누어 요약하고 마지막에 장별 요약을 합쳐 다시 정리하게 합니다.

**영어 논문 전체를 번역해 달라고 해도 되나요?**
가능하지만 시간이 오래 걸리고 번역 오류가 생길 수 있습니다. 구조 정리를 먼저 하고, 필요한 부분만 번역해 원문과 비교하는 것이 효율적입니다.
