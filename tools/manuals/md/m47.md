# 보건행정과 AI

## 보건행정 직무와 AI가 닿는 곳

보건행정 인력은 의료기관의 원무, 보험 청구와 심사, 의무기록, 경영 기획, 고객 응대를 맡습니다. 이 분야는 문서, 규정, 숫자를 다루는 일이 많아 생성형 AI를 활용할 여지가 큽니다. 동시에 환자 개인정보와 건강정보를 가장 많이 다루는 직무이기도 해서 보안 기준을 가장 엄격하게 지켜야 합니다.

| 직무 | AI가 돕는 부분 | 담당자가 판단할 부분 |
|---|---|---|
| 원무·접수 | 응대 매뉴얼, 안내 문구, 외국인 환자 안내 번역 초안 | 실제 환자 상황 판단, 수납 정확성 |
| 보험 청구·심사 | 기준 문서 요약, 개념 학습 | 실제 청구 코드와 기준 적용 |
| 의무기록 | 질병분류 학습, 서식 이해 | 실제 코딩, 기록 열람 권한 |
| 고객 만족 | 설문 설계, 주관식 응답 분류, 개선안 초안 | 원인 판단, 개선 우선순위 |
| 경영 기획 | 보고서 초안, 지표 정리 | 수치의 정확성, 의사결정 |
| 정책 분석 | 정책 자료 요약, 비교표 | 원문 확인, 해석 |

## 원칙

- **환자 정보는 어떤 형태로도 넣지 않습니다.** 이름, 등록번호, 진료 내역, 청구 내역은 일반 AI 서비스에 입력하지 않습니다. 의료기관의 진료 정보는 의료법과 개인정보 보호법이 특히 엄격하게 보호합니다.
- **보험 기준은 원문으로 확인합니다.** 요양급여 기준과 수가는 자주 개정되므로 AI 답변이 아니라 건강보험심사평가원 등 공식 자료로 확인합니다.
- **질병분류 코드는 공식 분류표로 확인합니다.** AI가 제시한 질병분류 코드는 틀리는 경우가 많습니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 병원 원무관리 | 응대 사례 강의 | AI로 상황별 응대 매뉴얼을 만들고 역할극으로 검증 | 고객 응대, 매뉴얼 작성 |
| 의료보험·청구 실무 | 기준 암기 | AI 요약과 원문 기준을 대조하며 학습 | 기준 해석, 원문 확인 습관 |
| 질병분류 | 코딩 연습 | AI가 제시한 코드의 오류를 분류표로 찾기 | 정확한 코딩 |
| 병원 경영·마케팅 | 사례 분석 | 만족도 설문 설계, AI로 응답 분류, 개선안 발표 | 자료 기반 의사결정 |
| 보건의료 정책 | 정책 강의 | AI로 정책 자료를 요약하고 원문과 대조해 토론 | 정책 해석 |

# 교수자용 수업 활동

## 활동 1. 원무 창구 응대 매뉴얼 만들기

```prompt 프롬프트 1. 응대 매뉴얼 과제
보건행정학과 2학년 학생이 생성형 AI로 병원 원무 창구 응대 매뉴얼을 만드는 과제 지시문을 써 주세요.

상황 목록 예: 대기 시간 항의, 진료비 문의, 서류 발급 요청(본인·대리인), 외국인 환자 접수, 보호자의 진료 정보 문의.
수행 단계: AI로 상황별 응대 문안 초안 → 관련 법령과 병원 규정 예시로 검증(특히 대리인 서류 발급과 진료 정보 제공 범위) → 역할극 시연 → 매뉴얼 완성.
함께 만들 것: 검증 체크리스트, 20점 루브릭.
```

대리인의 진료기록 사본 발급, 보호자에게 진료 정보를 알려 주는 범위는 의료법에 기준이 있습니다. 학생이 AI 답변이 아니라 법령 원문으로 확인하도록 지도합니다.

## 활동 2. 만족도 조사 설계와 분석

```prompt 프롬프트 2. 만족도 설문 설계
의료기관 외래 환자 만족도 설문을 설계해 주세요.
영역: 접근성과 대기, 직원 친절, 설명과 소통, 시설과 환경, 전반적 만족과 재이용 의향.
영역마다 5점 척도 문항 3개, 마지막에 주관식 2개.
문항마다 측정하려는 것을 한 줄로 적고, 이중 질문(한 문항에 두 가지를 묻는 것)이 없게 해 주세요.
```

수집한 응답(가상 자료 또는 개인정보 없는 수업용 자료)은 엑셀로 집계하고, 주관식은 AI로 분류한 뒤 학생이 직접 검증합니다. 주관식 분류 방법은 「행정 통계 요약 및 엑셀 수식·매크로 자동 생성 가이드」를 참고합니다.

## 활동 3. 질병분류 오류 찾기

```prompt 프롬프트 3. 코딩 연습 자료
질병분류 수업용 가상 진단 기록 문장 10개를 만들어 주세요. 주진단과 부진단이 있는 문장, 원인과 결과가 함께 적힌 문장을 섞어 주세요.
각 문장에 대해 당신이 생각하는 분류 코드도 적어 주세요.
```

학생은 AI가 적은 코드를 한국표준질병·사인분류 공식 분류표와 지침서로 확인해 맞는지, 틀리다면 왜 틀렸는지 적습니다. 이 활동은 AI 코드를 믿지 않고 원문을 확인하는 습관을 기르는 것이 목적입니다.

```prompt 프롬프트 4. 진료 안내문
조건: 70대 어르신도 읽기 쉬운 말, 항목은 5개 이내, 병원마다 다를 수 있는 부분은 [병원 기준 확인]으로 표시.
같은 내용을 문자 메시지용(90자 안팎)으로도 써 주세요.
```

## 정책 자료 요약

```prompt 프롬프트 5. 정책 자료 비교
첨부한 [정책 보도자료 또는 보고서] 를 요약해 주세요.
1. 핵심 내용 5줄
2. 변경 전후 비교표
3. 의료기관 행정 부서에 미치는 영향 3가지
첨부 자료에 없는 내용은 추가하지 말고, 해석이 들어간 문장에는 [해석]이라고 표시해 주세요.
```

```prompt 프롬프트 6. 원무 직무 면접

```

# 전공 지식으로 검증하기

| 영역 | 확인할 것 | 대조 자료 |
|---|---|---|
| 진료 정보 제공 | 본인, 대리인, 보호자별 제공 범위와 필요 서류 | 의료법, 기관 규정 |
| 개인정보 | 수집·이용 동의, 보관 기간 | 개인정보 보호법, 기관 지침 |
| 보험 기준 | 급여 기준, 본인부담 기준 | 건강보험 관련 고시 원문 |
| 질병분류 | 코드와 분류 규칙 | 한국표준질병·사인분류 공식 자료 |
| 통계 | 출처, 연도, 정의 | 국가 통계 원자료 |
| 경영 지표 | 계산식과 정의 | 교재, 기관 지표 정의서 |

!!! 보건행정 AI 결과물을 쓰기 전에 확인합니다
- 환자 정보와 청구 내역을 AI에 넣지 않았다
- 법령과 보험 기준을 원문에서 확인했다
- 질병분류 코드를 공식 분류표로 확인했다
- 통계 수치에 출처와 연도를 적었다
- 응대 문안이 법령상 정보 제공 범위를 넘지 않는다
- 환자용 안내문을 쉬운 말로 썼다
