# 수업설계서 작성 안내

## 이 템플릿의 쓰임

X × AI 전공융합 수업은 전공 지식(X)과 AI 활용을 하나의 수업 안에서 엮는 수업입니다. 수업설계서는 그 수업이 왜 AI를 쓰는지, 어디에 어떻게 쓰는지, 무엇으로 평가하는지를 한 문서에 담습니다. 잘 쓴 설계서는 다음 세 가지에 쓰입니다.

- 학기 전 수업 준비와 조교·공동 강의자와의 공유
- 학기 말 CQI 보고서와 우수사례 제출의 기초 자료
- 학과 교육과정 평가와 인증 자료

## 항목별 작성 요령

| 항목 | 작성 요령 | 흔한 실수 |
|---|---|---|
| 기존 수업의 한계 | 학생이 실제로 어려워한 장면을 구체적으로 | "학생 참여가 저조함"처럼 막연하게 |
| AI 도입 목적 | 한계를 어떻게 해결하는지 연결해서 | AI를 쓰는 것 자체를 목적으로 |
| 학습목표 | 전공 지식, AI 활용, 검증과 윤리를 행동 동사로 | "AI를 이해한다"처럼 관찰 불가 |
| AI 활용 허용 범위 | 정책 유형과 단계별 허용 범위 | 유형만 고르고 구체적 범위 누락 |
| 주차별 설계 | 적용 주차마다 교수·학생 활동, 검증 기준, 보안 유의사항 | 검증 기준과 보안 칸을 비워 둠 |
| 평가 | 과정과 결과의 배점, 루브릭 | 결과물만 평가 |
| 환류 | 산출물, 공유 방법, 다음 학기 개선 | 형식적인 문장 |

## AI로 초안 만들기

```prompt 설계서 초안 만들기
아래 정보로 X × AI 전공융합 수업설계서 초안을 써 주세요.
- 학과, 교과목, 학년·학기, 학점·시수: [ ]
- 기존 수업에서 학생이 어려워한 점: [구체적으로]
- AI를 적용할 주차와 주제: [예: 6주차 대상자 맞춤 교육자료, 11주차 임상 사례 분석]
- 주로 쓸 AI 도구: [ ]

작성할 것: AI 도입 목적, 학습목표 3개(전공 지식, AI 활용, 검증·윤리), 적용 주차별 교수·학생 활동, 검증 기준, 보안 유의사항, 과정 중심 평가 배점.
지킬 것: 제가 주지 않은 교재명이나 지침명은 [확인 필요]로 둡니다.
```

# 작성 예시

아래는 작성 방법을 보여 주기 위한 예시입니다.

| 항목 | 예시 |
|---|---|
| 교과목 | 치위생학과 2학년 구강보건교육학 및 실습 |
| 기존 수업의 한계 | 학생 1인이 다룰 수 있는 대상자 사례가 2~3개에 그쳐, 전신질환자나 장애인처럼 조건이 다른 대상자에게 교육 내용을 맞추는 연습이 부족함 |
| AI 도입 목적 | 생성형 AI로 대상자 조건별 교육 시나리오 초안을 빠르게 만들어 연습량을 늘리고, 학생이 교재 기준으로 오류를 찾아 고치게 하여 근거 확인 습관을 기름 |
| 학습목표 3 | AI가 만든 구강보건교육 자료의 내용을 예방치학 교재와 대조해 오류를 찾고 근거를 들어 수정할 수 있다 |
| 6주차 활동 | (학생) 배정받은 대상자 조건으로 AI 교육 시나리오 초안 받기 → (학생) 검증표 작성 → (교수) 대표 오류 사례로 전체 피드백 |
| 6주차 검증 기준 | 칫솔질법과 위생용품의 대상자 적합성, 불소 이용 기준, 전신질환 주의사항을 교재 해당 장과 대조 |
| 6주차 보안 | 실제 환자 정보 입력 금지, 가상 조건만 사용 |
| 평가 배점 | 질문 설계 20%, 전공 검증 50%, 최종 결과물 30% |

!!! 설계서를 확정하기 전에 확인합니다
- 기존 수업의 한계와 AI 도입 목적이 이어진다
- 학습목표에 검증과 윤리 목표가 들어 있다
- 적용 주차마다 검증 기준과 보안 유의사항이 채워졌다
- 평가에 과정 평가가 들어 있다
- 1주차에 AI 윤리·보안 안내와 서약서 제출이 있다
- 교재명과 지침명을 실제 자료로 확인했다
