# 안경광학과 AI

## 안경사의 일과 AI가 닿는 곳

안경사는 시력 보정을 위한 굴절검사, 안경 조제와 가공, 콘택트렌즈 판매와 관리 교육을 맡습니다. 정확한 측정과 계산, 고객의 생활 방식에 맞춘 렌즈 상담이 핵심입니다. 생성형 AI는 계산 원리 학습, 상담 연습, 교육 자료 작성에 도움을 줄 수 있지만 계산 자체는 틀리는 경우가 있어 반드시 직접 확인해야 합니다.

| 영역 | AI가 돕는 부분 | 안경사가 판단할 부분 |
|---|---|---|
| 안광학 학습 | 공식의 의미 설명, 풀이 과정 예시 | 계산 결과 검산 |
| 굴절검사 학습 | 검사 순서 정리, 흔한 오류 | 실제 측정 |
| 렌즈 상담 | 생활 방식별 렌즈 특징 설명 연습 | 고객 처방과 상태에 맞는 선택 |
| 콘택트렌즈 교육 | 착용·관리 안내문 | 제품별 사용 기준 확인 |
| 고객 응대 | 불만 응대 연습 | 실제 상황 판단 |

## 원칙

- **계산은 직접 검산합니다.** AI는 디옵터 계산, 정점간거리 보정, 프리즘 계산에서 부호나 단위를 틀리는 경우가 있습니다.
- **업무 범위를 확인합니다.** 안경사의 업무 범위와 처방이 필요한 경우는 의료기사 등에 관한 법령에 정해져 있습니다.
- **눈 질환 판단은 하지 않습니다.** AI가 증상으로 눈 질환을 추정하더라도, 안과 진료가 필요한 신호가 보이면 의뢰하는 것이 원칙입니다.

# 수업 설계

| 교과목 | 기존 방식 | AI 융합 방식 | 기르는 역량 |
|---|---|---|---|
| 기하광학·안광학 | 공식 풀이 | AI 풀이 과정의 오류 찾기, 직접 검산 | 계산 정확성 |
| 굴절검사 | 실습 | 검사 단계별 흔한 오류를 AI로 정리하고 실습에서 확인 | 측정 정확성 |
| 안경렌즈학 | 렌즈 종류 암기 | 생활 방식별 상담 역할극 | 상담 능력 |
| 콘택트렌즈학 | 관리법 강의 | 대상별 관리 교육 자료 제작과 검증 | 교육 자료 작성 |
| 안경원 경영 | 사례 강의 | 고객 불만 응대 역할극, 응대 매뉴얼 작성 | 고객 응대 |

# 교수자용 수업 활동

## 활동 1. AI 풀이의 오류 찾기

```prompt 프롬프트 1. 풀이 과정 받기
다음 안광학 문제를 단계별로 풀어 주세요.
[교수자가 만든 계산 문제, 예: 정점간거리가 달라질 때 필요한 유효 굴절력 계산]
단계마다 쓴 공식과 단위, 부호 규칙을 밝혀 주세요.
```

학생은 AI 풀이를 한 줄씩 따라가며 공식, 부호, 단위, 계산을 확인합니다. 교수자는 미리 정답과 AI 풀이의 오류 여부를 확인해 둡니다. AI가 맞게 풀었다면 조건을 바꾼 문제로 다시 시도합니다.

## 활동 2. 상담 역할극

```prompt 프롬프트 2. 고객 역할극
당신은 안경원을 찾은 가상의 50대 고객입니다. 최근 가까운 글씨가 잘 안 보이고, 운전과 컴퓨터 작업을 많이 합니다. 누진렌즈가 어지럽다는 말을 들어 걱정합니다. 저는 안경광학과 학생입니다.
제가 상담하면 실제 고객처럼 질문하고 걱정을 말해 주세요. "상담 끝"이라고 하면 역할을 멈추고, 제가 확인하지 않은 생활 정보와 설명이 부족했던 부분을 알려 주세요.
```

# 학생용 실습 프롬프트

## 공식 이해

```prompt 프롬프트 3. 공식 설명
[공식 이름, 예: 프렌티스 법칙]이 무엇을 계산하는지, 각 기호의 뜻과 단위, 실제 안경 조제에서 어떤 상황에 쓰는지 설명해 주세요.
예제 1개를 만들어 제가 먼저 풀게 하고, 제가 답을 말하면 풀이를 보여 주세요.
```

## 콘택트렌즈 교육 자료

```prompt 프롬프트 4. 관리 교육 안내문
콘택트렌즈를 처음 쓰는 대학생을 위한 관리 안내문을 써 주세요.
포함: 착용 전 손 씻기, 세척과 보관, 착용 시간, 하면 안 되는 행동(수돗물 세척, 착용한 채 수면 등), 바로 안과에 가야 하는 증상.
렌즈 종류마다 다른 기준(교체 주기, 착용 시간)은 [제품 설명서 확인]으로 표시해 주세요.
```

# 전공 지식으로 검증하기

| 영역 | AI가 자주 틀리는 것 | 대조 자료 |
|---|---|---|
| 안광학 계산 | 부호 규칙, 단위(미터와 밀리미터), 정점간거리 보정 | 안광학 교재, 직접 검산 |
| 굴절검사 | 검사 순서, 조절 통제 | 굴절검사 교재 |
| 렌즈 | 렌즈 재질과 설계의 특성 | 안경렌즈학 교재, 제조사 자료 |
| 콘택트렌즈 | 착용 시간, 교체 주기 | 교재, 제품 설명서 |
| 업무 범위 | 처방이 필요한 경우 | 의료기사 등에 관한 법령 원문 |
| 의뢰 신호 | 안과 진료가 필요한 증상 | 교재 |
