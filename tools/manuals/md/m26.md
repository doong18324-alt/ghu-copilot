# 이 툴킷 쓰는 법

## 술기는 순서와 근거를 함께 외웁니다

실습에서 가장 흔한 실수는 단계를 빠뜨리거나 순서를 바꾸는 것입니다. 손 위생을 잊고, 환자 확인을 한 번만 하고, 무균 영역을 무심코 넘어갑니다. 대개 단계만 외우고 왜 그 단계가 필요한지 모를 때 생깁니다. 근거를 알면 단계가 자연스럽게 이어지고, 예상하지 못한 상황에서도 원칙에 맞게 판단할 수 있습니다.

이 툴킷은 술기마다 다음 여섯 가지를 정리하도록 구성했습니다.

| 구성 | 내용 |
|---|---|
| 1. 개요와 준비물 | 목적, 대상, 금기, 준비물 |
| 2. 단계별 체크리스트 | 시작 전, 수행, 마무리 단계와 각 단계의 근거 |
| 3. 돌발 상황 | 흔한 문제와 대응, 보고 기준 |
| 4. AI 가상 OSCE | AI 평가관 앞에서 단계를 말로 수행 |
| 5. "왜" 문답 | 단계의 근거를 묻고 답하기 |
| 6. 자가점검 | 흔한 오염·오류와 내 수행 기록 |

## 가장 먼저 지킬 원칙

- **기준은 교재와 실습 기관 지침입니다.** 이 툴킷의 체크리스트 골격은 공통 원칙만 담았습니다. 물품, 순서, 기록 양식은 학과 실습 지침서와 기관 프로토콜을 따릅니다. 서로 다르면 기관 지침이 우선이며, 차이는 지도자에게 묻습니다.
- **AI가 만든 절차는 초안입니다.** AI가 쓴 단계는 교재와 대조하고, 근거가 확인되지 않은 단계는 넣지 않습니다.
- **학생의 수행 범위를 지킵니다.** 실습 기관과 학과가 학생에게 허용한 술기만, 지도자의 감독 아래 수행합니다.

# 모든 술기에 공통인 단계

## 시작 전, 수행, 마무리

| 단계 | 공통 항목 | 근거 |
|---|---|---|
| 시작 전 | 처방·의뢰 확인 | 올바른 환자에게 올바른 처치 |
| | 손 위생 | 교차 감염 예방 |
| | 환자 확인(두 가지 이상 식별자) | 환자 오인 사고 예방 |
| | 자기소개와 설명, 동의 | 환자의 알 권리와 협조 |
| | 사생활 보호(커튼, 노출 최소화) | 존엄성 |
| | 물품 준비와 유효기간·포장 확인 | 중단 없이 안전하게 |
| 수행 | 적절한 자세와 조명 | 정확성과 근골격계 부담 감소 |
| | 무균 또는 청결 원칙 유지 | 감염 예방 |
| | 환자 반응 관찰 | 이상 반응 조기 발견 |
| 마무리 | 환자 편안한 자세, 호출벨 위치 | 안전과 낙상 예방 |
| | 물품 정리, 손상성 폐기물 분리 | 찔림 사고와 감염 예방 |
| | 손 위생 | 교차 감염 예방 |
| | 기록과 보고 | 연속성, 법적 근거 |

이 공통 단계는 모든 체크리스트의 처음과 끝에 들어갑니다. OSCE에서는 공통 단계의 누락이 감점 사유가 되는 경우가 많습니다.

# 체크리스트 만들기

## 좋은 체크리스트의 조건

- 한 줄에 행동 하나를 씁니다. "손 위생 후 장갑 착용"은 두 줄로 나눕니다.
- 행동은 관찰할 수 있게 씁니다. "주의한다"보다 "바늘 끝이 다른 물건에 닿지 않게 한다"
- 단계마다 근거 칸을 둡니다.
- 꼭 지켜야 하는 단계(안전 핵심 단계)를 따로 표시합니다.

## AI로 초안 만들기

```prompt 술기 체크리스트 초안
저는 [학과] [학년] 실습 준비생입니다. [술기명]의 학습용 체크리스트 초안을 만들어 주세요.
- 형식: 표(번호, 단계, 근거, 안전 핵심 단계 표시)
- 구성: 시작 전, 수행, 마무리
- 공통 단계(처방 확인, 손 위생, 환자 확인, 설명과 동의, 사생활 보호, 기록)를 빠짐없이 넣어 주세요.
- 교재마다 다를 수 있는 세부(물품 규격, 각도, 시간, 용량)는 [교재 확인]으로 비워 두세요.
- 마지막에 이 술기의 흔한 오류 5가지를 적어 주세요.
```

받은 초안은 다음 순서로 다듬습니다.

1. 학과 실습 지침서의 체크리스트와 한 줄씩 대조합니다.
2. [교재 확인] 칸을 채웁니다.
3. 지침서에 없는데 AI가 넣은 단계는 근거를 찾고, 근거가 없으면 지웁니다.
4. 실습 지도자에게 최종본을 확인받습니다.

# AI 가상 OSCE와 "왜" 문답

## 가상 OSCE 평가관

실기시험 전에 AI를 평가관으로 세우고 술기를 말로 수행해 봅니다. 손으로 하지 못해도 순서와 근거를 말로 하는 연습만으로 누락이 크게 줄어듭니다.

```prompt 가상 OSCE 평가관
당신은 [술기명] OSCE 평가관입니다. 아래는 우리 학과 체크리스트입니다.
[내가 확정한 체크리스트 붙여 넣기]

진행
- 상황을 짧게 제시하고 "시작하세요"라고 해 주세요.
- 제가 단계를 말로 수행하면 끼어들지 말고 기록만 하세요.
- 제가 "끝"이라고 하면 체크리스트 기준으로 수행한 단계, 빠진 단계, 순서가 바뀐 단계를 표로 알려 주세요.
- 안전 핵심 단계를 빠뜨렸다면 맨 위에 표시해 주세요.
- 마지막에 돌발 상황 하나를 제시하고 제 대응을 평가해 주세요.
```

## "왜" 문답

```prompt 술기 왜 문답
[술기명]의 체크리스트입니다. [붙여 넣기]
단계를 무작위로 하나씩 골라 "왜 이 단계가 필요한가요?", "이 단계를 빠뜨리면 어떤 일이 생길 수 있나요?"라고 물어 주세요.
제가 답하면 맞은 점과 부족한 점을 짚고, 근거를 교재 어디서 확인하면 좋을지 알려 주세요. 10단계를 물으면 마쳐 주세요.
```

# 대표 술기 체크리스트 골격

아래 골격은 공통 원칙을 보여 주는 학습용 예입니다. 세부 절차와 수치는 교재와 기관 지침으로 채웁니다.

## 간호: 말초정맥 주사와 채혈

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 시작 전 | 처방 확인, 환자 확인, 알레르기 확인, 손 위생 | 오류와 감염 예방 |
| 부위 선택 | 혈관 상태 확인, 피해야 할 부위 확인(마비된 팔, 동정맥루가 있는 팔, 림프절 절제한 쪽 팔 등) | 합병증 예방 |
| 소독 | 기관 지침의 소독제로 소독 후 마를 때까지 기다림 | 소독 효과 |
| 수행 | 지혈대, 정맥 고정, 삽입, 역류 확인, 고정 | 정확한 위치 |
| 마무리 | 바늘을 다시 씌우지 않고 손상성 폐기물 용기에 폐기 | 찔림 사고 예방 |
| 관찰 | 부종, 통증, 발적 등 침윤과 정맥염 징후 | 합병증 조기 발견 |

## 간호: 유치도뇨관 삽입

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 시작 전 | 처방 확인, 필요성 확인, 설명과 동의, 사생활 보호 | 불필요한 도뇨는 감염 위험 |
| 준비 | 멸균 물품 포장 확인, 멸균 영역 설정 | 요로감염 예방 |
| 수행 | 멸균 장갑, 회음부 소독, 삽입, 소변 확인 후 고정 | 무균술 |
| 유지 | 폐쇄 배액 유지, 소변백은 방광보다 낮게, 바닥에 닿지 않게 | 역류와 오염 예방 |
| 마무리 | 소변 양상 관찰과 기록, 필요 없어지면 빨리 제거하도록 확인 | 감염 위험 감소 |

## 간호: 기관 내 흡인

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 사정 | 흡인 필요성 확인(호흡음, 분비물, 산소포화도) | 불필요한 흡인은 손상과 저산소 유발 |
| 준비 | 기관 지침에 따른 흡인 압력과 카테터 준비 | 점막 손상 예방 |
| 산소 | 필요시 흡인 전후 산소 공급 | 저산소 예방 |
| 수행 | 무균적으로 삽입, 흡인은 짧게, 빼면서 흡인 | 저산소와 손상 예방 |
| 관찰 | 산소포화도, 심박수, 분비물 양상 | 합병증 조기 발견 |

## 응급: 기본소생술과 자동심장충격기

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 현장 안전 | 주변 위험 확인 | 구조자 안전 |
| 반응 확인과 도움 요청 | 반응 확인, 119 신고와 자동심장충격기 요청 | 빠른 제세동 |
| 호흡 확인 | 정상 호흡 여부를 짧게 확인 | 지체 없는 가슴압박 |
| 가슴압박 | 가슴 중앙, 성인 기준 깊이와 속도는 현행 지침 확인, 완전 이완, 중단 최소화 | 관상동맥·뇌 혈류 유지 |
| 자동심장충격기 | 도착 즉시 켜고 음성 안내에 따라 패드 부착, 분석 중 접촉 금지, 충격 후 즉시 가슴압박 재개 | 제세동 효과 |

심폐소생술의 세부 수치와 순서는 국내 심폐소생술 지침의 최신판으로 확인합니다.

## 물리치료: 침대에서 휠체어로 이동 보조

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 사정 | 환자의 근력, 균형, 인지, 체중 부하 제한 확인 | 안전한 방법 선택 |
| 환경 | 휠체어를 건측 가까이 비스듬히 두고 바퀴 고정, 발판 접기 | 이동 거리 단축, 미끄러짐 예방 |
| 설명 | 신호와 순서를 미리 약속 | 환자 협조 |
| 수행 | 보조자는 무릎을 굽히고 허리를 세운 자세, 환자 무게중심 가까이 | 보조자 허리 보호, 낙상 예방 |
| 마무리 | 자세 정렬, 발 위치, 안전벨트 확인 | 욕창과 낙상 예방 |

## 방사선: 흉부 후전방향 촬영

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 확인 | 의뢰 확인, 환자 확인, 임신 가능성 확인 | 정당화와 태아 보호 |
| 준비 | 금속·장신구 제거 안내 | 인공물 방지 |
| 자세 | 서서 가슴을 검출기에 붙이고 어깨를 앞으로 돌려 어깨뼈를 폐야 밖으로 | 영상 품질 |
| 조건 | 기관 기준의 거리와 조건, 조사야 제한 | 확대 왜곡과 피폭 감소 |
| 호흡 | 깊이 들이쉰 뒤 숨 참기 | 폐야 확장 |
| 마무리 | 영상 품질 확인, 재촬영 필요성 판단, 기록 | 불필요한 재피폭 방지 |

| 단계 | 핵심 행동 | 근거 |
|---|---|---|

| 재평가 | 다음 방문 때 지수 재측정 | 행동 변화 확인 |

| 단계 | 핵심 행동 | 근거 |

| 영양 주입 | 주입 전 위치와 잔류량 확인(기관 기준), 머리 쪽 올린 자세 유지 | 흡인 예방 |
| 마무리 | 관 세척, 고정 상태와 피부 확인, 주입량 기록 | 막힘과 피부 손상 예방 |

## 간호: 무균 드레싱과 상처 사정

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 사정 | 상처 위치, 크기, 깊이, 삼출물 양과 성상, 냄새, 주변 피부, 통증 | 치유 단계와 감염 판단 |
| 준비 | 진통이 필요하면 미리 보고, 무균 물품 준비 | 환자 편안함과 무균 유지 |
| 제거 | 오염된 드레싱은 장갑 끼고 제거해 바로 폐기 | 교차 오염 예방 |
| 세척 | 기관 지침의 세척액과 방향(깨끗한 곳에서 덜 깨끗한 곳으로) | 오염 확산 방지 |
| 적용 | 상처 상태에 맞는 드레싱(기관 지침) | 습윤 환경과 보호 |
| 기록 | 사정 결과와 변화, 감염 징후 보고 | 경과 추적 |

감염 징후로는 발적 범위 확대, 열감, 부종, 통증 증가, 고름, 악취, 발열 등이 있습니다. 새로 생기거나 심해지면 즉시 보고합니다.

## 공통: 활력징후 측정

| 항목 | 핵심 행동 | 근거 |
|---|---|---|
| 준비 | 활동 후라면 잠시 쉬게 함, 기구 점검 | 정확한 측정 |
| 혈압 | 팔 둘레에 맞는 커프, 심장 높이, 측정 중 말하지 않게 | 커프가 좁으면 높게, 넓으면 낮게 측정 |
| 맥박 | 불규칙하면 1분 동안 측정, 필요시 심첨맥박 | 맥박결손 확인 |
| 호흡 | 환자가 의식하지 않게 맥박 측정에 이어 관찰 | 의식하면 호흡이 바뀜 |
| 체온 | 측정 부위에 따른 차이 고려, 직전 음식·흡연 확인 | 측정 오차 감소 |
| 산소포화도 | 손가락 끝 상태(차가움, 매니큐어) 확인, 파형 안정 후 읽기 | 잘못된 값 예방 |
| 기록·보고 | 기준을 벗어나거나 이전보다 크게 변하면 보고 | 악화의 조기 발견 |

## 임상병리: 정맥 채혈과 검체 관리

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 확인 | 환자 확인, 검사 의뢰 확인, 금식 등 준비 상태 확인 | 잘못된 검체 예방 |
| 라벨 | 환자 앞에서 라벨 확인 | 검체 뒤바뀜 예방 |
| 채혈 | 지혈대는 오래 두지 않음, 기관 기준의 채혈관 순서 지키기 | 혈액 농축과 첨가제 오염 방지 |
| 혼합 | 첨가제가 있는 관은 정해진 횟수만큼 부드럽게 뒤집기 | 응고와 용혈 방지 |
| 운반·보관 | 검사별 온도와 시간 기준 지키기 | 결과 변화 방지 |
| 거부 기준 | 용혈, 응고, 양 부족, 라벨 오류 검체는 기준에 따라 재채혈 | 잘못된 결과 방지 |

채혈관 순서와 혼합 횟수, 보관 조건은 검사실 지침과 교재로 확인합니다. 용혈된 검체는 칼륨 같은 항목이 실제보다 높게 나올 수 있습니다.

## 치위생: 진료 전후 감염관리

| 단계 | 핵심 행동 | 근거 |
|---|---|---|
| 진료 전 | 수관 물 흘려보내기, 표면 소독 또는 차단막 | 수관 세균막과 표면 오염 감소 |
| 보호구 | 마스크, 보안경, 장갑, 가운 | 비말과 에어로졸 노출 차단 |
| 기구 | 멸균된 기구 포장 확인, 사용한 기구는 정해진 동선으로 이동 | 교차 감염 예방 |
| 날카로운 기구 | 뚜껑을 손으로 다시 씌우지 않기, 손상성 폐기물 용기 | 찔림 사고 예방 |
| 진료 후 | 표면 소독, 차단막 교체, 손 위생 | 다음 환자 보호 |
| 멸균 확인 | 기관 기준에 따른 멸균 지표 확인과 기록 | 멸균 실패 조기 발견 |

# 술기별 "왜" 질문 은행

시험 전에 단계보다 근거를 묻는 질문으로 점검합니다. 답은 내가 먼저 쓰고 교재로 확인합니다.

| 술기 | 왜 질문 |
|---|---|
| 손 위생 | 장갑을 끼는데도 왜 손 위생을 하는가? |
| 환자 확인 | 왜 이름만으로는 부족한가? |
| 정맥 주사 | 왜 소독제가 마를 때까지 기다리는가? |
| 유치도뇨 | 왜 소변백을 방광보다 낮게 두는가? |
| 흡인 | 왜 흡인 시간을 짧게 하는가? |
| 비위관 | 왜 공기 주입 소리만으로 위치를 판단하지 않는가? |
| 드레싱 | 왜 깨끗한 곳에서 덜 깨끗한 곳으로 닦는가? |
| 혈압 | 왜 팔 둘레에 맞는 커프를 써야 하는가? |
| 채혈 | 왜 채혈관 순서가 정해져 있는가? |
| 이동 보조 | 왜 휠체어를 건측에 두는가? |
| 방사선 촬영 | 왜 임신 가능성을 확인하는가? |
| 옷 입기 | 왜 마비측부터 입히는가? |

```prompt 왜 질문 은행 점검
아래는 제가 쓴 "왜" 질문의 답입니다.
[질문과 내 답]
답마다 맞는지, 근거가 부족한지 평가하고, 교재 어디서 확인하면 좋을지 알려 주세요. 정답을 길게 쓰지 말고 고칠 방향만 알려 주세요.
```

# 돌발 상황 대응

## 원칙

예상하지 못한 상황에서는 다음 순서로 판단합니다.

1. **멈추고 환자 안전을 확인합니다.** 의식, 호흡, 출혈, 통증.
2. **즉시 지도자에게 알립니다.** 학생 혼자 해결하려 하지 않습니다.
3. **오염되었으면 처음부터 다시 합니다.** 무균 물품이 오염되면 새 것으로 바꿉니다.
4. **기록하고 보고 절차를 따릅니다.** 찔림 사고 같은 직원 사고도 즉시 보고합니다.

## 흔한 돌발 상황

| 상황 | 우선 행동 |
|---|---|
| 무균 영역에 오염 | 수행 중단, 오염 물품 교체, 필요하면 처음부터 |
| 주삿바늘 찔림 | 즉시 상처를 씻고 지도자와 담당 부서에 보고, 기관 절차 따름 |
| 환자가 어지러움·실신 | 수행 중단, 눕히고 활력징후 확인, 보고 |
| 환자가 거부 | 강요하지 않고 이유를 듣고 지도자에게 보고 |
| 절차가 기억나지 않음 | 추측으로 진행하지 않고 지도자에게 확인 |

```prompt 돌발 상황 훈련
[술기명] 수행 중 생길 수 있는 돌발 상황 5개를 한 번에 하나씩 제시해 주세요.
제가 우선 행동을 말하면 환자 안전, 학생 권한, 보고 측면에서 평가하고, 놓친 점을 질문으로 알려 주세요.
```

# 실기시험 준비 2주 계획

| 시기 | 할 일 |
|---|---|
| 14~11일 전 | 시험 술기 목록 확인, 체크리스트 확정, "왜" 질문 은행 작성 |
| 10~7일 전 | 술기마다 말로 하는 가상 OSCE 1회, 실습실에서 실제 수행 1회 |
| 6~4일 전 | 친구와 짝을 지어 평가자 역할 바꾸며 수행, 누락 단계 기록 |
| 3~2일 전 | 누락이 많았던 술기만 반복, 돌발 상황 훈련 |
| 전날 | 공통 단계와 안전 핵심 단계만 소리 내어 점검, 충분한 수면 |

## 짝 평가 기록지

| 술기 | 수행자 | 빠진 단계 | 순서 오류 | 안전 핵심 단계 누락 | 잘한 점 |
|---|---|---|---|---|---|
| | | | | | |

평가자 역할을 해 보면 내가 수행할 때 놓치는 부분이 더 잘 보입니다. 평가자는 체크리스트를 보며 조용히 기록하고, 수행이 끝난 뒤에만 피드백합니다.

# 실습 기관 지침과 다를 때

학교에서 배운 체크리스트와 실습 기관의 절차가 다를 수 있습니다. 물품, 소독제, 기록 방식, 순서의 일부가 기관마다 다릅니다. 이럴 때는 다음 순서로 대응합니다.

1. 기관의 절차를 따릅니다. 기관에는 그 기관의 환경과 장비에 맞춘 이유가 있습니다.
2. 차이를 메모해 두고, 적절한 때에 지도자에게 이유를 여쭙니다.
3. 학교로 돌아와 담당 교수와 차이를 이야기해 내 체크리스트에 "기관별 차이" 칸을 더합니다.
4. 안전과 관련된 원칙(환자 확인, 손 위생, 무균술)이 지켜지지 않는 것으로 보이면 혼자 판단하지 말고 지도자나 학교 담당 교수에게 알립니다.
