# 자동화를 배우는 이유

## 반복 작업은 줄이고, 판단할 시간을 늘립니다

학생 생활에도 반복 작업이 많습니다. 동아리 회원 명단 정리, 봉사활동 시간 집계, 팀 과제 회의록, 실습 일지 양식 맞추기 같은 일은 매번 비슷한 순서로 반복됩니다. 졸업 후 병원이나 기관에서도 근무표, 물품 재고, 교육 이수 현황, 통계 보고처럼 같은 형식의 일이 매주 돌아옵니다.

노코드(No-Code) 도구는 프로그래밍 없이 이런 반복을 줄여 주는 도구입니다. 설문지 응답이 표로 자동 정리되고, 표의 숫자에 따라 색이 바뀌고, 정해진 질문에 같은 방식으로 답하는 AI 도우미를 만들 수 있습니다. 목표는 일을 기계에 맡기고 손을 놓는 것이 아니라, 반복에 쓰던 시간을 확인과 판단에 돌리는 것입니다.

## 자동화하기 좋은 일, 피해야 할 일

| 구분 | 예 |
|---|---|
| 자동화하기 좋은 일 | 규칙이 분명하고 자주 반복되는 일: 응답 집계, 양식 채우기, 일정 알림, 형식 맞추기 |
| 사람이 해야 하는 일 | 예외가 많거나 책임이 따르는 일: 환자 상태 판단, 성적·징계 결정, 민감한 상담 답변 |
| 자동화하면 안 되는 일 | 개인정보를 외부 서비스로 무단 전송하는 일, 기관 규정상 승인 없이 할 수 없는 일 |

# 나만의 AI 도우미 만들기

## 맞춤형 도우미란

ChatGPT의 GPTs, Gemini의 Gems, Claude의 프로젝트처럼 주요 AI 서비스에는 지시문과 참고 자료를 미리 넣어 두고 같은 방식으로 답하게 하는 기능이 있습니다. 매번 긴 프롬프트를 붙여 넣지 않아도 되므로 반복 질문에 특히 유용합니다. 기능 이름, 사용 가능한 요금제, 공유 방법은 서비스마다 다르고 자주 바뀌므로 쓰기 전에 각 서비스의 안내를 확인합니다.

## 설계의 기본: 지시문 네 부분

| 부분 | 내용 | 예(해부학 복습 도우미) |
|---|---|---|
| 역할과 대상 | 누구를 위해 어떤 역할을 하나 | 물리치료학과 1학년의 근골격 해부학 복습 조교 |
| 할 일 | 어떤 요청에 어떻게 답하나 | 근육 이름을 주면 이음, 닿음, 작용, 신경 지배를 표로 답함 |
| 하지 않을 일 | 금지와 한계 | 진단이나 치료 권고는 하지 않음, 모르면 교재 확인을 권함 |
| 형식 | 답의 모양 | 표 1개와 외우는 요령 1줄, 마지막에 확인 퀴즈 1문제 |

```prompt 맞춤형 도우미 지시문 초안 만들기
저는 [학과, 학년]입니다. [반복되는 일: 예, 매주 배운 근육을 복습하는 일]을 돕는 맞춤형 AI 도우미를 만들려고 합니다.
다음 네 부분으로 지시문 초안을 써 주세요.
1. 역할과 대상
2. 할 일(사용자가 보낼 요청의 예와 답하는 방식)
3. 하지 않을 일(정확하지 않을 때 추측하지 않기 포함)
4. 답의 형식
지시문은 500자 이내로, 존댓말로 써 주세요.
```

## 참고 자료를 넣을 때

수업 자료나 학과 공지처럼 도우미가 참고할 파일을 넣으면 답이 더 정확해집니다. 다만 다음은 넣지 않습니다.

- 교재 전체 스캔본(저작권 문제)
- 다른 학생의 과제, 성적, 연락처
- 실습 기관 내부 자료

도우미를 다른 사람과 공유할 때는 넣어 둔 자료를 상대도 볼 수 있는지 확인합니다. 공유 설정에 따라 참고 자료가 노출될 수 있습니다.

## 시험해 보고 고치기

도우미를 만든 뒤에는 일부러 어려운 질문, 범위 밖 질문, 틀린 전제가 들어간 질문을 던져 봅니다. 예: "가시위근은 어깨를 안쪽으로 돌리죠?" 이때 도우미가 틀린 전제를 바로잡는지 확인합니다. 그대로 맞장구친다면 지시문에 "질문에 틀린 내용이 있으면 먼저 바로잡으세요"를 넣습니다.

# 설문과 표로 정리 작업 줄이기

## 설문지 응답을 표로 받기

구글 폼이나 마이크로소프트 폼으로 받은 응답은 자동으로 표(구글 시트, 엑셀)에 쌓입니다. 동아리 참가 신청, 봉사활동 일정 조사, 팀원 가능 시간 조사에 쓰면 사람이 하나하나 옮겨 적을 필요가 없습니다.

!!! 설문을 만들 때 확인합니다
- 이름, 학번, 연락처처럼 꼭 필요한 개인정보만 받는다
- 수집 목적과 보관 기간을 설문 첫 화면에 밝힌다
- 선택지는 겹치지 않게 만든다(예: 1~2회, 3~4회, 5회 이상)
- 자유 응답보다 선택형을 우선해 집계를 쉽게 한다
- 응답 링크를 공유 범위에 맞게 설정한다(학교 계정만 등)

## 표를 보기 좋게: 조건부 서식과 데이터 유효성

| 기능 | 하는 일 | 쓰는 예 |
|---|---|---|
| 조건부 서식 | 조건에 맞는 칸의 색을 바꿈 | 봉사시간이 목표에 못 미친 사람을 빨간색으로 |
| 데이터 유효성 검사 | 정해진 값만 입력하게 함 | 학년 칸에 1~4만 입력, 날짜 칸에 날짜만 입력 |
| 드롭다운 목록 | 선택지 중에서 고르게 함 | 상태 칸에 "예정, 진행, 완료" |
| 필터와 정렬 | 원하는 행만 보거나 순서 바꾸기 | 미제출자만 보기 |
| 피벗 테이블 | 집단별로 세거나 합계 | 학년별 참가 인원 |

## AI에게 수식과 서식 규칙 묻기

```prompt 시트 자동화 묻기
구글 시트 구조입니다(실제 값은 넣지 않았습니다).
A열 이름, B열 학년, C열 봉사일자, D열 봉사시간(시간)
하고 싶은 일:
1. 사람별 봉사시간 합계를 다른 시트에 자동으로 만들기
2. 합계가 20시간 미만이면 빨간색 표시
3. 새 응답이 추가되어도 자동으로 반영
필요한 수식, 넣을 위치, 조건부 서식 설정 순서를 단계별로 알려 주세요.
```

받은 수식은 가짜 이름 몇 줄로 먼저 시험해 본 뒤 실제 시트에 적용합니다.

# 문서 작업 줄이기

## 회의록과 공지문

팀 회의 뒤 메모를 AI에 주고 정해진 형식으로 정리하게 하면 회의록 작성 시간이 줄어듭니다. 녹음을 문자로 바꾸는 기능을 쓸 때는 참석자 모두에게 녹음 사실을 알리고 동의를 받습니다.

```prompt 회의록 정리
아래는 오늘 팀 회의에서 제가 적은 메모입니다.
[메모 붙여 넣기]

다음 형식으로 회의록을 정리해 주세요.
- 일시, 참석자(이름 대신 역할로: 팀장, 자료조사 담당 등)
- 결정한 것
- 할 일(담당 역할, 마감일)
- 다음 회의에서 정할 것
메모에 없는 내용은 추가하지 마세요.
```

## 같은 형식의 문서 반복

실습 일지, 활동 보고서처럼 형식이 정해진 문서는 양식을 AI에 주고 내 메모를 그 칸에 맞게 옮기게 할 수 있습니다. 단, 실습 일지의 관찰 내용과 느낀 점은 내가 직접 쓴 내용이어야 합니다. AI는 맞춤법과 형식만 맞추게 합니다.

## 노션 같은 작업 공간 도구

노션처럼 문서, 표, 할 일 목록을 한곳에 모으는 도구는 팀 프로젝트와 개인 학습 기록에 쓰기 좋습니다. 많은 작업 공간 도구에 AI 기능이 들어 있어 페이지 요약, 할 일 뽑기, 표 채우기를 할 수 있습니다. 학교 계정이나 무료 요금제에서 쓸 수 있는 기능 범위는 도구마다 다르므로 확인합니다.

# 팀 프로젝트 관리

## 팀 프로젝트가 어긋나는 지점

| 문제 | 원인 | 도구로 줄이는 방법 |
|---|---|---|
| 누가 무엇을 하는지 모름 | 역할이 말로만 정해짐 | 할 일 보드에 담당자 표시 |
| 마감 직전 몰아치기 | 중간 마감이 없음 | 단계별 중간 마감과 알림 |
| 파일 버전 혼란 | 각자 파일을 따로 저장 | 공유 폴더와 공동 편집 문서 하나 |
| 결정 사항이 흐려짐 | 회의 기록이 없음 | 회의록 형식 고정 |

## 할 일 보드 만들기

할 일을 "할 일, 하는 중, 검토, 완료" 네 칸으로 나누고 카드마다 담당자와 마감일을 적는 방식(칸반 보드)이 가장 쉽습니다. 노션, 트렐로, 구글 시트 어느 것으로도 만들 수 있습니다.

```prompt 팀 프로젝트 일정 쪼개기
과제: [예, 지역사회 노인 대상 건강 교육 자료 제작과 10분 발표]
팀원: 4명(역할: 팀장, 자료조사 2명, 디자인·발표 1명)
기간: [시작일]부터 [발표일]까지

1. 과제를 15개 이내의 할 일로 쪼개 주세요.
2. 할 일마다 담당 역할, 예상 시간, 마감일, 앞서 끝나야 하는 일을 표로 정리해 주세요.
3. 발표 3일 전에 전체 리허설이 들어가도록 일정을 짜 주세요.
```

## 무임승차를 줄이는 장치

AI가 일정을 짜 준다고 팀워크가 생기지는 않습니다. 다음 장치를 함께 씁니다.

- 회의마다 각자 지난 회의 이후 한 일과 막힌 점을 1분씩 말합니다.
- 공동 문서의 편집 기록을 남깁니다(누가 어느 부분을 썼는지 확인 가능).
- 최종 제출 전에 각자 맡은 부분을 다른 팀원이 검토합니다.

# 보건의료 현장의 자동화 예

| 현장 | 반복 작업 | 노코드 도구로 줄이는 방법 | 사람이 할 일 |
|---|---|---|---|
| 병동 | 교육 이수 현황 집계 | 설문 응답을 시트로 받아 미이수자 표시 | 미이수 사유 확인 |
| 재활실 | 장비 점검 기록 | 점검표를 폼으로 만들어 날짜별 자동 정리 | 이상 장비 조치 |
| 보건소 | 건강 교실 참가 신청 | 신청 폼과 자동 확인 메일 | 대상자 선정 기준 판단 |
| 복지관 | 프로그램 만족도 조사 | 폼 결과를 피벗 테이블로 요약 | 결과 해석과 개선 결정 |
| 학과 | 실습 일정 공지 | 공유 캘린더와 알림 | 일정 조정 협의 |

기관에서 자동화를 만들 때는 기관이 허용한 도구와 계정만 쓰고, 환자 정보가 외부 서비스로 넘어가지 않게 설계합니다.

# 자동화의 안전 수칙

## 연결하기 전에 생각할 것

여러 서비스를 연결해 자동으로 데이터가 오가게 하는 도구(예: 설문 응답이 오면 메신저로 알림)는 편리하지만, 정보가 어디로 흘러가는지 보이지 않게 됩니다.

!!! 자동화를 켜기 전에 확인합니다
- 어떤 정보가 어느 서비스로 넘어가는지 적어 보았다
- 개인정보가 포함된다면 꼭 필요한 항목만 넘어간다
- 학교나 기관 규정상 외부 서비스 사용이 허용된다
- 자동화가 잘못 작동했을 때 누가 알아채는지 정했다
- 더 이상 쓰지 않는 자동화와 공유 링크는 끈다

## 결과에 대한 책임

자동으로 만들어진 집계표나 문서도 제출하거나 공지하는 사람이 책임집니다. 자동화를 처음 켠 뒤 몇 주 동안은 손으로 계산한 결과와 비교해 오류가 없는지 확인합니다.
