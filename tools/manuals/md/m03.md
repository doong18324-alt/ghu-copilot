# 왜 보건의료인이 데이터를 알아야 하나

## 숫자는 환자의 상태를 기록한 문장입니다

병동에서 간호사가 재는 혈압, 물리치료실에서 기록하는 관절가동범위, 임상병리실에서 나오는 혈액검사 결과, 영양사가 계산하는 하루 섭취 열량은 모두 데이터입니다. 이 숫자들은 따로 떨어져 있을 때보다 시간 순서로 이어 볼 때 더 많은 것을 말해 줍니다. 수축기 혈압 150 mmHg는 한 번만 보면 "조금 높다"에 그치지만, 사흘 동안 130, 140, 150으로 오르고 있다면 이야기가 달라집니다.

보건의료인에게 필요한 데이터 역량은 통계학자의 역량과 다릅니다. 복잡한 모형을 만들 필요는 없습니다. 대신 다음 네 가지는 졸업 전에 익혀 두어야 합니다.

| 역량 | 현장에서 하는 일 |
|---|---|
| 읽기 | 검사 결과지, 기록지, 추세 그래프를 보고 무엇이 정상 범위를 벗어났는지 찾기 |
| 기록하기 | 단위, 날짜, 측정 조건을 빠뜨리지 않고 정확하게 남기기 |
| 정리하기 | 흩어진 기록을 표로 모으고 평균, 변화량, 비율을 계산하기 |
| 보여 주기 | 동료와 환자가 한눈에 이해하도록 표나 그래프로 바꾸기 |

## 이 매뉴얼의 순서

1. 보건의료 데이터의 종류를 구분합니다.
2. 병원 정보 시스템이 데이터를 어디에 어떻게 쌓는지 봅니다.
3. 엑셀(또는 구글 시트)로 데이터를 정리하는 규칙을 익힙니다.
4. 평균, 중앙값, 표준편차, 비율처럼 꼭 필요한 기초 통계를 배웁니다.
5. 데이터에 맞는 그래프를 고릅니다.
6. AI에게 데이터 작업을 맡길 때의 안전 수칙과 검증 방법을 익힙니다.
7. 데이터 역량을 실습, 취업, 졸업 후 업무로 연결합니다.

# 보건의료 데이터의 종류

## 형태에 따른 구분

| 종류 | 뜻 | 예 |
|---|---|---|
| 정형 데이터 | 행과 열로 된 표에 바로 들어가는 숫자나 코드 | 혈압 128/82 mmHg, 공복혈당 104 mg/dL, 질병분류 코드 |
| 반정형 데이터 | 정해진 태그나 항목 구조는 있지만 표처럼 고정되지는 않은 자료 | 처방 전송 메시지, 검사 장비가 내보내는 결과 파일 |
| 비정형 데이터 | 형태가 정해지지 않은 글, 영상, 소리 | 간호 서술 기록, 의사 경과기록, X선 영상, 상담 녹음 |

정형 데이터는 계산하기 쉽지만 맥락이 빠지기 쉽고, 비정형 데이터는 맥락이 풍부하지만 그대로는 계산할 수 없습니다. 예를 들어 "환자가 밤새 잠을 못 자고 불안해함"이라는 간호 기록은 숫자로 바로 바뀌지 않습니다. 최근에는 생성형 AI가 이런 서술 기록에서 핵심 정보를 뽑아 정형 데이터로 바꾸는 일에 쓰이기 시작했지만, 뽑아낸 결과가 원문과 맞는지 사람이 확인해야 합니다.

## 측정 수준에 따른 구분

같은 숫자라도 어떤 성격의 숫자인지에 따라 계산할 수 있는 것이 달라집니다.

| 수준 | 성격 | 예 | 할 수 있는 계산 |
|---|---|---|---|
| 명목 | 이름표 역할만 함 | 성별, 혈액형, 진료과 | 빈도, 비율 |
| 서열 | 순서는 있지만 간격이 같지 않음 | 통증 정도(없음, 약간, 심함), 욕창 단계 | 빈도, 중앙값, 순위 |
| 등간·비율 | 간격이 같아 더하고 뺄 수 있음 | 체온, 체중, 혈압, 보행 속도 | 평균, 표준편차, 변화량 |

학생들이 흔히 하는 실수는 서열 자료에 평균을 내는 것입니다. 만족도를 1(매우 불만)부터 5(매우 만족)까지 물었을 때 평균 3.4라는 값은 관행적으로 많이 쓰이지만, "3.4만큼 만족한다"는 뜻은 아닙니다. 이런 자료는 응답 분포(각 점수를 고른 비율)를 함께 보여 주는 것이 정확합니다.

## 데이터에는 늘 조건이 붙습니다

같은 혈압이라도 앉아서 5분 쉰 뒤 잰 값과 계단을 오르자마자 잰 값은 의미가 다릅니다. 데이터를 기록할 때는 숫자와 함께 다음을 남깁니다.

- **단위:** mg/dL과 mmol/L처럼 단위가 다르면 숫자가 크게 달라집니다.
- **시각:** 식전인지 식후인지, 투약 전인지 후인지
- **측정 조건:** 자세, 측정 부위, 사용한 기구
- **측정자:** 누가 쟀는지(재측정과 책임 확인에 필요)

# 병원 정보 시스템과 표준

## 데이터는 어디에 쌓이나

병원에는 여러 정보 시스템이 서로 연결되어 있습니다. 이름은 병원마다 조금씩 다르지만 역할은 비슷합니다.

| 시스템 | 하는 일 | 주로 쓰는 사람 |
|---|---|---|
| 처방전달시스템(Order Communication System, OCS) | 의사의 처방을 약제부, 검사실, 병동으로 전달 | 의사, 간호사, 약사 |
| 전자의무기록(Electronic Medical Record, EMR) | 진료 기록, 간호 기록, 경과기록을 전자로 작성·보관 | 모든 진료 인력 |
| 검사정보시스템(Laboratory Information System, LIS) | 검체 접수, 검사 결과 관리 | 임상병리사 |
| 의료영상저장전송시스템(Picture Archiving and Communication System, PACS) | X선, CT, MRI 영상 저장과 판독 | 방사선사, 영상의학과 의사 |
| 원무·청구 시스템 | 접수, 수납, 진료비 청구 | 원무 직원, 보건의료정보관리사 |

## 서로 다른 시스템이 말을 맞추는 방법: 표준

병원 안팎의 시스템이 데이터를 주고받으려면 같은 "말"을 써야 합니다. 이 말이 표준입니다. 이름만 알아 두어도 실습과 취업 면접에서 큰 도움이 됩니다.

| 표준 | 무엇을 표준화하나 |
|---|---|
| 한국표준질병·사인분류(KCD) | 질병과 사망 원인 코드. 진단명 기록과 통계에 사용 |
| LOINC | 검사 항목의 이름과 코드 |
| SNOMED CT | 진단, 증상, 시술 같은 임상 용어 |
| HL7, FHIR | 시스템 사이에서 진료 정보를 주고받는 형식 |
| DICOM | 의료영상과 영상 정보를 저장하고 전송하는 형식 |

## 데이터 품질 문제는 현장에서 생깁니다

통계 분석에서 가장 시간이 많이 드는 일은 계산이 아니라 데이터를 바로잡는 일입니다. 자주 보는 문제는 다음과 같습니다.

| 문제 | 예 | 예방 |
|---|---|---|
| 빠진 값 | 체중 칸이 비어 있음 | 측정하지 못한 이유를 함께 기록 |
| 단위 섞임 | 같은 열에 kg과 lb가 섞임 | 열 이름에 단위를 적고 한 단위로 통일 |
| 오타와 자리 착오 | 체온 36.5를 365로 입력 | 입력 범위 제한, 이상값 점검 |
| 같은 뜻, 다른 표기 | "고혈압", "HTN", "혈압 높음" | 코드나 정해진 용어 사용 |
| 날짜 형식 혼란 | 2026.3.4와 3/4/2026 | 연-월-일 형식으로 통일 |

# 엑셀로 데이터 정리하기

## 표를 만드는 다섯 가지 규칙

엑셀이나 구글 시트는 지금도 병원 부서, 보건소, 복지관에서 가장 많이 쓰는 데이터 도구입니다. 계산 전에 표를 바르게 만드는 것이 가장 중요합니다.

1. **한 행에 한 사례(사람 또는 측정 1회), 한 열에 한 변수**를 넣습니다.
2. **첫 행은 변수 이름**만 둡니다. 이름에는 단위를 넣습니다. 예: 체중_kg
3. **셀 병합을 하지 않습니다.** 보기에는 좋아도 정렬과 계산이 망가집니다.
4. **한 셀에 한 값**만 넣습니다. "130/85"처럼 두 값을 한 셀에 넣지 말고 수축기와 이완기를 나눕니다.
5. **원자료 시트와 계산 시트를 나눕니다.** 원자료는 고치지 않고 보관합니다.

## 꼭 알아 둘 함수

| 함수 | 하는 일 | 예 |
|---|---|---|
| AVERAGE | 평균 | =AVERAGE(C2:C31) |
| MEDIAN | 중앙값 | =MEDIAN(C2:C31) |
| STDEV.S | 표본 표준편차 | =STDEV.S(C2:C31) |
| MIN, MAX | 최솟값, 최댓값 | =MAX(C2:C31) |
| COUNT, COUNTA | 숫자 개수, 비어 있지 않은 칸 개수 | =COUNTA(B2:B31) |
| COUNTIF | 조건에 맞는 칸 개수 | =COUNTIF(D2:D31,">=140") |
| IF | 조건에 따라 다른 값 | =IF(C2>=140,"높음","정상") |
| ROUND | 반올림 | =ROUND(E2,1) |

피벗 테이블은 "진료과별 평균 재원일수", "연령대별 낙상 건수"처럼 집단별로 묶어 세거나 평균을 낼 때 씁니다. 원자료 표를 선택하고 피벗 테이블을 삽입한 뒤, 행에 집단 변수를, 값에 계산할 변수를 끌어 놓으면 됩니다.

## AI에게 수식을 물어보기

엑셀 함수가 기억나지 않을 때 AI는 좋은 조수입니다. 다만 데이터 자체를 넣지 말고 표의 구조만 설명합니다.

```prompt 엑셀 수식 묻기
엑셀 표의 구조는 다음과 같습니다. 실제 값은 넣지 않았습니다.
A열: 대상자 번호, B열: 성별(남/여), C열: 나이, D열: 수축기혈압_mmHg, E열: 측정일(연-월-일)
데이터는 2행부터 51행까지 있습니다.

하고 싶은 일: 성별에 따라 수축기혈압이 140 이상인 사람의 수와 비율을 구하고 싶습니다.
필요한 수식과 넣을 셀 위치를 알려 주시고, 수식이 무엇을 계산하는지 한 줄씩 설명해 주세요.
```

AI가 준 수식은 작은 예제(5~6행)에 먼저 넣어 손으로 계산한 값과 같은지 확인한 뒤 전체 표에 적용합니다.

# 꼭 필요한 기초 통계

## 대표값: 평균과 중앙값

평균은 모든 값을 더해 개수로 나눈 값이고, 중앙값은 값을 크기 순으로 세웠을 때 가운데 값입니다. 재원일수처럼 대부분은 짧고 일부만 아주 긴 자료에서는 평균이 극단값에 끌려 올라갑니다.

| 환자 | A | B | C | D | E |
|---|---|---|---|---|---|
| 재원일수 | 3 | 4 | 4 | 5 | 34 |

이 자료의 평균은 10일이지만 중앙값은 4일입니다. "우리 병동 환자는 평균 10일 입원한다"는 말은 실제 대부분 환자의 경험과 다릅니다. 한쪽으로 치우친 자료는 중앙값을 함께 보고합니다.

## 퍼짐: 표준편차와 범위

두 병동의 평균 대기 시간이 모두 20분이어도, 한 병동은 모두 15~25분이고 다른 병동은 1분부터 60분까지 흩어져 있다면 환자 경험은 전혀 다릅니다. 표준편차는 값들이 평균에서 얼마나 떨어져 있는지를 나타냅니다. 보고할 때는 "평균 ± 표준편차" 형식으로 함께 씁니다. 치우친 자료는 중앙값과 사분위범위(하위 25% 지점부터 상위 25% 지점까지)를 씁니다.

## 개수, 비율, 율

| 지표 | 계산 | 주의할 점 |
|---|---|---|
| 건수 | 사건의 개수 | 대상자 수가 다르면 비교할 수 없음 |
| 비율(%) | 해당 사례 ÷ 전체 × 100 | 분모가 무엇인지 반드시 밝힘 |
| 율 | 일정 기간 동안 대상 집단에서 생긴 사건 수 | "재원 1,000일당 낙상 건수"처럼 기준 단위를 밝힘 |

"A 병동 낙상 6건, B 병동 3건"만으로는 A 병동이 더 위험하다고 말할 수 없습니다. A 병동의 병상과 재원일수가 B 병동의 세 배라면 율은 오히려 A 병동이 낮을 수 있습니다.

## 정상 범위와 변화량

검사 결과지의 참고 범위는 건강한 사람 대부분이 들어가는 범위이지, 그 안에 있으면 반드시 정상이라는 뜻은 아닙니다. 검사 기관과 방법에 따라 참고 범위가 다르므로 결과지에 적힌 범위를 기준으로 봅니다. 재활이나 운동 처방에서는 "치료 전보다 얼마나 변했는가"가 더 중요할 때가 많습니다. 변화량을 볼 때는 측정 오차보다 큰 변화인지 함께 따집니다.

# 표와 그래프로 보여 주기

## 목적에 맞는 그래프 고르기

| 보여 주려는 것 | 알맞은 형태 | 피할 것 |
|---|---|---|
| 시간에 따른 변화(활력징후 추세) | 선 그래프 | 막대를 시간 순으로 늘어놓기 |
| 집단 간 크기 비교(진료과별 환자 수) | 막대 그래프(0에서 시작) | 축을 중간에서 자른 막대 |
| 두 변수의 관계(나이와 보행 속도) | 산점도 | 3차원 효과 |
| 분포(재원일수 분포) | 히스토그램, 상자그림 | 평균 하나만 표시 |
| 단 하나의 핵심 수치 | 큰 숫자와 짧은 설명 | 원그래프 여러 개 |

원그래프는 항목이 두세 개일 때만 쓰고, 항목이 많으면 막대 그래프로 바꿉니다. 사람의 눈은 각도보다 길이를 더 정확하게 비교하기 때문입니다.

## 좋은 그래프의 조건

- 제목에 무엇을, 누구를, 언제 측정했는지 씁니다. 예: "2026년 3월 7병동 입원 환자 수축기혈압 추세(n=28)"
- 축 이름과 단위를 씁니다.
- 색은 의미가 있을 때만 씁니다. 같은 변수는 같은 색으로 통일합니다.
- 표본 수(n)를 밝힙니다.
- 출처를 그래프 아래에 적습니다.

## AI에게 그래프 초안 맡기기

```prompt 그래프 설계 요청
다음 요약표를 발표 슬라이드 한 장에 넣으려고 합니다. 실제 환자 정보는 없는 가상 수치입니다.
[요약표 붙여 넣기: 예, 주차별 평균 보행 속도 m/s, 1주 0.62, 2주 0.68, 3주 0.75, 4주 0.81]

1. 이 자료에 가장 알맞은 그래프 형태와 이유
2. 그래프 제목, 축 이름, 단위
3. 청중이 가장 먼저 봐야 할 메시지 한 문장
4. 이 그래프로 말할 수 없는 것(과장하면 안 되는 해석)
을 알려 주세요.
```

4번 질문이 중요합니다. 대조군이 없는 전후 비교 그래프로는 "치료 효과가 입증되었다"고 말할 수 없습니다. AI가 이 한계를 짚지 않으면 직접 덧붙입니다.

# AI와 데이터를 함께 쓸 때의 안전 수칙

## 넣어도 되는 것과 안 되는 것

| 구분 | 예 | 판단 |
|---|---|---|
| 표 구조와 변수 이름 | "A열 나이, B열 혈압" | 넣어도 됨 |
| 가상 자료, 공개 통계 | 국가통계포털 공개 표, 직접 만든 가상 수치 | 넣어도 됨 |
| 가명처리했지만 희귀 정보가 남은 자료 | 나이, 입원일, 희귀 진단이 함께 있는 표 | 넣지 않음(다시 알아볼 수 있음) |
| 실제 환자, 실습 기관 자료 | 실습 중 본 검사 결과, 기관 내부 통계 | 넣지 않음 |

실습 기관의 자료는 기관의 허가 없이 밖으로 가지고 나올 수 없습니다. 과제를 위해 데이터 연습이 필요하면 공개 데이터나 직접 만든 가상 데이터를 씁니다. AI에게 "이런 구조의 가상 데이터 30행을 만들어 달라"고 요청하는 것도 좋은 방법입니다.

## AI 계산 결과를 믿기 전에

생성형 AI는 문장을 만드는 데 강하지만 계산에서 실수할 수 있습니다. 파일을 올려 분석하는 기능은 실제로 코드를 실행해 계산하므로 더 정확한 편이지만, 어떤 열을 어떻게 썼는지는 확인해야 합니다.

!!! AI 분석 결과 점검
- 표본 수(n)가 내 자료의 행 수와 같은가
- 평균, 최솟값, 최댓값을 엑셀로 한 번 더 계산해 같은가
- 빠진 값을 어떻게 처리했는지 설명했는가
- 단위가 바뀌지 않았는가
- 그래프의 축이 0에서 시작하는가(막대 그래프)
- 해석이 자료가 말해 주는 범위를 넘지 않는가

# 데이터 역량을 진로로 연결하기

## 직종별로 만나는 데이터

| 직종 | 자주 다루는 데이터 | 필요한 기초 역량 |
|---|---|---|
| 간호사 | 활력징후, 섭취·배설량, 낙상·욕창 위험 점수 | 추세 읽기, 기록 정확성 |
| 물리치료사 | 관절가동범위, 근력, 균형·보행 검사 점수 | 전후 비교, 측정 신뢰도 |
| 임상병리사 | 검사 결과, 정도관리 자료 | 정밀도와 정확도, 관리도 해석 |
| 방사선사 | 영상, 선량 기록 | 장비 품질관리 자료 정리 |
| 보건의료정보관리사 | 질병분류 코드, 의무기록, 병원 통계 | 코딩, 병원 통계 산출 |
| 사회복지사 | 상담 기록, 서비스 이용 현황 | 사례 통계, 성과 보고서 |
| 영양사 | 식단 영양가, 섭취량, 급식 원가 | 영양 계산, 비용 분석 |

## 포트폴리오로 남기기

데이터 역량은 말보다 결과물로 보여 주는 것이 효과적입니다. 다음과 같은 작은 결과물도 면접에서 구체적인 이야기가 됩니다.

- 공개 통계(예: 국가통계포털의 연령별 만성질환 자료)로 만든 그래프 한 장과 해석 세 문장
- 동아리나 봉사활동에서 직접 모은 설문 결과 요약표
- 실습 중 배운 측정 도구의 신뢰도와 한계를 정리한 한 쪽 메모(기관 자료 없이)

# 맺음말과 실습

## 실습 1. 가상 데이터로 기초 통계 내기

```prompt 가상 데이터 만들기
보건계열 학생의 엑셀 연습용 가상 데이터를 만들어 주세요.
- 30행, 열: 대상자번호, 성별, 나이(65~85), 앉은 자세 수축기혈압_mmHg, 30초 의자 일어서기_회
- 실제 사람과 무관한 가상 값이라고 표 위에 밝혀 주세요.
- 일부러 빠진 값 2개, 입력 실수로 보이는 값 1개를 섞고, 정답은 표 아래에 따로 알려 주세요.
```

받은 표를 엑셀에 붙여 넣고 다음을 직접 합니다.

1. 빠진 값과 이상값을 찾아 처리 방법을 정합니다(AI가 표 아래 알려 준 정답과 비교).
2. 수축기혈압의 평균, 중앙값, 표준편차를 구합니다.
3. 140 mmHg 이상인 사람의 비율을 구합니다.
4. 나이와 의자 일어서기 횟수로 산점도를 그리고, 그래프로 말할 수 있는 것과 없는 것을 한 문장씩 씁니다.

## 실습 2. 그래프 고쳐 보기

과제나 기사에서 본 그래프 하나를 골라 위 "좋은 그래프의 조건"에 맞춰 무엇이 빠졌는지 적고 다시 그려 봅니다.

# 바이탈에서 이어서 하기

- **개인정보 가명처리기:** 공개 전 자료에서 이름, 연락처, 날짜 같은 정보를 가리는 연습을 합니다. 실제 환자 자료는 가명처리 뒤에도 AI에 넣지 않습니다.
- **프롬프트 라이브러리 0-2:** AI에 넣기 전 개인정보와 비공개 정보를 점검합니다.
- **프롬프트 라이브러리 1-1:** 통계 용어처럼 어려운 개념을 내 학년 수준으로 풀어 달라고 요청합니다.
- **어려운 개념 쉽게 풀기·미니 퀴즈:** 표준편차, 율 같은 개념을 퀴즈로 확인합니다.
